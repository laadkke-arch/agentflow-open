# AgentFlow Open

오픈소스와 웹서비스를 조사하고, 사용자의 프로젝트에서 무엇을 재사용할 수 있는지 검증하는 독립 실험 저장소입니다.

## 목표

링크 수보다 다음 질문에 답하는 품질을 우선합니다.

- 어떤 기능을 직접 만들지 않고 해결할 수 있는가?
- 대체 서비스, 개발 부품, 참고 구현 중 어떤 관계인가?
- 실제 지원 근거, 사용 조건, 아직 확인하지 못한 점은 무엇인가?

## 현재 상태

2026-11-15: 빈 저장소에 연구 기반을 초기화했습니다. 실행 가능한 웹앱, 클라우드 DB, Render 배포는 아직 없습니다. 코드나 도구를 실제로 실행하지 않은 경우 문서 조사와 구분합니다.

## 작업 범위

기존 AgentFlow Studio와 분리해 실험합니다. 기존 저장소, 운영 데이터, 인증정보는 가져오지 않습니다. 이 저장소의 공개 범위를 변경하거나 유료 자원을 생성하는 작업은 별도 승인 대상으로 둡니다.

## 자료 관리

외부 자료는 출처 URL, 확인일, 용도, 제약과 검증 수준을 함께 기록합니다. 커뮤니티 글과 README를 무단으로 통째로 복제하지 않습니다. 비밀키, 사용자 개인정보, 비공개 프로젝트 내용은 커밋하지 않습니다.

## 이후 문서

설계, 조사 목록, 평가 질문과 실행 가능한 데이터 검증 도구를 작은 변경 단위로 추가합니다. 향후 앱에서는 목록 데이터를 클라우드 DB에 저장하고, Git에는 코드와 작은 재현용 데이터만 보관합니다.

## 라이선스

이 프로젝트 자체의 공개 라이선스는 아직 결정하지 않았습니다. 조사 대상으로 링크한 외부 프로젝트의 라이선스는 각 원 출처를 따릅니다.
