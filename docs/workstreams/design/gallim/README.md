# 갈림 · 프로젝트의 구조에서 다시 쓸 것을 찾는 탐색기

**입력은 개발자가 만들고 있는 것의 전체 또는 선택한 부분, 그 부분이 이루려는 목적, 바꿔도 되는 것과 지켜야 하는 것이다.** 출력은 그 부분을 대체할 서비스, 끼워 쓸 부품, 다른 분야에서 빌릴 수 있는 작동 원리 중 근거가 있는 후보다. 각 결과에는 어느 부분의 어떤 결정에 쓸지, 어디서 더 읽을지, 어느 조건에서 권고가 깨지는지를 붙인다.

원래 프로젝트 기록과 외부 링크 자료집은 생기는 시점이 다르다. **외부 자료는 여러 프로젝트에 재사용하고, 적합성 판단은 요청의 특정 판에만 귀속한다.** 그래서 대형 문서 아카이브 없이 시작할 수 있고, 링크를 열어 확인한 뒤에도 단서와 확인 결과를 구별할 수 있다.

## 한 요청으로 읽기

1. 스캔 파일 수집 단계를 선택했다. 같은 파일을 다시 넣어도 문서가 하나만 생겨야 하고, 처음 넣은 폴더의 파일은 삭제하거나 이동하면 안 된다. OCR는 이번 범위에서 제외했다. 원문 구절과 대상 부품을 같은 요청 판에 저장한다.
2. 공유 자료집에서 제품·서비스·기능 이름과 설명을 찾는다. 동시에 “작업을 거쳐도 원래 위치의 대상을 보존한다”는 관계로 검색한다. 두 번째 검색에는 문서 관리나 PDF라는 분야명이 필요 없다. 얻은 후보마다 검색한 이유와 원 링크가 남는다.
3. 직접 소비하는 제품은 그 기능 덕분에 검색되지만 같은 기능 설명에 원본 위치를 비우는 동작도 있다. 해당 판·구성은 배제된다. 보존용 원본에서 이용용 사본을 만드는 기록보존 방식은 별도 원리로 남는다. 그 원리에서 새 수집 설계를 착안할 수 있으나, 재투입 때 중복 등록되지 않는지까지 확인한 것은 아니다.
4. 사용자는 해당 부분의 답과 원문 링크를 받는다. 다음 조사 모델은 결정에 영향을 줄 한 가지를 이어받는다. 예를 들어 같은 파일을 두 번 넣고 중간에 한 번 실패시켰을 때 최초 경로와 문서 수가 유지되는지 확인할 수 있다. 프로젝트 요청이나 외부 문서가 바뀌면 새 판에서 다시 판단하며, 옛 답은 당시 근거와 함께 조회한다.

위 요구는 공개 연구 AF-RES-012의 K02를 바탕으로 한 예시다. Paperless-ngx 문서는 지정된 소비 동작을 설명한다. 미국 국립문서기록관리청의 보존 마스터와 복제 마스터는 원본과 접근용 사본의 역할 분리에 대한 실제 비교 자료다. 두 시스템을 결합한 제품의 효능은 시험할 가설이다. ## 직접 확인

이 디렉터리에서 다음 두 명령을 실행한다. 첫 명령은 메모리 DB를 새로 만들고, 선택한 수집 단계에 대해 근거 링크와 적용 제안을 출력한다. 예제 안에서 자체 주석을 정정한 후 옛 답과 새 판단을 나란히 보여준다. 두 번째 명령은 입력·카탈로그·검색·판정·이력·트랜잭션을 검사한다.

```sh
python3 -B db/roundtrip.py
python3 -B -m unittest discover -s db -v
```

링크 저장량과 회수율을 다시 측정하는 명령과 필요한 연구 커밋은 [비교 실험](LINK_STUDY.md#재현)에 있다. 제품 적용 전 확인할 항목과 실행 기록은 [인계](HANDOFF.md)에 있다.
