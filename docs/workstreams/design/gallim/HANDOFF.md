## 다음 작업자가 이어받을 것

입력 제공자는 프로젝트 전체 또는 사용자가 고른 부분, 목적·제약의 원문, 해당 부분과 이웃의 접점을 건넨다. 탐색기는 독립된 자료집에서 기성품·부분 기능과 타 분야 원리를 찾고 특정 요청판에 연결한다. 등록 당시에는 URL 하나로 충분하다. 찾기 어려운 대상에는 짧은 용도와 작동 관계를 추가하고, ‘여기서 쓸 수 있다’는 판단이 필요할 때 해당 판의 문서 절을 붙인다. 같은 링크를 다른 프로젝트에서 다시 써도 전 프로젝트의 채택 판단은 승계하지 않는다. 상세 조사는 답을 받은 사용자나 다른 모델이 이어갈 수 있다. ## 검증이 더 필요한 결정

- 자료집에 없는 타 분야 원리를 **새로 발견**하는 능력. 왕복 표본은 고정 자료, 제한된 관계 어휘, 미리 판독한 공개 문서 두 개로 작동한다. 다른 링크도 입력·탐색할 수 있고, 상세 판독이 없는 항목에는 원 주소와 보류 사유를 돌려준다. 공개 웹에서 새 문서를 가져와 의미를 판독하는 경로와 실제 입력 제공자 연동은 후속 구현이다.
- 링크에 어떤 설명까지 **미리 작성할 가치가 있는가**. 실험에서 한국어 부분 질문의 알려진 관련 후보 상위 10개 회수율은 주소만 0.000, 한 줄 추가 0.102, 용도까지 추가 0.215였다. 사람의 편집 시간과 요청 때 원문을 여는 시간은 측정하지 않았다. 주소·한 줄·관계를 선택적으로 보존할 수 있도록 DB를 구성했다.
- 실제 사람이 **새 설계 선택**을 얻는가. 같은 프로젝트·열람 예산에서 직접 검색, 링크 중심 답, 적용 근거를 붙인 답을 비교하고, 기존 대안과 달라진 결정·원문 열람·재작업까지 측정한다. 과거 연구에서 채택을 재구성하지 못한 사례와 앞으로 사용할 비교 조건은 [연구 대응표](RESEARCH-MAP.md), [사례집](CASEBOOK.md), [제품 평가 설계](EVALUATION.md)에 있다.
