# AF-RES-106 — 정답 개봉 전 목적 축의 읽기 계약

원 Stage1 `purpose_visual`과 `purpose_api` 문구는 수정하지 않는다. `predictions.csv`의 원 `prediction_U`도 유지한다. 표본·경로 신호를 본 뒤 새 본문을 열기 전에 Matplotlib 담당자가 `purpose-axes-before-new-body.json`을 추가했다. 이는 단순 표기 변경만이 아니라 **구체적 예시 목적과 일반적인 시각 역할을 구분하는 추가 해석**이다. 따라서 일반 역할의 성공만으로 원래 구체 목적까지 보존됐다고 보고하지 않는다.

각 실제 쌍의 판독과 혼동표에 다음 축을 모두 남긴다.

| 축 | 물을 질문 | 계승과 실패를 구분할 예 |
|---|---|---|
| `U_original_purpose` | 옛 원장에 적힌 구체적인 시각 결과·설명 대상·제약을 새 절이 이어가는가? | 원장이 특정 그룹/의미를 약속했다면 그 대상이 사라진 경우 일반 도형만 같다고 YES로 바꾸지 않음 |
| `U_visual_role` | 사전 추가 선언한 일반 시각 역할/구조를 새 절이 이어가는가? | 그룹별 계열을 나란한 막대와 숫자 라벨로 비교하는 설명. 데이터 소재 변경은 별도 축 |
| `method_inherited` | 옛 구체 API/코드 방법을 새 예제가 이어가는가? | `Axes.bar` offset과 `Axes.bar_label`, `Axes.twinx`·spine 이동 등 실제 호출 확인 |
| `literal_data_identity` | 원 예시의 범주 이름·값·데이터 의미가 그대로 남았는가? | `Men/Women`, `G1~G5`, Scores 등의 보존. 그림 바이트 동일성과는 다름 |

`barchart`의 원 목적은 “G1~G5의 Men/Women 점수를 나란한 막대와 수치 라벨로 비교”이고, 추가 일반 역할은 “범주별 여러 계열의 그룹 막대와 수치 라벨”이다. 원 목적이 약속한 대상을 이어가지 않지만 일반 역할은 이어갈 수도 있다. 그때 **같은 경로 예측이 구체 목적 기준에서는 FP, 일반 역할 기준에서는 TP가 되는 조건부 차이**를 그대로 표에 쓴다. 이 문장은 사후 결과 예고가 아니라, 두 정의가 다를 때 사용할 판정 규칙이다. 현재 새판 barchart 본문은 열지 않았다.

다른 사례에서도 단순 색·안티앨리어싱·해상도 변경을 원 목적의 실패로 세지 않는다. 구체 목적에 필수인 대상·작동 의미와 부수적 표현의 차이를 원문과 설명한다. 목표가 모호해 YES/NO를 결정할 수 없으면 `미확인`이다. NO에는 SCOPE에 정한 후보/절/소스·공식 변경 대조 범위를 적용한다. 원 코드가 새 예제의 다른 블록에 남으면 그 정확한 블록 위치를 판정 근거로 둔다.

두 U 축의 실제 양성·음성 분모와 TP/FP/FN/TN을 따로 산출하고, 해당 축의 음성 분모가0이면 FPR는 산출 불가다. 원래 구체 목적을 생략한 채 일반 역할 혼동표 하나를 원 예측의 유일한 검증처럼 제시하지 않는다. 전역 오류율, 두 층 또는 보조 사례를 합친 성능 비율은 만들지 않는다.

추가축의 선언 UTC는 `evidence/matplotlib/purpose-axes-before-new-body.json`에 있고, source-set 규칙 교정은 `METHOD_AMENDMENT.md`에 있다. 둘 다 경로/선택 노출 후·결과 본문 전이라는 한계를 최종 RESULT/SELF_CHECK에 공개한다. 이 파일도 묶음②의 원격 봉인에 포함한다.
