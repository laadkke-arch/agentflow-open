반환 live URL8개는 실제 DOM id·코드·이미지 참조와 decoded RGBA를 고정판과 대조했다. A1-old/G2-new는 PNG metadata가 없어 byte SHA가 달랐지만 RGBA는 같았다. live 주소는 불변 인용이 아니므로 고정 SHA 절·source·payload와 GitHub HTML행을 함께 제공한다. 브라우저 실제 표시와 meta refresh의 fragment 보존은 미실시다.

`counts.json`, `lineage.csv`, `returns.csv`, `audit.json`, `request-costs.json`, `source-work-map.json`이 각 표의 기계 판독 원장이다. HTTP 시도와 고유URL, 오래된 캐시 재열람, Git diff 명령, 자동 source522 스캔과 보수 고유저작16개를 합치지 않는다.
