## 해석과 적용 범위

옛 reference 195페이지를 전수 기계 판독하여 잔여 독립 논리예제 68개를 얻었다. 기존40, 과거 교정2, 그와 같은 논리예제3, 잔여 안의 논리중복4 및 비적격78을 제외했다. 인라인 전용0, 접근실패0이다. 첫 실행 결과와 그 전 코드가 단위이며 페이지 제목의 API를 첫 예제에 억지로 귀속하지 않았다. 예컨대 scale_shape의 첫 결과는 geom_point(shape=cut), stat_unique의 첫 결과는 geom_point(alpha=0.1)이다. `stage1-frame.csv`, `old-logical-alias-audit.json`에서 전수 분모와 제외 계보를 확인할 수 있다.

완전한 새 tree에서 옛 대표 외부 자원68개가 모두 남았다. 경로 부재 A=0, 자원은 남되 확인된 문서 저자 source-set 경로가 사라진 M=57, 나머지 G=11이다. source 경로의 .r→.R 대소문자를 보존하였다. 이는 실제 경로 변화이지만 의미 삭제를 뜻하지 않는다. 최초 man-only 해석과 그 뒤 정답을 보지 않고 공개한 source-set 보완은 `sensitivity-man-only/`와 부모 METHOD_AMENDMENT.md에 남아 있다. 결과를 보고 그 기록이나 예측을 고치지 않았다.

주4쌍은 모두 옛 자원경로를 새 첫 예제에서 실제로 참조하고 원래 구체 목적·일반 시각 역할·구체 API를 잇는다. 양성4, 음성0, TP4, FP/FN/TN0, 결원2이다. 실제 음성 분모가0이므로 거짓양성률은 **산출 불가**다. 관측된 FN율0/4는 이 양성4에만 해당하며 외부 자원 부재 방향은 결원이다. source 변화7개를 본 주/대조/보조의 본문은 모두 목적을 잇지만 이 7을 주 혼동표에 합치지 않는다.

주·대조·보조9개 모두 PNG 바이트가 달라졌다. 정확한 DOM 참조, 코드, 목적과 그림을 함께 확인한 결과 모두 목적을 이었다. 바이트 변화는 목적 변화의 충분조건이 아니다. 반대로 경로가 남아도 새절이 사용하지 않는 엄밀한 잔류미사용, 같은 경로를 다른 목적으로 교체하는 유형, 옛 경로가 없지만 다른 이름/내장 후계가 있는 유형은 별개로 세었다. 직접 판독한 주4·보조2·별도대조3에서 첫 두 유형은 각각0이고, 마지막 유형은 전수68에서 부재 후보 자체가0이다. 9개의 U 판독으로 나머지59개의 목적 보존을 주장하지 않는다.

이동/삭제 source 이력의 옛 예제 연결 사건은2건이다. 시간·SHA순 사전 봉인한 Upkeep와 ggproto 개편을 열고 register_theme_elements와 guide_axis를 대표로 추적했다. 전체57페이지에 연결되지만 전57 새본문을 읽었다는 뜻은 아니다. guide_axis는 두 사건에 겹치는 하나의 예제다. 삭제된 R/guides-axis.R의 새 후계 R/guide-axis.R는 공식 삭제/추가 patch와 공개 guide_axis(n.dodge=2) 코드, 실제 결과를 함께 확인했다. source 삭제를 목적 삭제로 바꾸어 말하면 틀리는 사례이나, 이미지 경로 존재 예측의 FN은 아니다.

공식 추가 기록4daadf…는 주 position_jitterdodge의 내부 중복수 계산을 바꾼 실제 사건이며 사전 이동/삭제 보조분모 밖의 해설 근거다. helper range/utilities 삭제2건은 읽었지만 사례 연결을 확정하지 못해 자료하한에 산입하지 않았다. 공식 Upkeep API 응답은300파일까지 반환하므로 완전변경목록으로 취급하지 않았고, 완전 Git 이력의 경로와 선택 source의 git patch를 함께 보존했다.

독자 반환은4개 모두 두 판 병기다. 현재 독자에게 새판의 고정 GitHub 코드 위치와 실제 PNG를 주고, 과거 판을 인용하는 저자에게 옛판 고정 위치·PNG를 함께 남긴다. `#ref-examples`는 원 HTML에서 실재한다. 원시 HTML 응답은 text/plain이므로 그 fragment를 렌더링된 웹사이트 도착으로 주장하지 않으며 GitHub `#L` 원문 위치를 별도로 제공한다. 브라우저에서 스크롤·동적 레이아웃을 직접 실행한 결과는 미확인이다.

G는 실제 실행별 manifest와 출력 지문 연결을 얻지 못했으므로 모두 미확인이다. PNG가 Git tree에 존재하고 현재 보인다는 사실에서 당시 실행 성공을 추정하지 않았다. 같은 diamonds/economics/mpg 패키지 데이터 blob과 동일한 공개 입력 코드를 확인했지만 당시 R 버전·의존성·runtime dataset 바이트까지 동일하다고 주장하지 않는다. 과거 빈 CI 조회는 반복하지 않았다.

## 근거·비용·독립성

`lineage.csv`는 주12판 자리, `supplemental-lineage.csv`는 보조4판, `control-lineage.csv`는 별도 대조6판이다. `returns.csv`와 `access-costs.json`에서 각 추가 GET의 URL·UTC·성공·영수증을 따라갈 수 있다. 동일 body/PNG/Rd/R와 양판은 `source-lineage-map.json`의 한 논리예제 계보로 묶었다. 주본문4 + 보조본문2 + 별도계보 payload3 + 관련 공식 사건3 = **신규 고유 자료12**다. 자동195페이지 스캔과 직접9논리예제 판독은 별도다. stat_unique의 stage1 임시 본문 산입을 최종 payload 범주로 이동했으며 한 번만 센다.

작성자의 원문·그림 직접 판독과 교차검토자의 범위는 구분한다. 이 파일은 작성자 자체 판독이며 부모 evidence의 별도 검토 영수증이 실제 독립 판독 범위를 정한다. 작성자 결과 전달시점과 검토자 최초 열람시점을 혼동하지 않는다.
