## 모집

- GitHub REST 목록의 `state=all&sort=created&direction=asc`에서 각 저장소의 UTC 2023-01-01 포함, 2026-01-01 미포함인 공개 이슈를 생성 시각·번호순으로 정렬한다. `pull_request` 필드가 있는 항목을 제외한다. 각 opening body의 API UTF-8 문자열에서 코드 블록을 검사한다. 40번째를 포함하고 첫 배제 41번째까지 기록한다. 기준선까지 조사한 전체 후보·제외 목록과 페이지 경계를 남긴다.
- Vega-Lite는 JSON 펜스 또는 JSON으로 판독되는 예제에서 스키마·레이어·마크·인코딩·조합 등 도표 사양의 구조 키가 있는 블록을 고른다. JSON 주석·미완성 구문은 해당 구조가 명시되면 부분 사양으로 표시한다. 컴파일된 Vega, API 호출 코드와 단순 데이터 배열은 별도다. Mermaid는 명시적으로 Mermaid로 표시된 비어 있지 않은 문법 또는 도표 시작문·구체 노드/간선/설정이 있는 블록을 고른다. 그림과 외부 링크만 있는 요청은 모집 자격을 주지 않는다.
- 각 프로젝트 처음 40 자리에서 원 작성자의 글이 **실제 바꾸거나 구분하고자 지시한 발생·설정·관계**와 **보존하거나 비교할 별도의 주변 객체·조건**을 언급한 첫 세 건을 고른다. 재현 절차만 있고 둘 중 하나를 지시하지 않으면 제외한다. 외부 데이터, 부분 사양, 판 미상, 렌더 실패는 자리를 보존한다. 작성자가 답을 이미 아는지, 패치가 있는지, 어느 보기가 이기는지는 자격에 사용하지 않는다.
- 각 API body와 원문 코드 범위의 UTF-8 바이트 지문을 기록한다. 편집 이력을 확인할 수 있을 때만 최초 게시본 일치 여부를 판정한다. REST의 `updated_at`과 최초 편집 시점은 별도다. 작성자 펜스, 화면 그림, 외부 편집기 복제, 보완 사양과 작업자 변형의 계보를 구분한다. 이 모집은 글 내부에 데이터가 노출된 사례에만 적용한다.

## 비교와 렌더

- A는 예제 사양을 빼고 남긴 원 요청·목적 구간이다. B와 C는 같은 요청 및 같은 시작 후보 전부를 받는다. 원글에 있는 문자열·필드·좌표가 지목한 레코드를 먼저 고르고, 작업자가 해석한 후보는 별도 원장에 근거와 함께 남긴다. 한 후보만 정답처럼 전달하지 않는다. Vega-Lite의 구조 주소와 Mermaid의 ID·발생 줄을 구별한다.
- B는 직렬화 순서 거리, C는 해당 형식의 직접 선언→사용 및 역관계 1단계로 레코드를 고른다. 같은 시작·동점은 원 위치 순서로 정렬한다. 이웃은 실제 필드가 지지할 때만 만든다. 직접성 및 잘린 레코드를 원장에 기록한다.
- B/C에 공통 4레코드와 사양 1,200 Unicode 문자 상한을 적용한다. 직렬화 내용과 줄바꿈을 포함해 센다. 잘린 레코드는 근거 판독에서 제외한다. 차이가 있으면 두 보기 중 짧은 쪽의 문자수로 양쪽을 재생한다. 기능 후보 절·설명·주소 및 공통 입력과 총 상한은 각 사건에 동일하다. 금액·시간 비용과 실제 확인 질문 효과는 이 비교에서 측정하지 않는다.
- 전체 원글·사양과 확인 가능한 공식 판에서 허용 대상 집합, 보존 집합, 반환 후보 및 오판 조건을 먼저 봉인한다. 판이 미상이면 스키마 계열과 보조판의 근거를 적는다. 공식 근거와 실제 렌더 관측을 별도 기록한다. 후속 작성자 패치는 봉인 다음의 외부 대조에만 쓴다. 동일 작업자의 전체 사양 선열람은 해당 사건의 판단 누출로 표시한다. 보기 판독에는 고정 규칙에 주어지는 입력을 기록하며 오염 셀은 주효과에서 제외한다.
- **정확**은 허용 링크·대상·영향과 보존 조건을 알고 맞춘 경우, **오확정**은 근거 없는 유일 대상이나 전체 보존을 확정한 경우, **정당 보류**는 주어진 입력에서 구별할 수 없는 후보와 필요 값을 특정한 경우, **오류**는 충분한 근거와 충돌한 경우다. 판·대상 또는 비교 조건 미확인은 **비교불가**다. 실제 원문에서 답이 노출되면 이미 아는 근거로 표시한다.
- 원본과 발생 하나·공유 정의 변경안을 먼저 저장하고 각 런타임에서 원본·두 변경안을 각각 두 번 렌더한다. 실제 소스 값과 SVG/scenegraph의 원값 및 해시를 보존한다. ID, 배치, 값, 가시성, 연쇄 이동을 구별한다. 같은 고정 환경에서만 반복을 비교한다. 정확 원판이 확인되지 않은 대체판, 보완 사양, 구성 반례는 별도 분모로 집계하고 원판 성공을 대신하지 않는다.
