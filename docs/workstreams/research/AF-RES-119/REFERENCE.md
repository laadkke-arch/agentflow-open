# 전체 원문 기준 봉인

`truth.csv`는 전체 사양과 공식 코드/문서의 기준 판독이다. 본문 일치·URL·정확/대체 실행판은 [cases.jsonl](cases.jsonl)에 있다. `fixtures/operations.json`은 렌더 전 저장 위치·원값·새 값·영향 예상·보존 집합을 고정한다. 기준 판독은 예측이고 출력 관측은 별도다. 동일 작업자가 전체 원문·사양을 열었으므로 그 작업자의 수동 18셀은 본 효과에 포함하지 않는다.

[공식 후보 절 메뉴](links.json)에는 A/B/C에 같은 설명과 주소를 넣었다. 업스트림 조작 지원 여부가 확인된 범위만 링크한다. 입력을 사용한 정적 판독과 렌더에서 개별 사용처를 유지하는 효과는 서로 다른 증거다. 기준의 예상과 실제가 어긋나도 예상값을 바꿔 적지 않는다.
