검토 대상은 작업 중 파일이 아니라 `git show 74dc9f887bc47bc0a92b9a75ea327ffa30aca70b:<path>`로 읽은 봉인판이다. root가 보고한 원격 봉인 시각은 2026-11-23T03:32:00Z이다. 검토자는 같은 모델의 donor 분담 조사자이며 제품의 봉인 후 결과 파일은 읽지 않았다. 실제 실행 시각, 입력 해시, 기계 재계수는 [sealed-ledger-audit.json](sealed-ledger-audit.json)에 있다. 본 검토는 main 파일이나 예측을 수정하지 않는다.

## 확인된 일치

- sources98행의 source_id98개는 모두 고유하다. 필수 정규화 필드의 누락, card→source 참조 누락, prediction→card 참조 누락, contrary_source_ids 참조 누락은 각각0개다.
- cards18행과 predictions18행 모두6자리×3보기다. 실제 display_window를 공백으로 나눠 센 단어 수가18/18행에서 기재값과 일치한다.
- E/D 추가 창의 단어 수는6/6쌍에서 같고 도판 수는 모든 창에서0이다. 코드 행 수는 E와 D가 같지 않으며, 원장의 pair_budget_note가 이 차이를 이미 고지한다.
- choice, opA/opB의 undo/redo, preserved_other_edits, normal_prediction, boundary_prediction을 **설명·근거 필드와 분리하여** 비교하면 E와 D가6/6자리에서 정확히 같다. 상이 예측은 관측0/6자리다. 따라서 상이 예측에 조건을 건 D 신규 정답률의 분모는0이며 해당 없음이다. 이는 정답률0% 또는6자리 모두 정답을 뜻하지 않는다.
- 앞선 검토에서 지적한 Yjs 변형 예측의 D 연결은 봉인 CSV에서 해결됐다. PT1의 의미적 답 노출도 세 보기 모두 exposure_status와 new_hit_eligible에 반영됐다. 같은 예측을 읽었다는 사실과 새로운 적중 자격은 따로 유지된다.

이 매핑의 배당 합계는 서로 겹치지 않는17저작이다. 시험 입력만 읽은 Y-T-DIAG를 보수적으로 제외하면16저작이다. **전체 고유65개가 시험·수정6계보 목표의 결손을 메우지는 않는다.** 이미 읽은 수십 개의 모집 이슈를 근거 없이 시험·수정 자료군으로 재분류해서도 안 된다. 이 지적은 ② 봉인 시점에 한하며, 이후 실제 읽은 assertion·서로 다른 수정 커밋·실행 기록을 합친 최종 배당은 새 시각과 출처로 다시 계산해야 한다.

## 수정이 필요한 메타데이터와 감도

1. **YN1-A의 code_lines=0:** 표시 창은 한 줄의 constructor 선언이다. 코드 행 수는1로 기록하는 것이 맞다. 단어 수13과 E/D 예산에는 영향이 없다. 봉인판은 그대로 두고 오류 정정 기록에 기존값0→정정값1을 남기면 된다.
2. **입력 전용 시험의 적격성 기준:** Y-T-DIAG는 `inputonly/assertion masked`이면서 external_minimum_eligible=true, P-T150-INPUT은 같은 종류의 차폐 상태에서 false다. 둘을 같은 기준으로 다루거나 strict sensitivity를 함께 제시해야 한다. 전자를 제외한 전체 수는64로 여전히20 이상이지만 시험군의 실측 상태에는 영향을 준다. 봉인 후 기대값을 읽었다면 그 새 취득 행과 실제 시각으로 보완하며 사전 행의 노출을 덮어쓰지 않는다.
3. **계보 수와 사건 검증 수:** P-E130-GROUP과 P-E150-GROUP은 동일 multilevel 시험의 판 차이로 이미 한 work_id에 묶였다. Y-I240/241과 Y-I317/343/355도 각각 한 계보로 보수 병합했다. 이 중복 제거는 적절하다. 그러나 여러 테스트 선언명을 work_id로 나눈 것만으로 '서로 다른 변경' 조건이 성립하는지는 별도 계보 확인이 필요하다.

검토 결과는 root에게 즉시 전달했다. 최종 문서의 결과 주장·관측 분모 검토는 제품 결과 원장이 준비된 뒤 별도 수행해야 한다.
