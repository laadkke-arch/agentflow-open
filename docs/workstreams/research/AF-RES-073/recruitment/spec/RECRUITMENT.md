최초 확인 Git 판은 [846579d4의 spec-0009/index.md](https://github.com/scientific-python/specs/blob/846579d4b8d5ca90ba6a9792c263574c73b9f48d/spec-0009/index.md)다. 최초 본문은 여전히 draft이며, 여러 모델 중 하나를 고르는 문제를 열어 두었다. 원문의 선택 요인은 프로젝트 단계, 구성원, 규모, 자원, 변화 가능성이다.

두 조건은 L138-140의 향후 조정 가능성과 L173-175의 문서·회의록·결정 공개다. 정확한 원문 인용은 selection.json에 24단어만 보존했다. 동일 원저작에서 추가 긴 인용은 하지 않는다.

행위 주체는 관리·결정 역할, 대상은 거버넌스 규칙과 결정·회의 기록, 관찰자는 프로젝트 공동체다. 공동체의 피드백을 받는다는 내용은 있으나 모든 구성원이 모든 결정을 승인한다거나 특정 표결 정족수가 있다는 내용은 없다. 공개 자체가 규칙의 집행을 입증하지도 않는다. 성장한 공동체에서 역할 변경과 의사결정 기록 공개가 필요한 상황은 원문이 지지하지만, 구체 인원수·기한·표결값은 연구자가 새로 만들어야 하는 시험 입력이다.
