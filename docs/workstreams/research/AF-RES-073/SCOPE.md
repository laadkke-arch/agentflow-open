## 모집 규칙 — 결과 탐색 전에 고정

대상 순서는 matplotlib/matplotlib MEP, jupyter/enhancement-proposals JEP, scientific-python/specs SPEC다. 공개 기본 브랜치의 고정 HEAD에서 도달 가능한 파일 이력 중 2018-01-01T00:00:00Z부터 2024-12-31T23:59:59Z까지 최초 추가된 제안을 최초 Git author 시각 내림차순, 동률은 최초 경로 오름차순으로 나열한다. committer 시각과 파일 본문 날짜도 별도 열에 남긴다. --follow와 파일 status로 이름 변경·이관을 추적한다. 최초 Git blob과 그보다 앞선 작성판은 다르며, 앞선 초안의 존재가 명시되고 원문을 확보하지 못하면 별도 관측층이다.

저장소별 첫8개 원순번을 보존한다. 공통 템플릿·목록·작성안내는 제외하되 모집 영수증에 남긴다. 첫 blob에 부분·목적, 인용 가능한 두 조건, 남아 있는 선택이 모두 있는 첫 제안을 고른다. 조직·거버넌스 제안은 사용자 기준에서 명시적으로 제외하지 않았으므로 코드 변경이 없다는 이유만으로 건너뛰지 않는다. 이런 표본이 뽑히면 소프트웨어 기능 탐색으로 일반화할 수 없다는 범위 제한을 둔다. 현재 채택 여부나 알려진 해법으로 선정하지 않는다.

한 목록이 비면 **남은 저장소의 원래 순서(JEP → SPEC)** 로 각 목록의 다음 적격 제안을 사용한다. 최대3건, 최소2프로젝트를 유지한다. 후보가 부족하면 기간이나 적격 기준을 넓히지 않고 PARTIAL로 기록한다. 모집 원자료와 결과 탐색을 분리한다.

## 원실험 규칙 — 질의 작성 전 고정

각 제안에서 A는 원 프로젝트 명칭/용어, B는 고유명사·대상 종류를 뺀 동작과 관계, C는 B에 원문이 지지하는 대상 종류·행위 주체·결과 관찰자만 복원한다. 목적과 C1/C2는 세 보기에 같다. 알려진 공여 분야·해법 이름은 질의에 넣지 않는다. 실제 18질의·삭제/복원 단어·경계 입력은 queries.jsonl에 넣어 별도 커밋한 후에만 실행한다. 질의는 사후 고치지 않는다.

검색 도구는 search_service의 **system1_search_query**, 영어 질의, domain/recency 제한 없음, response_length=long로 고정한다. 원 검색 결과는 현재 관측이며 당시 검색 순위가 아니다. 질의당 반환된 첫5개 웹 결과를 원순서 그대로 남긴다. 도구가 덜 반환하면 해당 자리는 missing_result로 둔다. 동률은 도구 순서, 같은 URL도 순위 행에는 모두 남긴다. 첫5 밖 자동 노출은 별도 exposure이며 검색 성적에 넣지 않는다.

제안 순번 P1/P2/P3의 시작 순서는 각각 A→B→C, B→C→A, C→A→B다. 보기별 질의2회와 원문 작업6회가 상한이다. 두 질의를 모두 받은 뒤 **Q1-R1, Q2-R1, Q1-R2, Q2-R2, ...** 순으로 원문을 연다. 같은 보기에서 이미 열린 URL은 다시 열지 않고 이전 영수증을 연결한다. 같은 제품의 서로 다른 URL은 읽기 전 동등하다고 간주하지 않으며, 사후 계보를 맞춘다. 다른 보기에 재등장하면 그 보기 비용으로 다시 연다. 현재 선택한 제안 자체·직접 후속 결정 링크가 반환되면 already_known 또는 outcome_exposure로 보존하되 원문은 사후 단계로 유보하고 다음 순위를 연다. 결과 제목/미리보기만으로 적격을 선언하지 않는다.

열기·재시도·찾기·추가 절·PDF 화면 각각1회다. 자동 HTTP redirect는 한 open의 실제 도착 URL로 남긴다. 접근 실패는1회를 지출하고 **원실험에서는 재시도하지 않으며 다음 순위를 연다**. 본문이 잘린 경우 다음 절을 여는 선택 대신 우선 남은 순위 원문을 읽어 불충분으로 표시한다. PDF가 텍스트 추출되지 않으면 다음1회를 첫 내용 페이지 screenshot에 쓰고, 그 역시 실패하면 종료한다. 최대6회가 끝나면 미열람을 실패로 바꾸지 않는다. 원실험 내부의 임의 추가 검색·클릭은 없다. 원문이 모두 소진되면 조기 종료한다.

누적 비용은 보기별 검색2회 후 원문1..6회(총3..8)다. 공통 비교는 각 제안에서 세 보기 실제 총비용의 최솟값까지 같은 prefix를 비교한다. 첫 적격은 양 조건이 같은 구성에 맞고 구체 선택·기각 입력이 원문으로 지지되는 '조건부 설계 적격'과, 대상에서 실제 실행된 '적용 확인'을 구분한다. 후자는 목표 시스템 실행이 없으면 미확인이다. URL 적중, 독립 대상, 작동원리의 수를 섞지 않는다.

## 사전 노출·작업자

사용자 브리프의 기록관리·공연진행 예시는 사전 노출이다. 069의 타입 손실·비용 수치와 인계 결론도 사전 노출이다. 모집을 같은 모델의 별도 에이전트3개에 분담하지만 인간 피험자나 무힌트 실험은 아니다. root는 원문·세 보기를 모두 보는 작성자다. 독립 모델 문맥 검토가 있으면 수행 범위와 실제 읽은 파일을 적고 독립 인간 판독과 구분한다. 후행 원자료는 원실험 봉인 뒤 별도 커밋으로만 추가하며 원 검색 분자에는 넣지 않는다.
