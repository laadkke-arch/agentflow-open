# 입력 판정과 노출 경계

- P1=JEP122(원1), P2=SPEC9(원1), P3=JEP97(원3, MEP 공석 보충). 조직·거버넌스2건을 임의로 제외하지 않는다.
- JEP118(원2)은 새 메시지 대안이 이미 기각되고 남은 것은 정확한 문구라고 최초판에 명시되어 있다. 이번 '열린 선택'은 Q4의 서로 다른 관측을 낼 행동·구성 선택이어야 한다고 해석하여 제외한다. 일반적인 문구 선택까지 적격으로 보면 표본은 바뀌므로 민감도와 한계에 남긴다.
- P1 C1은 저장소 선정의 호환성/전략 기준이다. 편입만으로 기술적 호환성이 성립하는 조건으로 잘못 강하게 만들지 않는다.
- P2는 특정 프로젝트의 미해결 구현 요구가 아니라 권고 초안이다. C1/C2를 고정 연구 제약으로 받아 비교하지만 실제 운영 요구·채택 관측으로 부르지 않는다.
- 세 건은 최초 공개 Git blob이 확인되며, Git 이전 작성판은 확인되지 않았다. 창설 초안 엄격층을 임의로 채우지 않는다.
- author UTC 주정렬과 committer UTC 대체정렬에서 각 목록의 첫8개·선정결과가 같다는 모집 담당 확인을 받아 남긴다. SPEC7의 다른 생존 브랜치 이전판은 이름 변경/이관 감사 사례이며 검색 표본으로 선택하지 않았다.
- P3 최초판 내부의 required 목록 불일치를 지우지 않는다. 조건 문장과 제시된 완성 스키마의 실행 동작은 다를 수 있다.
- root는 원문 세 개와 JEP118 탈락 원문을 GitHub 연결로 직접 읽었다. 모집 담당이 이미 하위 후보 원문 일부를 읽은 노출은 각 EXPOSURES/selection에 있다. 원실험 검색0회, 후속 토론·원시험·출시 원문0회 상태에서 이 파일과 질의를 커밋한다.
- 원문 인용은 짧은 조각으로 제한하고 원절 주소로 연결한다. 쿼리의 fixed meaning, observers 등은 관계 표현의 연구자 번역이며 원문 요구를 늘리는 조건이 아니다.
