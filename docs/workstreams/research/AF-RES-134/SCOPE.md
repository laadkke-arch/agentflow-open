원저자가 한국어 설명에서 자기 tensor 조작 또는 데이터 적재·배치의 달성 목표를 묻는 첫 글을 적격으로 본다. 학습 정확도·설치·저장소 요청·일반 모델 사용만 있고 그 목표를 찾을 수 없는 경우는 제외한다. 개별 목표의 범위를 명확히 한 질문은 목록에 바로 맞는 카드가 없어도 유지한다. 번역·봇·PR·홍보·답글·과거 제외·동일 질문 재게시를 이유와 함께 기록한다. 같은 저자의 별개 질문은 채택 가능하되 저자 수는 중복 제거한다. 층 우선순위는 A→B→G1→G2다. 미접근 선행층의 중복은 미확인으로 남긴다.

응답의 origin HTTP 상태, 프록시 연결 코드, DNS 실패, HTML 오류, 명시 삭제, 원문상 불적격을 구분한다. 접근 실패를 원문 삭제 또는 적격 0건으로 간주할 수 없다. 순서상 앞선 결측이 있으면 후행 원문의 관측 순서와 실제 첫 적격을 구분한다. 검색 스니펫·답글·외부 검색엔진 순서는 모집 대체물이 아니다. 뷰·검색 슬롯·직접 연 #1·채택 요청을 각각 기록한다.

## 원문, 표시, 기준, 점수

- 제목과 답변은 점수 입력에서 제외한다. 작성시각과 공개 편집 정보를 메타데이터로 보존한다. 첫 본문의 NFC 코드포인트 `[start,end)`에서 목표, 시도, 거절, 제3자 인용, 입력/객체, 출력/보존을 표시한다. 작성자의 일반 서술, 저자 코드의 심벌/변수, 인용의 역할을 구분한다. 원문 전체는 임시로 확인하고, 저장소에는 필요한 최소 구절·해시와 고정 재생 투영을 둔다.
- 표시 판독은 전체 요청×16에 대해 점수/순위/기준 없이 먼저 커밋한다. 희망 조작에 연결되는 요청 구절과 호환되는 출력의 카드 원절이 모두 있어야 통과한다. 명시 보존과 모순되거나 출력이 원문에서 확인되지 않으면 보류한다. 상충 가능한 해석의 표시 조건을 기록한다.
- 기준은 다른 커밋에서 전체 쌍을 판정한다. 직접은 요청한 역할·필수 입력/출력/보존을 충족하는 카드, 일부는 더 큰 목표에서 명시한 하위 조작, 충돌은 명시한 반대 출력 또는 보존 위반을 일으키는 카드, 미확인은 요청과의 구체적인 적합성 근거가 부족한 경우다. 동일 판독자의 두 번 판독이다. 별도 세션 여부, 애매한 대안, 보류 비용은 따로 기록한다.
- 순위는 두 판독 이후에만 계산한다. B는 전체 어절, C는 어절 맨 뒤 조사 한 개(은·는·이·가·을·를·에·에서·로·으로·와·과) 허용이다. AF-RES-126의 NFC·한글 구간·공백 경계와 AF-RES-122의 자연 심벌/URL·경로·타 수신자 제외를 재사용한다. 자연 심벌 입력을 사용하되 일치 심벌 유무를 하위층으로 표시한다. 정확 심벌 12점, 고유 활성 별칭 구절당 4점, 영어 고유 어절 교집합 수를 합한다. 동점은 카드 ID순이다.
- B/C는 양수 조사 8, 표시 3이다. Gate는 C의 같은 조사 8 안에서 통과 후보를 순서대로 최대 3개 표시한다. 0점과 실제 공석을 기록한다. 상세 앞/뒤 정책 차분은 동일 요청·카드·단계에서 세고, 추가 원절 수는 편집자가 C 조사 상위에서 세 번째 통과나 후보 소진까지 실제 정책상 확인할 요청 구절 및 카드 출력 위치의 수로 정의한다. 같은 카드 원절 위치와 같은 요청 구절은 한 요청 안에서 한 번만 센다. 이는 실제 사용자 클릭·읽기 시간·이해를 측정하지 않는다.

## 분모와 완료 조건

층별 예정 창, 공개 응답/확인 ID, 원저자 열람, 제외·중복·미확인, 적격·채택·저자, 비교 가능한 요청×16을 구별한다. 소문자 기계 값은 RESULT의 표에 한국어로 풀어 쓴다. 비어 있는 모집 슬롯과 표시 정책 공석은 구별하며 분모 0인 비율은 산출 불가다. 요청 선택과 별개로 모집 경계, 한 글의 여러 해석, 심벌 없는 층, 같은 저자의 반복, 채널 선택 편향을 점검한다.

적격 외부 고유 저작 최소 24편과 유형별 하한(자연 질문 8 저자·PyTorch 구현/시험 6·한국어 문법/용례 4·철도 3·서지/전거 3)을 각각 검사한다. 이전 API 재열람과 신규를 구분한다. 철도와 도서관은 이름만 비교한 판정 및 식별자/역할을 확인한 판정의 차이와 미해결을 남긴다. 두 분야의 사례는 기능 순위 표본과 별개다. 고정 입력 재생·코드포인트/부호화 시험·서로 다른 프로세스의 결과 일치와 원격 계약 검사를 기록한다.
