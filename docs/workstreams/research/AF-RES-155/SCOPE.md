## 입력 봉인과 판정

1. 네 사건에 각각 A/B/C 3개, 총 12면. A는 UTF-8 원출처 내 선택과 목적·판이다. B는 실제로 연결된 생산자/소비자 한 원문 범위다. 중복·정답 노출을 표시한다. C는 같은 원출처의 무관한 형제 구간에서 B와 같은 유니코드 코드포인트 수를 택한다. 신뢰할 실제 형제 범위가 없거나 B가 없으면 C를 결측으로 둔다. 같은 원문 내 목적 또는 명령에 소비 조건이 이미 있으면 A의 조건으로 유지한다. 있는 정보를 가려 A에서 인위적으로 모호하게 만들지 않는다.
2. 전체 입력·출처 본문·선택·추가 범위의 바이트 SHA-256, 반열림 코드포인트·바이트 오프셋, CR/LF 및 발췌/절단 경계를 보존한다. 내용 그대로의 파일과 접수된 본문은 구별한다. 예상 두 경로 또는 보류를 예측 CSV에 커밋하기 전 변환을 실행하거나 이 작업의 실행 출력을 열지 않는다. 사전 노출은 별도 기록한다. 개봉 뒤 필요한 변경은 원판을 보존하는 후속 커밋으로 남긴다.
3. 같음은 먼저 선택의 바이트 일치, 다음 A의 목적·판·기존 조건 일치다. 그 상태로 검증된 두 상태에서 목표 계층의 값이나 정당한 처리 경로가 갈리고 B의 한 필드가 해당 상태를 지목해야 구별된다고 판정한다. 작성자가 실제 두 상태를 제시하지 않은 사례는 자연 짝 해당 분모에서 결측이다. C가 그 성질을 말해주면 C가 오염된 것이다. C 때문에 그럴듯한 답을 적은 사례와 실제 기술적 분기를 구별한다.
4. 표현(바이트/해시), AST(태그·속성·본문), 다음 소비의 HTML 또는 배치, 작성자 요구 값(셀의 값·순서, 코드 문자 등)은 서로 다른 점수다. 성공 종료, 바이트 차이, AST 차이는 각각 목표 보존의 충분조건이 아니다. 음성 대조에 동일 출력, 관련 있지만 목표와 무관한 차이, A에 중복한 B를 포함한다. 취향과 기술값 결측을 구별한다.
5. 독립 판독 모집이나 AF-RES-148 0/18 보충은 범위 밖이다. 두 새 체크아웃에서 같은 고정 입력·바이너리로 반복하는 것은 한 연구자의 기술 재현 시험이다. 두 반복과 실패도 남긴다. 원저자 경로(환경 전부 알려짐), 작성자 입력에 적용한 구성 소비, 공개 시험, 연구자 입력을 다른 분모로 센다.
