# 동결한 자료집

[entries.jsonl](entries.jsonl)의 대상은 011의 공식 후보 표면 329개와 012의 고정 방해 자료 156개다. 원래 링크의 제품 페이지가 이동하거나 링크가 없는 실제 답은 [후보 대응표](supplemental-links.tsv)에 근거 후보를 기록했다. 공식 원문을 읽을 수 없는 신규 항목은 자료집 밖에 두었다. 실패·리다이렉트 실패·비후보 표면은 [원장](../sources.json)의 `excluded`에 있다. 같은 자료의 원 링크 실패와 공식 대체 성공이 공존할 수 있다.

웹 읽기와 GitHub·공식 레지스트리 직접 GET으로 본문, README 개요 또는 버전 요약을 읽었다. 원장의 각 주소와 절은 실제 읽은 범위를 보여 준다. 응답의 개인정보 원장이나 웹·질문 본문 전문은 저장하지 않았다. 법인 표제, 레지스트리 제품명, 원래 소프트웨어 링크가 필요할 때 URL의 저장소 식별자를 사용했다. `read_native.py`는 GitHub·npm·PyPI 표제를 읽고 짧은 발췌만 내보낸다. 재현 실행은 라이브 자료 대신 고정 JSONL을 사용한다.

- `curated_purpose_mechanism`은 원문을 대조해 목적과 작동 방식을 다시 쓴 자료다. `curated_mechanism_title_fallback`은 D-a에 표제를 썼으나 D-b의 목적과 기전을 확인했다.
- `opening_excerpt`은 원문 개요의 짧은 설명을 사용한다. 개요가 목적만 밝히면 작동 방식은 추가로 추정하지 않았다.
- `title_fallback`은 개요나 기전을 확실히 추출할 수 없어 표제를 사용했다. 012의 세 설명과 지위는 동결 값을 재사용했다.
- 제외 한계는 근거와 적용 범위가 확인된 경우 생성했다. 빈 `exclusions`는 지원을 확인했다는 뜻이 아니다. 기존 라벨이 답에만 있고 설명 대상을 연결할 근거가 없는 자료의 역할은 빈 값이다.
- [실제 답 판정](../qrels/answers.tsv)은 011의 고정 답 ID와 대표 후보를 연결한다. [자료집 밖 판정](../qrels/unmapped.json)은 URL 또는 복합 해법의 대응을 확보하지 못한 관측이다.
