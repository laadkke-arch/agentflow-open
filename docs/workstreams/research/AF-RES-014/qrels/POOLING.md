# 상위 10개 풀링과 내부 별도 검토

- [풀의 후보쌍](../results/pool_candidates.tsv)은 21개 실행 전체의 질의별 상위 10개 합집합에서 실제 답 판정 299행과 중복되는 쌍을 뺐다. 61개에서 1,945쌍이 남았다. 방법과 순위를 제거하고 질의 요약·must, 자료 설명·URL·역할만 보며 판정했다.
- 작업자 판정 [pooled.tsv](pooled.tsv)은 1 35쌍, N 5쌍, 0 1,864쌍, U 41쌍이다. 0은 표시된 역할에서 요구를 처리할 구체 경로를 찾지 못한 경우다. 문자 정보가 부족하지만 같은 역할일 가능성이 있으면 U다. 판단은 설치·실행 시험을 대신하지 않는다.
- 내부 별도 판정 [independent.tsv](independent.tsv)은 seed 14014로 먼저 뽑은 10개 질의의 동일 풀 290쌍을 새 문맥에서 검토했다. 질문·후보의 주어진 자료만 읽고 방법, 순위, 실제 답 등급, 작업자 판정 없이 수행했다. 1 11쌍, N 1쌍, 0 277쌍, U 1쌍이다. 이는 내부 별도 검토다. 원시 TSV SHA-256은 `c692e847c33826eec030a2e82c74b0f64a1c194df6963a8e5c00d08b60b6700b`다.
- 각 파일을 실제 답 기반 판정에 별도로 합쳤다. 실제 답 등급은 그대로였다. U는 알려진 관련이나 명시 0 분모에 넣지 않았다. 방법 순위 비교는 동일 10개와 D-b 용어 사전 조건에서 시작한다. 모든 실행과 다른 범위의 지표는 CSV에 있다.
- 작업자와 내부 별도의 근거 범위는 다르다. 작업자는 J01–J16의 공식 자료를 필요한 후보에 추가 확인했다. 예를 들어 T015의 GIF 레이어 내보내기와 프레임별 명령은 작업자 판정에서 직접 확인했다. 이 차이까지 포함해 판정 출처 민감도로 해석한다.
- 상위 검색의 편향과 실제 답의 표집 편향이 모두 남는다. 일치하지 않은 이름·링크가 있는 실제 답을 다시 찾기도 한다. T025의 Logo.dev API와 T028의 open-wa 소켓 클라이언트가 그 예다. 풀로 들어오지 않은 관련 자료의 수·인기 분포는 측정하지 않았다.
