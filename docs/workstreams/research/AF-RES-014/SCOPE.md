# AF-RES-014 사전 분석 계획

## 입력과 비교

- 통합 기준 `cbcc585f01c1c53acc8de8739dd41766cdd0629c`. AF-RES-011 `478c301b693896e2c6d777f46ac441f071bfdfe8`의 CASES, near-misses, accepted-answer-mapping, 코드북·표집을 사용한다. AF-RES-012 `cb602858378db90adb1f085953016267f9afbd6d`의 156개 자료와 검색·지표 구현을 재사용한다. 합성 질의·판정을 재실행하지 않는다.
- 원 모집단은 고정 61개다. 첫 게시판을 찾을 수 있는 경우에만 원문으로 센다. 최신판을 최초판으로 증명할 수 없거나 API 접근·본문 확보가 실패하면 AF-RES-011의 고정 한국어 요약으로 대체한다. 원문은 코드·서명·프로필을 제거하고 메모리에서만 처리한다. 저장하는 질의별 정보는 출처·시점·라벨·조건·해시·단어 수·접근 영수증이다. 재실행은 저장된 출처 모드와 해시를 확인한다.
- 011의 실질 추천 대상과 012의 고정 방해 자료를 합친다. URL 정규화는 스킴과 추적 파라미터, 말단 슬래시 차이를 흡수하고 기능 문서와 구성·버전·앵커 차이는 유지한다. 대조할 공식 페이지·공식 레지스트리가 확인되면 편집을 수행한다. 실패·다른 제품·커뮤니티 글을 원문의 근거 개수에 더하지 않는다. 원래 링크가 실패해도 동일 제품의 다른 실제 공식 원문을 확인하면 원 링크 실패와 대체 근거를 모두 기록한다. 012의 원문 근거가 없던 행은 기존 방해 자료 계보와 이번 실측 수를 따로 공개한다.
- D-a는 공식 한 줄(최대 25단어 또는 짧은 원문 설명)이며 없으면 제목 대체를 표시한다. D-b는 목적+작동 방식의 출처 기반 요약이다. D-c는 같은 D-b에 확인된 한계 문장만 붙인다. 근거를 못 찾은 한계는 D-c에서 생성하지 않는다. D-b와 D-c에 스레드의 채택·순위·질의 문장을 섞지 않는다. 011/012의 역할 분류를 복사하고 연결이 없으면 미코딩으로 둔다.
- 공급자 원문이 현재 버전만 제공할 수 있으므로 게시일에 적용되었다는 주장은 별도로 확인한다. 수집 전에 확인 가능한 제품·기능을 추정으로 늘리지 않는다. 각 자료마다 원문·시점·선택 절·확인 내용과 한계가 있는지를 센다. 실행 원문과 방법 문헌은 각각 사이트당 최대 3개를 최소 개수에 인정한다. GitHub·레지스트리 같은 공유 호스트도 이 수에서 한 사이트로 센다.

## 실행 및 지표

| ID | 설명 | 처리 |
| --- | --- | --- |
| a | D-a | 공식 한 줄의 설명 기준점 |
| b | D-b | 그대로 검색 |
| c | D-c | 한계 인라인 |
| filter | D-b | 후보 전체를 검색한 뒤 [대조 규칙](qrels/EXCLUSIONS.md)이 충돌로 판정한 항목 제거 |
| penalty | D-b | 동일 충돌을 기반으로 강등 |

- BM25·LSA는 AF-RES-012 토크나이저와 파라미터를 기본으로 하고 RRF는 k=60을 유지한다. 모든 조건은 같은 질의와 자료를 사용한다. 011 요약이 대개 한국어이고 011 공식 설명이 대개 영어이므로 질문·정답·결과에 맞춰 고치지 않는 한영 기술 용어 사전을 검색 전 동결한다. 사전은 양쪽에 동일한 개념 토큰을 덧붙이며, 사전 미적용 기본 어휘/LSA를 민감도에 남긴다. 사전 사용 여부로 추론되는 차이는 학습 임베딩의 성능으로 해석하지 않는다.
- Q4는 고정 E5 리비전 `0a1c1d9ee03224db176563ffcfbc3bbc38f35266`의 Hugging Face 가중치와 config, 공개 모델 배포처와 런타임 배포처의 표준 경로만 확인한다. 가중치 접근 실패 시 실측 코드를 기록하고 BM25·LSA·그 RRF로 계속한다. 접근 허용 시 E5 단독 및 BM25+E5 RRF를 같은 텍스트로 비교한다.
- 지표는 recall@10(1·2의 회수율), nDCG@10(0/1/3 이득), MRR(첫 1·2의 전체 순위, 없으면 0), 상위 10개 중 N 개수의 질의별 평균(012와 같은 단위), N/실제 노출 슬롯, 필터가 제거한 1·2 및 그중 D-b 상위 10개 수다. 새 결과는 질의 수, 양성 질의의 분모, 자료집 밖의 관측 양성, 동점·무신호를 같이 공개한다. 회수율과 nDCG는 코퍼스 안에 해당 판정 양성이 존재하는 질의만 매크로 평균하고 풀링 후 분모 변경을 함께 보고한다.
- 원문/요약 및 whole/part, 부분 중 I5 present/그 외로 분리한다. 전체·부분은 짝지은 발췌 실험이 아니므로 같은 질문의 문맥 제거 효과로 해석하지 않는다. 실제 질문자 채택/사용은 랭킹을 관측한 결과가 아니다. 보고 수치와 별도로 같은 조건의 질의별 변화와 다섯 종류의 반례를 전수 탐색한다.
- 결과 확인 전 [판정 규칙](qrels/RULES.md)을 고정한다. 순위와 방법을 가린 상위 10개 합집합으로 사후 판정한다. 고정 시드로 선택한 10개 동일 질의의 비교에는 답 기반·작업자 풀링·내부 별도 각각의 nDCG@10 방법 순위를 쓴다.
