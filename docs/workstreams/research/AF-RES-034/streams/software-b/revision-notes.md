# 최초 추출 묶음 확정 전 수정 기록

이 분지의 최초 원장 커밋 전에 원문과 대조해 바로잡은 작업 중 판단이다. 개별 원장 이전판이 원격에 있었다고 주장하지 않는다. root가 최종 묶음 커밋을 담당한다.

| 대상 행 | 수정 | 결론 영향 |
| --- | --- | --- |
| Swb-P05 / SWB-SEA | Seahawk의 과제·질의 평가를 사람의 실제 작업 수행으로 세지 않았다. 세 평가 모두 알고리즘/저자 관련성 판정으로 전문 제외했다. | 사람 일차 연구 최소수에서 제외. |
| Swb-P03 / SWB-ACAR-1 | 원 Methods의 round-robin과 Results의 random 표현을 함께 남기고 Q로 낮췄다. 등록56·분석54·시행216·기능성공122를 분리했다. | 엄격 무작위 비교 수 감소. 조건부 보안 이점을 배정 전체의 안전한 성공으로 바꾸지 않음. |
| Swb-CIT-CORRECTION / Swb-X01 | Examplore가 REST 검색에 반환된 것을 인용 간선으로 임시 해석했다가, 실제 Sohan 참고문헌 검색이0인 것을 확인해 철회했다. REST 전방은 Cerit2019의 명시적 인용으로 연결했다. | 검색 동시 출현을 인용으로 세지 않음. |
| Swb-A02–A04 | 두 NCQ CSV의 사람 ID가 재사용돼 코호트가 불명확했으나 원 분석 스크립트 주석의 first/second study 대응을 직접 읽어 해결했다. | 별도 코호트 원자료2개로 연결하되 참가자20명만 산입. |

| Swb-Q-single-general-1–4 | 초기 묶음 검색의 질의별 상한 불명확성을 별도 단일질의4회·반환17/28/29/18건의 전건 심사로 보완했다. | 기본 일반/반례 경로의 실제 반환 상한은 검증 가능. native 색인 미접근과 초기 산출물 검색2회 기록 불완전은 남음. |
| SWB-E15–E16 | Acar 원 계수·SE에서 근사95%Wald 구간을 추가했다. 원보고 구간·위험차 구간으로 오해하지 않도록 명시했다. 추가 코드의 괄호 오류로 실행1회 실패한 뒤 수정·재실행했다. | 반복시행 독립 이항 가정을 쓰지 않고 모델 불확실성의 제한적 검산 가능. |
