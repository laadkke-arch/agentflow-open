# AF-RES-034 · Software B 판독 결과

이 분지의 확정 결과는 **사람 연구 원문 6편, 6연구군, 7실험**이다. 같은 NCQ 논문에 별개 참가자 10명씩인 실험 두 개가 있으며, 논문·연구군 수를 두 배로 세지 않았다. 별도 저자 산출물 4개를 직접 읽었다. Seahawk는 논문 전문의 평가를 확인한 뒤 사람 수행 연구에서 제외했다. 최소수에 넣지 않는 부분 열람·인용 탐색 자료는 별도 `discovery_only`로 남겼다. 모든 원문 URL과 위치는 `sources.jsonl`, 실제 추출값은 `studies.jsonl`과 `effects.jsonl`에 있다.

## 분모·시간·품질을 추출한 규칙

`studies.jsonl`의 한 행은 실험 단위이고 `arms`에 군별 값을 둔다. NCQ 연구1/2는 `SWB-NCQ-1/2`로 별도 행이다. 사람 수와 시행 수를 분리하고, Prompter의 동일 사람 12명이 두 조건을 수행한 것을 24명으로 합산하지 않는다. Acar는 등록56, 분석54, 시행216, 기능성공122라는 서로 다른 분모를 보존했다.

eXoaDocs의 시간은 다음 과제 문서를 30초 넘게 본 로그로 전환을 추정한다. 첫 테스트 통과를 직접 찍은 타이머와 다르다. Table X가 완료자만이라고 명시하므로 테스트 통과 Table XII의 분모12를 그 평균에 그대로 붙이지 않았다. 원문의 “up to67% faster” 및 시간값이 “higher”라는 문장은 표의 초 단위 값과 일관되지 않는다. 추출은 14:40=880초, 8:53=533초에서 시작하며 “67% 시간 절감”으로 쓰지 않았다.

REST는 전원 분모로 평균을 정의하지만, 참가자가 만족하거나 막혀 다음으로 넘어가는 경계와 첫 성공 API call은 다르다. 어떤 참여자는 세 번째 call에 정답을 얻고도 총11번 호출했다. 호출 수 감소는 사람 시간 자체가 아니며, 단일 시도마다 독립 사람처럼 취급하지 않는다. 원문이 제공한 그래프 방향·p값과 재계산 가능한 정확값을 분리했다.

Prompter의 두 평가자는 연구 목적과 조건을 몰랐고, 24개 제출물 중4개의 불일치를 추가 코드 검토로 해결했다. 이 방법은 블라인드 품질 평가의 재사용 가능한 요소다. 다만 체크리스트의 가중치에 따른 부분 완성 점수이며, 장기 유지보수·보안·사용성의 등가를 뜻하지 않는다. 90분은 주어진 예산이며 시간을 절감했다고 주장할 시계가 없다.

NCQ의 두 코호트는 모두 정해진 출력 조건을 충족해 좁은 기능 완료 기준은 함께 관측됐다. 그러나 baseline이 항상 먼저이므로 연습 효과가 개입 효과와 얽힌다. 평균 경력과 모집·실력 선별도 코호트 간 달라서 논문 논의의 구판1045초 대 개선판774초를 개입의 순수 효과로 쓰지 않는다. 20분은 연구 설계의 예상 소요이며, 엄격한 중단 기준으로 읽지 않았다.

## 노출·열람·채택과 개입의 구성

eXoaDocs는 API 문서에 요약 예제와 인기도 표시를 추가했다. Strathcona는 구조 seed, 이유, UML 요약, 코드 원문을 함께 제공했다. Prompter는 맥락 검색·랭킹·자동 알림을, NCQ는 검색·package 설치·REPL·자동 코드 수정을 결합했다. REST의 문서는 예제 내용·실제 값·헤더를 추가했고, Acar는 허용 자료원의 범위를 바꿨다. 여섯 군 모두 **B(묶음 개입)**다. 목적과 근거를 적은 링크만 동일 조건에서 더 보여준 L 효과는0이다.

NCQ의 원 프로토콜은 `seen`, `attempted use`, `successful use`를 구분한다. 웹 영상에서 일부만 보인 조각은 전부를 평가할 수 없어 `seen` 분석에서 제외한다. 원 CSV의 `Used?`와 `Runs?`는 특정 조각의 상태이며 전체 참가자 성공이나 후속 설계 채택과 같지 않다. Prompter의 사용 자기보고 문장은3+8+2=13으로 N12와 불일치하므로 채택 비율을 계산하지 않았다. eXoaDocs의 예제 사용10/12 대4/12도 자기보고다.

## 후속 재작업

채택한 최초 설계 뒤 다음 수정 시점까지 비교 관측한 연구는 이 분지에서0이다. Strathcona의 불필요한 코드를 지우거나 다른 예제를 고르는 과정, REST T6에서 앞의 게시물을 수정하는 과제, NCQ에서 package를 교체하는 과정은 **즉시 수행 중 탐색/수정**이다. 나중에 선례를 발견해서 이미 채택한 설계를 다시 만드는 것을 따로 추적하지 않았다. Acar의 대규모 앱 정적분석은 실험 참가자가 만든 같은 앱을 추적한 결과가 아니고, Prompter의1년 뒤 연구는 추천의 관련성 평정이며 동일 참가자의 재작업 창이 아니다.

## 검색·중복·전방/후방 인용의 실제 범위

`searches.jsonl`은 반환 기록을 보존한 초기15개 검색 호출의 질의·기본 정렬·반환 위치·최대30개를 담는다. 초기3개는 묶음 호출이었으므로 쿼리별 원색인 순위가 노출되지 않았다. 이 문제를 줄이기 위해 기본 일반·반례 검색4개는 2026-11-22 16:06:10 UTC에 **질의마다 별도 호출**로 다시 실행했다. `searches-single.jsonl`에 각각17·28·29·18개의 반환 순서와 전건의 제목/요약 심사, 기존 포함군·제외·후속 후보 연결을 기록했다. 반환 기록이 있는19개 호출 외에, 산출물·대체원문을 찾은 초기 탐색2개 호출(7질의)은 순위별 반환 기록이 보존되지 않아 `attempts.jsonl`의 `Swb-EXPLORATORY-01/02`에 메타데이터와 한계만 남겼다. 이들을 완전한 상한/순위 검색으로 주장하지 않는다. 원래 묶음의 흔적도 지우지 않았다. ACM/IEEE의 native 검색 URL은 도구에서 접근 실패했다. 저자본과 출판사·기관 원문으로 보완했지만, native 색인 검색의 포괄성 조건은 이 분지만으로 완전히 충족하지 않는다.

후방·전방 각1단계의 실제 경로13개는 `citation-walks.jsonl`에 있다. eXoaDocs→Strathcona, Strathcona←eXoaDocs, REST←Cerit2019, NCQ←Dagstuhl2024는 본문/참고문헌에서 간선을 확인했다. NCQ가 인용하는 Prompter는2014판이므로 동일 가족의2016확장판과 연결하되 정확히2016논문 인용이라고 쓰지 않는다. Acar→Jain2014는 API의 선택지 자체를 바꾸는 설계이고, Gorski2021 전방 후보는 반복 접근이 봇 페이지로 바뀌어 세부 결과 추출을 끝내지 못했다. Examplore가 REST 제목 검색에 나왔다는 이유로 인용 관계라고 잠시 판단했으나 실제 참고문헌의 Sohan 검색 결과가 없어 철회했다.

2009/2010 eXoaDocs, 2004 Strathcona 학위논문·2005 도구 데모, 2014 Prompter·2016확장판, NCQ2021 arXiv·2023 TSE·FSE Journal First는 표본 독립성이 확인되지 않으면 가족 안의 판으로 연결한다. 이름이 비슷하다는 이유로 별도 사람 수를 더하지 않는다. Seahawk는 세 평가가 모두 저자 관련성 판정인 것을 확인했으므로 full-text 제외다. Prospector는 원문·저자 대체경로 실패로 접근 실패이며, 효과 없음으로 판정한 논문이 아니다.

## 제품 후속 시험에 옮길 측정법

새 연구에는 실제 새 설계 문제와 자유 검색을 대조로 두고, 제공 링크의 목적·근거 외에 인터페이스·시간 예산·검색 가능성을 같게 두는 병렬 무작위 설계가 적합하다. NCQ의 고정 순서 문제를 피하고, eXoaDocs처럼 성공한 사람만 시간에 남기는 대신 시작한 모든 사람의 활성 작업 시간·중단·품질을 같이 보존한다. Prompter처럼 조건을 모르는 독립 평가자에게 최초 제출과 다음 수정 제출을 모두 채점하게 할 수 있다. Acar처럼 “완성자 중 좋은 결과”와 “배정자 중 좋은 완성”을 별도 열로 저장해야 한다.

즉시 관측에는 시작·링크표시·열람·선택·첫 통과·최종 제출의 타임스탬프와 시도/포기 사유를 둔다. 최초 제출을 승인한 뒤 사전에 정한 변경 요청을 제시하여 다음 수정이 끝날 때까지 추적하고, 되돌린 결정의 ID와 그에 사용한 활성 시간을 저장한다. 과제 수정 자체와 늦은 선례로 되돌린 수정을 나눠야 한다. 이 설계는 아직 시행하지 않은 제안이며, 본 연구 숫자로 그 절감량을 예측하지 않는다.

`build_ledgers.py`는 원문 표에서 손으로 옮긴 값을 초 단위·분모·비율로 다시 계산하며, `strand-counts.json`에 소스 조인 누락0을 기록한다. 총16개 효과행 중 SWB-E15/E16은 Acar TableIII/IV의 회귀계수·표준오차에서 계산한 근사95%Wald구간이다. 이는 반올림된 원계수에 기반한 비보정 모델 구간이며, 논문에 그대로 보고된 구간이나 위험차의 구간이 아니다. 기존 반복측정모형을 쓰므로216시행을 독립인원으로 바꾼 이항 검정은 하지 않았다. 별도의 `complete_trace.py`는 검색·실패·부분 열람을 묶는다. `verify_strand.py`와 `verification.json`은 JSON 파싱, source/claim ID 조인, 실제 산식14개, 단일질의 상한, 임시 원본16개의 해시와 git 제외 상태를 검사한 실제 종료코드0 영수증이다. 이 실행은 동일 작성자의 자체 재검이며 독립 판독이나 원 연구 재실험이 아니다. root의 통합·원격 재독·세션 검사는 이 분지에서 시행하지 않았다.
