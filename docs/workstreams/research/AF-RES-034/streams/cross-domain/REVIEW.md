# 교차 분야 원장 자체 재검 영수증

- 검사 범위: sources/studies/effects/screening/attempts 식별자, 연구군 연결, 알려진 군 분모 합, 최소수 및 시간·품질·재작업 분모. 독립 사람 판독이 아닌 동일 작성자의 자체 검산이다.
- 결과: sources11행 중 적격 일차 원문8, 중복 의심 학회판1, 정확 실험판 미확인 공식 교육 산출물2. 적격은 핵심 산업·제품 디자인3 + 학습과학4 + 추상 탐색 인접1이다.
- 연구군8, 독립 실험10. 시간과 공통 품질검사가 함께 있는 것은3연구군5실험이다. 동등 품질 입증0, 최초 채택 후 실제 노동 재작업 비교0.
- 효과23행: 숫자 재계산17 + 비시간/불가6. 숫자17 중5는 McLaren E1 군 n 충돌 때문에 CI 없음. 나머지는 반올림 요약값의 독립군 Welch 근사이며 다중 비교 조정하지 않았다.
- 효과행의 n_all/n_complete는 **그 실험 전체**의 배정/완료 인원이다. 특정 두 군의 재계산 분모는 n_intervention/n_control이고 별개다. 예컨대 McLaren E1 전체179→155, WE–PS는39/37이며 Reisslein 전체185, EP–PE는61/61이다. 군별 최초배정·탈락은 모르면 null이다.
- McLaren PDF p4/p8/p10을 렌더해서 분모 충돌을 직접 보았다. 저자 조판본 첫쪽의 Available online xxx 때문에 최종판 동일성을 확인하지 못했다. 충돌의 범위를 이 열람판으로 제한한다.
- Leahy2018의 N·성별·연령·과제·일부 평균이2020과 같지만 절차85분/각25분/자기평가 대95분/각30분/독립코딩이 다르다. 같은 코호트일 가능성이 높다는 추론만 기록하고 새 사람 표본으로 세지 않는다.
- 원문 전문·추출 텍스트·렌더는 tmp 안의 임시 파일이다. root 커밋 대상에서 제외한다. Git 작업은 이 작성자가 하지 않았다.

기계 검산 결과·미해결 군 분모·입력 해시는 audit.json 및 calculation-receipt.json에 있다. 검색/열람/실패·대체원문·선택 인용경로는 attempts.jsonl, 개별 반환과 최종 선정은 screening.jsonl에 있다.

최초 자체검산은 Chan2011 군n합151 대 본문153을 탐지해 exit1로 끝났다(audit-first-pass.json). PDF p3 직접 렌더 확인 뒤 원문의 충돌임을 기록하고, 불확실한 총배정·완료 인원을 null로 고쳤다. 이는 실패를 숨긴 재검이 아니라 원문 모순과 내부 전사 오류를 구분한 것이다. 개별군 원값은 그대로이며 d 방향·시간 미측정 결론은 바뀌지 않았다.
