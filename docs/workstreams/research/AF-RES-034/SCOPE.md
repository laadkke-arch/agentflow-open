## Q1 검색 틀과 중단 규칙

다음 질의를 세 검색 갈래에서 수행한다. 각 질의는 관련도 기본 정렬, 처음 30개 이내를 심사한다. 검색 도구가 30개 또는 순번·정렬을 공개하지 않으면 **반환된 전부(최대30)**를 대상으로 하고 실제 반환 수와 불투명 정렬을 명시한다. 없는 순번·결과를 채우지 않는다. 네이티브 색인과 일반 웹의 site 제한 검색을 구별하며 후자를 ACM/IEEE 전수 검색으로 부르지 않는다.

| 갈래 | 색인/저장소 | 일반 질의 | 반대 방향 질의 |
| --- | --- | --- | --- |
| SW-A | ACM DL CHI/CSCW/TOCHI, 기관/저자본 | `developer code search API examples task completion time controlled study`; `site:dl.acm.org programming examples user study completion time` | `code examples programming study no significant time correctness`; `API examples novice expert errors user study` |

검색 seed는 사용자의 질문에 맞는 명칭을 찾는 보조 경로다. 긍정 효과가 알려진 도구만으로 표본을 구성하지 않는다. 결과가 없는 검색·차단·공개 저자본 탐색도 attempts에 기록한다. 직접 원문에 도달하지 않은 검색요약은 sources 최소수에 넣지 않는다.

적격 원 연구의 참고문헌을 뒤로 한 단계, 제목/DOI를 인용한 원 연구를 앞으로 한 단계 찾는다. backward/forward의 parent study_family와 쿼리·검토 결과를 기록한다. 재귀적 눈덩이 표집은 하지 않는다. 색인 접근 실패로 전방 인용 목록을 전수 확보하지 못한 경우 제목/DOI 검색 대체와 미충족을 명시한다. 최소 원문 수를 넘겨도 남은 사전 질의와 반대 방향 검토를 마쳐야 종료한다.

## 설계와 인과 등급

출처 열람 등급 D0 발견, D1 원문 확인, D2 공개 코드·원자료 관찰을 적용한다. 자체 계산은 원 연구 재실행이나 D3 사람 시험이 아니다.

별도의 비교 등급은 R(무작위 병렬 또는 적절히 균형화한 교차), Q(비무작위 비교), O(단일군/관찰), U(배정 미확인)다. **제품 직접성**은 L(같은 조건에서 링크/목적·근거 제공만 변경), B(검색·예제 도구 묶음/훈련/화면/코퍼스 동시 변경), X(다른 분야 전이)로 나눈다. R이어도 B/X이면 제품의 링크 단독 효과로 환산하지 않는다.

- 개입: 링크만 / 링크+용도·한계 / 실행 예제 / 완성 솔루션 / 다른 분야 자극. 제공 시점: 과제 전 / 필요 시 / 자유 검색 / 도구 없음.
- 노출·열람·채택은 다른 변수다. 배정 또는 화면 표시만으로 실제 링크 열람·채택을 추정하지 않는다.
- 사람 수, 팀 수, 세션 수, 시행 수, 배정 수, 분석 수, 성공자 수를 별도 칸에 둔다. 사람×과제를 독립 사람 수로 늘리지 않는다.
- 모집·제외·탈락·경험 측정·사전 인지·무작위화·순서 균형·학습/오염을 기록한다. 사전 해법을 몰랐는지 측정하지 않으면 미확인이다.

## 시간·품질·효과 산식

- 시간은 원 연구의 타이머/화면 로그/일지/자기보고를 구별한다. 시작(과제 노출/검색 시작/코딩 시작), 종료(첫 정답/테스트 통과/최종 제출), 중단/시간초과, 준비/읽기 비용 포함 여부를 적는다.
- 동일 정확도 기준·테스트·독립 채점표를 양 군에 적용하고 완료율과 미완료 처리까지 확인한 경우에만 같은 품질 기준의 시간 비교를 허용한다. **유의차 없음은 동등성 입증이 아니다.** 같은 평가 기준을 썼다는 것과 실제 품질 동등성을 검증했다는 것을 별도로 표시한다.
- 원값의 평균/중앙값/분산/단위/전체 배정 분모·완료자 분모/시점을 보존한다. 성공자 조건부 평균은 전체 배정 효과로 바꾸지 않는다.
- 가능한 행: 절대차 `개입-대조`, 시간비 `개입/대조`, 상대 시간 변화 `100*(개입-대조)/대조`. 입력이 없는 경우 계산 불가 사유를 쓴다. 논문에 보고된 상대효과만 있으면 원보고로 표기하며 절대 분을 역산하지 않는다.
- 독립군 평균/SD/n이 있으면 표준오차와 Welch CI를 계산할 수 있다. 교차·반복 설계는 개인별 차이 또는 공분산 없이는 독립군 CI를 만들지 않는다. 반올림된 원보고를 재계산한 값에는 근사 표시. 효과를 연구 간 풀링하지 않는다.

## 후속 재작업의 시작점과 반례

재작업 관측은 첫 설계/해법을 **채택·제출한 뒤** 시작한다. 새로운 요구/품질 재검/선례 공개로 기존 결정을 되돌린 기록과 수정 노동을 별도 측정해야 한다. 첫 제출 전 디버깅·아이디어 반복·검색 횟수·편집 줄 수·PR 달력 기간은 이 재작업 시간으로 치환하지 않는다. 같은 관측창·비교군·사람 노동이 있을 때만 절감량을 계산한다. 장기(다음 날 이상) 관측과 같은 세션 내 재검을 구별한다.

반례는 SW 오류·타임아웃·불확실한 시간 차이, 디자인 고착/참신성 저하, 학습 전문가 역전/전이 실패를 의도적으로 찾는다. 반례가 같은 자극·인구·과제·평가지표가 아니면 같은 효과의 반증이라고 부르지 않는다. 각 Q의 결론을 바꿀 조건과 실제 읽은 반대 자료를 SELF_CHECK에 연결한다.

## 보존과 검토

① 이 SCOPE·manifest → ② 초기 선정·기대/비교 조건 → ③ 관측·출처·실패·반례 → ④ 재집계·RESULT·SELF_CHECK·수용 근거 → ⑤ 고정판 원격 재독 후 HANDOFF를 별도 커밋한다. 원격 SHA는 PROGRESS에 기록한다. 소유 경로 밖은 수정하지 않는다.

세 독립 조사 갈래의 작성자들은 별도 하위 경로에 기록한다. 주 작성자가 통합·재검산하고 다른 갈래의 작성자가 핵심 판단을 추가 판독한다. 이는 서로 다른 사람 코더의 맹검이 아니며 같은 모델 계열 협업이다. 원문 열람/선정 시 이미 결과가 노출되면 사전 무노출로 표기하지 않는다. 미충족은 수용 파일의 met=false와 다음 최소 입력으로 남긴다.
