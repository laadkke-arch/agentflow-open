# 주 관측 — 보충층만
9개 티켓 원문 중 8개는 최초 역할과 종료 발신 로그에 접근, 1개는 최초/현재 header만 읽고 종료 로그 실패. 8개에 대해 제출자 표적 발신과 종료자 ack 각각 8(16 통지 행), 수신함 전달이나 인지 승인 0, 실제 미수신 판정 0, 인지 후 대응 승인 0. 두 종류의 메시지는 D1027832처럼 수신인 역할이 겹쳐도 별개 사건. D1114994는 소스 패키지로 별도 보충. D1075856 원 제출자의 6일 뒤 block 제거, D1027832 본인의 종료 직후 자기 종료 설명은 실제 후속 행동이지만 해당 통지 인용 없음. 따라서 인지 후 행동으로 귀속하지 않는다. 6개 archive tail을 확인했으나 전체 창을 연속 읽지 않았으므로 완전 침묵 표본이라고 부르지 않는다. EGU 두 기록은 별도 보강층이며 사전 응답/반복 결정과 후속 제출을 분리한다. 실제 발신 로그와 수령증은 다르다.
