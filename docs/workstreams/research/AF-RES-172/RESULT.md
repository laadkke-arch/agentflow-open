## 조건부 대안과 추가 분석
1. **가장 잘 지지되는 설명:** 준비된 부품은 구현 노동을 줄일 가능성이 있지만 검색·독해·adapter·검수·후속 수정·유지로 노동을 이동시킬 수 있다. S22,S24,S45,S46,S07–08가 이동 가능한 노동 종류/품질 게이트를 실제 기록한다. **대안:** 부품 문제 아닌 사전숙련/과제 난이도/처치 오염/타이머 정의로 차이가 생긴다. S09,S26,S35,S37이 구별해야 할 요인; 이 자료로 우리 재사용 인과효과를 가를 수 없다. 분리된 X/Y와 matched task/role/acceptance/time + 사전 숙련 블록으로 구별.
2. 같은 참가자의 반복설계는 within-person precision 이점 vs 학습/순서·재사용 carryover(S21/S23, S35). 기본 독립 배정, 별도 counterbalanced 교차 설계는 washout·과제 동등성 확인 후. 동일한 B와 C 과제를 서로 다른 난이도로 대체하지 않음. Y B sentinel 방식은 현실적인 선택가능성 연구에는 좋지만 3경로 사람 인과 비교는 불가. 실행 승인 전 두 과제·하네스 사전 확인.
3. 탐색기 표현 제한: 설명/기성 API compatibility 문장, 실제 관측 조건별 시간(원 단위), measured quality/coverage, 제한된 비용식만. 결과를 전부 하나의 score로 합치지 않음. evidence=observed/documented/design/unknown, role_window/acceptance/denominator 필수. X/Y 가상 예시는 제품 절감률이나 실제 사용자의 효율 측정 아님. 결과를 사람이 검토한 독립 검증 아님. DB/검색/Studio 설계 결정 없음.
4. 후속 계산 의뢰: 공개 비식별 full assignments, activity intervals, per-test acceptance, unit dictionary, versions, stop/crossover reason, reviewer/producer/after rows가 확보된 후 Codex Cloud에서 CSV 행/키 uniqueness, valid UTC interval, union of active, role별 cap, per-cell N=assigned, p+fail+unknown=N, amount bounds, shared-A covariance, X/Y expected fixture consistency를 검산. 연구 참가 모집/배정·코드 실행 이번 제외. 산식은 손계산이며 도구로 검증하지 않았다.
