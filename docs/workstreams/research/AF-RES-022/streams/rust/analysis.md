## 날짜와 비용

A17의 본문 Start Date는1월27일이지만 첫 커밋은1월4일이다. 불일치를 보존했다. A19의 원문 헤더2017년은 기존1946의 날짜이며,2018년은 의미 변경 선택이다. A19는 구현 PR이 수정 RFC보다 먼저 열리고 먼저 병합됐다. A23은 승인과 구현 사이가 길지만 그 전체를 인시나 회피 가능한 비용으로 볼 근거가 없다.

costs.csv의 4행은 구현 PR별 추가/삭제 줄과 변경 파일 수다. 코드·테스트·기타 수정을 포함하는 변경 규모이지 버린 일이나 절감액이 아니다. 각 구현은 계속 사용되는 기능·테스트를 남겼다. 단위가 같아 보여도 기능 범위가 다르므로 합산하지 않았다. 각 사례에 실제 최초 요구·당시 실패 입력·작업 기록 등 인과를 가를 최소 입력을 붙였다.

## 근거 구조와 남은 한계

초안 8개와 댓글/후속 문서 8개는 같은 사건별 계보로 묶었다. 원 작성자·리뷰어·언어/도구/라이브러리팀·기능 공급자의 발언을 구별했고, 공급자의 릴리스는 독립된 사용자 인지 증거로 세지 않았다. 내부 언어 설계가 많은 Rust 선택군은 일반 구매·자체개발 팀의 확률을 대표하지 않는다.

통합 감사 후 지식사건 connected_chain은 A19의1개다. A20은 대안 평가→결정→구현의 decision_chain이지만 새 정보 수신/제약 교정이 직접 관측되지 않아 지식사건 사슬에서는 제외했다. 이 값도 몰랐던 외부 해법 발견의 엄격 양성과는 다르다. strict_discovery_change는0/8이다. A21의 명시적 미인지 발언1개는 리뷰 참여자에게만 귀속한다. 첫 인지일 미상과 늦은 발견 사슬 미상은 원장에 따로 남겼으며, 최종 범위 집계에서는 기지 대안·후발 제공을 분리한다.

자료의 각 URL·고정판·절·직접 확인 내용·한계는 sources.json, 연속 포함/탈락은 sampling.csv, 사례별 다음 확인 입력은 decisions.jsonl, 실패 경로와 다음 출발점은 search-log.json에 있다.

통합 전 보수 재판정: A17·A22는 제안 거절 뒤 실제 소비자의 자체 코드 유지/배포가 연결되지 않았으므로 outcome을 change_unconfirmed로 조정했다. A18은2021-12-02의1.57에서 named profile 안정화를 추가 확인했다. Rust Book의 서로 다른 절2개는 별도 독립 저작수에서 제외했다.

최초 공개 구현의 재감사: 연결된4개 구현 PR의 공개일을 earliest_observed_code로 이동하고, 전역 최초 공개 commit은8/8 미확인으로 남겼다. 이 조정은 실제 병합·릴리스 날짜를 지우는 것이 아니라 최초성의 과장을 막기 위한 것이다.
