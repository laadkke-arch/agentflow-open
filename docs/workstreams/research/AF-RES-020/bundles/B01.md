# B01 — 원 질문·부정·제약을 보존하기

## 식별·질문

- 브리프 질문: input. 상태: **조건부 검토**. 확인일: 2026-11-21 UTC.
- 판단할 질문: 표현을 바꾸면서 무엇은 원문으로 되돌릴 수 있어야 하는가?
- 입력은 아래 고정 SHA 원 결과다. 결정을 바꾸어도 인접 묶음의 결론을 자동 변경하지 않는다.

## 짧은 핵심

원문을 남기고 대상·범위·부정·시점·강제성·발언 지위를 유지한다. source_span을 붙인 해석도 뜻을 잃을 수 있으므로 참조 존재와 의미 보존을 따로 확인한다. 입력을 구조화할지 여부와 관계없이 채택할 수 있는 보존 요구다.

## 대안·기발한 조합

A 원문 그대로, B 원문에 짧은 표시, C 원문과 수정 가능한 분해를 모두 유지한다. H: 짧은 질문은 A, 혼합된 조건은 B, 장문에서 추가 가치가 입증된 경우만 C를 쓰되 동일한 의미 보존 검사를 붙일 수 있다. 어느 표현이 우수한지는 미선택이다.

## 반례·한계

원문 자체가 상충하거나 길면 보관만으로 독자의 오해를 막지 못한다. 001의 모든 원문은 정돈된 6문장이므로 실제 장문·그림의 손실률로 일반화하지 않는다. K01의 span 존재는 보존 완료의 반례다. K06에서 부정 없이 “외부 전송 조건 필수”만 저장하면 극성이 사라진다.

## 관계

B02·B23의 입력 처리에 선행한다. B06의 주장 분해와 함께 쓰되, 원문과 분해를 합치지 않는다. B24의 제외 필터가 금지/선호를 읽으려면 이 구분이 필요하다. 의미를 잃은 C 제안만을 후속 입력으로 쓰는 정책과 충돌한다.

## 검토

AF-RES-020 내부 별도 검토(같은 모델 계열, GPT-6 Astra Pro)가 원 결과와 하위 근거를 대조했다. 원 연구의 작성자·정답 구성자와 이번 대조자를 구별한다. 각 주장 판정은 `CLAIM_CHECK.json`의 `C-B01-*`로 추적한다. 사람 검토나 외부 모델 재현성 검증은 아니다.
