# B10 — 구조화 기록 가치 H1·H2의 선택 경계

## 식별·질문

- **브리프 질문:** assembly, scope. **선택 단위:** 구조화 자료집을 채택할 이유를 단발 검색 효용(H1)과 지속 재검토 효용(H2)로 분리하고 작은 절차(H3)를 대안으로 유지할지.
- **상태:** 가설 경쟁의 틀로 채택 가능. 어느 가설의 참도 확정하지 않는다.

## 짧은 핵심

H1은 조건·제약·근거를 미리 연결하면 후보 검증 부담이 줄어드는지 묻는다. H2는 여러 공급원에 걸친 판 변경과 영향 재검토를 더 잘 수행하는지 묻는다. 기존 조합의 단발 성공은 H2를 반박하지 않고, 긴 유지 비용이 있다는 사실도 H1을 증명하지 않는다. H3는 독립 제품 대신 기존 작업 흐름의 작은 절차가 충분할 가능성이다.

## 대안·기발한 조합

H: 처음에는 B09 기존 조합을 쓰고 B05의 링크·조건 설명만 쌓는다. 변경 검토가 반복해서 실패한 기록에만 B06 주장 단위를 추가한다. 반대로 고위험·반복 질문에서는 B06부터 시작하되 검색 자체는 기존 서비스에 남길 수 있다. 각 구성은 독립 제품·내장 절차·자료집이라는 유통 방식과 분리해 선택한다.

## 반례·한계

기존 조합에 제한된 시간·문맥만 주고 새 자료집에는 선별 완료된 답을 넣으면 H1 검정이 아니다. URL 생존·검색 색인 최신성·인용 위치 재현·주장 영향 추적은 각각 다른 유지 결과다. 유지 기능을 약속한 제품의 종료 원인이 관측됐다는 이유로 모든 유지 계층을 무용하다고 결론 내릴 수 없다. 자료집을 오래 만들수록 좋아진다는 근거도 없다.

## 관계

B09가 기준선을 제공하며 B05와 B06은 시험할 저장 대안이다. B16·B17의 유지 관측이 H2의 실질 입력이고 B07·B24는 판정·증거 기록을 공통화한다. H1과 H2는 서로 대체가 아니라 다른 성과 창이다. 두 가설을 하나의 ‘구조화가 좋다’ 점수로 합치면 독립 채택·보류가 불가능해진다.
