## 1. 묶음 기준

하나의 묶음은 **결정 하나와 교체 경계 하나**를 가진다. 단독 읽기로 채택·보류·교체를 판단할 수 있도록 필요한 정의와 관측 범위를 짧게 포함한다. 실행에 필요한 전제까지 독립이라는 뜻은 아니다. 두 묶음이 서로의 정의 없이는 판정 불가능하면 합치거나 공통 정의 계약을 명시하고 숨은 의존을 등록한다.

각 파일은 연구 운영 규칙 §4의 식별·질문 / 짧은 핵심 / 근거 / 대안·기발한 조합 / 반례·한계 / 관계 / 검토 / 다음 확인을 갖는다. 원 결과는 고정 SHA permalink로 연결한다. 최소 15개, 계획 목표 24개. scope·identity·storage·retrieval·input·maintenance·evaluation·assembly 모두를 대응시킨다. 근거가 없는 독립 질문은 빈칸 묶음으로 남긴다.

## 3. 재대조 판정과 변별력

- `일치`: 원 결과가 같은 단위·분모·관측 창·조건으로 해당 문장을 지지한다.
- `불일치`: 원 결과가 반대이거나 핵심 단위·수치·조건을 누락해 뜻이 변했다. 유형은 수치 오류 / 분모 누락 / 관측 창 누락 / 과대 일반화 / 인용 위치 오류 중 하나 이상.
- `확인 불가`: 해당 판의 위치 부재·근거 파일 부재·자료로 식별 불가능. 부재를 불일치로 단정하지 않는다.
- 일치가 80% 이상이면 알려진 나쁜 주장(분모 제거, 관측 창 변경, 역할 축 혼동, fetch를 run으로 승격, 0건의 무효과 일반화)을 별도 음성 대조군으로 넣는다. 실제 CLAIM_CHECK 개수에는 심은 문장을 섞지 않고 변별력 기록을 남긴다.

## 4. 모든 묶음 쌍의 관계

n(n−1)/2개의 순서 없는 쌍을 모두 한 번 기록한다. 한 쌍의 상황별 관계가 복수이면 relations 배열로 보존한다. 선행 관계는 방향을 별도로 기록한다.

- 함께 씀: 서로 다른 책임을 맡고, 같은 구성에서 함께 사용할 조건이 있다.
- 충돌: 같은 운용 조건에서 동시에 채택하면 서로 다른 요구·판정을 강제한다. 단순 숫자 차이를 충돌로 올리지 않는다.
- 선행: A가 제공하는 정의·자료·검증이 없으면 B의 주장이 성립하거나 실행될 수 없다. A→B.
- 대체: 같은 질문을 푸는 선택지다. 같이 시험할 수 있지만 동일 실행 경로에서는 하나를 고르거나 명시적으로 혼합해야 한다.
- 무관: 이번 결정·관측 범위에서 확인된 직접 의존 또는 선택 충돌이 없다. 영구적인 무관이나 연관성 없음의 증명이 아니다.

무관 외 관계에는 조건, 원 결과 위치, 미확인을 붙인다. 순환 선행·정의 혼합·같은 수치의 상충 전달을 별도로 점검한다.

## 5. 충돌 성격

- 경험적: 같은 구성·단위·관측 창·판정 조건을 비교한 결과가 다르다.
- 정의상: 같은 말의 축·단위·판정 규칙이 다르다.
- 범위 차이: 질문·자료집·시점·분모·표본·실행 조건이 다르다.

한 충돌에 주성격과 보조성격을 둘 수 있다. 상태는 해소 / 부분 해소 / 미해소. 해소는 용어·조건 차이를 설명했다는 뜻이며 제품 성능 검증을 뜻하지 않는다. REVIEW-4 §3의 11개 지점을 그대로 추적 가능한 ID로 유지한다.

## 6. 외부 비교와 반증

방법·비교 문헌 20개 이상: set-based ≥3, real options·모듈화 ≥3, QOC·IBIS·ADR ≥3, EtD·living review·evidence gap map ≥4, 대안 유지의 비용·실패 ≥2. 같은 사이트는 최소 개수에 최대 3개. 직접 연 본문만 센다. 공개 원문과 저자·공식 기관을 우선하며 검색 snippet·차단은 excluded에 분리한다.

각 방법에서 대안을 언제까지 열고, 무엇을 기록하고, 어떤 증거로 좁히며, 유지 비용이 무엇인지를 읽는다. 제조·소프트웨어·설계 논증·보건 근거 종합·조직 의사결정 중 4분야 이상을 비교한다. Q1–Q8 각각 내부 결과와 외부 방법이라는 2종류를 연결한다.

찾을 반례 다섯 가지: 분리 불가능한 정의 / 정의와 경험 충돌의 혼동 / 가벼운 구성의 비가역성 / 수치·분모·범위 전달 오류 / 같은 주장의 이중 수치. 발견하지 못한 종류는 탐색 기록과 최소 추가 확인을 남긴다.

## 8. 커밋과 완료 게이트
