# 최상위 설계자에게 남기는 결정

## 1. 읽는 규칙

선택지와 최소 확인 규모는 이번 조립 연구자의 H다. 아래 수는 결정을 바꿀 반례·진단을 확보하기 위한 최소 입력 제안이며, 우월성·동등성 통계 검정의 검정력 보장이 아니다. 동일 시간·자료·필수 조건과 판단자를 사전 고정한 뒤 해석한다. 작은 수치 차이보다 알려진 잘못된 승인과 복원 불가능한 정보 손실을 먼저 본다. AF-RES-017~019는 결과를 읽지 않은 대기 입력이다.

## 3. 선택 순서와 되돌림

D01·D02로 목표 비용을 정한 뒤, D10·D11의 평가 단위와 D08·D09의 입력을 함께 고정한다. D04–D07의 표현·검색 결정을 그다음 필요한 범위에만 적용한다. 유지 방식 D13은 추천 시점 검증과 별개이며, 신호가 싸다는 사실만으로 정확성을 전제하지 않는다.

D14의 의미 보존은 모든 구성에서 첫날 필요하지만 정교한 저장 엔진 선택을 선행시키지 않는다. D15의 대안 유지에는 다음 검토일·담당·비용 상한과 종료 조건이 필요하다. B20의 독립 조립 가능성은 이 조건을 각 묶음이 스스로 밝히는 것으로 검토한다.

## 4. 역할별 사용할 결정

- 최상위 설계자: D01–D15에서 선택·보류 이유와 바꿀 증거를 남긴다.
- 편집 담당: D16에서 원 상태와 현재 읽기 경로를 유지한다.
- 후속 연구자: 각 행의 최소 확인을 별도 사전 고정 과제로 구체화한다.
- 앞선 작업자: CLAIM_CHECK의 원 위치·분모·범위와 판정 계약 축약이 정확히 옮겨졌는지 검토한다.

## 5. 외부 방법과의 연결 — H

결정의 문맥·상태·바뀐 이유를 남기는 방식은 ADR X10, 보류를 유지할 중요성·새 근거·종료 조건은 living review X13, 결정을 바꿀 추가 정보와 분석 비용은 NASA X22, 대안의 포함/제외 이유와 switching values는 Green Book X24에서 비교했다([CROSSFIELD §2·6](CROSSFIELD.md)). 이 방법들은 위16결정의 답이나 최소 표본 크기를 검증하지 않는다. 실제 최소 규모와 적용 순서는 이번 연구자의 H이며 각 선택을 바꿀 진단 입력으로만 쓴다.

## 한계

실행하지 않은 비교의 유리한 방향을 미리 정하지 않았다. pending_input은 작업 연결점이며 결과 대기 때문에 이 조립 결과의 인계를 미루지 않는다. 선택은 이 파일을 읽을 미래 설계자의 몫이다.
