# AF-RES-020 — 독립 연구 묶음과 조건부 조립

## §1 필수 결과 표

대조 범위는 지정12작업의 고정 SHA다. 각 원 결과는 앞선 작업자가 작성했고, 이번 전달 재대조는 GPT-6 Astra Pro 작업자와 같은 모델 계열의 내부 별도 감사가 수행했다. 별도 모델 `gpt-6.2-sol`은18개 통제 문장과 구성의 숨은 전제를 검토했다. 사람 검토나 제품 효과 검증으로 세지 않는다. 아래 모든 조립 관계·구성·최소 조사 규모는 **H**이며 최종 구성을 고르지 않았다. 원 위치 링크는40자리 SHA로 고정했고 표에서는8자리로 줄여 표시했다.

현재 요약: **24묶음, 73주장 대조(공유3행을 묶으면70주장군), 57/73의2단계 확인, 276쌍, 16충돌, 3구성, 16결정**. 직접 읽은 원 결과는 필수33개를 포함한75고정파일/12작업, 외부 방법·비교 원문24개(같은 사이트 상한3)다. 연구 종료 조건 중 ‘동일 주장·동일 조건이 두 묶음에서 실제로 다른 수치’인 반례는 이번 표집에서 찾지 못했다. 이 미충족과 운영 절차 공백을 숨기지 않고 REVIEW_READY_WITH_GAPS로 인계한다.

처음의 ‘많이 나누고 오래 열어 두면 좋다’는 가설은 유지하지 않았다. X11의 실제 설계팀은 잘 규정된 문제에서 형식적 대안 기록의 부담을 드러냈고, X18은 소멸하는 선택지를 유지하려고 기회 비용을 쓰는 행동, X19는 수정 가능성의 정서 비용을 보고했다. 이 비용은 AF-RES의 금전 가치나 기술적 정답률로 직접 환산할 수 없다. 따라서 보관 대안과 활성 개발 대안을 구별하고, 다음 확인·중단 조건·유지 비용을 묶음 형식에 연결했다.

**연구 종료 조건 미충족:** ⑤ 동일 주장·동일 조건의 두 묶음 수치 충돌은 73행 목적 표집과 공유 3군·의심 숫자 대조에서 미발견이다. 실제 오류 사건이 없는 한 발견으로 바꿀 수 없다. 미표집 수치 주장의 같은 대상/분모/조건 중복 목록이 추가 검사의 최소 입력이며, 단순 자료 증가가 오류 발견을 보장하지 않는다.

**운영 절차 공백:** 초기 예정 16호스트와 달리 추가 19호스트의 응답 코드 확인은 본문 열람 뒤에 실시했다(PROGRESS·external-network-check). 첫 커밋 전 사전 확인을 소급 충족했다고 쓰지 않는다. 공통 workbench.session start는 고정 013 결과와 현재 branch HEAD 차이로 exit 2였으며 manifest를 얻지 못했다(contract-start-attempt). 고정 입력을 최신판으로 바꾸거나 검사기를 약화하지 않았다. 별도 고정 객체·파일·경로 검사는 그 공통 gate 통과의 대체 판정이 아니다.

011 CASES는 구조·집계만을 주장 근거로 썼다. 다만 초기 탐색에서 outcome dict 집계 출력에 기존 요약 필드가 부수 노출된 절차 위반이 있다(audit-late.md). 그 텍스트를 새 개별 분석이나 산출물 복사에 사용하지 않았으며 이후 필드를 제한했다. 이 사실도 완전한 절차 준수로 덮지 않는다.

외부 24원문은 목적 표집이고 Ward1995·Design Rules 전권 열람을 주장하지 않는다. 실제로 읽은 원문의 범위와 전이 한계는 CROSSFIELD에 모았다. 과거 원 연구의 013/016 인수 공백은 이번에 소급 해소하지 않았다. 최종 설계·공통 색인·dot-control·DB/API·배포·상시 수집을 변경하지 않았다.
