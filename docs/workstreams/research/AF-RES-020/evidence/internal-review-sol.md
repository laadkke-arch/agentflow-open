# AF-RES-020 별도 내부 검토

도구가 표시한 모델은 `gpt-6.2-sol`이다. 고정 입력 전달문 18개를 각 원 결과와 필요한 하위 자료에 대조했다. 통제 키와 조립 주 작업자의 주장·감사 파일은 대조 시 열지 않았다. 결과는 일치 4개, 불일치 12개, 확인 불가 2개다. 각 문장과 근거 행은 [통제 대조 기록](control-review-sol.json)에 있다. 이 검토는 같은 서비스에서 별도 모델을 선택한 내부 검토다. 외부 독립 정답, 사람 검토, 실사용 성능 검증을 제공하지 않는다. 통제 18개는 실제 주장 재대조 분모에서 제외한다.

## 구성안의 전제 누락

[CONFIGS.md](../CONFIGS.md), [구성 데이터](configs-data.json), [관계 명세](relation-spec.json)의 방향 있는 선행관계를 비교했다. 해당 경로를 실제로 쓰는 경우의 권고이며 상시 저장 구조를 요구하는 판단은 아니다.

| 구성과 선행관계 | 보완해야 할 의미 |
| --- | --- |
| C0·C1의 B06→B07 | 요청별 검토 영수증에서 원 설명의 좁은 주장, 대상·배포/판·적용 범위, 수식어·부정·제외 조건, 제공 근거의 위치/판과 확인 시각을 제안 사용·설정에 연결한다. 그 연결에서 E 원문 지지와 H 필수 조건을 각각 판정하고, 근거 부족과 알려진 위반을 구분한다. C0는 기존 제공자의 후보를 그대로 사용하면서 같은 영수증으로 처리할 수 있고, C1은 설명 카드와 영수증 연결로 처리할 수 있다. 별도 후보 자료집이나 전역 주장 원장은 필요하지 않다. |
| C0의 B12→B14 | 역할별 성능표를 만들 경우에만 노출된 원 라벨, 코딩 방식/판정자, 후보 형태의 관측 대상과 제안 사용의 기여 대상을 고정하고 역할 층화 시 분모를 표시한다. 이 전제를 채우지 못하면 역할 층화 지표의 상태를 보류하고 판정 출처 민감도는 전체 범위로 산출한다고 명시한다. |
| C2의 B11→B12 | 형태의 단위는 대상 배포물·문서와 판이다. 기여의 단위는 원 질문의 선택 범위 × 특정 답/제안의 후보·사용 문맥이다. 같은 후보를 전체 대안·부분 부품·비교 기준으로 제안하면 각 연결에 판정이 있어야 한다. 원 질문 위치와 답/제안 위치를 따로 남기고, 형태 및 기여 원 라벨·코드북 판·판정자를 보존한다. 구성표의 ‘쌍 contribution’만으로는 어떤 쌍인지 결정할 수 없다. |
| C2의 B11→B14 | 실제 답을 기준으로 평가할 때에만 공식 현재 채택·명시 선택/사용·검증된 통합을 각각 다른 관측 사건으로 유지한다. 질문/답 ID·원 위치·관측 시각, 후보에 귀속되는 사용 범위 및 미확인을 함께 기록한다. 이 조건이 없으면 문서 근거 판정으로 범위를 제한하고 실제 답 기준 결과는 보류한다. |
| C2의 B11→B23 | 요약·구조화 변환으로 검색할 경우 원 질문 또는 확인된 판의 위치, 전체/부분 선택 범위, 원문·요약 구분, 변환 판과 실제 검색 입력을 남긴다. 답 반응을 질의 평가에 연결한다면 답의 원 위치와 관측 시각까지 보존한다. 최초판 미확보는 미확인으로 기록한다. |

공통 최소 의미와 표·JSON의 각 첫날 보존 항목에서 원 판정 상태와 판정 규칙 판을 읽을 수 있어야 한다. C0의 문구는 검색 변환 판과 판정 이유는 기록하지만 원 H/E 판정이나 판정 규칙 버전은 직접 명시하지 않는다. C1이 C0 영수증을 상속하더라도 형태 판정 규칙만 명시하면 그 빈칸이 남는다. C2가 기록하는 근거판도 제공 근거 전체를 식별할 수 있도록 위치·판과 묶는다.

관계 명세의 B11→B23은 모든 요약 변환을 설명하는 정의 공통부와, 답 반응을 사용하는 경우에만 필요한 관측 출처를 구분해 적용할 수 있다. 다른 선행관계도 전체 묶음 편입과 좁은 공통 정의의 충족을 나누어 표시하면 구성별 비용 경계를 읽기 쉽다.
