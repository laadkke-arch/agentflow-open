## 동일 입력과 라이선스

`inputs/Q05.md`부터 `inputs/Q08.md`까지는 GitHub connector가 반환한 최초 초안 전문을 UTF-8 바이트로 저장했다. Q07의 CRLF를 포함해 보존했으며 git blob SHA를 원 응답 blob SHA와 대조했다. G/R 각 행에 같은 SHA-256을 기록했다. 원문 링크와 commit은 `sources.json`과 `questions.jsonl`에 있다.

Rust RFC 저장소의 고정 README `fb838b3989f5ad2305526d45fcd4683dd27ba241/README.md`의 License/Contributions 절은 MIT 또는 Apache-2.0 선택 및 기여 조건을 안내한다. 같은 판의 LICENSE-MIT를 `inputs/LICENSE-MIT`에 포함했다. 과거 전체 저장소의 재라이선스 완료를 주장하지 않으며, 이번 초안은 2021년의 새 기여다. 출처·저자 계보를 유지하고 실험 입력 전문 외에 외부 본문을 추가 복제하지 않는다.
