## 설계 검토자가 옮길 수 있는 것

`relations.json`에는 각 분야에서 두 개 이상의 행위자·상태·규칙·결과 관계와 정확한 원문 위치를 연결했다. 도서관 비교에서 옮길 수 있는 것은 **문서 동일성, 관련성, 변경 근거를 서로 다른 관계로 기록하는 방식**이다. 이것은 후보의 기능을 검증하는 공급자 증거를 대신하지 않는다. 같은 목적의 제품을 전거의 이명처럼 합치면 오히려 서로 다른 호출 경계를 지워 버린다.

제조 비교에서 옮길 수 있는 것은 **작업 대기열과 실제 투입 수를 구별하고, 완료가 다음 투입 허가를 돌려주는 관계**다. 연구자의 조건부 제안으로는 후보 한 건의 근거 묶음을 해결하거나 실패로 닫을 때까지 허가를 유지하는 읽기 서비스에 대응한다. 문서 길이, 재시도, 공유 근거, 분기 때문에 단순 개수 제한은 토큰 상한이나 인시 절감을 보장하지 않는다.

Q10의 반례는 더 직접적이다. 커널 시작 수를2개로 제한해도 두 프로세스가 같은 미예약 포트를 고를 수 있다. 재공품 상한은 유지되지만 endpoint 소유권 조건은 실패한다. CONWIP 역시 라인에 들어온 뒤 공정 사이에서는 작업을 밀어 보낼 수 있으므로, ‘pull’이라는 이름만으로 내부 모든 호출 관계를 판단할 수 없다(SP-M02 §5, L345–353).
