# 관측 대조 원장

주 실행 ID의 `-SEL`과 `-NON`은 같은 주 실행에서 각각 한 셀만 바꾼 별도 자식이다. `pairs.csv`의 행 단위는 이 짝이다. 단순 복제와 대조 파일 생성은 준비 과정에서 수행했다. 분석 프로세스에서 열린 경로는 `runs.jsonl`의 `os.by_path`를 따른다.

| ID | 예상에 반하는 해석과 직접 대조 | 영향을 받는 사실 |
| --- | --- | --- |
| X01 | S2-1/2, T2-1/2는 main과 extra 해시가 같다. 분석 자식이 연 것은 main이다. extra의 선택 필드를 바꾼 네 `-SEL`에서도 값과 행 집합이 유지됐다. | 같은 내용·발행 객체 바이트와 해당 경로의 사용을 구별한다. |
| X02 | S3-1/2는 probe에서 1377 B, T3-1/2는 74 B만 읽었다. 개별 1 B read 호출 수와 헤더 바이트 수가 같았다. 별도 필드 접근 중단 검사는 대상 값에 도달하지 않았다. | 열기 참, 데이터 키 읽기와 결과 감도 거짓. C3 대조 사본은 내용도 같지 않다. |
| X03 | S4-1/2 선택값의 469→470은 원합 1300→1301, 보고 1300→1300이다. 선택 필드가 산식에 들어갔다. | 보고값 불변에서 필드 미사용을 추론할 수 없다. |
| X04 | T4-1/2는 AAMV2의 trip_id를 읽은 뒤 방향 1에서 제외했다. ID 변경은 고유하나 stop_times 참조를 바꾸지 않았다. 본 집계는 stop_times를 열지 않으며 AAMV1/3 두 행이 남았다. | 필드 조회는 있었고 보고·원값 기여는 없었다. 변형 사본의 전 피드 적합성은 별도다. |
| X05 | T-A-DIR은 2007-01-06에 방향만 바꿨다. 2→2이고 행은 AAMV1/3→AAMV2/4다. T-A-SAME은 날짜만 01-07로 옮겨 같은 두 행을 보였다. T-A-DATE의 01-08에는 WE가 없어 관측 0이다. | 2라는 값만으로 방향, 날짜, 서비스 집합을 복원할 수 없다. |
| X06 | NYC 2021-03-24/25 배포의 03/19 진단일 합은 1300→1331, 보고는 1300→1300이다. 03/20 판에는 이날이 빠졌다. 최근 공통일 03/17은 367→1382, 보고 400→1400이다. | 동일 참조일 비교에 판 날짜를 별도로 보존한다. 미수록 날짜는 0으로 채우지 않았다. |
| X07 | T-A-EDITION과 T1-1은 2016/2026 Git commit·시각이 다르고 ZIP과 11개 멤버 해시가 같다. 서비스 기간은 같다. | 전체 ZIP 해시도 Git 발행 snapshot의 유일 ID가 될 수 없다. |
| X08 | `receipt-sensitivity.json`은 T1-1의 열린 경로·키 항목을 제거했다. 누락을 감지하면 A/K/R 보류, 잘못 완전하다고 표기하면 세 사실이 거짓 음성이다. | 사전 P2 집계에는 넣지 않은 증거 누락 감도다. 독립적 scope 확인 없이 P2의 역추론을 적용할 수 없다. |
| X09 | T-A-EXCEPTION과 T-A-EXCEPTION-COMP에서는 같은 AB 방향 0을 2007-06-04/05로 바꿨다. FULLW 제거 예외의 행 2가 적용될 때 0, 다음 날 AB1 한 행이다. | 달력의 기본 요일만 쓰면 이 ZIP의 실제 예외를 놓친다. |
| X10 | S-A-MISS에서 469만 공란으로 교체했다. 독립 검산 유효 개수 2→1, 원합 1300→831, 보고 1300→800이다. | 결측·제외와 유효 0은 다른 상태다. 부분 합의 범위는 유효 개수와 함께 제공한다. |

X08의 보조 감도는 기록 규칙이나 주 점수를 바꾸지 않았다. 목록 자체가 결측일 때 보류하도록 사전 규칙을 코드에 적용했다. 목록이 비어 있지만 수집 범위를 완전하다고 잘못 기록한 경우를 재현했다.
