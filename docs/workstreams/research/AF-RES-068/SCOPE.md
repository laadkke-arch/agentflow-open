## 세 경로와 정보 차단

[B 대응, C 정규화, 둘째 열람 규칙](rules.json)은 공급자 문서 제목·공개 선언을 열기 전에 이 묶음에서 고정한다. [12건에서 추출한 공개 이름 후보 토큰](mentions.jsonl)에는 원문 줄과 표현 형태가 있으나 API 목록이나 C1/C2 기대값은 없다. 코드 선언·입력에 등장한 표현을 포함하며 본문 템플릿·URL 목적지·관측 출력 블록·로그 줄·타깃 목록의 정답은 공급하지 않는다. 요청의 C1/C2와 기대 반례는 routes 선정기와 별개 파일의 열에 있다.

A는 공급자 배포 소스 README 시작, B는 넓은 작업 계열에 맞는 해당 판 공식 문서 제목, C는 초기 본문 표기의 순서대로 정확히 일치하는 공용 키·옵션·API다. 후보 없을 때 A로 돌아가는 경로와, 후보가 존재하나 동일 위치에 도착한 경우, 정상 선택 후 접근 실패한 경우, 실제 노출 초과를 각각 구분한다. 공용 문서와 공개 선언·키워드 표의 메타데이터만 선정기로 보낸다. 섹션의 예제나 fixture 정답은 공급하지 않는다.

한 경로에서 최대 2행동, 한 번에 원문 순서 500토큰. 앞선 비교와 같이 유니코드 단어 연속열과 공백 아닌 구두점 각 하나를 계수한다. 코드도 포함하고 이미지·수식은 생략하며 생략량·raw/표시 bytes·최대 토큰 bytes·출처 행을 기록한다. 긴 무공백 단어 자체에는 별도 bytes 제한을 두지 않는다. 같은 pinned URL·시작 행에서 나온 같은 창은 한 번 표시해 고유 창을 증거로 참조한다. 선택 메타데이터 조회와 사람에게 표시하는 근거 창을 분리하며, 판독자가 앞서 본 인접 문맥이나 재독은 노출 원장에 남긴다. GitHub 화면을 흉내 내는 고정 본문 텍스트 투영이다.

## 판정과 실행 자리

C1·C2·환경에 각각 직접 지지(D), 직접 반박(R), 조건부 이름 전이(T), 미확인(U)을 부여한다. D/R은 원문 위치와 입력→출력·거부 또는 필수 환경의 직접 원문을 요구한다. T는 필요한 옵션과 구조 및 자료형 조건이 유지된 국소 이름 치환이나 부분 예시를 표시한다. 기능 목록, 상위 API 설명, 단순 단어의 일치는 U다. 064의 사후 예시를 신규 D/T로 이월하지 않는다. 서로 다른 경로를 합쳐 공동 확인을 만들지 않는다.

같은 route에서 C1·C2·환경 모두 D를 주는 엄격 노출만 공동 확인이다. 별칭 또는 재구성은 별도로 산출하며, 실제 선택·같은 첫 주소·실제판·비교판·노출 준수의 분모를 명시한다. 두 위치의 순서가 다른 경우 판정 이득과 잃은 환경을 별도로 계산한다. 경로명·기대값을 가린 고유 창의 1차 기록을 먼저 고정한다. 한 판정자가 수행하므로 모집 지식 및 이전 연구의 Ajv 노출은 사후 맹검 독립성의 증거가 될 수 없다.

실행 자리는 모집순으로 A01 #1872, A02 #1875, L01 #465, L02 #466이다. 각각 정상, C1 근접음성, C2 근접음성, 경계·구조 보존의 4군을 고정한다. 문서 판정과 기대값 커밋 뒤에 새 파일로 실행한다. 실제 Node나 종속 패키지·원문판을 알 수 없으면 일치도 및 관측의 범위를 제한한다. 코드에서 새로 만든 로컬 데이터만 실행한다.
