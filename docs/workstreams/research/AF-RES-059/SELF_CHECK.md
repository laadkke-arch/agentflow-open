## 수용 경계

- 발행 파일·상류판·네 값·두 방향·경계의 분모는 [기계 검산](evidence/acceptance-evidence.json)에 고정했다. 배포물의 동일 결과는 IANA의 최신 파일 전체나 사용자 설치판을 식별하는 기준으로 쓰지 않았다.
- 내부 인수, 검색 결과 조각, PyPI file 두 종류, 동일 공지 여러 형식은 외부 최소 수에서 뺐다. 열람한 파일 위치와 강한 해시, 접근 실패를 [출처 원장](sources.jsonl)에 남겼다.
- 이 세션의 확대 감도는 npm 방식으로 뽑은 Grafana 끝 대조판 9.5.0과 9.4.7의 보존 OCI 이미지다. 본 배포 표본의 이름·수·순서·예측을 재정의하지 않았다. 로컬 공식판 실행의 충분성과 ALFRED 빈티지 미수신은 별개 상태다. [범위](SCOPE.md)
