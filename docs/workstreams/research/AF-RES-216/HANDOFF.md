## 5. 고정 자료 재생 명령

GitHub의 이 작업 브랜치를 받은 clone의 루트에서 실행한다. 원응답 재생은 추가 PyPI 요청 없이 가능하다. `AF216_TMP`에 그때의 입력과 출력이 분리된다.

```sh
AF216_DIR=docs/workstreams/research/AF-RES-216
AF216_TMP="$(mktemp -d /tmp/af-res-216-replay.XXXXXX)"
git fetch origin refs/heads/work/research-af-res-200
git show "1ae3b56d3f445188109c343b00a1b67516f683ce:docs/workstreams/research/AF-RES-200/releases.csv" > "$AF216_TMP/baseline.csv"
git archive e2b767089a72c2e58c1a360d524f2b0d71df8ca9 -- "$AF216_DIR" | tar -x -C "$AF216_TMP"
AF216_SNAPSHOT="$AF216_TMP/$AF216_DIR"
python -B "$AF216_SNAPSHOT/reconcile.py" --baseline "$AF216_TMP/baseline.csv" --api "$AF216_SNAPSHOT/receipts/api" --html "$AF216_SNAPSHOT/receipts/html" --out "$AF216_TMP/replay"
python -B "$AF216_SNAPSHOT/reconcile.py" --controls "$AF216_SNAPSHOT/controls.json" --out "$AF216_TMP/controls"
cmp "$AF216_TMP/replay/files.csv" "$AF216_SNAPSHOT/files.csv"
cmp "$AF216_TMP/replay/summary.json" "$AF216_SNAPSHOT/receipts/reconciliation.json"
cmp "$AF216_TMP/controls/controls-result.json" "$AF216_SNAPSHOT/receipts/controls-result.json"
python -m workbench.session check "$AF216_DIR/af-res-216.json" --fetch
```

후속 시점의 실제 응답이 필요하면 같은 임시 경로의 새 디렉터리로 `python -B "$AF216_SNAPSHOT/fetch.py" --group api --out "$AF216_TMP/new-api"`, HTML은 `--group html --out "$AF216_TMP/new-html"`을 쓴다. 그 응답으로 재집계할 때 기존 88키 CSV는 그대로 입력하고 시점별 차이를 남긴다. [공개 입력 지정](fetch.py)
