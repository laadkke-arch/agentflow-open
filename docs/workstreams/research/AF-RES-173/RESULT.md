## Q1–Q7

**Q1 요구.** B01/B02는 OOXML 문서 가용성과 metric 호환 목표, B03은 원 문서 글꼴 설정을 바꾸지 않는 런타임 표시, B06은 템플릿 참조 축소, B04는 QA 오류를 재현하는 숫자. B13은 수학 Greek 조판 옵션. 이들은 파일 복제, 동일 줄/쪽, 문자 표시에 대한 서로 다른 요구다. 로케일·임베딩은 개별 정확 입력에서 미확인. [S06](https://blog.documentfoundation.org/blog/2015/07/29/the-road-to-libreoffice-5-0/) · [S09](https://help.libreoffice.org/latest/en-US/text/shared/optionen/01010700.html?DbPAR=BASIC&System=MAC) · [S22](https://github.com/LibreOffice/core/commit/625f341d4c1e7e1043702687a55a972f55cb8ebb) · [S27](https://github.com/LibreOffice/core/commit/ec73b2894009a4cbb3446f8370b3de7bbbd5a35f) · [S33](https://ctan.org/ctan-ann/id/mailman.5238.1703488279.3764.ctan-ann@ctan.org)

**Q2 배포.** 4.4.0.3에서 WITHOUT_FONTS가 아니면 두 filelist 선언, 각 Bold/Italic/BoldItalic/Regular 네 TTF 설치 규칙. 실제 배포 파일 포함은 확인하지 못했고 원 Calibri/Cambria가 제거됐다는 증거도 아니다. DocRepair MORE_FONTS optional tarball hash는 결정 근거. TL 2024 final DB 존재는 확인했으나 19MB 본문 접근 오류, 2023/24 archive timeout, TeX author history는 패키지 기본값 결정일 뿐 배포 목록 대체 불가. [S07](https://mail-archive.com/libreoffice@lists.freedesktop.org/msg98312.html) · [S59](https://github.com/LibreOffice/core/blob/libreoffice-4.4.0.3/scp2/source/ooo/file_font_ooo.scp) · [S60](https://github.com/LibreOffice/core/blob/libreoffice-4.4.0.3/external/more_fonts/ExternalPackage_carlito.mk) · [S61](https://github.com/LibreOffice/core/blob/libreoffice-4.4.0.3/external/more_fonts/ExternalPackage_caladea.mk) · [S32](https://github.com/LibreOffice/core/commit/958cabd2e933ec85caf6eca4f0aacee77195fe7a) · [S10](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2024/tlnet-final/tlpkg/) · [S11](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2024/tlnet-final/tlpkg/texlive.tlpdb) · [S47](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2024/tlnet-final/archive/) · [S48](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2023/tlnet-final/archive/)

**Q3 원출전/이유.** Carlito 제작자 원문 Lato 파생/Latin·Cyrillic, OFL1.1과 RFN Carlito. Caladea는 Huerta Tipográfica 2012 Cambo 파생, 1.001의 2013 UFO sources, WGL418 glyphs와 4 styles, OFL1.1. 이 고지들은 실제 사용 파일과 연결해야 한다. 원 Calibri/Cambria 및 Helvetica/Euler 등 원 파일의 정확판/원저자 표시 미확인. TeX Gyre는 URW Nimbus Sans L 계열 및 GFL 표기; SticksToo는 STIX2 기반 재작업; UnBTeX는 subscript spacing, newpx는 asterisk, B06 선언 감소를 적었다. 권리 때문에 교체했다는 설명은 만들지 않는다. ## 조건부 대안·추가 분석
- 배포 담당자는 실제 bundle과 고지, 제작자는 glyph/metrics/출전, 다국어 작성자는 fallback·script·shaping, 독자는 누락 없는 실제 출력과 참조 연속성을 본다. 한 링크가 네 기준을 모두 만족하지 않는다.
- 가설 H1: metric-compatible 후보는 특정 시험 보존 가능성을 높인다. 경쟁 H2: 실제 font 선택, engine, text/style 및 QA 조건 때문에 결과가 달라진다. O01은 H1과 H2 양쪽의 증거(서로 다른 대체 후보), O02/O03은 경쟁 원인을 통제하지 못한다. O04/O05는 layout 변동 신호이나 정확 대체 효과는 아니다. 따라서 H1의 보편 명제는 보류, 목적별 후보 추천만 유지.
- 이름만 치환하거나 런타임 대체가 일어나는 B03/B09는 명명/실제 렌더를 분리해야 한다. B01 bundle 선언만으로 해당 파일이 실제 문서에서 사용되었다는 결론 금지. 포함됐는데 다른 폰트로 렌더된 동일 문서/누락 glyph와 같은 layout의 엄격 사례는 미확인.
- 페이지 참조만 필요하면 원 페이지 ID의 anchor mapping을 별도 보존(P01), 물리 페이지가 필요하면 동일 페이지 경계 검사. 원본 font 사용 권한/가용성이 없으면 렌더 재현을 꾸며내지 말고 원출전 링크, 대체 후보와 보존 미확인을 안내. 후속 실행에는 원 문서, 양쪽 font hash, renderer version/options, locale, style 모두 필요.
