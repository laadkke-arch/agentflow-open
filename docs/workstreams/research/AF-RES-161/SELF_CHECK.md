- 원장 고유 source_id 검사와 count_reason 집계는 함수 내부 JSON 파싱으로 수행(별도 환경 실행 아님). 84행 예상, 26 산입, history 2 (공통 계보 1). 첫 16 OL 원순위, 4 무관, 1 제안, 1 중복, 관련 10. WD 16 자리는 미복원(최초 8/확장 후보 8); 실제 0건 결과라는 뜻 아님. frame 58행(34 OL +16 WD 미복원 +8 보강). transactions 21행, fields 22행, citations 8행. ④ 보정에서 W05–W08 추가했으나 자연 분모/산입 하한 불변.
- 강한 경쟁 설명: 후속 편집이 없다면 full restore도 유효할 수 있고, 역 diff가 반드시 더 낫지 않다. KG-A는 next-edit 직접 확인으로 이를 지지하지만 실제 수행은 Undo. W07 빠른 복구 보고도 무손실 증명 아님. 실제 전체판 무손실 반례 미확보로 강한 판정을 낮춤.
- 역방향: KG-A 후 KG-B의 P910은 1분 차이 별도 undo; 모든 관계가 한 번에 복구되지 않았다. W01과 #6271은 보고로만 보존. #5664는 실패이지 성공한 부분복구 아님. W05 후속 링크 추가 보고에는 실제 복구가 없음.
- 원판 블록은 보존율 0으로 바꾸지 않음. 150의 구성 실험을 운영 사건으로 다시 세지 않음. 외부 편집/실행 없음. GitHub 원격 파일/경로 비교는 API 사용; git diff --check 및 workbench 계약 검사는 실행하지 않았으므로 HANDOFF에 재개 명령을 둔다.
