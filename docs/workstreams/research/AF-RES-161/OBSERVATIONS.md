# ③ 주 관측
- 교정 C1/C2는 같은 게시물에 등장하지만 구성원과 revision 조인 키가 없어 미확인. C3도 독립 예시로 분리. 실제 제목·설명·표지·주제 값은 모른다. 손실 보고 네 필드와 직접 손실 0건을 혼동하지 않는다.
- 자연층은 원판 연속 관측 0/16 OL, WD 16자리 원순위 미복원. 2019 WD-KG는 시간창 밖 보강이며 빈자리를 채우지 않는다.
- KG-A는 D02N의 next-edit가 병합→undo 직행임을 직접 확인했다. KG-B는 별도 객체의 봇 P910 변경 및 수동 undo를 확인했다. 두 편집 계보를 원전 2개로 세되 동일 사건 1개, 네 시점 중 독립적인 후속 무관 편집은 0(수신자·하류 각각 next-edit 확인); 봇 변경 1은 병합 의존. 선택한 무관·안정 필드 보존 4행, 직접 손실 0행(선택 필드만); 전체판 동치/원본 항목 복원은 확인하지 않았다.
- OL #5664의 후속 2017 병합 및 2024 validation error는 전체 rollback이 실패할 경쟁 설명. #5206의 copied dump는 댓글 자체를 읽은 것이며 원판 직접 판독 아님. #6371 역 diff 적용은 2023 제안일 뿐.
- ② 원장 Ixxx 본문 행의 요약에 댓글 관측도 포함되어 있다. 댓글에서만 나온 값은 IxxxC와 정확한 comment ID로 귀속한다. ② 커밋 원판 유지. D02N은 D02의 동일 저작 재열람이다.
