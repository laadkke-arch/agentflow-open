# AF-RES-016 — 자기 점검

## 1. 점검 결과와 완료 판정의 범위

산출물 구조·동결·원응답 보존·표본 재현·수치 일관성의 기계 점검은 **72개 PASS**다. 별도 내부 감사도 원 198행에서 점추정과 5,000회 cluster bootstrap을 재계산해 수치 오류를 발견하지 않았다. [validation.json](evidence/validation.json), [verification-audit.md](evidence/verification-audit.md)

**전체 요청을 무조건 완료로 표시하지 않는다.** 방법·체계 문헌의 최소 개수와 실행 산출물은 충족했지만, Q3에서 지정한 Hooper(1965)·Markey(1984) 원문 본문은 추가 보강에도 확보하지 못했다. 아래 §3에 막힌 이유와 답을 바꿀 최소 추가 확인을 적었다. 사용자 지시의 “보강할 수 없으면 그 행에 이유와 최소 추가 확인을 적는다” 예외에 따라, 이 미충족을 숨기지 않는 HANDOFF를 다음 단독 커밋으로 작성한다.

추가 조사만32질의·10URL, 지정 원문 확보0/2다. 검색 입력·관측·실패는 [reliability-supplement.json](evidence/reliability-supplement.json)에 있다. 본문을 읽은 MS01/MS02는 후속 자료이므로 두 원문의 대체물이나 최소 자료 증가분으로 계산하지 않았다. Cohen(1960) 원문도 미열람으로 구분했고, 같은 저자의1986 회고 M06과 실제 지표 방법 원문7건을 사용했다.

이 공백은 자료가 존재하지 않는다는 뜻이 아니다. 접근 가능한 새 원문이 필요하다는 뜻이며, 사람에게 연락·로그인·유료 구입·제한 우회는 작업 범위에 없었다. 현재 브랜치의 수치와 원응답은 이 공백 때문에 수정할 대상이 아니다.
