## 6. Q7 0/30에 대한 핵심 감사

불일치가 있는 고유 단위 59개(011 47·012 10·004 2)를 ID 순서로 정렬하고 `round(i×58/29), i=0..29`로 고른 30개는 서로 다르며 선택 규칙과 정확히 맞는다. 영향 JSON의 A/B 역할도 동결 코딩과 일치한다. 판단의 구성은 다음과 같다.

| 재확인 항목 | 값 | 해석 |
| --- | --- | --- |
| 전체 판단 객체 A/B가 다른 행 | 0/30 | 독립 재판정의 관측 변화율은 아님 |
| 알려진 mismatch | 1/30 | 004-R03의 같은 사용 구성에 대한 판단 |
| INSUFFICIENT | 14/30 | 근거 부족의 유지이지 충분한 근거 아래 무영향 확인이 아님 |
| 전체 판정 라벨 null | 15/30 | 조언·비교 10개와 필수 기준이 부족한 실제 대안 제안 5개 |
| H 목록이 비어 있는 행 | 18/30 | 모든 필수 조건 통과라는 뜻이 아님 |
| 추가 사용 가정의 T 대비 | 2개, 주 변화 분자에는 0개 | proposed_use/근거가 달라진 H 가설 예시 |

`build_impact.py`의 `add()`는 작업자가 작성한 하나의 `common` 판단을 `judgment_a`와 `judgment_b`에 복사하고 `label_only_changed=False`를 기록한다. **현재 생성 경로 자체가 양쪽 판단의 동일성을 유지한다.** 따라서 0을 새 독립 관측에서 추정한 영향 빈도라고 부르거나 binomial 상한을 붙여서는 안 된다. 검토할 수 있는 실질은 각 공통 판단의 근거와 역할명만으로 must를 삭제하지 않았는지다.

현재 `IMPACT.md`는 이 사실을 숨기지 않고 §1에서 설명하며, §6에서 역할 무영향의 상한 추정도 아니라고 명시한다. 최종 문서의 완료 설명은 “불일치 30개에 대한 조건부 문서 판단 감사 완료; 역할 표지의 독립 H/T 영향 실험 미실시”로 분리하는 것이 정확하다. “0/30이므로 역할 불일치는 측정 잡음”이라는 결론은 지지하지 않는다.

실제 역할 표시 효과를 확인하려면 같은 대상·사용·근거를 유지한 새 사례에 역할 표시 없음/A/B를 무작위 배정하고, 기존 라벨과 공통 판단을 보지 않은 평가자가 H/T를 별도로 작성해야 한다. 현재의 SQLite·Postgres 2개 대비는 추가 가정이 사용 단위를 바꾸므로 그 실험의 대체물이 아니다.
