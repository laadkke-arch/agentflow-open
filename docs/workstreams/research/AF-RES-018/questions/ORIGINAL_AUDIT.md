# 질문 원판 회수 감사 — 실행 전

고정 011의 질문 33개(본표 30 + 엄격 N 보조 3)를 선택했다. 최초 질문판을 확인한 Stack Exchange 19개는 `original`, 나머지 14개는 고정 011 요약 입력이다. `original`은 현재 페이지가 열렸다는 뜻이 아니다. revision_number=1 본문의 정규화 SHA-256을 재확인한 질문만 포함한다. 본문 전문은 저장하지 않는다. 원판을 회수하는 명령은 입력 파일에 있으며 질문만 출력하고 답변을 가져오지 않는다.

## 원판과 과거 코딩의 차이

| ID | 실행 전 확인 | 처리 |
|---|---|---|
| T001 | 최초판은 공개 소스·자체 호스팅·모바일 조건을 담지만, 011 요약의 모든 상세 기능을 열거하지 않는다. | 원판만 A/P에 전달한다. 과거 코딩을 입력의 추가 조건으로 주입하지 않는다. |
| T002 | 최초판의 GUI는 선호이며 벡터 출력은 최초판에 없다. | 후속 요구를 새 필수조건으로 넣지 않는다. 공개 소스 조건은 최초판에도 존재한다. |
| T006 | 최초판은 무료를 선호하되 적절한 대안이 없으면 유료도 허용한다. | 가격 선호와 필수 공개 소스 조건을 혼동한 배제는 감사 대상이다. |
| T009 | MongoDB 유지 조건은 011의 후속 반박 기록에서 나타나며 최초판에 없다. | 최초판 N 구성에 이 조건을 사용하지 않는다. 고정014 정답과 최초판 적합성의 차이를 별도로 다룬다. |
| SXR05 | 최초판에는 Java 명령행 파싱과 자료형이 있지만, 뒤에 추가된 ‘옵션 이름 사전 선언 없음’은 없다. | 고정 011의 picocli/args4j N을 최초판 기준 N으로 자동 승격하지 않는다. gold에서 판별 가능한 범위를 따로 적는다. |
| SX01 | 최초 질문 생성일은 API 기준 2016-08-11이다. | 초기 보조 목록의 추정일 대신 확인한 생성일을 metadata에 쓴다. |
| T019·T049·T054·T058 | 고정 011 표본에도 2026-06-01 이후 질문이 있다. | ‘011/새 질문’은 표본 출처 구분이다. 모든 011 질문을 오래된 날짜라고 부르지 않는다. 새 표본은 011 전체61개와 중복 제거한다. |

## 재현

```bash
python docs/workstreams/research/AF-RES-018/questions/generate.py --emit T001
```

해시 불일치나 접근 오류가 나면 현재 본문으로 조용히 대체하지 않는다. 해당 실행을 차단/부분 실행으로 표시하고 두 조건의 입력 동일성을 확인한다. `--fetch-old`는 회수 시점 자료를 재생성하는 명령이며, 동결한 파일을 덮어써 재실험 입력을 바꾸는 명령으로 사용하지 않는다.

## 한계

현재 HN·Reddit·Lobsters 본문을 읽어도 최초판을 입증할 수 없었다. T044 웹 열람은 DisabledError, T054는 웹 오류와 익명 GitHub API HTTP403, T059는 본문 없는 페이지였다. 실패한 경로와 현재판 열람은 `original-retrieval.json`에 구별한다. 비-SE 웹 호출은 정확한 호출 초를 기록하지 못했으므로 통합 기록 시각임을 명시했다. 원판이 회수되어 과거의 조건 코딩과 달라진 사례는 층별 해석의 한계이며 코딩을 소급 재설계하지 않는다.
