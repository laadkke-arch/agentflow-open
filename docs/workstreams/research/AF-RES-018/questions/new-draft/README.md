## 정답과 검사 후보의 해석

정답은 AF-RES-014 `42dc266dfd096bcc3c71f951fe0d9176f2eb9fd9:qrels/RULES.md`의 2/1/N/0 규칙을 적용했다. 채택 답이나 실제 사용은 등급2이며, 감사·시도 의향은 등급2로 올리지 않았다. 한 답의 여러 실체를 개별 후보로 분리하고, Sourcey처럼 두 답이 같은 제품을 추천한 경우 한 번만 셌다. 제품 이름의 중의성, 구성 요소의 기여, 상충 조건은 `note`로 남겼다.

엄격 N 제안 11개는 플랫폼·버전·요금제·구성 범위를 유지해야 한다. 특히 Proton Mail **Free**, MailEnable **직접 운영 서버**, Flameshot **14.0 RC의 Wayland 구성**, gpt-oss-120b **MXFP4 모든 가중치 GPU 상주**를 일반 제품 전체로 넓히지 않는다. N015의 Node.js 회피는 원문의 should 표현이므로 선호로 보는 민감도 분석을 함께 한다. N001의 플랫폼·Qt6 선호를 필수로 올리지 않는다.

나머지 N002·N003·N008·N009·N013·N014·N016·N018·N019는 엄격 N을 입증하지 못했다. 각 질문의 두 번째 검사 슬롯에는 공식 실체를 확인한 `auxiliary_unjudged` 후보를 넣었다. 실제 3후보 유지/제외 판단은 수행할 수 있지만, 이 9개는 엄격 N 거절률 및 양성 오거절률 양쪽 분모에서 제외한다. **모든 질문에 양성·엄격 N·무관의 세 역할이 완비됐다는 조건은 충족하지 않는다.**

PBS FAQ와 Crash JS의 양성 실체 URL은 채택 답에 실제로 있는 링크다. 각각 공식 페이지 열람 불가와 고정 코드 페이지 DisabledError로 본문을 확인하지 못했다. 이 실패를 새로운 기능 확인이나 N 판정으로 바꾸지 않는다.

## 결론을 바꿀 수 있는 사례

`counterexamples.json`에 자세한 근거와 추가 확인을 남긴다. 이는 아직 P의 실제 오거절을 관측했다는 뜻이 아니라, 이후 실행에서 확인해야 할 입력/정답 충돌이다.

- N004: Pentaho 채택과 오픈소스 금지 사이의 관계는 에디션이 불명이라 미정이다. Debezium에 상용 지원을 붙인 답도 별도로 있다. 상용 지원과 소스 공개 여부는 다른 속성이다.
- N005: Caddy를 채택하면서 단순성의 의미가 완화됐고 배포 OS 선호도 바뀌었다. 실제 채택을 지우거나 최초 조건을 나중 답에 맞춰 고치지 않는다.
- N010: 질문은 단일 바이너리를 원했으나 질문자는 여러 실행 파일인 sshguard를 사용했다고 명시했다. 채택 적중과 엄격 조건 충족이 반대 방향으로 움직일 수 있다.
- N020: 8GB GPU를 전제로 질문했지만 24GB GPU를 산 뒤 Qwen3.8-27B Q4를 사용했다. 공식 모델 출시도 질문일 뒤다. 하드웨어 고정 및 질문일 가용성 민감도를 별도로 보고한다.
- N008·N013·N016: 기존 도구의 일부 한계, 다른 실행 위치, 라이선스 이름만으로 유용한 구성까지 모두 배제하면 잘못된 N을 만들 수 있다.

## 재현과 부모 통합

다음 명령은 저장된 요약·매핑을 다시 만든다. 질문 동결 이후에는 `finalize_samples.py`를 임의로 다시 실행하지 않는다. 본문 다운로드 재현은 `NORMALIZATION.md`와 개별 `revision_loader_url`을 사용하며, 전체 본문 파일을 만들지 않는다.

```bash
python docs/workstreams/research/AF-RES-018/questions/new-draft/build_gold_draft.py
python docs/workstreams/research/AF-RES-018/questions/new-draft/build_checks_and_sources.py
python docs/workstreams/research/AF-RES-018/questions/new-draft/build_search_log.py
python docs/workstreams/research/AF-RES-018/questions/new-draft/audit_draft.py
```

부모는 gold/checks를 최종 경로로 복사하고, 판단 대상에는 후보명과 실체 URL만 보낸다. 등급·정답 근거·분모 자격·source IDs·반례 요약은 검색 작업자에게 전달하지 않는다. 두 조건의 최초 실행 전에 이 정답/검사 묶음을 커밋한다.

## 한계

이는 접근 가능한 질문을 목적 표집한 것으로 무작위·대표 표본이 아니다. GitHub 1개는 하나의 저장소에서 왔고, HN이 50%다. 새 질문 중 최초판은 9/20뿐이다. 반복·변경된 현재 제품 문서와 질문 시점의 상태를 혼합하지 않는다. 정답은 커뮤니티 답변/채택 기록이며 기능 진실성이나 객관적 우수성의 증명이 아니다. 9개 질문에 엄격 N이 없고, 일부 N 제안의 해석 민감도가 남아 있다. 수집 단계의 일부 과거 검색 문자열과 정확한 웹 열람 초는 남아 있지 않아 `SEARCH_LOG.json`에 그 결손을 명시했다. 웹 도구는 원본 HTTP 숫자 상태를 노출하지 않아 모든 공식 호스트의 숫자 사전 점검을 충족했다고 주장하지 않는다.
