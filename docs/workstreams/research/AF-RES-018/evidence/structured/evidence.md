# 다른 분야에서 구조화 절차가 얻은 것과 얻지 못한 것

## 결론과 적용 범위

**구조화의 이득은 누락 방지, 정보 결합의 일관성, 증거 갱신에서 기대할 수 있지만, 정확도와 검토 부담이 함께 좋아진다는 일반 법칙은 확인되지 않는다.** 직접 읽은 14편은 임상 판단, 수술 안전, 정보 분석, 채용 면접, 문헌 종합의 다섯 분야를 다룬다. 실증과 방법론 논의를 구분했으며, 이 문헌들이 AF-RES-018의 A/P 차이를 대신 입증하지는 않는다. 이 문서는 A/P 결과를 보지 않은 상태의 비교 자료다.

자료별 실제 열람 주소·읽은 절·확인 내용·한계·웹 참조는 [sources.json](sources.json), 실제 질의 40개와 실패 기록은 [SEARCH_LOG.json](SEARCH_LOG.json)에 있다. 본문을 확보하지 못한 11개 경로는 제외 목록이며 문헌 수에 넣지 않았다. 원문 전체는 저장하지 않았다.

## 2. 정확도와 비용이 함께 움직이지 않는 직접 사례

STR12의 전문 심전도 판독 실험은 Q7에 특히 가깝다. 15명의 전문가가 수행한 검증 조건당 89개 판독에서 체크리스트는 순수 교정 오류 수를 늘렸지만 검증 시간은 평균 63초 대 35초, 추가 문자 수는 24 대 4였다. 따라서 정확도 이득을 곧바로 검토 부담 감소로 해석할 수 없다. 이 연구의 시간은 전문가 자신의 검증 시간이며 AF-RES-018에서 측정하지 않는 독자의 검토 시간과 같지도 않다. [STR12]

이번 실험에서는 첫 관련 후보 순위, 단어 수, 명시적 미확인, 근거 없는 주장, 검색·열람 수, 벽시계 시간을 각각 보고해야 한다. 가령 오류율이 낮아지지만 모든 후보에 미확인이 붙는 경우와, 오류율은 같지만 첫 관련 후보가 빨리 나오는 경우를 한 숫자로 합치면 H1의 어떤 부분이 달라졌는지 사라진다. 이는 지표 해석에 관한 추론이며 사전 기준을 결과에 맞춰 바꾸자는 제안이 아니다.

## 5. 자료 수와 독립성

직접 본문을 읽은 방법·비교 문헌은 14편이다. 같은 사이트를 기관 도메인 단위로 합쳐도 Cambridge 2편, umn.edu 2편이며 다른 사이트는 각 1편이어서 사이트당 최대 3편 조건을 만족한다. 이 하위 묶음 자체에는 25편 전체 기준을 주장하지 않는다.

STR07·10은 원 저자의 이론·방법론 문헌으로 신규 실증 두 건으로 세지 않는다. STR03·04는 같은 50명 분석가 표본의 과정·정확도 분석이므로 독립 실험은 하나다. STR05·08 역시 기존 선택 평가 문헌의 종합과 재검토로서 독립된 두 신규 면접 실험이 아니다. 문헌 수와 독립 표본 수를 혼동하지 않았다.

## 한계

분야 간 효과 크기를 합치지 않았다. 환자 사망, 행동 단계 누락, 상관 타당도, 확률오차는 서로 다른 성과다. 수술 전후 연구의 잠재적 혼란과 모의 실험의 외적 타당도도 서로 다르다. 문헌 고찰의 범위는 사용자 지정 사례와 반증 검색에 집중했으며 완전한 체계적 문헌고찰이 아니다.

Urbach 본문의 Table 2 비교 p값과 소득을 추가한 회귀 분석 p값은 구별했다. 초록에 제시된 합병증 OR의 구간은 .90–1.03인데 HTML 본문 OCR의 한 줄에는 .80–1.03으로 나타난다. 이 문서는 논문의 주된 무효과 방향과 Table 2의 관측률만 사용하며, 그 OCR 차이를 새 효과로 해석하지 않았다.

접근 시각은 개별 호출별 초 단위가 아니라 UTC 읽기 세션 구간으로 보존했다. 첫 8개 호스트의 익명 HTTP 응답은 NETWORK.json에 있다. 후속 호스트 점검의 출력 조회는 자동 심사에서 차단 호스트 우회 우려로 거절되어 재시도하지 않았다. 실제 제출 목록에 심사가 지목한 web.archive.org는 없었다. 해당 경로의 HTTP 코드가 확인되지 않은 것과, 정상 공개 웹 열람으로 논문 본문을 확보한 것은 별도 사실이다. 이 사건 때문에 이미 확보한 문헌을 미열람으로 취급하지 않는다.
