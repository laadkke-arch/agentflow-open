# 내부 별도 블라인드 판정 규칙 — 실행 전

## 평가자가 받는 것

배정된 질문의 원판 재현 입력 또는 요약, 조건을 가린 후보 이름·URL·30단어 이하 이유, 이 규칙을 받는다. 원 실행 파일, 조건 키, gold, 결과표, 다른 평가자의 판정은 읽지 않는다. 파일 접근 제한은 지시이며 OS 격리를 주장하지 않는다. 평가자에게 A/P의 결론이나 어느 조건이 더 나아야 하는지 알려 주지 않는다.

후보 행의 원 순위·조건·모델 표시·P 전용 항목 이름·004 라벨은 제거한다. 질문 안에서 무작위 순서로 제시하며 동일 실체가 두 번 나오더라도 각각의 주장 범위를 보고 판정한다. 질문과 후보의 사실 관계가 같다면 표현이 더 길거나 정형적이라는 이유로 등급을 바꾸지 않는다. 길이 정규화는 사실을 개선하는 편집이 아니다.

## 판정 값

- `relevance`: `1`(질문의 전부/부분에 유용하고 결정적 위반을 확인하지 않음), `N`(같은 문제 범주의 근접 후보이나 실제 필수 조건을 위반), `0`(다른 문제·무관·표면적 이름 유사), `U`(판정에 필요한 사실이 확인되지 않음). 실제 채택/사용 `2`는 외부 기록의 값이므로 이 평가자가 만들지 않는다.
- `L`: ok/broken/missing. 후보 주소가 실제 해당 실체/출처로 연결되는지다.
- `E`: supported/contradicted/unknown. 제공된 이유의 사실 주장을 출처가 뒷받침하는지다.
- `H`: pass/fail/unknown/not_in_scope. 필수 조건별 대상·극성·적용 범위를 보존한다.
- `T`: not_needed/mapped/analogy_only/unknown. 전체 해결이 아닌 참고/전이 관계일 때 실제 연결 작업을 설명할 수 있는지다.
- `label`: 결정적 위반/작동관계 불일치는 `SURFACE_OR_CONSTRAINT_MISMATCH`; 결정적 사실이 미확인이면 `INSUFFICIENT`; 좁힌 전이 관계와 실패 조건이 구체적이면 `CONDITIONAL_TRANSFER`; 해당 설정의 필수조건과 주장이 문서로 뒷받침되면 `DIRECT_DOCUMENTED`.

‘확인 필요’를 위반으로 바꾸지 않는다. 원문에 없는 필수조건을 새로 만들지 않는다. 선택적 요구를 위반했다고 근접 오답으로 판정하지 않는다. 목적에 맞는 다른 새 후보를 실제 답 목록에 없다는 이유로 무관 처리하지 않는다. 원 질문이나 답변 스레드의 외부 정답은 검색하지 않는다.

후보의 실제 최신 공식 문서/공개 코드에 접근할 수 있으면 읽어야 한다. 열람한 URL, UTC 시각, 확인 범위를 기록한다. 현재 문서로 과거 기능이 있었다고 소급하지 않는다. 각 판정은 문서 기반이며 직접 설치·실사용을 주장하지 않는다. 평가 단계의 문서 열람은 실행자의12/20 예산에 합산하지 않고 평가 비용으로 따로 기록한다.

## 제출 형식

각 opaque row_id마다 relevance, L, E, H, T, label, must_violations(조건·판정·근거URL·범위), evidence_urls, reason, checked_at_utc, judge_model_label, limitations를 쓴다. 판정 원문도 별도 raw_response에 보존한다. 조건을 추정하거나 그 추정을 판정에 사용하지 않는다.

## 서로 다른 판정 출처

주 분석의 채택·추천 정답은 실제 커뮤니티 답/질문자 사용 기록에014규칙을 적용한 외부 기록이다. 별도 내부 평가의 관련성은 전체 후보 풀에서 판정되며 채택 정답을 대체하지 않는다. 두 출처의 A/P 순서를 비교하되 서로 다른 분모의 수치를 같은 성과라고 부르지 않는다.

같은 모델 계열의 새 문맥 판정 외에, 작업공간의 명시적 모델 선택 기능을 사용하여 다른 구성 모델의 추가 판정을 시도한다. 선택한 모델명과 실제 도구 응답에 나타난 표시를 함께 기록한다. 선택 실패 시 같은 모델을 다른 모델이라고 보고하지 않는다. 다른 모델도 내부 모델 판정이며 외부 사람 검토가 아니다.

## 한계

조건 가림과 무작위 순서는 위치·길이·자기 선호를 완전히 제거하지 않는다. 같은 후보의 조건별 라벨 변화, 평가자 간 순서 역전, 정규화에서 사라진 범위 표현을 결과에 보고한다. 불일치한 원 판정을 사후 합의값으로 덮어쓰지 않는다.
