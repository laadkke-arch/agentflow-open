# 사실 주장 추출·검증 규칙 — 실행 전

## 단위와 추출

검사후보를 받기 전에 동결한 `raw_response`의 후보별 사실 주장만 대상으로 한다. 가격, 라이선스, 오프라인, 자체 호스팅, 플랫폼, 구체 기능을 원자적 주장으로 나눈다. 원문에서 어느 부분을 추출했는지 실제 문자열과 위치를 남기며, 후보에 관해 알고 있다는 이유로 출력에 없는 사실을 더하지 않는다. 선호·권고·미래 계획·추론·실행자가 명시한 미확인은 사실 단정과 구분한다. 한 문장의 두 독립 사실은 두 주장이다. 같은 답에서 같은 사실을 되풀이하면 한 번만 센다.

주장 원장은 발견 단계의 모든 후보를 대상으로 만든다. 출력 자체가 가격/기능을 단정하지 않고 확인 필요라고 한 문장은 `uncertainty` 원장에 남겨 Q7에 쓰며 참/거짓 분모를 채우는 사실 주장으로 만들지 않는다. 각 사실에 주어진 근거 URL을 연결하고, 후보 홈페이지 URL만 제공된 경우도 별도 표시한다. ‘URL 존재’와 그 URL의 실제 지지는 다른 속성이다.

추출자는 사실의 맞고 틀림을 보고 고르지 않는다. 검증을 시작하기 전에 추출 풀과 표집 목록을 기록한다. 원 응답에 없는 문구가 없는지는 문자열 대조로 감사한다.

## 고정 표집

조건마다 80개(요구 최소75개 이상), 합계160개를 목표로 한다. seed=18018의 동일한 재현 알고리즘을 쓴다. 각 조건에서 질문 ID를 정렬하고 사실이 있는 질문마다 주장 하나를 무작위 추출한 뒤, 나머지 풀에서 중복 없이 80개까지 채운다. 특정 유형의 오류가 잘 보인다는 이유로 교체하지 않는다. 풀이80개 미만이면 전부 검증하고 부족한 이유를 남긴다. 나머지 주장은 전체 출력의 URL·미확인 감사에만 쓸 수 있고, 표집 검증의 참/거짓 결과로 간주하지 않는다.

## 현재 공식 자료 판정

| 값 | 기준 |
|---|---|
| 참 | 현재 공식 문서/공개 코드가 주장한 제품·판·요금제·플랫폼·범위를 직접 뒷받침한다. |
| 거짓 | 같은 범위의 현재 공식 문서/코드와 명시적으로 모순된다. |
| 확인 불가 | 접근 실패, 기능 비언급, 범위 불명, 서로 다른 공식 자료 충돌, 실제 실행이 필요한 성능·완전성 등으로 참/거짓을 정할 수 없다. |

부정 주장도 같은 원칙이다. 문서에 없다는 이유만으로 지원하지 않는다고 판정하지 않는다. ‘무료’는 어떤 이용/판/계정 한도인지, ‘오프라인’은 설치·인증 이후인지, ‘자체 호스팅’은 필수 외부 연결이 있는지 확인한다. ‘지원’이라는 말이 플러그인·추가 작업을 허용하는지 원 응답의 범위를 보존한다. 기능 목록이 모든 운영체제에서 동일하다고 일반화하지 않는다.

011 질문의 현재 검증은 추천 당시의 역사적 사실과 다르므로 `temporal_basis=current`를 명시한다. 새 질문에도 확인 시각을 남기며 질문 이후 변경 가능성을 없다고 가정하지 않는다. 역사 자료는 별도 보충 근거다. 표집 이후 접근이 실패해도 더 확인하기 쉬운 주장으로 바꾸지 않고 확인 불가로 남긴다.

거짓의 오류 유형은 `outdated_information`, `product_confusion`, `version_or_plan_scope_omission`, `unsupported_generalization` 중 주요 하나와 보충 설명이다. 오류 발생 과정을 직접 관측하지 못했으면 원인을 확정하지 않고 가능한 유형임을 표시한다.

## 기록과 분석

CLAIMS.json 각 행은 id, condition, qid, candidate, claim, claim_type, evidence_url, checked_at_utc, verdict, error_type, judge를 포함한다. 추가로 원 응답 위치/인용, 제품 범위, 확인한 내용, 접근 결과, current 기준을 남긴다. 검증자는 내부 별도 검토이며 사람이 아니다. 오류율은 거짓/(참+거짓), 확인 불가는 전체 표집 중 별도 비율이다. 보수 하한/상한은 거짓/전체와 (거짓+확인불가)/전체다. 질문을 군집으로 한 paired bootstrap에서 사실160개를 독립 질문160개로 세지 않는다.

## 한계

공식 문서에 대한 현재 대조는 실제 설치·통합 시험이 아니다. 표집한 주장 이외의 사실까지 확인했다고 부르지 않는다. 내부 모델이 추출과 판정을 도우며, 명시적 인용·범위 감사로 확인할 수 있는 오류와 모델 계열의 공유 편향을 구분한다.
