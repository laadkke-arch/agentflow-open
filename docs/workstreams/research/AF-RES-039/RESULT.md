H 수는 표시/입력 검증 바이트 순이다. 시간은 작업 프로세스의 벽시계/논리 요청 경과 합 순이다. 표 2의 엄격 기준은 같은 실행의 문서 교환을 두 번째까지 절단한 것이다. 실제 C2 G02는 세 번째 교환도 수행했다. 비용표의 모의 열은 **참조별 합**이며 036의 공유 취득 결과와 단위가 다르다. [짝 비교](pairs.csv) · [감사 영수증](evidence/receipts.json)

- **T현재** — C1과 C2가 각각 1/12에서 목적 절과 행동을 확인했다. 두 구현의 출력은 유지 1, 보류 11로 같았다. 같은 조회창에서 기준을 세운 G02/G05/R01/R03만 따지면 각 1/4를 확정했고 3/4는 보류했다. 나머지 8/12의 기준이 미확인이다. 네 기준은 036의 유지·교체 방향과 일치했다. R01에서 실제로 다시 읽을 수 있었던 교체 절은 최신 release 경로이고, 036에서 쓴 3.11 경로의 상태는 미확인이다. 공개 웹 응답은 당일 조회했으며 도구가 전날이나 사흘 전 크롤한 표현도 포함한다. [기준과 확인 범위](evidence/current-criteria.jsonl)
- **T복원** — 정확 N은 각 1/12, H 발췌 표시는 C1 0/12, C2 12/12다. 두 조건을 동시에 충족한 짝은 G02 C2 한 건이다. G02 C1은 태그 목록을 받았고 H 본문은 찾지 못했다.
