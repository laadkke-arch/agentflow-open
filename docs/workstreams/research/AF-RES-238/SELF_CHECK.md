## 자체 검산과 독립 검토

정상 실행기의 실제 수신 시도와 영수증 재생을 했다. 영수증 재생 exit 2는 원자료가 없어 명제를 보류한 결과다. `python -I .../verify.py`는 기존 정상 진입점으로 합성 성공·실제 실패·위변조 거부를 검사했으며 exit 0이다. 테스트에서 발견한 주 API URL 전달 결함을 수정했다. 후속 독립 검토자의 평가와 실제 판독은 미실시다. [실행 로그](receipts/run-archived-attempts.json) · [자체 시험 로그](receipts/verify-local.json)
