# 짝짓기 결과

대조 후보 70개에서 동일 범주, 최초 도달 가능 커밋의 연도, T 전 365일 비병합 작성자 수 구간을 검토했다. 선택한 비교 행 40개 중 두 수치 조건·범주와 확인 가능한 범위 조건을 갖춘 엄격 짝은 7개다. 탐색 20개, 서비스 유사 8개, T 미확정 5개도 보존했다. 최초 Git 이력은 현재 기본 브랜치에서 도달 가능한 뿌리다. Vue 2처럼 이력이 이동한 경우 공개 최초 시작과 달라질 수 있다.

- [수치 원장](MATCH_FACTS.json)과 [선택된 비교](CONTROLS.json)는 작업자 판정이다. 각 행에 고정 SHA, 관측 창, 자료 경로, 범주 근거와 확인 한계를 붙였다. 파일 존재·공식 문구·레지스트리 확인으로 한정한 무사건 판정이며 내부 연속 운영을 증명하지 않는다.
- [제외/대체 후보](UNSELECTED.json)에서 SciPy는 연도와 구간을 만족해도 1.13 릴리스에 별도의 수치 API 제거가 있었다. 반례를 기록했고, SymPy는 유사 범주의 탐색 행으로만 포함했다. [SciPy 1.13 release notes](https://docs.scipy.org/doc/scipy/release/1.13.0-notes.html)
- Directus의 수치상 후보 두 개를 비교했다. Payload의 옛 스냅샷에서 라이선스 계열을 자동 확인하지 못했다. Keystone 6은 양 끝 MIT 헤더가 확인되어 선택됐다. E03의 후보는 활동 구간은 같았지만 표식 변경과 당시 새 판을 함께 검증하기 어려웠다.
- 수치 프로필을 산출한 뒤 React·브래킷·UI 프레임워크·컨테이너·음성 인식·HTTP·드래그 도구 일부의 대체 후보를 한 번 더 조사했다. 사건과 임계값은 그대로이며 2차 후보는 candidate_round=2에 기록했다.
- 서비스는 운영 Git의 최초 커밋과 작성자 구간이 없으므로 엄격 짝을 입증하지 못했다. 같은 때 기능이 제공됐는지 확인할 수 있는 1차 날짜 자료를 보강해야 한다.
