## 네 정책

| 정책 | 일치 |
| --- | --- |
| A | 별칭 점수를 사용하지 않는다. |
| B | 선행과 같은 한국어 어절 완전 일치다. |
| C | B 및 마지막 어절에 `은, 는, 이, 가, 을, 를, 에, 에서, 로, 으로, 와, 과` 중 정확히 한 조사가 붙은 완전 어절을 허용한다. |
| D | 마지막 어절 내부 어디서나 별칭 부분문자열을 허용한다. 앞쪽 어절들은 B와 동일하다. |

네 정책에서 NFC, 선행의 영어 토큰과 심벌 가림을 사용한다. 한글 어절은 완성형 `[가-힣]+`의 최장 연속 구간이다. 앞 어절 사이에는 하나 이상의 Python 유니코드 공백 `\s`가 필요하며 줄바꿈과 탭도 포함한다. 문장부호·숫자·라틴 문자·밑줄은 어절을 끊고 다단어 별칭의 어절 사이를 이어 주지 않는다. 선행의 영문 심벌 검출은 대소문자·수신자·URL/경로 제외를 유지한다. 원문과 가림 모두 NFC 기준 0 시작·끝 미포함 코드포인트 오프셋이다. 각 가림 구간은 같은 길이의 공백으로 바꾼다. 따라서 가림이 경계를 새로 이을 가능성도 기록한다.

D는 B와 C를 포함한다. 붙은 문자열이 목록 밖이거나 한 글자 앞에 다른 글자가 있어도 D가 후보로 올릴 수 있다. 모음·받침에 따른 문법적 적합성은 별도 판독 항목이다. B→C와 C→D는 각 구간에서 처음 해당하는 전이로 표시한다. 같은 어구가 여러 번 나타나도 한 기능에서 그 별칭 문구는 한 번만 4점을 얻는다. 서로 다른 두 문구는 같은 구간 일부를 공유해도 선행처럼 각 4점을 얻는다. 심벌은 기능당 12점, 대소문자를 낮춘 후보 영어 어절과 질의 어절의 교집합은 서로 다른 어절당 1점이다. 동점은 ID순, 양수의 상위 8개 조사와 상위 3개 표시를 사용한다. 두 상한 아래에 후보가 없으면 공석이다.
