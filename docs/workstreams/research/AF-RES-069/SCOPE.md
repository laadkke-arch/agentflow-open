## 검색과 판정의 사전 규칙
- A: 프로젝트명·실제 기술·기능·오류 구문을 허용한 일상 검색. B: 순서·상태·입출력·제약·경계 입력의 관계 표현만; 미리 정한 분야·알려진 해법·후보명 금지.
- 문제마다 원문 위치/목표/필수조건(원문에 있는 최대 두 조건)/반례 입력/해법이 없을 때 선택/사전 노출을 problems.jsonl에 동결한다. 원문 조건과 연구자 해석을 분리한다.
- 같은 공개 검색 엔진 `system2_search_query`, 영어, 동일 세션 시간 창; 각 문제·갈래당 정확히 3 질의, 각각 반환 첫 5자리. 각 갈래 전체에서 최초 등장 순서의 서로 다른 원문 최대 5개 직접 열기. 재시도/실패도 한 번의 비용으로 기록하고 결과가 적으면 빈 자리 유지. 결과에는 검색엔진이 반환한 원순위만 사용한다.
- 질의는 양 갈래 모두 정답 노출 전에 커밋. 홀수 문제 A→B, 짝수 문제 B→A. 가능하면 같은 모델의 별도 문맥 작업자를 사용하며, 가림 실패/부모 문맥 유입은 별도 기록. 독립 사람 판독으로 부르지 않는다.
- 자료 획득 제한 때문에 `system2_search_query`의 첫 5자리가 출력되지 않으면 반환 전체/부족 수와 순위 미확정을 명시한다. 새 검색엔진으로 임의 교체하지 않는다.
- 판정 단위: 원문과 요구의 조건별 대응. 부품(직접 사용 가능/통합 미확인)과 원리(이전 조건 필요)를 따로 집계. 같은 이름·그림·일반 목적만 공유하면 부적격. 접근 못한 원문은 실패가 아니라 미확인.
- strict pair 분모와 observed pair 분모를 분리. 동결 반환 URL 합집합, 독립 저작 합집합, 직접 읽은 합집합을 각각 기록한다. 전체 웹 재현율, 원작자 선택 변화, 시간 절감은 미측정.
- 후보마다 필요한 조작/변수/목적 대응, 조건별 근거 절, 최소 기각 반례, 새 선택/다음 검사를 기록한다. A/B 공통/한쪽만/둘 다 실패는 동일 기준으로 계산한다.
- 판정 봉인 뒤 댓글/PR 및 최소 하나의 타 분야 실제 절차를 별도 보조 비교한다. 보조 발견은 검색 적중에서 제외한다.
