# P06 · 동일 요구 재검 · t1

모든 검사는 t0에서 선언한 dtype으로 [1,2,3]을 새로 생성한 독립 상태에서 시작합니다. 첫 채택의 같은 schema/대입 경계를 사용하세요.

1. index1=3.0
2. index1=1.5
3. index1='potage'

각 검사에서 허용/오류, 값 변경 전후, dtype 변경 전후, 검증과 실제 쓰기의 순서를 적으세요. P06-R1~R3별 유지 / 수정 필요 / 미확인과 근거를 연결하세요. 숫자가 같은 dtype으로 남았다는 사실만으로 손실 없는 대입이라고 판단하지 마세요.

수정이 필요하면 D-P06-COMPATIBILITY 또는 D-P06-SCHEMA 중 되돌린 결정을 적고 같은 원래 요구 ID를 연결하세요. NA를 새로 지원하는 변경은 별도 새 요구이며 이번 예방 가능 재작업에 넣지 않습니다.
