# P04 · 동일 요구 재검 · t1

t0 알고리즘과 errors='raise' 선언을 그대로 사용하여 P04-R1~R3을 재검합니다. 두 batch는 독립 입력입니다.

입력 1: ['12-01-2000 00:00:00', '13-01-2000 00:00:00'].

입력 2: ['12-01-2000 00:00:00', '01-13-2000 00:00:00'].

각 batch에서 format을 언제 확정했는지, 각 행에 적용한 format, 출력 또는 오류를 적으세요. 성공한 날짜 수 자체가 합격 기준은 아닙니다. 선언한 모드가 batch 전체에서 일관된지가 기준입니다.

요구별 유지 / 수정 필요 / 미확인과 근거를 적으세요. 수정 시 D-P04-FORMAT과 같은 원래 요구를 연결하고, 기존 제출판을 덮어쓰지 마세요. 새 API에서 추가된 mixed-format 지원은 이번 요구에 추가하지 않습니다.
