# N08 · 구매기록 집계 흐름 · t0

공개 인터넷 검색, 실행 도구, 도움 요청 규칙, 교육과 작업 예산은 모든 보기에서 같습니다. 진행자가 사전에 공통 공지한 예산·재검 간격·도구 정책을 적용하세요. 첫 채택을 선언할 때 결정 ID와 제출판을 고정하세요. 찾은 자료와 사전 인지를 기록하고, 실행하지 않은 결과는 미확인으로 적으세요. 후대 자료를 발견했다면 URL·판·첫 노출을 기록하세요. 이 과제는 문서·의사코드의 요구 합치성을 판독하며, 실행하지 않은 성공을 요구하지 않습니다.

## 상황과 최초 요구

2010년의 구매기록을 입력으로 받는 집계 흐름을 작성하세요. SKU별, 월별, 점포별로 number의 최솟값·최댓값·합계·산술평균을 각각 내세요. 입력 행의 순서는 보장되지 않습니다. 같은 키의 수량만 같은 그룹에 속해야 하며 결과에는 원 키를 붙이세요. 이 자료는 단일년이므로 월 키는 month 또는 (year,month)로 표현해도 됩니다. 작동 순서가 드러나는 설명/의사코드와 결과표, 선택 근거의 URL·절, 선택의 한계를 제출하세요. 특정 도구 이름은 합격 조건이 아닙니다.

계획 기준은 2010-04-27 작성, 2010-04-29 저장소에 추가된 공개 문서판입니다. 이 과제는 작은 집계 흐름을 설계하며 새 API 도입 정책 전체를 결정하지 않습니다.

- N08-R1: SKU별·월별·점포별 집계를 각각 제공하고 원래 필드를 다른 의미로 대체하지 않는다.
- N08-R2: 각 관측 그룹의 number에 대해 max/min/mean/sum 네 통계를 모두 낸다. 행 수는 수량 합계를 대신할 수 없다.
- N08-R3: 같은 키를 가진 원래 행의 수량만 함께 집계한다. 행 순서가 달라져도 키별 의미와 결과는 유지한다.

NEP8 원 필드와 의미를 유지한다. 이 과제지는 양의 작은 정수 수량, 단일년, 실제 관측된 비어 있지 않은 그룹을 사용한다. 결측·미관측 빈 그룹·성능 임계값·연도경계·분산 실행은 평가하지 않는다.

## 제출

선택한 처리 흐름과 대안 하나, 세 grouping의 키, 원행 배정 방법, 네 통계를 내는 의사코드 또는 동등한 설명, 세 결과표를 제출하세요. 원문 URL·절과 적용 한계, 실행 여부를 함께 적으세요. 첫 채택 선언과 제출판을 고정하고 D-N08-KEY / D-N08-MEMBERSHIP / D-N08-REDUCTION 결정 ID로 연결하세요. 분수 평균 표기도 허용합니다.
