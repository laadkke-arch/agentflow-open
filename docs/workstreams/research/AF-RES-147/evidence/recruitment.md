# 발표순 모집과 입력 고정

TZ의 창은 2022g 이후 2023a·2023b·2023c·2023d, 그다음은 2024a다. 2023c 공급자는 2023b를 되돌린 신규 발행임을 밝혔다. 2023a와 동등하다는 보고는 2023b에서 바뀐 답을 검사해야 하는 이유다. IANA 목록의 2023b·2023d 표기 날짜는 해당 메일의 UTC 날짜보다 하루 이르다. 각 메일의 명시 UTC는 최초 전송 발견의 대푯값이고 공개 객체의 최초 접근 가능 초는 미확인이다. 코드·데이터·결합 파일은 같은 판의 포장이다. [공식 목록](https://www.iana.org/time-zones/releases) · [원본 아카이브 색인](https://data.iana.org/time-zones/releases/) · [메일 및 고정 SHA](../editions.csv)

CLDR의 창은 42 이후 43·43.1·44·44.1, 그다음은 45다. CLDR 43 릴리스 노트의 43.1 문단에는 Beta 표현이 남아 있고 정식 목록은 2023-06-15와 정식 태그를 준다. 태그의 산출물과 정식 목록의 판 번호를 기준으로 포함했다. 44 출시 노트는 숫자 JSON의 npm판 44.0.1을 별도로 표시한다. npm의 숫자 패키지 44.0.0은 2023-09-14T19:18:30.778Z로 공식 Alpha와 같은 날, 44.0.1은 2023-10-31T19:11:54.471Z에 게시됐다. 43.1의 숫자 JSON은 2023-06-14T16:58:17.423Z, 두 44.1 JSON 패키지의 게시 시각은 numbers-full 2023-12-13T17:31:21.110Z와 core 2023-12-22T17:48:39.232Z다. 이는 채널 시각이며 정식 XML 자료 발표 시각으로 전환하지 않았다. TZ-A는 2023b 레바논 일정 변경 공지에서 가능한 전환일 중 가장 이른 03-25의 다음 날을 사용한다. TZ-N은 같은 Zone에서 UTC 기준 7일 앞서며, 공지 층과 분리한다. CL-A는 43.1 출시에 실린 CLDR-16247의 en_ZA 두 기호 중 UTF-8 정렬 첫 요소 decimal, CL-N은 같은 부모 아래 group이다. 따라서 인접 CL-N도 변경이 예고되었다. 같은 파일의 인접 대조는 불변을 보장하지 않는다. 43.1의 en_ZA, en_001, en에는 defaultNumberingSystem의 직접 노드가 없고 root에는 latn이다. 선정 때 메타데이터 노드만 추출했다. 이때 대상 decimal/group, 규칙/TZif 출력은 판독하지 않았다. 미열람 층은 고정 목록을 정렬한 앞 두 개다.
