# 이중 언어 질의

12개 문제마다 전체(.w)와 부분(.1, .2)을 동결했다. K01–K06 전체는 AF-RES-001 CASES.json의 original.full_text 그대로다. P1·P2는 AF-RES-002 PROTOCOL.md §2·§3의 고정 인용문이다. P01–P04에는 AF-RES-004 CASES.json의 goal, target_part, given, 각 hard_requirements, out_of_scope의 원문을 차례대로 넣었다. 네 문제의 구조화된 JSON은 읽는 순서만 문자열로 펼쳤다. P04 조건의 역할 표시도 남겼다.

부분 질의는 지정된 원문의 문장 또는 조건의 정확한 발췌다. 대상을 문장 밖에서 보충하거나 새 검색어를 넣지 않았다. 예를 들어 K01.2는 별도 브로커 금지, K02.2는 최초 폴더 파일 유지, P03.1은 대기 8·처리 중 4다. 지시어가 가리키는 내용이 사라지거나 부정 조건만 남는 경우도 관측 대상으로 삼았다.

영문은 이 작업 에이전트가 문장별로 옮겼다. 외부 번역 API 호출은 없었다. 제품명, 명령·프로토콜 이름, 수치, 상태·시간, 필수/선호/미결정, 의무 주체와 부정 범위를 유지했다. 표현이 어색해지는 직역 대신 맥락에 맞는 말을 썼다. 저장된 결과물에 한국어를 요구하는 K06 조건은 영문 질의에도 들어 있다. 사람 번역·검토는 미실시다.

`origin_sha`는 원문 커밋, `origin_ref`는 부분 원문의 문장/조건 또는 절이다. 기본 비교는 같은 언어의 설명과 질의다. 한국어 질의와 영어 설명의 교차 비교도 별도로 기록한다.
