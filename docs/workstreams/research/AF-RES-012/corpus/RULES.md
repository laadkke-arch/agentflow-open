# 소형 자료집과 실행 전 비교 규칙

## 대상과 대표 주소

- AF-RES-001~004 고정 원장, foundation 발견 사례, 원장에 등장한 오탐을 우선 수집한다. 같은 대상의 설정·코드·가이드·버전·배포 페이지는 대표 URL 하나로 묶고 원장 ID를 함께 남긴다. 버전·배포별 중요한 한계는 설명에 주어와 함께 유지한다.
- 독립 재사용 단위 또는 서로 다른 판정 대상이면 부모 제품과 기능을 각각 둔다. 예를 들어 SQLite FTS5와 Session, OpenTelemetry Collector와 내구 전송 부분을 분리한다. 이름 변경은 병합한다. 역사적 포크/후계는 독립 대상을 유지한다. 같은 P04 도구의 제공처가 여러 군데여도 한 레코드다.
- 역할은 검색에 넣지 않는 판정 메타데이터다. product는 독립 앱/서비스/도구, component는 적용할 기능/라이브러리/하위 시스템, principle은 전이 가능한 패턴·명세·알고리즘, other는 카탈로그·평가 데이터 등이다. 정답 판정의 역할은 질의가 요구한 적용 범위를 따른다.
- 중복 제거 뒤 150개 미만이면 공개 PyPI/npm 레지스트리에서 같은 단어·범주 또는 유사 이름의 배포물을 보충한다. 실험용 보충 항목에는 `distractor: true`를 붙인다. 점수에서 사전 배제하지 않으며 유용성이 발견되면 판정에 반영한다.

## 설명

- 색인 텍스트는 각 표현의 본문뿐이다. URL은 링크로 돌려주고 ID·주소·역할·태그는 어휘로 넣지 않는다. 모든 표현에 같은 대상명을 접두어로 둔다. D-a는 다시 연 공식 페이지의 한 줄, 확보하지 못하면 연결된 고정 원장 제목이다. `da_status`가 그 차이를 나타낸다. D-b는 그 원장의 역할·목적·메커니즘을 압축한다. D-c는 D-b를 그대로 두고 한계 문장 하나를 추가한다. 영어와 한국어는 각각 공백 토큰 40개 이하다. D-a 한국어는 공식 한국어 문구가 없는 경우 원문에서 옮긴다.
- 원장 읽기와 D-a 직접 재열람을 구분한다. 보충 배포물의 새 원장은 공개 레지스트리 필드와 그 한계로만 작성한다. URL 또는 특정 단어가 비슷하다는 이유로 실제 동작을 추론하지 않는다.

## 고정 비교

- 기본은 3표현 × 3방식 × 2언어다. 별도로 한국어 질의→영어 설명을 모두 평가한다. M1은 BM25, M2는 리비전 고정 multilingual-e5-small을 우선한다. 다운로드 차단 시 자료집에서만 적합한 TF-IDF+LSA를 실행한다. M3은 RRF(k=60)다. 언어별 색인과 질의 점수는 공유하지 않는다.
- 상위 10개와 순위에 기반해 positive 1/2 recall, gain 1/3 nDCG, MRR, N 개수, 역할별 recall을 측정한다. 관련 항목의 분모가 0이면 해당 recall과 nDCG는 NA로 기록하고 평균에서 제외한다. MRR에서 첫 관련 항목이 없으면 0이다. 질의별·전체/부분 구분을 모두 남긴다. 기본 MRR은 전체 순위, 상위 10개 밖의 첫 적중도 포함한다.
- qrels는 순위 산출 전 동결한다. 기본 18 조합과 9개 교차조합에 대한 상위 10개 합집합에서 미판정 쌍을 모아 방법과 순위를 숨긴 상태로 사후 판정한다. qrels의 결손을 0으로 채점하는 관례를 쓰되, 판정 완료된 0/N과 구분하고 판정 전후의 분모를 공개한다.
- 민감도 분석은 레지스트리 보충 항목을 제거한 집합과 seed 12012로 ID를 선택한 무작위 절반을 재색인한다. 각 집합에 존재하는 판정으로 분모를 다시 계산하고 관련 항목이 남지 않은 질의 수도 센다. 순위 없이 별도 검토자가 15개를 판정한다. 사후 판정 및 별도 검토 결과를 합쳐 최초 qrels를 덮어쓰지 않는다.
