M2는 모델 다운로드 차단으로 TF-IDF+LSA를 실행했다. M3은 BM25와 이 대체 방식의 RRF다.

# AF-RES-012 검색 실험 결과

156개 고정 자료와 36개 이중언어 질의에서 이름과 공식 한 줄 또는 제목만 쓴 D-a의 평균 recall@10은 **0.172**였다. 목적과 메커니즘을 넣은 D-b는 **0.269**, 한계 문장을 더한 D-c는 **0.323**이었다. D-c의 근접 오답도 질의당 **0.394 → 0.755**로 늘었다. 검색으로 후보를 찾은 뒤에는 문장이 말하는 대상과 적용 조건을 읽어야 한다.

기본 비교는 3개 설명 × 3개 방식 × 동일 언어 2개, 교차 비교는 한국어 질의→영어 설명 9개다. 같은 자료를 156개, 등록소 보충 항목을 제외한 91개, seed 12012로 추출한 78개에서 다시 색인했다. 역할과 주소는 메타데이터로 두고 설명만 색인했다. M1은 Unicode NFKC와 대소문자 정규화 후 어절 기반 BM25, M2는 같은 토큰의 1·2그램 TF-IDF와 48차원 LSA, M3은 RRF(k=60)다. RRF의 동점에는 같은 경쟁 순위를 부여했고, 표시에 쓴 동점 순서는 ID의 고정 seed 해시로 정했다.

초기 235행에는 1/2가 185행, N이 46행, 0이 4행 있었다. 순위와 방식을 가린 1,858쌍 풀의 사후 판정은 1이 135개, N이 22개, 0이 1,701개였다. 상위 10개에서 판정하지 않았던 자료를 더 많이 알아낸 반면 분모도 커졌다. 예를 들어 P01.1의 local JSON DB lowdb는 한국어 D-b RRF 4위였다. 초기 미판정에서 제한적인 재진입 저장 부품 1로 바뀌었다. 별도 검토자는 입력 156개와 질문 15개를 다시 읽고 277행을 판정했다. 예를 들어 P02.w의 SQS Standard는 맡은 정책에 보존/timeout/ack를 설정할 수 있는 조건을 근거로 1에서 2로 올렸다. ## 한계와 설계 판단

링크와 짧은 설명은 조회용 후보를 만들 수 있다. 원래 목표에 대한 적합성까지 판단하려면 어떤 제품/기능/설정에 관한 설명인지와 지원을 제외하는 조건을 읽어야 한다. 실험 결과가 지지하는 가장 작은 다음 비교는 D-b와 같은 검색용 표현을 두고, 적용 범위와 제외 조건을 별도 필드로 판정에 사용하는 방식이다. D-c처럼 한 문장 안에 넣을 때의 이득과 오탐을 공통 기준으로 다시 잴 수 있다.

질의는 12개 문제에서 파생했고, 관련성은 이전 원장의 도메인과 작업자 해석에 좌우된다. 같은 자료를 설명·판정에 사용한 의존성이 남고, 별도 검토도 내부 평가다. 소형 실험에는 원문 본문 색인과 다국어 사전 학습 모델, 독립 질의 표본, 형태소 분석 또는 실제 운영 제품 시험이 들어 있지 않다. 백업이나 큐의 실제 안전성도 문서상 사례에서 읽은 범위에 한정된다.
