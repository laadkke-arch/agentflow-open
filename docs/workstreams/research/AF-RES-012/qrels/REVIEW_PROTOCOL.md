# 별도 재판정 입력

검토 범위는 12개 전체 질의와 P01.1, P02.2, P03.2로 고정했다. 검토자는 순위, 연구자의 초기 판정, 선행 EXPECTED나 후보 평가 결론을 받지 않았다. 동일한 입력 질의와 자료집을 읽고 필요한 경우 고정 원문 근거를 참고했다. 결과 TSV는 질의별 1, 2, N 및 명시 0을 보관한다. 독립 판정에 없는 쌍은 그 비교에서 미판정이다.

같은 15개에 대해 초기 판정, 풀링 추가 판정 및 별도 판정을 각각 적용한다. 세 판정표에 동일한 순위를 제공한다. 비교 전후 차이는 평가의 민감도이며 모델이나 번역 간 독립 실험을 뜻하지 않는다.
