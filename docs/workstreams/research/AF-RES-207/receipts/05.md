# 깨끗한 GitHub checkout 재생

재검산 코드판은 `375058d11904e5f446306b8be175f33f241b623a`다. GitHub에서 해당 브랜치의 판을 clone해 코드를 실행했다. 후속 문서 커밋은 이 검사의 checkout에 포함되지 않는다.

```sh
set -euo pipefail
scratch=$(mktemp -d)
git clone --no-tags --single-branch --branch work/research-af-res-207 \
  https://github.com/laadkke-arch/agentflow-open.git "$scratch/repo"
cd "$scratch/repo"
git switch --detach 375058d11904e5f446306b8be175f33f241b623a
git fetch --no-tags origin \
  a674c67aaf2c4f1a6aaef4b1ac278dabf44188c0 \
  6147197ee77016a096412353bd9c3a9f4cd61b1e
d=docs/workstreams/research/AF-RES-207
python3 -B "$d/audit.py" observe --inputs "$d/inputs.json" --repo . --out "$scratch/core" --phase core
python3 -B "$d/audit.py" observe --inputs "$d/inputs.json" --repo . --out "$scratch/controls" --phase controls
python3 -B "$d/audit.py" score --gold "$d/gold.json" --runs "$scratch/core" "$scratch/controls" --out "$scratch/scored"
python3 -B "$d/receipts/context-check.py" --rail "$d/receipts/rail-2024.json" \
  --core "$scratch/core/observations.jsonl" > "$scratch/context.stdout.json"
python3 -B -m workbench.session check "$d/session.json" --fetch
python3 -B scripts/cloud_check.py --environment codex-cloud --fetch-contract --require-clean
cmp "$d/matrix.csv" "$scratch/scored/matrix.csv"
cmp "$d/costs.csv" "$scratch/scored/costs.csv"
cmp "$d/receipts/core.jsonl" "$scratch/core/observations.jsonl"
cmp "$d/receipts/controls.jsonl" "$scratch/controls/observations.jsonl"
cmp "$d/receipts/context.stdout.json" "$scratch/context.stdout.json"
```

clone, fetch, 두 관측, 채점, 맥락 검산, 계약 검사 및 공통 검사 종료 0. 깨끗한 판의 10개 비교 지문은 [원출력](replay-compare.stdout)에 있다. 관측 시작 시간, 실행 경로와 조회한 HEAD는 재실행마다 달라진다. 점검 시점의 Git 통합판과 저장 경로 범위는 [계약 검사](replay-session.json), 공통 명령과 하위 종료 코드는 [공통 검사](replay-cloud.json)에 있다.

자체점검판에서 입력과 판정 산술을 별도 파일로 대조하기 위해 아래 명령을 실행했다. [원출력](verify.stdout)과 종료 0을 확인했다.

```sh
d=docs/workstreams/research/AF-RES-207
python3 -B "$d/receipts/verify.py"
```
