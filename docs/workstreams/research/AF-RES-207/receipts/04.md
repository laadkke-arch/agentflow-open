# 반례와 타 분야 대조 실행

세 입력 자료를 같은 로컬 파일 이름으로 회차마다 공급했다. 통제 사본은 원본에서 파생한 별도 임시 입력이며, 표시 주장과 인용 구간이 가리키는 로컬 조각은 각 사본에 맞춰 다시 봉인했다. C1과 C4는 오승인 여부를 검사하므로 사본 바이트의 자체 해시 일치를 유지했다. 선택할 195 원문 단위 코호트의 투영은 사본에서 바꾸지 않았다. 한 번의 실행은 4개 입력 파일과 판독 코드만 staging한다.

```sh
d=docs/workstreams/research/AF-RES-207
scratch=$(mktemp -d)
python3 -B "$d/audit.py" observe --inputs "$d/inputs.json" --repo . --out "$scratch/core" --phase core
python3 -B "$d/audit.py" observe --inputs "$d/inputs.json" --repo . --out "$scratch/controls" --phase controls
python3 -B "$d/audit.py" score --gold "$d/gold.json" --runs "$scratch/core" "$scratch/controls" --out "$scratch/scored"
python3 -B "$d/receipts/context-check.py" --rail "$d/receipts/rail-2024.json" --core "$d/receipts/core.jsonl"
```

본 실행·통제·채점·맥락 계산 종료 코드는 각각 0이었다. 원 stdout/stderr와 20개 관측 지문은 [core](core-run.json) 및 [통제](controls-run.json)에 있다. [맥락 원출력](context.stdout.json)은 원 분절과 철도 원자료의 차원을 비교한다. 이 비교의 195 부분은 두 문장에 이미 연결한 관측만 더했다.

Eurostat 공식 2024 API를 웹 본문에서 직접 열어 `value`, `status`, 차원 좌표, 응답 업데이트일, 자료흐름, DSD 및 상태 라벨을 확인했다. [보존 입력](rail-2024.json)은 정규화한 값이다. 전송 바이트를 확보하는 별도 curl의 정확한 주소와 결과는 다음과 같다.

```sh
curl -fLsS --max-time 25 --output /tmp/rail-2024-live.json \
  'https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/rail_pa_typepas?lang=en&time=2024'
```

이 환경에서 curl은 종료 22 `curl: (22) The requested URL returned error: 403`이었다. 원 HTTP 바이트와 그 지문은 미확인이다. 전송 가능한 환경에서 위 입력의 JSON을 확보하면 마지막 `context-check.py` 명령에 `--live-json /tmp/rail-2024-live.json`을 추가한다. 갱신 일자와 여섯 좌표·값·상태를 비교한다. 공식 API가 갱신돼 값이 달라져도 저장한 2024 대조는 그 시점의 고정 관측으로 다시 계산할 수 있다.
