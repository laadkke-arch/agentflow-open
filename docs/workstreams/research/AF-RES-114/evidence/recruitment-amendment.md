# 모집 봉인 2 · 접속 관측과 보조 비교

원래 모집 구획, 순서, 24자리, 자연 선발 기준과 네 스위치를 [봉인 1](../SCOPE.md)에 보존했다. 이 파일과 카드를 저장할 때 공식 이슈 목록·요구·정답·순위는 보지 않았다.

- Krita는 한·영 5.3.0 발행판 HTML과 KDE GitHub 미러의 영어 원본 `1931b5dfda19086f16d4526a65c169a130c68742`를 열었다. 유통 HTML의 배포 SHA와 별도 SVN의 한국어 PO 키는 미확인이다. 여섯 레이어 카드에서 한 개, 여섯 출력 카드에서 두 개가 해당 조작의 한국어 표지를 표시했다.
- Blender 5.3은 원경로 web.open에서 402, 셸에서 도메인 정책에 따른 CONNECT 403을 받았다. 스테이징 원본과 Weblate도 직접 읽지 못했다. 동일 5.3 발행자의 sl 목차에 남은 영어 항목과 uk·vi 목차 캐시에서 순서를 복구해 12 기표를 보존했다. GitHub 미러의 `v5.3.0` 고정 구현·UI gettext를 열어 노드 심벌, 소켓, 동작과 UI 이름을 대조했다. Blender 12자리의 영어 발행 TOC 직접 대조 및 한·영 매뉴얼 PO 대조는 미확인이다. 개발판 5.4나 다른 위치의 노드로 바꾸지 않았다.
- 주 분석에서는 `alias_verified`만 넣는다. 목표 매뉴얼 PO 대응 열람이 현재 0/24라 별칭 스위치의 주 분석은 입력 결손을 보여준다. 별도 `publisher_partial` 보조판은 Blender의 앱 gettext 표기와 Krita의 같은 절 HTML 표지를 `alias_publisher`에서 사용한다. 두 유형의 위치·키 조건을 각 행에 남기며 앱 PO를 매뉴얼 PO 증거로 사용하지 않는다. 후보·역할·토큰화·조회 수·동점 규칙은 같은 것을 사용한다.
- 사전 지정 Clone Layers의 한국어판 표제는 영어다. Q7 원래 대조는 null에서 null로 남기고, 비공백 결측 효과를 관찰할 보조판의 대상 하나를 **K-L04 Filter Layer**로 등록한다. 당시 카드 중 한국어 표지와 같은 영어/한국어 발행 절을 모두 확인한 첫 Krita 기능이다. 기존 봉인에 대한 수정 이유는 영어로 남은 Clone Layers 표제다. 보조판 비교에서만 K-L04의 한국어 표지를 제거한다.

자료 열람은 [sources.jsonl](../sources.jsonl)의 status, source_url과 landed_url로 대조한다. 코드 미러의 각 절은 한 기능 계보만 한 번 산입하고 두 Cryptomatte 심벌은 한 구현 파일 계보다.
