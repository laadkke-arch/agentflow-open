# 질문과 순위 비노출 판독

동일 작업자가 카드 봉인 이전에 기능 절과 번역 경로를 읽었다. 카드 원격 고정 뒤 작성자 공개 본문에서 영어 문장을 먼저 단문화하고 한국어 문장을 만들었다. 작성자에게 직접 번역 판독을 받거나 독립 판독자를 배정하지 않았다. 작성 후 24개 카드의 고정 절을 다시 읽어 조작과 보존을 따로 판독했다. 순위 코드와 실행물은 이 봉인 시점에 없었다.

- 공식 트래커 창 40 + 40은 두 창의 생성순·40/41 경계를 확인할 목록 응답을 얻지 못했다. [frame.csv](../frame.csv)의 예약 자연 6자리와 [truth.csv](../truth.csv)의 144개 예약쌍을 공석으로 뒀다. 빈 쌍은 미확인 판정이나 확증된 음성으로 합산하지 않는다.
- 날짜가 있는 발견 표본 안에서 원문과 두 조건을 읽은 먼저 나온 세 건씩을 사용했다. Blender는 공식 Issues 둘과 Right-Click Select 원 작성자 제안 하나다. Krita는 파일 크기 변경을 다른 저자가 보고한 #467257과 #470110가 연결돼 두 작품이 한 결함 계보다. #473603은 별도 보존 조건을 확인할 수 없었고, #484353은 가능한 발견분 가운데 날짜가 더 늦다. #464692의 원본 유지 조건은 기존 복제·병합 조작에서 추론했다. 원본 최초 제출 revision의 인증은 0건이다. [요청 위치·번역](../queries.jsonl) · [탐색 판정](truth-exploratory.csv)
- 구성한 대조의 직접 적격은 C-P1의 K-L01과 C-P2의 B-M03이다. C-P1은 동일 한국어 페이지에서 영어 심벌이 남는 대조다. C-P2는 고정 코드의 Add 분기를 작은 입력으로 검산했다. C-N1은 입력 Mask와 출력 Image를 교차했다. C-N2는 화면 표시를 필터 레이어 추가와 교차했다. [구성 판정](truth-controls.csv)
- 질문 유형별 언어는 같은 원뜻의 두 표현으로 기록했다. 약한 보존 추론, 출판 캐시, 판·UI 미실행 범위를 그대로 노출했다. 본문 판독 후 담당자가 영어 카드 표기를 떠올렸는지는 확인할 수 없으므로 엄격한 카드 비노출 번역은 미확인이다.

별칭·역할과 별개로, [5.3/6.0 고정 코드](https://github.com/KDE/krita/blob/148ce5cfc24252922e3866e67af91c12f17b2e08/libs/ui/kis_file_layer.cpp#L359-L403)의 `ToImageSize` 경로와 [당시 변경 원본](https://github.com/KDE/krita/commit/91aa790cab80fac35b62bd96b8b9f15e92d1bc8b)이 File Layer의 축소를 일부 지지한다. 두 수정 경로와 변형 마스크의 위치 보존을 함께 재현한 근거가 없어 K-L02의 탐색 두 행을 일부로 판정했다.
