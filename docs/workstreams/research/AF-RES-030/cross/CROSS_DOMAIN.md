## 절차적 결정

C-L2 rubric처럼 질문 여부·출처 지지·교육·종료를 별도 평가한다. 완료 transcript만 읽는 선택은 본 과제에서 쓰지 않는다. BLS 프로토콜에서 배운 것은 질문의 위치·이미 답한 값 점검이라는 설계 후보이며, 해당 절차가 GitHub에서 시간을 줄였다는 사실이 아니다. C-S3/C-S5의 집계가 있어도 개별 GitHub 답의 진실성을 깎는 근거로 사용하지 않는다. C-S4에서는 정의 설명 뒤 같은 사람의 답이 바뀐 두 반대 방향 사례를 확인했다. C-S6은 조건을 통제하면 명확화의 이익을 관측할 수 있다는 반대 관점을 보존하지만, 본 A/B는 그런 배정이나 고정 정답을 갖지 않는다.

## 남은 미확인과 첫 자료

Census Q18의 실제 probe 발화·익명 참여자 ID·전후 의견 계보는 공개 PDF pp.4-40–4-42까지가 마지막 확인 위치다. 답을 바꿀 다음 자료는 같은 조사에서 공개 승인된 익명 interview case summary/protocol이다. 사서 John 사례의 실제 최종 링크와 사용은 C-L1 부록 p.279 이후 원 transcript가 필요하다. 비공개 개인 기록은 요청하지 않는다.
