# AF-RES-030 집계 사전

작성 시점: 각 계열 T0 봉인파일 작성 중, 작성자의 후속 답 본문을 통합자는 아직 읽지 않음. SCOPE의 원칙을 재집계용 열로 구현하며 SCOPE를 대체하지 않는다. 전역 B 선택은 최초질문만으로 M1,X1,D1... 순서를 따른다.

## 서로 다른 분자

- `first_question`: 첫 실질 응답이 기존 환경·목표·입력을 묻는다. 단순 수사적 질문/링크 권유·새 패치 시험요청·봇 문구는 제외. 요청문과 혼합된 실제 질문은 포함.
- `any_question_root30`: root 시각부터30일 안의 어떤 단계에서든 같은 정의의 실제 명확화 질문이 있음. 첫 답이 즉답인 뒤의 질문도 별도 기록하고 포함. first와 any의 차이를 보여 준다.
- `same_variable_answer`: 원 작성자가 바로 그 대상·판·변수를 실제로 답함. `direct_existing_new_disclosure`와 `restatement_already_present`를 구분한다. 재진술도 질문에 대한 답이지만 새 정보의 편익은 아니다. 일부만 채움/제3자/후발 새요구/지시대상 애매함은 엄격 직접답에서 제외한다.
- `linked_recommendation_change`: 직접답 후 같은 지원자가 답 내용을 명시적으로 받아 후보·옵션/설명·다음 행동을 수정했다는 근거. 순서만 앞뒤인 경우 `analyst_inference`; 답전 제안이 없으면 `no_prior_proposal`, 새 제안을 변경으로 세지 않는다. 엄격분자는 전 제안 존재+동일지원자+명시연결+실제 변경.
- `new_execution_success/failure`: 원 작성자가 같은 목표로 새로 실행/재현/사용한 구체적인 결과를 본문·코드/출력과 함께 보고. 처음부터 했던 실행 재진술·감사·닫힘·emoji·공급자 자체재현/PR은 별도. 일부 성공과 원목표 전체성공을 구분.
- `chain_success`: 명확화 직접답과 명시적 권고변경 및 그에 이어진 동일목표 새 실행성공의 모두를 충족한 사례. 독립적인 실행성공이나 공급자 수리는 이 분자에 합치지 않는다.

## 시간창

원 요청 root+30일은 주 집계. 같은 사건 root+90일은 후속. 질문시각+30일은 답 대기 관측을 위한 별도 창이며 root+90일을 넘으면 `late_question_extension`으로 분리한다. 최초 답이16개월 뒤인 B라도 A/B 선정은 유지한다. 다만 첫답 질문 유무의 T0 분류와 root30의 실제질문 분모를 같다고 취급하지 않는다.
관측된 전체 댓글/타임라인의 pagination, last endpoint/UTC, 삭제 흔적, cross-reference 목록을 남긴다. 창이 닫혔지만 자료가 비어 있는 경우 unobservable; 온전히 관측한 창의 무답은 no_answer. 마지막 질문 뒤30일이 지났어도 사이트에서 보지 못한 reply를 없다고 꾸미지 않는다.

## 분모와 대기

A24 및 B8(실제확보 수)는 기본 사례수. 변수행/발화행/왕복은 다른 단위다. 여러 질문변수에 같은 reply가 답하면 (case_id,question_comment_id,answer_comment_id) 한 왕복. 질문시각부터 작성자 답까지 elapsed hours; 답없음은 남은 관측창과 검열 상태를 표시. 중첩대기를 합산한 총 노동/클릭 비용은 만들지 않는다.
민감도는 미노출, root원판 확인/부분/미확인, 반복발신자 첫1건, 유지관리자 겸 질문자 제외, 미확인 분자0/1 양끝을 각각 재집계한다. 원판 확인0이면 해당 하위집합 비율은 해당 없음. 공개 handle 개수를 독립 사람 수라고 부르지 않는다.

## 봉인과 정정

initial.jsonl, questions.csv, frame.csv, comparisons.csv의 stage2는 후속 전 커밋과 파일해시로 고정한다. 비교 선정에는 root정보/첫전략만 사용. 후속에서 깨진 예측은 별도 `corrections.jsonl` 또는 stream 분석 원장에 기록한다. 이미 써 둔 질문의 값을 후속 지식으로 바꾸지 않는다. 후발 첫명확화의 변수는 chains 및 later-questions에 추가하고, 당시 미열람 예측인 척하지 않는다.

## 첫 응답의 두 질문 층(후속 열람 전 고정)

M03의 후보 기능이 목표에 맞는지 묻는 문장은 실제 답을 요구하므로 broad_first_question에 남기지만 기존 환경·목표·입력 회수인 first_information_question에서는 제외한다. M07의 이전 신고 행동과 M08의 재현 입력 요청은 실제 정보 요청이다. 따라서 A 첫 질문 발화8건/기존 정보·입력 질문7건을 혼동하지 않는다. B는 사전 기준의 기존 환경·목표·입력 질문만으로 선정한다.
