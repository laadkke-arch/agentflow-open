# P3 범위 재검토 기록

결정 기록 UTC: 2026-11-23 18:11:39 UTC.

1. 최초 사후 검토에서는 원 작성자의 버전 호환 우려를 전체 목적의 필수요건으로 넓게 해석하여, 8.3.0의 두 경로 배열 비교를 조건부 묶음으로만 두고 전체 gold 유보를 예정했다. 이는 사전 A/B 예측을 읽은 결과가 아니었다.
2. root가 기존 사전 SCOPE의 기준을 전달했다. 기준은 사용자가 명시한 판과 해당 요청의 실제 조작/관찰 목표이며, 8.2.0 호환을 자동 필수로 추가하지 않는다. 이 검토자는 SCOPE 파일 자체나 A/B records를 열지 않았다.
3. 이미 직접 열람한 원 본문과 사후 자료를 이 기준으로 재검토했다. 원 본문에는 8.3.0+와 getpalette()[:len(p)] == p가 있고 새 순서를 선호한다고 밝힌다. 사후877558030에는 같은 p/P image의 양 경로8.3.0 출력이 있으며,877853085에는 OP의 직접 배열 전달 수용이 있다.
4. 이 관찰 범위에서는 두 후보가 같은 목표를 충족하므로 true_pair_label=묶음, scorable=true로 확정했다. 넓은 설치판 호환/8.2 blue 보존/후속 저장·변환 목표는 별도 유보로 남겼다. 사전 요청, 후보, 판, A/B 예측을 변경하지 않았다.
5. 근거 강도는 maintainer가 게시한 paired test와 OP 수용이다. 새 독립 실행이나 외부 제3자 검증이라고 바꾸지 않았다. 후보 signature의 default rawmode 확인은 매핑 근거이며 독립 outcome 검증 수에 더하지 않았다.

이 재판정은 필요한 판·관찰 범위를 명시하기 위한 것이다. root는 A/B 예측·기대결론을 전달하지 않았고, 이 검토자는 금지된 예측/판정 파일을 읽지 않았다. 초기 넓은 해석과 최종 제한범위 결론의 차이를 삭제하지 않고 기록한다.
