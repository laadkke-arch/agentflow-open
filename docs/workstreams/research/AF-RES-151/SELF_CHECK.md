## 정확한 재개/재집계
승인된 GitHub 접근 가능 checkout에서:
```sh
git fetch origin chore/workspace-foundation work/research-af-res-151
git switch --detach origin/work/research-af-res-151

```
manifest가 없음: SCOPE.md에 기록된 시작 SHA·dependency 두 개로 start 계약부터 생성/검증. 아직 check 실행 못 함.
원장 재계산(입력 pairs.csv, decisions.csv, sources.jsonl; 미실행 Python 동등 명령, 실제 실행은 JS):
```sh
python -B - <<'PY'
import csv,json,collections,pathlib
root=pathlib.Path('docs/workstreams/research/AF-RES-151')
p={(x['pair_id'],x['request_id']):x for x in csv.DictReader((root/'pairs.csv').open())}
s=[json.loads(x) for x in (root/'sources.jsonl').read_text().splitlines()]
counted=[x for x in s if x['counted']]
print(len(counted),collections.Counter(x['kind'] for x in counted))
t=collections.defaultdict(lambda:[0,0,0,0,0])
for d in csv.DictReader((root/'decisions.csv').open()):
    x=p[d['pair_id'],d['request_id']]
    a,b=({i for i,c in enumerate(x[k]) if c=='S'} for k in ('a_atoms','b_atoms'))
    sa,sb=d['a_status'],d['b_status']
    den=len(a|b)
    active=len((a if sa=='K' else set())|(b if sb=='K' else set()))
    retained=len((a if sa!='X' else set())|(b if sb!='X' else set()))
    hidden=sum(c!='K' for c in (sa,sb))
    excluded=sum(c=='X' for c in (sa,sb))
    vals=[den,active,retained,hidden,excluded]
    assert vals==[int(d[k]) for k in ('confirmed_atom_denominator','active_atoms','retained_atoms','hidden_slots','excluded_slots')]
    key=d['phase'],d['method'],d['variant']
    t[key]=[i+j for i,j in zip(t[key],vals)]
print(dict(t))
PY
```
원문 실행 미실시/입력: R3 원 PDF가 공개 첨부로 확보되는지 먼저 확인([R3](https://softwarerecs.stackexchange.com/questions/3412/free-ocr-software-that-makes-a-pdf-searchable-with-searchable-text-at-the-right)); 고정판·원 언어팩 확인 후 `ocrmypdf -l ron+eng input.pdf output.pdf` 와 `pdftotext -bbox output.pdf output.html`(공급자 실제 라이선스/버전과 언어팩 확보, 원 이미지 글자 좌표와 대조). R1/R4 음성 원본 및 실행판 미확보: 테스트 허가된 원 mp3에 `ffmpeg -i input.mp3 -ar 16000 -ac 1 -c:a pcm_s16le input.wav`; 해당 고정판 binary/model 확보 후 `whisper-cli -m model.bin -f input.wav`; 실제 사용자 원본 대체 아님. R5 P1b Android 샘플/모델/AAR 버전 확보 후 해당 repo의 Gradle wrapper 확인; 입력 앱/기기·OS 필요. R6 시스템 오디오 캡처는 대상 OS/버전/동의된 샘플 스트림부터 확보; OS 미상이라 실행 명령 단정 불가. X1 첫 행동: curl 또는 승인된 HTTP 환경에서 SCOPE의 exact URL 원응답 저장, creation 순서·거절 모두 봉인. 이전 자연 실패를 덮지 않는다.
