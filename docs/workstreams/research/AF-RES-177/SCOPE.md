## 판독 계약
각 원문 span을 목표, 출력 atom, 필수/선호/허용/미정, 논리식 AND/OR/priority/IF/unknown, scope tuple(독자, 빌드·배포 단위, 버전·시점, 출력경로, 네트워크), 예외와 부정, 출처, 최초/후속 명료화/새 요구로 보존. 단어 and/or만 보지 않는다. 같은 사람의 후속 확인만 저자 확인; 유지자 추정이나 close는 정답 아님. 무응답은 정답 분모 제외. 논리식 후보 둘 이상 가능하면 하나로 고정하지 않음.
각 출력의 개별 지원 증거와 공동 양립 증거는 별도. 두 개의 README가 참이어도 같은 빌드에 모두 나온다는 결론은 미정. version tuple/설정/순서/경로/자산/네트워크/실제 산출물/실행 로그를 별도로 확인. 정적 문서, 당사자 보고, 구현, 자체 실행 구분(D1/D2/D3); 본 작업 D3 없음. 조건 불일치는 충돌이 아니라 우선 적용 범위 외, 직접 덮어쓰기/재현 보고만 해당 환경 충돌.
동일 후보·두 링크 한도 비교: F=평평한 리스트, L=논리+범위 보존, Q=한 질문 후 조건별 답. 단독 충분/조합 필요+양립/조합 충돌/미정 분기. 오승인=필수/범위/양립 미증명인데 충족 승인; 배제=명시 OR 허용인데 필수 AND로 배제; 보류=판정에 필요한 증거 부족. 저자 확인 없이는 관찰된 정확도 주장 금지. 원문 예시 10, 보충 4, 구성 대조 별도. 22 unique work 하한, 각 출처 확인 내용·한계·계보·시도 구분. 교육/기록관 규정과 실제 이수/인수 사건은 별도.
