## 사전 A/B와 후속판 가림

옛 배포본·의존 선언·079 근거·상류 변경 공지까지 먼저 읽는다. **선정 레코드와 A/B를 커밋한 뒤** 소비자 후속판의 해당 원문·수정 이력·시험을 연다. tag/release 목록의 날짜·SHA metadata 조회는 판 선택용이며 후속 내용 판독과 구별한다. 실수로 먼저 읽은 내용은 protocol-deviations.md에 적고 해당 행을 사전 평가에서 제외한다. 원래 기준을 소급 변경하지 않는다.

- A: 같은 옛 주소 또는 qualified 이름이면 발행자가 명시한 단일 수신 주소/심벌로 일괄 치환한다. 공식 단일 수신자가 없거나 여러 후계 중 고를 수 없으면 보류한다. 옛 인용 자체는 provenance로 보존한다. 단순한 Parquet라는 단어만으로 GeoArrow를 바꾸지 않는다.
- B: 원 독자의 요구·호출·판·근거 위치를 연결하고 유지, 판 한정 별칭, 의미 분리, 조건 변경, 보류 중 선택한다. 하한 의존성만으로 실제 설치판을 확정하지 않는다. 079의 다른 함수나 다른 인코딩 입력을 옮겨 실행 증명으로 삼지 않는다.

각 제안에 수정할 원문 범위, 실제로 바꾸는 텍스트/조건, 적용판, 근거 ID, 필요한 추가 관측을 넣는다. 두 안 모두 같은 원 레코드에 적용한다. 보류를 놓친 변경으로 자동 계산하지 않는다.

## 사후 판정과 분모

후속 실제 행위는 주소만 수정 / 호출·인자 수정 / 기대값 수정 / 조건 추가 / 삭제 / 그대로 발행 / 위치 이동 / 소실·미확인으로 구분한다. publisher가 실제 수정했다는 사실은 정정 필요성의 정답 자체가 아니다. 당사자의 이유와 단순한 시점 일치를 별도로 쓴다.

독립 정오 기준은 (1) 고정판의 대상 namespace·심벌/인자 존재, (2) 독자에게 명시된 필요한 값·메타데이터·설정에 대한 정확한 해당 입력의 테스트 또는 실행, (3) 판이 명시된 공식 지원·비지원 문장이다. 구현 추론은 정적 근거로 표시하고 실행 결과와 분리한다. 원 안내가 그 조건을 요구하지 않거나 실제 설치판이 없으면 해당 행동 판단은 미확인으로 둔다.

불필요한 변경은 독자 계약과 허용판을 이미 충족하는 원문을 A/B가 손상·불필요하게 강제 이관한 경우, 놓친 변경은 독립 기준에서 필요한 수정이 확정되었는데 그대로 유지한 경우다. 유효 유지는 동일 조건에서 유지가 지지될 때다. 수정 필요, 수정 관측, 연구 제안의 유효성은 각각 별도 분모다. 효과 크기·운영 오류율을 6자리에서 추정하지 않는다.

## Q6·Q8와 자료 계수

patches/에는 배포본 원문 위치 metadata와 연구 수선의 정·역방향 diff만 둔다. 실제 소비자 merge/diff에는 PUBLISHER-, 연구용에는 RESEARCH- ID를 붙인다. 원문 인용·옛 판정은 보존한 채 조건부 새 view를 만들고 역적용하여 원 bytes 또는 정규화 레코드 hash 복구를 검사한다. byte 복구가 기능 호환을 증명하지 않는다.

다른 분야에서는 도서관 주제명 전거의 실제 분할/병합과 학술 출판 정오표/판 공지의 실제 사건을 두 제도에서 최소 4건 조사한다. 이전·수신 기록을 양쪽에서 열고, 일괄 변경 불가·이미 수정한 판의 중복 수정 반례를 찾는다. 이를 소프트웨어 행동 증명으로 계산하지 않는다.

자료 최소량은 독립 원저작/사건 20계보, 서로 다른 하류 저작 6개, 외부 두 제도 실제 사건 4개다. 같은 안내의 판·번역·미러와 같은 사건의 이슈/PR은 한 계보로 센다. 선택 6자리와 하류 저작 6개는 다른 분모다. 제외된 안내/보조층의 별도 원저작도 실제 읽고 목적과 한계를 남긴 경우 자료량에 산입하되 핵심 슬롯을 채우지 않는다. 검색 snippet·접근 실패는 attempts.jsonl에만 기록한다. sources.jsonl에는 자료ID·계보ID·종류·고정 URL/절/행·직접 읽은 UTC·Q/사례·확인 내용·한계·지지/반증을 기록한다.
