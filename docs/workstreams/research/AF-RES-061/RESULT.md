## 채택 가능한 판단과 실제 분모

**상태: 부분 인계.** ①~③을 보존하고 ④의 보고·카드·수용 원장·검사를 마쳤지만, Graphviz의 A 보기와 공개 한 단계 입력, Android의 첫 적격 이슈 모집, 주 사례의 독립 원출력, Barnes–Hut 1986 본문 접근 결손은 남는다. 이 결손 때문에 설명 가능한 범위와 원전 추가의 효과를 구분한다. 전체 절차의 검사 결과는 [수용 원장](evidence/acceptance-evidence.json), 최종 검사 SHA는 마지막 [HANDOFF](HANDOFF.md)에 있다.

첫 두 표의 비교는 **4구현×정상/경계 8행**이다. API/A/B 저장 행은 24개지만, GV의 A 2행은 결손 표시이므로 자료가 제공된 전체 보기는 22행(API8+A6+B8)이며, 추가 창을 제공한 A/B 보기는 14행이다. A/B 비교 가능한 6행에서 **운영 예측 차이 관측 0/6**이다. **다른 예측만의 분모는 0행**이며, 그중 같은 판·같은 입력 독립 원출력을 확보한 것은 **관측 0건**이다. 따라서 원전 새 적중률은 **해당 없음**이며 0%도 100%도 아니다. 주 8행에서 독립 보관 원출력은 **확보 관측 0/8, 존재 일반 미확인**이다. 연구자 보조 실행은 6/8행에 있고 GV 2행은 실행하지 않았다. 이 비율은 전체 생태계의 차용률·성공률이 아니다. [사전 비교 규칙](evidence/comparison-rule.json), [최종 계수](evidence/final-counts.json).

이 묶음이 지지하는 선택은 다음 세 가지다. **동작 설명**에는 원전의 변수·가정과 수신 코드의 변경점을 나란히 쓸 수 있다. **차용 기록**에는 수신자가 실제 지목한 경로만 적는다. **설계자 행동 변화**에는 저자의 실제 변경 보고가 필요하다. 이 조사에서 원전 링크를 받은 설계자의 행동 실험은 **미실시**다. 과거 이슈의 설정 변경이나 유지보수자의 패치가 그 실험을 대신하지 않는다. [차용 원장](transfer.csv), [반환 카드](cards.md), [자체 반증 점검](SELF_CHECK.md).

## Q3. 정확히 옮긴 것과 제품이 결정한 것

**그래프.** N체 근사의 셀 자료구조·집계·개방 조건은 힘 법칙과 독립적으로 옮길 수 있다. [Demmel](https://people.eecs.berkeley.edu/~demmel/cs267/lecture26/lecture26.html)의 중력 벡터는 Δ/r³이다. d3의 [apply](https://github.com/d3/d3-force/blob/156712c8c3285d77cb487e1685c5adafcd0394a4/src/manyBody.js#L55-L91)는 Δ/r²에 strength·alpha를 곱해 속도에 더한다. d3의 signed strength, 0합 셀 생략, 절댓값 가중 중심, 최소/최대 거리, jitter는 양의 질량·운동량 보존의 전제를 자동으로 유지하지 않는다. 최종 위치를 묻는다면 simulation의 velocity decay·tick과 다른 force까지 더 읽어야 한다. [D004/G020/G021](sources.jsonl).

[Hu §3.1–3.2](https://yifanhu.net/PUB/graph_draw_small.pdf)는 인력·척력 후 net force를 정규화해 step을 곱하고 각 노드를 즉시 갱신한다. 따라서 두 점의 첫 힘을 계산해도 전체 iteration의 두 이동을 얻은 것은 아니다. 이 순차 좌표 설명은 두 노드 direct 경로와 인접 끌림에 해당한다. n≥45의 normal 경로는 정점 루프 전에 quadtree를 만들므로 모든 집계 중심이 각 노드 이동마다 갱신된다고 일반화하지 않는다. Graphviz 고정 코드는 K, p, C=.2로부터 `KP=K^(1−p)`, `CRK=C^((2−p)/3)/K`를 계산한다. header의 단순 식과 executable 계수를 구별했다. 초기 좌표 재생성, adaptive step, stop threshold와 maxiter, 이후 overlap/packing은 별도 선택이다. Hu의 폭/거리 **≤θ**와 d3의 엄격한 검사, 셀 폭 정의까지 같다고 하지 않는다. [G025–G030/D013](sources.jsonl), [상세 대응](streams/graph/transfer-notes.md).

**애니메이션.** 교재의 `m y″ + b y′ + k y = 0`에서 y는 목표에 대한 변위다. Android는 별도 질량 API 없이 ω²=stiffness와 b=2ωζ를 사용하고, long ms를 초로 바꿔 세 감쇠 영역의 해석해를 계산한 뒤 float로 바꾼다. react-spring은 mass/tension/friction을 대응시킬 수 있지만 velocity는 값/ms이고, 힘과 감쇠 항의 10⁻⁶/10⁻³ 변환 후 1ms step을 반복한다. 두 제품의 숫자를 물리 kg·m로 부르거나 같은 숫자 하나로 순위 매기지 않는다. [MIT 원절](https://www.ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/911bc225e5913ba15517dbd70528c27a_MIT18_03SCF11_s13_1text.pdf), [SpringForce](https://android.googlesource.com/platform/frameworks/support/+/d5923c378c00b537f3421786eb3a50e6f6868386/dynamicanimation/dynamicanimation/src/main/java/androidx/dynamicanimation/animation/SpringForce.java#272), [SpringValue](https://github.com/pmndrs/react-spring/blob/b6fbb98101f2cf00a6668cffed6d1b4d0012ae3a/packages/core/src/SpringValue.ts#L278-L325).

API의 finish/cancel, target snap, 시각적 허용량, retarget 순서, reduced-motion 설정은 ODE 항이 아니다. 식이 같은 범위와 사용자가 보는 결과가 같은 범위가 다르다는 것이 이 대응의 가장 유용한 결론이다. 역으로 물리 해석이 목적이면 제품의 snap·clamp를 물리 법칙으로 받아들이면 안 된다. [AN 경계](streams/android/findings.md), [RS 경계](streams/react/findings.md).

## Q5. 어떤 관측과 맞았는가

고정 코드의 선언, 상류 시험의 assertion, 저자가 보관한 원출력, 이번 연구자의 보조 실행을 분리했다. D3의 선택 태그 test 디렉터리5군에는 주 입력의 manyBody assertion이 없었다. 다른 forceCollide의 동일 위치 대칭 시험을 manyBody의 정답으로 옮기지 않았다. Graphviz의 관련 regression4함수는 다른 입력이고, isolated-node 제목 시험은 실제로 `-Kneato`를 실행한다. 최종 배치 fixture도 한 단계 힘 출력이 아니다. [시험 목록](streams/graph/test-inventory.json), [G031–G043](sources.jsonl).

Android의 원 SpringTests에는 다른 초기값·감쇠·강성의 선언이 있으며, 일부 scale 시험은 `@Test`가 없고 duration-scale listener 시험은 `@Ignore`다. 반대 부호를 세려는 코드가 먼저 같은 velocity를 복사한 분기도 있다. 이를 정상 가동 증거로 세지 않았다. react-spring의 underdamping 표제 시험은 `xit`이고 입력도 damping1이다. 저장된 특정 숫자 snapshot은 duration 시험이어서 spring 주 입력의 출력으로 쓰지 않았다. [Android 원시험](streams/android/evidence/SpringTests.java), [R028/R052](sources.jsonl).

6개 주 행의 자체 실행은 해당 배포판의 계산을 확인하는 보조 증거다. D3는 원 package source, Android는 배포 source와 명시한 Android 플랫폼 스텁, react-spring은 integrity가 검증된 배포 JS를 썼다. AN의 실제 단말, react의 mounted React/OS preference 통합, GV native 실행은 미실시다. 각 입력·시간표·단위·raw key는 [observations.csv](observations.csv)에 있으며, 실행 재현 명령은 [D3](streams/graph/reproduce.md), [Android](streams/android/reproduce.md), [react](streams/react/execution.md)에 있다. 앞 세션에서 끝난 실행을 이번 재개에서 반복했다고 기록하지 않았다.

## Q7. 첫 링크를 바꾸는 최소 조건

네 카드의 기본 선택은 수신 구현의 판별 절이다. 원전 저자는 오차·보존량·초기조건의 정확성을, 유지보수자는 API·호환성과 실행 경로를, UI 개발자는 원하는 화면·취소·프레임 예산을, 움직임이나 읽기 부담이 큰 사용자는 필요한 정보와 허용 가능한 움직임을 우선할 수 있다. 이 우선순위를 같은 물리 목적함수로 환원하지 않았다. [cards.md](cards.md)는 구현마다 네 관점, 옮길 조건, 중단 조건, 결정을 바꿀 자료를 기록한다.

그래프에서는 [Hu §6·Fig15](https://yifanhu.net/PUB/graph_draw_small.pdf)가 균일 mesh와 국소 세분화 mesh에서 모양 선호가 달라지는 사례를 제공하고, 실제 [D3 #186](https://github.com/d3/d3-force/issues/186)은 점별 울타리 cutoff와 tree pruning 비용이 충돌함을 보여준다. 화면에서는 [Heer/Robertson](https://idl.cs.washington.edu/files/2007-AnimatedTransitions-InfoVis.pdf)의 staging 선호가 정확도와 항상 같은 순서가 아니며 [Dragicevic 등](https://www.cs.au.dk/~elm/pdf/timedistort.pdf)의 adaptive pacing도 항상 더 좋지 않다. 움직임을 더 물리적으로 만드는 것만으로 읽기 과제를 개선했다고 말할 수 없다. [D013/E002/E003](sources.jsonl).

원전의 오차/비용이 실제 선택 기준이면 해당 원전과 수신 mapping을 앞세운다. 취소·무초과·필터·겹침이 선택 기준이면 그 구현 분기를 앞세운다. 무엇을 보존해야 하는지 불명확하면 사용자 우선순위를 먼저 묻는 카드가 더 정직하다. 이 판단은 반환 설계 제안이며, 실제 사람이 그 카드로 더 좋은 결정을 했는지는 **미실시**다.

## 원저작·비용·감도와 재사용 한계

직접 본 외부 1차 저작은 중복 계보를 합쳐 **31개**다. 같은 태그의 코드·README·테스트는1개, Hu의 다른 절은1개, react의 두 연결 이슈는1계보로 센다. 겹치지 않는 배당은 구현4, 독립 이슈·설계13, 천체 원연구2, 진동 원 실험서·실험보고2, 독립 출력 연구4, 추가 설명·접근성6이다. [출처 감사](streams/final-audit/source-audit.json), [출처 원장](sources.jsonl). 독립 출력4저작은 Hu/Fruchterman–Reingold/Heer–Robertson/Dragicevic이며 주8행의 같은판 출력4개를 뜻하지 않는다.

[Salmon/Warren](https://lss.fnal.gov/archive/other/ccsf-28-92.pdf)은 15,000+3,000입자의 불균등 은하가 셀 모서리를 지나는 원 실험에서 큰 국소 오차가 평균에 가려짐을 보고한다. [Dehnen](https://arxiv.org/pdf/astro-ph/0202512)은 direct-sum 대비 근사오차와 입자 표본·softening 오차를 분리한다. 둘의3D 양의 질량·당시 하드웨어 수치를 D3의2D signed strength나 현대 sfdp 성능으로 전이하지 않았다. D3의7노드 보조 corpus는 theta.9에서 평균 상대 벡터오차 .00398485/최대 .0264791, theta2에서는 .162555/.431830을 보였다. 의도적으로 고른7노드이고 속도 benchmark는 미실시다. [D007/D008](sources.jsonl), [오차 분포](streams/graph/d3-error-analysis.json).

[Vanderbilt Lab10](https://cdn.vanderbilt.edu/vu-my/wp-content/uploads/sites/942/2013/08/13201112/phys-1601L-Lab-Manual-Spring-2020.pdf)은 실물 감쇠 측정 조건을 정하지만 학생의 측정 결과는 제공하지 않는다. [Jayaprasad 원 보고](https://arxiv.org/pdf/1311.7489v1)는 두 방법의 감쇠계수 추정과, 저속/층류 가정이 깨져 점성값이 표준보다 약100배 커진 한계를 보고한다. 계수 이름·곡선 모양이 같다는 이유로 제품 단위를 실제 물리량과 같다고 하지 않았다. 해당 보고의 해 표기를 정밀 solver로 채택하지 않고 MIT/OpenStax의 식과 구별했다. [D009/D010](sources.jsonl).

자료·사건·참가자·조건을 별도로 센다. E002는 같은24명이 두 실험에 참여했고48명이 아니다. E003의 본실험12명과 파일럿4명의 중복은 미확인이다. E003은 원문에 총2280trial을 적었지만 제시된 요인의 곱은2880이다. 원시자료나 저자 정정이 없어 어느 수로도 합산 정확률을 만들지 않았다. 추가 감사도 PDF pp5–6을 다시 열어 이 불일치를 확인했다. [출처 감사 재열람](streams/final-audit/source-audit-sources.jsonl). 본 연구의 새로운 인간 참가자 모집·링크 효과 측정은 미실시다.

검토 과정에서 d3 고정 README의 잘못된 앵커 `#many-body-forces`를 발견하여 새 카드에는 실제 `#many-body`를 썼다. react 스트림의 이전 artifact manifest 중 CSV2개의 CRLF 해시가 커밋 LF bytes와 다른 것도 확인했고, 이전 기록을 삭제하지 않고 [최종 검토](streams/final-audit/animation-review.json)에 정규화 이유와 실제 해시를 병기했다. 사전 예측·원출력은 변경하지 않았다. 최종 구조 검사는 [audit](evidence/audit-final.json)에 기록하며, 사실 전체나 제품 품질의 자동 인증으로 부르지 않는다.
