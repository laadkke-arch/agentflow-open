## 4. 단위와 조작의 반례

### AUD01: 포함 프레임과 점 선택 조회

[Avid p82 Using Frame Offset](https://resources.avid.com/SupportFiles/attach/MCGS.PDF)는 시작 프레임을 길이에 포함하는 영상 계산을 설명한다. [Premiere CS6 PDF289–290 / printed285–286](https://help.adobe.com/archive/en/premiere-pro/cs6/premiere_pro_reference.pdf)는 오디오 표본 단위 In/Out을 별도로 다룬다. 25fps의 한 프레임0.04초는48kHz의 한 표본0.0000208333초의1920배다. `start=end=1.25`인 조회에 영상의 포함 프레임 규칙을 더하면 원래 계약을 바꾼다.

[Media Fragments REC2012 §4.2.1, §6.2.2](https://www.w3.org/TR/2012/REC-media-frags-20120925/)는 반열린 재생 구간과 `a>=b`의 무효·무시 처리를 함께 규정한다. 따라서 `a=b`를 빈 재생 구간으로 단정할 수 없다. 이것은 유효한 Audacity 점 선택 상태를 반환하는 getter와 다른 조작이다. 두 제공 후보가 같은 조회값을 내는 AUD01은 판별 성공으로 승격할 수 없다.

### AUD02: 정확한 색과 가독성

[WCAG2.1 SC1.4.11](https://www.w3.org/TR/2018/REC-WCAG21-20180605/#non-text-contrast)의 범위는 필요한 그래픽·UI 정보이며 예외가 있다. 같은색의 비율은 **1:1**, 검정/흰색은21:1이다. 봉인 AUD02-P1의 `contrast0`은 보이는 차이가 없다는 구어 표현이며 비율0이라는 뜻으로 쓰면 틀린다. 원문은 보존하고 이 주석을 단다. 사용자 선호만으로 essential 예외가 자동 성립하지 않는다. native waveform 설계에 이 원리를 적용한 것은 연구자의 기준이다. 정확한 RGB 보존이 강한 조건이면 자동 보정 B는 부적격이고, 가독성이 우선이면 B 또는 대비를 갖춘 별도 표현을 검토할 수 있다. 선택 테두리만 추가해도 waveform 자체가 읽히는 것은 아니다. 이 절과 glossary의 contrast ratio/essential을 봉인 뒤 다시 읽었으며 중복 원문으로 기록했다.

### AUD03: FFT-bin toy와 실제 Noise Reduction

Fs=48000, N=2048이면 bin 간격은23.4375Hz다. 봉인한 floor/ceil 규칙은 **42..85**를 포함한다. bin42는984.375Hz로1000Hz보다 낮다. bin86=2015.625Hz는 최초 제외 bin이다. 연속 주파수1000..2000Hz 조건과 모든 bin 중심이 그 안에 있다는 조건을 혼동하면 안 된다. 하한을ceil43으로 바꾸면 낮은 경계가 달라지며 이는 별도 민감도다.

봉인 toy는 안쪽의 gain을-6dB, 밖을0dB로 두고, B에서 대칭5개 bin의 log-gain을 등가중 평균한다. 정상 bin64에서는 두 방식 모두-6dB이고, 경계 bin86에서는 A=0dB, B=(2×-6+3×0)/5=**-2.4dB**다. 이 수치는 선택한 연산자의 산술 결과다. [Smith Rectangular Window / Side Lobes / Summary](https://ccrma.stanford.edu/~jos/sasp/Rectangular_Window.html)는 창 함수와 주파수 특성의 trade-off를 설명하지만 이5-bin 효과량을 도출하지 않는다. [Final Cut Softness](https://support.apple.com/en-lamr/guide/final-cut-pro/vera699eacc8/mac)는 주변 색을 포함시키는 조작이고, [Netflix §1·§2·§5](https://partnerhelp.netflixstudios.com/hc/en-us/articles/360051554394-Timed-Text-Style-Guide-Subtitle-Timing-Guidelines)는 읽기를 위한 자막 시간 조작이다. 색상 범위·시간 경계에서 FFT gain kernel을 곧장 얻을 수 없다.

| 바꾼 조건 | 최초 제외 bin의 B 예측 | 결과 |
|---|---:|---|
| radius0 | 0dB | A와 같아져 판별 사라짐 |
| 대칭3-bin 기하평균 | -2dB | 차이는 유지, 수치 변동 |
| 봉인 대칭5-bin 기하평균 | -2.4dB | 봉인 산술 |
| 대칭7-bin 기하평균 | 약-2.57143dB | 다른 실험 |
| 5-bin 선형 gain 산술평균 | 약-1.93305dB | 평균할 공간을 바꾸면 수치도 변동 |
| 선택 안쪽에만 smoothing | 0dB | 밖 보존 시 A와 같음 |

N=4096으로 바꾸면 첫 제외 bin은171=2003.90625Hz이고, 기존 숫자86은1007.8125Hz로 안쪽이 된다. Fs44100/N2048에서는 첫 제외가93=2002.587890625Hz이고, 기존86은1851.85546875Hz다. 각 판에서 **다시 계산한 최초 제외 bin**을 쓰면 같은 toy의-2.4dB 관계가 유지된다. 숫자86만 고정하면 다른 물리 입력을 시험한다.

부모가22:22:34Z 재독에서 확인했다고 전달한 NoiseReduction.cpp2.4.2 L75–77의 로컬 `#undef EXPERIMENTAL_SPECTRAL_EDITING`은 사전 API 검사의 중요한 누락이다. 전역 define과 조건부 구현만 읽고 실제로 활성화된 기능이라 판단하면 안 된다. 감사자는 이를 직접 후속 코드에서 확인하지 않았으므로 부모/수신 조사자의 고정 URL과 정정 원장이 필요하다. 봉인 예측은 유지하되 실제 NR 실행이나 지원 API라는 서술은 철회·정정해야 한다. 이 누락으로 toy arithmetic이 실행 증거로 바뀌지는 않는다.

### M02/M03: 비용과 목적

M02에서 고정 폰트·도면 크기·단일 페이지·방향 조건을 풀면 확대 용지/축소/회전/분할을 검토할 수 있으므로 clip만 남는 추천은 유지되지 않는다. M03에서 중앙 설명 대신 데이터값0.5의 정확한 위치 표시가 목적이면 B가 적합할 수 있다. 봉인 선형 범위 가정에서는 data0.5의 axes y가 max0.99에서0.50505, max0.099에서5.0505, max9.9에서0.050505인 반면 container center는0.5다. 좌표 숫자가 같아도 단위와 목적이 같지 않다.

## 5. 최종 판독에 넘길 조건

후속 원장과 결합할 때는 동일 출력 예측 M02/AUD01을 판별 성공에서 제외하고, AUD02를 강제 양자택일로 바꾸지 않으며, AUD03의 모델 산술을 실제 효과의 시험으로 집계하지 않는다. M01/M03도 조건을 만족한 정확한 관측 위치가 필요하다. 후속 정정은 원래 봉인과 바뀐 해석·영향 행·원래 집계를 나란히 남긴다. 같은 요구 이슈의 댓글, 같은 매뉴얼의 여러 절, 재방문은 최소수에 더하지 않는다. 성공 일치 하나로 역사적 영감·작성자 채택·검색 회수율을 주장할 수 없다.
