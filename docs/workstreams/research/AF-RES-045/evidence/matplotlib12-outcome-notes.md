# M01·M02 후속 판독 — 봉인 뒤 독립 작업자 기록

예측 봉인: `0d998cb3503e8a7f0faf2bf2f8e62dd046a662b1`, 2026-11-22T22:19:23Z. 처음 댓글·타임라인을 연 시각은 **2026-11-22T22:20:03Z**다. 이 파일과 JSON은 결과 공개 뒤 작성했다. 봉인 파일은 수정하지 않았다.

## 판정

| 요구 | 판독 결과 | 엄격한 판별 판정 |
| --- | --- | --- |
| M01 | A 조작은 원작성자의 간단한 예제 재시험 보고와 일치한다. 정상 Cartesian 대조와 B 전체 raster 축소 결과는 없다. | **판정불가**. A만 관측한 사실로 B 또는 P2를 기각할 수 없다. |
| M02 | 기존 API의 사용 제안을 원작성자가 수락했다. 10·30개 범례 각각의 고정 글꼴·10x3 캔버스 bbox는 미확인이다. | **판별불가**. 두 후보 모두 같은 조건부 B를 예측했다. |

M01에는 추가적인 봉인 표현상의 약점이 있다. P2의 선호 조작은 B로 표시되지만, 경계 예측은 내부 배치 문제라면 B가 해결하지 못한다고 이미 썼다. 따라서 선호 조작이 다른 것과 동일 관측값에 대한 두 원리의 예측이 충돌하는 것은 구별해야 한다. 예컨대 A 성공·B 실패가 실제로 관측되더라도 두 행의 서술된 출력 예상이 모두 맞을 수 있다. 이 점 때문에 원래 `different_conditional` 필드를 결과에 맞춰 고치지 않았으며, 이를 유일 지지로 세지 않는다.

근거별 D(결정) / S(명세) / C(코드) / T(시험 정의) / R(공개 실행 보고) / L(릴리스) 위치와 한계는 [matplotlib12-outcomes.json](matplotlib12-outcomes.json)에 둔다. R은 이 작업자가 수행한 실행이 아니다. T에 있는 코드의 존재도 시험 통과를 뜻하지 않는다.

## 직접 확인한 반례와 범위

1. **정리할 기하와 고정할 데이터 범위를 혼동하는 경우.** [Cartopy1370](https://github.com/SciTools/cartopy/pull/1370#issuecomment-569853924)은 M01을 직접 지목한 별도 수정안이다. 초기화에서 전역 범위를 강제로 선택하면 데이터 자동 범위 조절을 잃는다. 이 조작은 봉인 A/B 어느 쪽도 아니므로, A를 거짓이라고 판정하는 데 쓰지 않는다. 다만 “먼저 기하를 확정하라”를 무조건적인 전역 범위 고정으로 번역하는 추천을 막는다.
2. **정리 비용이 커지는 경우.** [Cartopy1956](https://github.com/SciTools/cartopy/pull/1956)의 큰 변환 데이터 비교는 불필요한 bbox 계산을 피하는 제안을 뒷받침한다. 이 기록은 비용 조건을 없앤 일반적인 pre-draw 권고의 한계를 보여준다. 다른 입력·다른 판의 작성자 성능 보고이며, 본 작업의 재현 수치가 아니다.
3. **수신 API가 조작을 허용하지 않는 경우.** [1355의 고정 시험](https://github.com/SciTools/cartopy/blob/4703efc6e85a3e0e616889e29382659a741299b9/lib/cartopy/tests/mpl/test_gridliner.py#L239-L280)은 Matplotlib2.0 미만을 건너뛰는 이유를 명시한다. 원리가 타당해도 당시 확장 지점이 없으면 동일 구현을 그대로 적용할 수 없다.
4. **그림에서 생략하는 것과 layout 계산에서 빼는 것은 다른 경우.** M02의 작성자가 고려한 범례 항목 수 제한은 실제 series key를 덜 그린다. 이후 수락한 API 조작은 그리기 자체를 지우지 않는다. 지도에서 지명을 생략하는 원문을 근거로 데이터 범례의 완전성을 보장할 수 없다.

M01에서 2020년 개선과 2022년 재시험을 한 결과로 합치면 안 된다. 새 판에서 재현되지 않았다는 사실은 2019년 판의 최초 저장 예측이나 어떤 개별 PR의 인과를 대신하지 않는다. 마찬가지로 M02의 2020년 튜토리얼 정정으로 2019년 30개 범례의 기대 bbox를 채우지 않는다.

## 아직 실행하지 않은 최소 확인

M01: Matplotlib3.0.2와 Cartopy0.17.0 환경에서 원문의 import만 `import cartopy.crs as ccrs`로 바로잡는다. 최초 요구의 PlateCarree 빈 axes에 동일 renderer로 A, 원래 두 저장, B 전체 raster 비례 축소를 실행한다. 그림 크기·글꼴·투영을 고정하고 axes의 절대 bbox, 정규화 bbox, aspect를 기록한다. 동일 크기의 Cartesian 대조도 수행한다. 그림 전체를 scaling한 뒤 canvas 크기만 보는 검사는 내부 상대 배치 판별을 대체하지 못한다.

M02: Matplotlib3.0.2에서 원문의10x3 inch,3subplot,5:1:5 코드에 범례10·20·30개를 각각 사용한다. A, B, 범례 artist 없는 대조를 같은 글꼴로 실행한다. 좌우 axes bbox와 범례 bounds, 실제 clipping, 경고를 각각 기록한다. `set_in_layout(False)` 뒤 추가 layout 호출 없이 이미 계산된 위치만 비교하지 않는다.

위 입력과 명령에 필요한 수신 원문은 [M01](https://github.com/matplotlib/matplotlib/issues/13430), [M02](https://github.com/matplotlib/matplotlib/issues/13522)다. 역사적 환경이 아직 구성되지 않았으므로 실행 명령은 환경을 재현한 뒤의 `python -B m01_repro.py`, `python -B m02_repro.py` 수준의 후속 제안이며, 해당 이름의 스크립트를 작성·실행했다고 주장하지 않는다. 부모 인계에서는 실행 가능한 원문 기반 스크립트 또는 정확한 코드 블록을 먼저 고정해야 한다.
