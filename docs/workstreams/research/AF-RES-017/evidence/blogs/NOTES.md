## 가장 강한 인과 기록과 반증

### B02: 오래된 알고리즘은 있었고, 검색은 실패했으며, 독자가 연결했다

2006-12 원글, 2007-01-08 독자의 선행 논문 소개, 2007-01-09 Menhir 안내, 2007-01-10 저자의 하루 이식 보고, 2007-03 공개 릴리스, 1977-09 출판사 날짜가 이어진다. 몇 시간 검색 실패라는 직접 진술도 있다. 단, 2022 회고가 초기 성능 문제의 원인을 메모이제이션 누락으로 정정한다. 선행 알고리즘 발견의 효용과 구현 버그를 고친 효용을 분리해야 한다. DOI 페이지에서 읽은 것은 출판사 요약·날짜이며 유료 논문 전문을 읽었다고 쓰면 안 된다. 관련 자료 B-S02–05.

### B15: 큰 교체 폭은 있지만 정확한 날짜와 선정 편향이 남는다

Pendo 엔지니어링 책임자의 직접 증언으로 Vue 문서에서 Cypress를 발견했고 자체 테스트 체계 6개월분을 2주 만에 대체했다고 보고한다. 6개월은 인월이 아니다. 발견 연도는 2019지만 월과 원래 착수일은 미상이다. 제품 공급자 Cypress가 발행한 성공 사례이므로 사실 기록의 존재와 대표성은 별개다. 후속으로 Pendo 자체 사이트의 2021-07 기술 링크를 읽었지만 최초 도입·비용의 독립 기록은 아니었다. 같은 PDF도2019 연도만 반복했다. 2018-10 이슈 댓글 표시는 본문·사건 연결이 미확인이라 날짜를 수정하지 않았다(`date-followup.json`). 관련 B-S35–37.

### B11: 기존 완성품을 더 일찍 알아도 결정은 같았을 강한 통제

Dropbox는 이미 S3를 사용했다. 2013년 여름 자체 저장소를 시작한 이유는 성능·단위 경제성·규모에 대한 직접 통제였고, 약 2년 반이라는 개발 기간이 공개된다. 그 기간은 무지로 낭비한 시간이 아니다. 별도 글에서 블록 인덱스의 자체 KV 계획을 MySQL로 충분하다고 바꾼 기록도 읽었으나 실제 만들었다가 폐기한 근거가 없어 추가 재발명 사례로 세지 않았다. 관련 B-S23–24, B-S48.

## 비용을 합치지 않은 이유

확인한 지표는 서로 다른 대상을 센다. B02 하루 이식, B08 종료 예고에서 종료까지 8개월·2000개 넘는 Jenkinsfile 변경 대상, B11 약 30개월 프로젝트, B12 140개 넘는 서비스 통합·세 엔지니어의 유지 부담, B15 6개월 작업분/2주 교체, B16 23000줄 넘는 파일 재구성이 있다. 일부는 전체 프로젝트가 아니며 일부는 코드 규모일 뿐이다.

Linkerd의 172K/30K LOC, Pebble의 코드 크기, Airbnb React Native 코드 크기는 삭제 LOC가 아니다. Prezi의 ‘most of a year’와 Dropbox의 ‘weeks’는 정확한 기간으로 바꾸지 않았다. 코드 이동을 삭제, 달력을 인월, 성능 개선을 피할 수 있었던 재발명 비용으로 바꾸지 않는다. 비용 분포는 부모가 같은 단위·같은 의미를 가진 지표끼리만 계산해야 한다.

## 공식 설명과 현재 검색 진단

16개 모두 공식 설명의 **25단어 이하 원문 발췌·제목·표제**를 `official_target_description.text`에 넣었다. 보조 연구자 요약은 별도 필드다. 원문 발췌를 모두 다시 확인했으며 B01은 부모가 공개 git으로 가져온 고정 객체를 수집자가 직접 `git show`로 읽었다. 일부 설명은 live이고, 일부 고정 설명도 실제 최초 결정 이후다. 따라서 어휘 겹침은 선택한 짧은 설명과 연구자 작성 필요 요약의 문자열 진단이다. 역사적 검색가능성이나 전체 의미 유사도가 아니다.

`ordinary-query-diagnostic.json`은 2026-11-21 04:06:12Z에 16개 질의를 먼저 저장한 다음 실행했다. 각각 필요 설명에서 두 단어를 골랐으며 목표 실체의 이름은 넣지 않았다. 답을 이미 안 수집자가 질의를 골랐으므로 비맹검 편향을 기록했다. 순위는 검색 도구가 반환한 순서이며 실제 검색엔진 화면의 순위를 독립 확인하지 않았다. 결과 다섯 개를 다시 조합·중복 제거하지 않고 그대로 보존했다.

현재 창의 목표 이름 출현은 **6/16**, 미출현은 **10/16**, 판정 불가는 **0/16**이다. 출현은 B03 1위, B04 1위, B08 2위, B09 1위, B11 2위, B15 5위다. 모두 반환된 발췌문 속 출현일 수 있고 공식 목표 페이지 직접 적중을 뜻하지 않는다. 엄격 양성 B02는 현재 이 단일 질의의 첫 다섯 결과에서 미출현했다. 처음 반환 발췌만 보았을 때 사례 회고 URL 자체는 0/16이었다. 이후 6개 목표 적중의 실제 본문과 B04의 추가 적중까지 총 7페이지를 열어 기능 적합성을 확인했다. B04의 WhichDB·1bench 두 페이지에는 후속 결과 Pebble/CockroachDB 관계가 노출되어 SCOPE의 목표 사건 누설 규칙으로 제외했다. 따라서 **본문 확인 및 사건 누설 제외 후 current_easy_hit는 5/16**이며, 현재 지식 일반의 시간 누설은 여전히 제거하지 않았다. 이를 ‘제품 추가 가치 없음 6/16’이나 ‘당시 발견 가능 6/16’으로 보고하면 안 된다.

두 단어 모호성의 구체 예는 B12 `event delivery`가 행사 배달·행사 운영 채용을, B13 `job queue`가 채용·일반 작업 큐를, B14 `asynchronous effects`가 형식효과 논문과 생물학·지각 연구를 반환한 것이다. 검색어 한 번의 실패는 더 좋은 일반 검색의 실패가 아니다. 검색 결과 본문은 새 1차 문헌으로 세지 않으며 D3-search 관측만 남겼다.
