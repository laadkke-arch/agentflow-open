## 어휘 겹침

`tools/analyze.py`와 `lexical-protocol.json`이 고정된 need/공식 설명에서 공유 핵심어를 계산한다. 40건 중앙값1개, 범위0–4개다. 단어 수를 의미 유사도나 검색 성공 확률로 바꾸지 않는다. 영어 원형 복원은 지정한 단복수 접미사만 사용한다. 공식 설명 중 PM01·PM03은 명시한 작업자 요약이며 나머지는 직접 읽은 짧은 공식 발췌/제목/표제이다. 버전별 설명과 현재 설명은 별도 표시했다. 사후에 필요한 문장을 골랐다는 편향도 남는다.
