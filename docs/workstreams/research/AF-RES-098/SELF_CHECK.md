## 산출물·분모·중복 검산

- 6개 사전 예측과 12개 판별 자리, P/U/G 각각 12개를 대조한다. generation_record_url의 빈칸을 빌드 규칙 URL로 메워 생성 증거인 척하지 않는다.
- 164 원장 행 중 고유 1차 자료 102개, 본문18·payload17·발행/빌드/목록48·EPUB3·데이터6으로 최소를 검산한다. 주6쌍만 보수적으로 dedup한 본문은8, 주src payload는10이다. 본문 최소10은 실제로 읽은 선행 제외 예제 본문을 더한 전체18로 충족하며, selected-only 분모와 섞지 않는다.
- 같은 SHA의 같은 저작·같은 anchor/raw/blob·판 중복, inherited calibration, 실패·빈job·미열람을 제외한다. source family12와 선택 publication/dataset lineage5를 별개로 보고한다.
- source count는 직접 읽은 고유 저작 수, frame1335는 경로 수, 주28은 body/src/srcset 주소 수, request receipt는 접근 회차 수다. 서로 바꿔 더하지 않는다. 전송량14,522,038B의 사전 목록 접근7회도 사람 시간으로 환산하지 않는다.
- mutable API/공식 release URL은 조회 UTC와 가능한 응답SHA를 남긴다. immutable 고정URL을 얻지 못한 목록은 없는 것으로 명시하며 생성 provenance로 승격하지 않는다.
- calibration의 정적 부재 주장은 위 특정 div와 URI유형/전체문서 후보 검색에 한정한다. 접근 실패는 UNKNOWN이며 사이트 전체 부재를 주장하지 않는다.

## 발견한 오류와 실제 검토 주체

작성자 검산에서 asciicast h2만 잡던 절 경계를 enclosing div로 고쳤고, 후속 검산에서 HTMLParser.offset의 컬럼값과 부딪힌 행번호 오프셋을 별도속성으로 바꿨다. 옛 img절대행150·160, 새 img0이라는 결과·분모는 유지됐다. 별도 AI 에이전트가 모집/봉인 파일을 다시 읽어 PY2 설명문500×322오기를 발견했다. 원IHDR와selected.json은500×320이었고 봉인문서는 보존한 채 후속증거에 정정했다. GG 원장의 빈 claim 3개도 채웠다. 최종 별도 검토에서 MP2 동일 article과 MP1 실행시간만 다른 본문을 중복 제외해 104/본문20에서 102/본문18로 정정했고, 협업 전체 최초 새 PNG 시각을 CPython19:46:14.414533Z로 바로잡았다. 작성보고서의 calibration 반환URL은 정확한 articles/asciicast-demo.html 절로 정정했다.

별도 AI 검토의 실제 실행과 한계는 [모집 검토](evidence/cross-review/review.md), [자료 수 검토](evidence/cross-review/source-count-review.md), [최종 결과 검토](evidence/cross-review/final-review.md)에 둔다. 자기 소관의 타 분야 조사 또는 GG 원장 검토는 독립 사람 검토로 부르지 않는다.

## 계약·검사·미실시

시작 통합SHA는01177554d0fbd33a914ea9c982c348d442d1358d이며 의존branch 원격b09dd21…와 연구입력082ba3…를 구별했다. 실제 읽은5blob은 같았다. start 명령 종료0은 [입력 계약](evidence/input-contract.json)에서 확인한다. 결과판의 `check --fetch`, 공통 `cloud_check --fetch-contract --require-clean`, 구조검산·선택적네트워크재검사의 실제SHA/종료값/범위와 skipped 상태는 **검사 후** [validation.json](evidence/validation.json)에 기록한다. 이 초안에서는 통과를 선기입하지 않는다.

예제프로그램 빌드·실행, browser/DPR·EPUBreader 실행, Corpus 대용량ZIP MD5재계산, 자원생성 job재현은 미실시다. 필요한 명령·입력과 재개의 첫 행동은 [reproduce.md](reproduce.md)와 마지막 HANDOFF에 둔다. 모든 최종수정은 owned_path에만 커밋하고, 필수표·원증거·재현절차를 GitHub고정결과판에서 다시열어확인한 뒤 HANDOFF만 마지막에 단독커밋한다.
