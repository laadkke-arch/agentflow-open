## 안내 선택과 적용 조건

- **인쇄 목차 제목을 원하는 저자.** 2.3 기본 article이면 `--toc`와 `--metadata=toc-title:Archive Contents 264`를 함께 안내하고 페이지의 제목·항목을 확인한다. 2.2.3.2를 유지하거나 이전 맞춤 템플릿을 쓴다면 `--template`에서 같은 조건부를 적용하는 대안이 있다. 실제 로드되는 템플릿과 class의 `\tableofcontents`가 해당 `\contentsname`을 쓰는 조건이다. 다른 제목 매크로나 언어 hook을 사용하는 클래스는 생성 TeX를 먼저 읽는다. [2.3의 옵션 절](https://github.com/jgm/pandoc/blob/e09dc44c00ff1661280bbf544d1913c61a901360/MANUAL.txt#L1368-L1370) · [2.2.3.2 맞춤 템플릿 절](https://github.com/jgm/pandoc/blob/672804922542cc3d3a1719a2b4064ba91fccc6c8/MANUAL.txt#L649-L656)
- **탐색창의 이름이나 위치를 원하는 독자.** 명시적 `\pdfbookmark`로 제목·대상 ID·계층을 별도로 지정할 수 있다. 이 배치에서는 기존 네 노드의 페이지 좌표가 이동했으므로 페이지 위치를 고정해야 하면 삽입 위치를 조정한 PDF에서 대상과 기하를 다시 확인한다. `--toc` 없이 본문 탐색만 원하는 경우에는 이 fixture의 기본 4노드가 이미 있다. 인쇄 목차만 필요한 문서에서 `bookmarks=false`는 직접 확인한 선택지다. [명시적 노드](receipts/controls/new-explicit-toc-bookmark/run.json) · [책갈피 정상 공석](receipts/controls/new-no-bookmarks/run.json)
- **유지보수자와 인쇄본 검토자.** 생성 TeX의 `contentsname`, 페이지 제목, 항목 수, outline과 link annotation을 차례로 점검하면 실패 지점을 좁힐 수 있다. `--toc-depth=1`처럼 두 층이 기본값을 공유하는 변수가 있다. 깊이·Beamer·book·다른 PDF 엔진에 적용하려면 해당 class와 엔진에서 각 층의 결과를 확인한다. [깊이 대조](receipts/controls/new-depth-one/run.json) · [반례 및 변경 이력](COUNTEREXAMPLES.md)
