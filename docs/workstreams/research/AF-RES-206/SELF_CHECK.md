## 재검증 범위

[실행 영수증](receipts/README.md)의 Python 3.12.14 / curl 8.14.1 비교 루틴은 원본 부재 상태에서 종료 2, stderr 0바이트다. 14개 통제와 자료의 상대 방향 비교는 실행했다. 원 OS 팩으로 끝까지 도는 경로 및 실자료 X05 HTML 구조 파서는 미실행이고, 저장한 웹 렌더링 추출은 실행했다.

공통 클라우드 검사 및 개별 배정 검사 결과는 [검사 실행 요약](receipts/repository-checks.txt)에 기록했다. 공통 검사에서 `check-all`은 `no_active_sessions`를 반납했고, 배정 경로 안에 위치한 manifest를 대상으로 `workbench.session check ... --fetch`를 따로 실행했다. 계약 해시가 같고 최신 통합판이 이동한 것을 확인했다. 이 검사들은 외부 문서의 참·거짓이나 좌표 변환을 판정하지 않는다. 결과 SHA의 원격 재열람과 최종 인계 전 검사를 HANDOFF에 명시한다.
