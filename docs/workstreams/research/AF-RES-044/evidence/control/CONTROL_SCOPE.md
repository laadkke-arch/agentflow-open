# 보강 표본 범위·봉인

C1은 HTTPX 공식 Requests 이관 가이드 본문 첫6 href다. C2는 pandas2.0.3 공식 ecosystem Visualization 첫6을 별도 봉인한다. C3/C4는 Python3.11 공식 변경 가이드의 PEP654/asyncio 절 첫6 href다. Python 표본으로 확장한 이유는 Pillow/psycopg/NumPy/Requests 원 HTML 취득실패이며, 초기 검색 실패 기록을 유지한다. 이들은 모두 해법을 아는 양성 대조이고 natural40 표집이나 발견 성공률에 넣지 않는다.

실제 headline/self permalink를 제거하지 않으며 source-section이 다른 후보의 충분근거를 이미 포함할 수 있음을 허용한다. A/B/C를 계산하기 전에 요구 원자·원6URL·HTML SHA256·순서를 freeze-C*.json으로 고정한다. C1 source별적격에 HTTPX/Requests를 함께 읽고 교환 가능성은 generic request 수준에 한정한다. C2 대표 ecosystem 절 자체에 여러 구현의 기능지원이 있으면 그 완전대안을 누락시키지 않는다. C3/C4는 특정 계약원자를 만족할 보완문서 묶음과 유사 오답을 명시한다.

C1 Requests후보의 HTTP403은 웹도구 원문직접열람과 구별한다. 실제DOM fragment 위치를 따로 확인하지 못한 경로는 클릭 도달판정 미확인. raw href를 성공URL로 고쳐 쓰지 않는다.
