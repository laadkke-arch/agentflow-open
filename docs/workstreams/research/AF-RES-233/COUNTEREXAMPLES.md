# 반례·정정 (③ 이후 자체 반증 검토)
각 근거의 원주소/위치는 sources.jsonl. 설계 예상과 실제 관측을 나눈다.

1. **같은 사람도 하나의 전거 레코드라는 가설 반증.** E03 교육 Twain 100/400/500 및 E04 L3073–3078 Nora Roberts / J.D. Robb 별도 접근점; R04/R06 500 related heading 및 여러 필명 관계. 실제 기관 원레코드 A06 BnF 공동 필명 Jalin에는 Dumas fils와 François, Alphonse 관계가 있으므로 Jalin=Dumas fils로 축약하면 다른 저자의 저작 연결까지 잘못 전파. A02 associated도 alias 아님. 개인 동일성, 서지 접근점, 공동 필명, 작품의 역할은 별개 노드/관계다. E03의 display에는 Clements/Clemens 철자 차이도 있어 표시용 문구가 원필드보다 강한 근거가 될 수 없다. 실제 500 MARC 현행 레코드는 확보 못했으므로 BnF 관계로 대체한 500 관측이라 말하지 않는다.
2. **같은 이름의 다른 저자는 실제로 존재.** A01/A02는 BnF가 서로 관련된 두 ID와 1802–1870 / 1824–1895를 나눔, A03/A04 NDL도 다른 ID. W01 한 서지에 두 Dumas 접근점이 함께 나타나므로 제목 문자열이나 co-occurrence로도 자동 동일성 불가. W02와 W03/W04는 서로 다른 저작 귀속. B 사례 자체는 E04/E02에서 두 자리로 가르치지만 현재 010·서지 연결이 없으므로 C 반례를 B 완료로 계산하지 않음.
3. **서지 표제와 이름 같음은 저작자 역할 같음이 아니다.** W05 제목 Dumas는 피전기 인물 Thomas Alexandre Dumas와 관련, 저자는 Tom Reiss, 번역/각색 역할은 다른 사람. W03/W04 번역 및 Maquet 협업, W01 scientific editors, W02 번역. 이름/작품만 저장하면 역할 지워짐. 반대로 원저자 동일성을 이유로 서로 다른 언어판/각색물을 같은 edition 링크로 병합해도 오류. W03/W04는 별도 서지이나 같은 underlying Monte-Cristo 계보.
4. **현재 ID는 과거 인용을 대체하지 않는다.** R01 010 $a와 반복 가능한 $z의 구분, R05 duplicate cancellation 운영과 005 버전 R02. 취소 번호 자체가 임의로 만들어낸 sameAs가 아님. 실제 cancellation 사건 0건 확보, R01 n80022124/n80014241은 예시. A02의 obsolete ISNI는 LC 010 z가 아니고 별개 namespace. 이전 링크를 옛 버전 그대로 보존하되 검증된 방향 redirect만 현재 검색에 추가한다.
5. **GNIS analogy 반례.** G02 동일 Census Code라도 Civil vs Populated Place의 다른 feature ID 가능, 좌표 대표점은 class마다 다름. G04 Mount Rainier 검색에서 네 후보; 산의 올바른 번호 1533614는 기관 지침 예시(다른 3개의 실제 번호나 행은 미확인). 현재 USGS WFS G05/G06은 flat schema; variant 행은 G03의 All Names에 있음. F24 실제 응답 실패. Springfield 후보를 확정 pair라고 쓰지 않고 좌표·종류를 확인할 때까지 보류. 책의 시대·저작 역할은 좌표처럼 비교용 context일 뿐 유일 키가 아니다.
6. **사후 정정.** E04 공식 교재 원문 텍스트 회복: E01 재전재는 동일 저작이고 E04를 별도 원저작으로 산입하지 않았다. F12는 최초 실패 경로로 보존. E04 Appendix B-1 OCLC 표시와 B-2 LC 화면의 로마자 전사에 parsed spelling 차이가 있어 exact spelling 확정하지 않음; F25 screenshot 실패. 실제 원기관 전거 current와 역사 교재가 같다고 확정하지 않음. 최초 ③의 LC C-père 실패 참조 F05는 A 경로였으므로 F06–F07로, C-fils는 F08로 고침; A 현행 실패 F01–F05. GNIS 원자료 3개 이상이라는 수량을 가이드/서비스 메타데이터로만 충족해도 actual feature pair/variant 0/3인 핵심 결측은 그대로.
