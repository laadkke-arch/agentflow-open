## 타 분야 인용 분류에 대한 경계

Swift 리뷰에서 Kotlin chaining을 비교한 것은 **다른 언어·생태계의 사용성 비교**다. Python 리뷰의 JavaScript destructuring 언급도 같은 범주다. 단지 언어 이름이 다르거나 유추 표현이 쓰였다는 이유로 ‘다른 분야 원리’로 올리면 안 된다. 이 메모는 코퍼스 밖 리뷰의 관측이므로 Q4의 사례별 비율 분모에는 넣지 않는다.

`as?`와 `try?` 비교의 반박은 같은 언어 안에서도 원리·구조의 적합성을 확인해야 함을 보여준다. 이는 어떤 분야가 더 좋은 유추를 제공한다는 증거가 아니라, 유사한 표현의 전제 차이를 실제 리뷰가 문제 삼았다는 증거다. 역할 분류와 AF-RES-004의 판정 축은 그대로 유지한다.
