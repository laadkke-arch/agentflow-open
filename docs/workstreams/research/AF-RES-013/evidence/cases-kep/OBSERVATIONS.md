# Kubernetes의 정답원 경계

1. K0127 고정판의 런타임mapping 대안은 연결한 댓글798760382의 실제주장과 다르다. 문서는 런타임마다선택하는제안으로요약하지만 댓글은혼합런타임때문에mapping/size를Kubernetes가명세해야한다고한다. 따라서 gold는‘문서에기록된비교항목’이며인용정확성이보장된정답이아니다.
2. K0383의현재ImplementationHistory는2017-10-7병합으로적었지만PR932 merged_at은2017-09-27이다. 단순포팅일/회고일을입력cutoff로쓰지않았다.
3. K0277의최신판에는docker cp/exec대안이추가되어있지만2019-04-16수용판의비교절에는없다. 이후추가항목을소급하지않고역사판10개를분모로사용했다.
4. K0019은7가지타이머알고리즘을비교하지만동기절은controller 전체의개선목적이다. 검색자에게타이머만찾도록사후힌트를주지않았다. 낮은회수는목적의넓이와gold의내부단위불일치일수있다.
5. K0383의능동태구조대안은언어역할을data필드로옮긴경계사례다. 외부학문문헌의인용없이제안안내에서쓰는용어·구조이므로엄격타분야원리에산입하지않으며넓은경계집계에만남긴다.
