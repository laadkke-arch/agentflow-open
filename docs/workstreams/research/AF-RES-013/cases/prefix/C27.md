# 결정 전 문제 문맥 — C27

Decision cutoff (UTC date): 2016-01-20

## 시점과 환경

2016년 초의 Swift 언어 문제다. 함수와 메서드를 일급 값으로 이용할 수 있으며, 호출할 때는 인수 레이블로 같은 기본 이름을 가진 메서드를 구별한다.

## 해결할 문제

함수 자체를 값으로 참조할 때에는 기본 이름만 제공할 수 있어 오버로드를 구분하기 어렵다. 타입 정보를 붙이는 방법은 장황하며, 인수 타입이 같은 오버로드 사이에서는 충분하지 않다. 이런 경우에 간단한 참조를 위해 별도 코드를 길게 작성해야 한다. 외부 객체 런타임에 전달할 특정 메서드를 지정하는 작업도 같은 문제와 연결된다.

## 반드시 고려할 조건

같은 기본 이름을 가진 오버로드 중 의도한 함수나 메서드를 값으로 참조할 수 있어야 한다. 인수 타입이 같아도 레이블이 다른 경우를 고려한다. 참조에 필요한 반복 코드와 불필요한 타입 표기를 줄인다.
