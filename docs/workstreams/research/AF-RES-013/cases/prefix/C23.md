# 결정 전 문제 문맥 — C23

Decision cutoff (UTC date): 2016-03-31

## 시점과 환경

2015년 말의 Swift 시스템 프로그래밍 문제다.

## 해결할 문제

포인터 정렬 확인, 포인터에 태그 넣기, 주소 사이의 비트 연산과 같은 저수준 작업을 언어 안에서 간결하게 수행하고 싶다. 주소 크기의 정수형 인수를 요구하는 외부 C 함수와의 연동도 필요하다. 당시 언어가 제공하는 포인터 조작만으로는 일부 작업이나 직접적인 함수 호출을 표현하기 어렵다.

## 반드시 고려할 조건

포인터를 다루는 시스템 프로그래밍과 C 상호 운용에 도움이 되어야 한다. 주소에 대한 산술·비트 연산을 Swift 코드에서 표현하는 목적을 고려한다. 이 작업이 본래 가진 불안전성을 제거한다는 요구는 문제 문맥에 없다.
