# Design context — C22

Decision cutoff (UTC date): 2014-08-05

In Rust, values accessed through a shared reference are not necessarily immutable because interior mutability exists. The phrase shared reference is therefore more accurate than immutable pointer. However, the existing trait named Share describes a different property: types that can safely be shared concurrently through such a reference. The overlapping terminology can confuse readers.

Find naming precedents or alternative terminology that distinguishes ordinary aliasable/shared access from concurrent sharing safety. Preserve the actual semantic property of the trait; a name must not silently redefine it.
