# 결정 전 문제 문맥 — C12

Decision cutoff (UTC date): 2016-09-08

## 시점과 환경

2016년의 Python 실행기 최적화 문제다. 내장 이름, 전역 이름, 타입과 객체의 속성 공간 등에 사전 형태의 저장소가 쓰인다. 함수의 지역 공간도 경우에 따라 사전일 수 있다.

## 해결할 문제

함수나 변수, 내장 기능의 바인딩이 실행 중에 바뀔 수 있어 최적화가 어렵다. 예를 들어 전역 이름을 한 번 찾은 뒤 상수처럼 재사용하면 빠를 수 있지만, 그 이름에 다른 값이 지정되면 원래의 동적 동작으로 돌아가야 한다. 변경 여부를 확인하는 비용이 최적화의 이득을 좌우한다.

## 반드시 고려할 조건

실행 중 변경 가능한 이름 공간이라는 Python의 의미를 보존한다. 캐시한 값이나 다른 최적화가 더 이상 유효하지 않은 시점을 판별할 수 있어야 한다. 변경 확인 자체가 반복적인 최적화의 이득을 없애지 않도록 비용을 고려한다.
