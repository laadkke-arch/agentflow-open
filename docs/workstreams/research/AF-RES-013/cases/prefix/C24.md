# 결정 전 문제 문맥 — C24

Decision cutoff (UTC date): 2016-01-13

## 시점과 환경

2015년 말의 Swift 초기화 설계 문제다. 컴파일러가 어떤 타입에 대해서는 저장된 속성으로부터 초기화 코드를 만들지만 적용 범위가 제한되어 있다.

## 해결할 문제

속성이 M개이고 초기화 경로가 N개이면 작성하고 유지할 할당 코드가 M×N에 따라 늘어난다. 유연한 초기화를 제공하려다 불변이어야 할 속성을 가변으로 만들거나, 객체를 만든 다음 여러 번 설정하여 의도한 사용에 맞지 않는 중간 상태를 거치기도 한다. 자동 생성 기능은 사용자 정의 초기화, 접근 제어, 클래스, 기본값, 지연 속성에서 제약이 있다.

## 반드시 고려할 조건

타입 작성자와 사용자의 반복 코드를 줄인다. 불변 속성을 쓰는 것을 어렵게 만들지 않아야 한다. 클라이언트가 설정할 속성과 숨겨진 구현 상태가 함께 있는 타입에서도 일부 초기화는 자동화하고 나머지는 작성자가 제어할 수 있어야 한다.
