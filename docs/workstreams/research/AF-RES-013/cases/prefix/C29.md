# 결정 전 문제 문맥 — C29

Decision cutoff (UTC date): 2016-04-01

## 시점과 환경

2016년 초의 Swift 접근 제어 문제다.

## 해결할 문제

클래스 또는 확장 안의 일부 선언은 공개 API의 구현에만 쓰이며 그 밖에서 직접 사용되면 안 된다. 현재 파일 단위의 가시성으로는 완전히 숨길 구현과 같은 파일의 관련 코드가 공유해도 되는 부분을 명확히 구별하기 어렵다. 관련 타입을 한 파일에 모으면서도 각 구현의 세부를 따로 보호하고 싶다. 이름 관례만으로 숨김 의도를 표시하면 컴파일러가 강제하지 못하고 코드 완성에도 잡음이 남는다.

## 반드시 고려할 조건

클래스 또는 확장 안의 구현 세부를 바깥 사용으로부터 보호한다. 관련 타입을 반드시 서로 다른 파일로 나눠야 하는 제약을 줄인다. 숨김 의도가 컴파일러에 의해 강제되고 API 사용자에게 분명해야 한다.
