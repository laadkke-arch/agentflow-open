# 결정 전 문제 문맥 — C08

Decision cutoff (UTC date): 2000-07-27

## 시점과 환경

2000년의 Python 언어 설계 문제다.

## 해결할 문제

원소를 반복해서 얻고, 필요하면 조건을 검사하거나 여러 반복을 결합하여 새 리스트를 만드는 코드를 더 간결하게 표현하고 싶다. 당시 문제 설명은 리스트 생성의 간결함만 명시하고 있으며, 별도의 성능 수치나 실행 환경 제약은 제시하지 않는다.

## 반드시 고려할 조건

결과는 리스트 생성에 도움이 되어야 한다. 반복에 따른 원소 생성과 조건에 따른 선택을 표현할 수 있어야 한다.
