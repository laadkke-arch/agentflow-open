# 결정 전 문제 문맥 — C13

Decision cutoff (UTC date): 2023-11-28

## 시점과 환경

2017년의 CPython 표준 라이브러리 문제다. 구현체는 오래전부터 하나의 프로세스 안에서 여러 독립적인 인터프리터를 두는 C API를 지원해 왔다.

## 해결할 문제

같은 프로세스 안에서 실행되는 코드 사이에 일정한 격리를 제공하는 기존 기능이 있지만, Python 코드에서 직접 이용할 표준 인터페이스가 없어 사용과 관리가 제한되어 있다. 기존 기능을 표준 라이브러리에서 접근 가능하게 만들면 활용과 유지에 도움이 될 수 있다.

## 반드시 고려할 조건

같은 프로세스 안의 여러 인터프리터라는 실행 범위를 다룬다. 그 사이의 격리를 존중하면서 Python 코드에서 기존 구현 기능을 이용할 수 있어야 한다. 원문 문제 설명에는 특정 처리량이나 병렬 속도 향상이 필수 조건으로 주어지지 않는다.
