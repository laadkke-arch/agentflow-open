# 결정 전 문제 문맥 — C09

Decision cutoff (UTC date): 2000-11-01

## 시점과 환경

2000년의 Python 언어 설계 문제다. 반복문은 일반적으로 시퀀스의 원소를 직접 순회한다.

## 해결할 문제

일정한 간격의 숫자열이 필요한 경우가 있다. 원래 시퀀스를 반복 중에 바꾸거나, 매 두 번째 원소만 처리하거나, 원소의 위치를 함께 사용하려는 경우가 대표적이다. 기존의 호출 표현은 부가적인 길이·간격 계산과 결합하면 읽기 어려워진다. 사용자가 관련 내장 이름을 덮어쓸 수 있다는 점은 컴파일러의 최적화 가정도 제약한다.

## 반드시 고려할 조건

시작·끝·간격으로 지정되는 숫자열을 다룬다. 반복문의 위치 기반 처리나 일정 간격 처리에 이용할 수 있어야 한다. 가독성과 내장 이름 재정의가 최적화에 미치는 영향을 설명해야 한다.
