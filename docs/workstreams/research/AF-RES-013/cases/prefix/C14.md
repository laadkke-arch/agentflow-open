# 결정 전 문제 문맥 — C14

Decision cutoff (UTC date): 2017-12-05

## 시점과 환경

2017년의 Python 언어 문제다. 함수와 변수에 붙는 주석 정보가 타입 힌트로 사용되고 있다. 함수 정의에 붙는 식은 정의 시점에 평가되는 동작을 가진다.

## 해결할 문제

타입을 설명하는 식이 아직 정의되지 않은 이름을 참조하면 특별한 우회 표현이 필요하다. 또한 모듈을 불러올 때 타입 설명까지 실행하는 비용이 발생한다. 이런 표현의 이용 편의와 불러오기 비용을 개선하고 싶다.

## 반드시 고려할 조건

아직 정의되지 않은 타입 이름을 다룰 수 있어야 한다. 모듈 불러오기 시점의 계산 비용을 고려한다. 언어는 동적 타입 언어로 남으며 타입 힌트가 의무가 되어서는 안 된다. 주석 정보는 타입 검사 외의 임의 용도에도 계속 이용할 수 있어야 한다.
