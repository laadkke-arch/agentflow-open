# 결정 전 문제 문맥 — C10

Decision cutoff (UTC date): 2007-05-18

## 시점과 환경

2006년의 Python 자료형 설계 문제다.

## 해결할 문제

서로 관련된 상수들의 집합을 표현하고 싶다. 값들은 이름으로 식별되며 집합 안에서는 순서대로 살펴보거나 비교할 수 있지만, 그 집합 밖의 다른 값과 본질적인 관계를 갖지는 않는다. 요일, 평가 등급, 오류 상태, 프로세스의 상태가 사용 문맥이다.

## 반드시 고려할 조건

집합은 불변이어야 한다. 값은 해당 집합의 다른 값과 구별되고 외부의 우연히 같은 값과 혼동되지 않아야 한다. 순서와 비교는 제공하되, 그 상태에 의미가 없는 연산까지 자동으로 허용하지 않아야 한다.
