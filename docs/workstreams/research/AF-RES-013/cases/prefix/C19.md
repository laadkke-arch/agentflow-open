# Design context — C19

Decision cutoff (UTC date): 2014-05-27

A Rust parser implementation repeats many similar patterns in match expressions. Reusing these patterns would make the implementation shorter and easier to relate to its specification. Macros already work in expression contexts, but the recurring structures also occur where a pattern is required.

Find language mechanisms or reusable techniques for expressing such recurring match patterns. Preserve the ability to read the implementation alongside the grammar or specification. The goal is reusable pattern structure in Rust; no particular macro expansion boundary or final syntax is fixed in this input.
