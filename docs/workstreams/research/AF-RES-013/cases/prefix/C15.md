# Design context — C15

Decision cutoff (UTC date): 2014-04-07

Rust compiler intrinsics currently have a different nominal ABI from ordinary Rust functions, even though the actual ABI implementation is the same. Common operations are put behind tiny wrappers whose only purpose is to make them look like normal functions. The compiler must inline many such wrappers, increasing compile work and hurting execution when optimization is disabled. Intrinsics also cannot simply be taken as ordinary function values and exposed directly through a public API.

Find prior designs or reusable mechanisms for exposing these operations with ordinary function behavior. Preserve the ability to use function values and reduce the unnecessary wrapper/inlining burden. Do not assume optimized builds hide the overhead.
