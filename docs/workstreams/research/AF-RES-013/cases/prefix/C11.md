# 결정 전 문제 문맥 — C11

Decision cutoff (UTC date): 2013-08-28

## 시점과 환경

2013년의 Python 표준 라이브러리 문제다. UNIX 환경에서 표준 라이브러리의 한 하위 프로세스 실행 경로는 이미 기본적으로 표준 입출력 외의 파일 디스크립터를 닫는다.

## 해결할 문제

그러나 다른 프로세스 생성 경로나 외부 모듈이 새 프로그램을 실행하는 경우에는 부모의 파일 디스크립터가 자식에게 그대로 넘어갈 수 있다. 예상하지 못한 공유 때문에 자원과 프로세스의 동작에 문제가 생긴다. 특정 고수준 실행 함수 하나를 사용하는 경우에만 성립하는 설명으로는 이 문제를 충분히 다루지 못한다.

## 반드시 고려할 조건

부모에서 열린 파일 디스크립터가 자식으로 의도치 않게 전달되는 문제를 다룬다. 여러 실행 경로와 외부 모듈이 존재한다는 조건을 고려한다. 표준 입출력과 추가로 열린 디스크립터를 구분할 수 있어야 한다.
