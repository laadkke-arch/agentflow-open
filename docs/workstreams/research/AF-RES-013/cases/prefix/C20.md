# Design context — C20

Decision cutoff (UTC date): 2014-06-11

Rust's current format strings contain ad hoc localization features. Experience with real localization needs suggests this support is inadequate. A full implementation is difficult and likely to belong in a separate library, while unused partial support adds complexity to the compiler and libraries.

Find prior localization designs or alternative ways to divide responsibility between basic formatting and localization. The goal is to handle real localization requirements while avoiding a permanently half-finished mechanism in the core language. No particular localization library or final decision is supplied.
