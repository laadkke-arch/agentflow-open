# Design context — C16

Decision cutoff (UTC date): 2014-07-15

Rust developers need finer control over annotations inside a function. Applying a lint allowance to the entire function can accidentally permit unrelated bad code. Conditional compilation currently requires duplicating the containing function or extracting code and explicitly passing its local variables. External tools would also benefit from annotations describing the permitted unsafe actions or audit state of a small block.

Find designs that support precise annotation scopes inside functions. The minimum useful scope includes blocks and local variable declarations. The solution should make these local intentions expressible without requiring whole-function duplication or manually threading all local state through a separate function.
