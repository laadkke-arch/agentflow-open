# 결정 전 문제 문맥 — C07

Decision cutoff (UTC date): 2000-08-03

## 시점과 환경

Python 2.0을 준비하는 2000년의 언어 설계 문제다. 기존 반복문은 하나의 시퀀스에서 순서대로 원소를 꺼낸다. 내장 시퀀스뿐 아니라 인덱스로 원소를 제공하고 끝에서 예외를 내는 사용자 정의 객체도 반복할 수 있다.

## 해결할 문제

둘 이상의 시퀀스를 함께 순회하면서 매 단계 각 시퀀스의 같은 위치에 있는 원소를 묶어 처리하고 싶다. 중첩 반복으로 모든 조합을 만드는 목적은 아니다. 당시 가능한 표현은 기능을 처음 보는 사람에게 의도가 뚜렷하지 않았고 특별한 인수의 의미를 알아야 했다. 길이가 다른 입력을 처리할 때 짧은 쪽의 빈자리를 자동으로 채우는 동작도 의도하지 않은 결과를 만들 수 있었다.

## 반드시 고려할 조건

복수 시퀀스의 같은 위치에 있는 값을 한 번에 처리한다. 기존 반복문과 사용자 정의 시퀀스의 이용 문맥을 고려한다. 길이가 다른 입력의 동작을 명확히 설명할 수 있어야 한다.
