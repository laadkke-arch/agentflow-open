# 결정 전 문제 문맥 — C28

Decision cutoff (UTC date): 2016-01-26

## 시점과 환경

2016년 초의 Swift 2와 Objective-C 상호 운용 문제다.

## 해결할 문제

Objective-C 메서드를 식별하는 값을 문자열로 작성하면 문법이 맞는지, 실제로 존재하는 메서드인지, 의도한 클래스의 메서드인지 확인되지 않아 오류가 나기 쉽다. Objective-C API 이름을 Swift 사용 방식에 맞게 자동으로 바꾸는 작업도 진행되고 있어서 두 언어의 이름 사이 대응이 덜 분명해지고 있다.

## 반드시 고려할 조건

Swift에서 의도한 Objective-C 메서드의 식별 값을 만들 수 있어야 한다. 임의 문자열의 오타와 대상 혼동 문제를 줄인다. 서로 다른 표면 이름 때문에 개발자가 외부 런타임의 원래 철자를 직접 추론해야 하는 부담을 고려한다.
