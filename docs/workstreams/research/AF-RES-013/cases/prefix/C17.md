# Design context — C17

Decision cutoff (UTC date): 2014-04-22

Rust needs commonly used text pattern matching facilities available with its distribution. Developers need a succinct way to describe patterns and match them against search text; many languages offer a standard facility for this use. Static patterns may also benefit from work being performed while the program is compiled.

Find implementation approaches, reusable libraries, and relevant precedents for this goal. Focus on usable pattern matching for Rust programs and explain the tradeoffs of including the facility with the language distribution. No worst-case time bound or particular backend is supplied as a mandatory input constraint.
