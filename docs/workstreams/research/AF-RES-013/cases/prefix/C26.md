# 결정 전 문제 문맥 — C26

Decision cutoff (UTC date): 2016-01-21

## 시점과 환경

Swift 2.2를 준비하던 2016년 초의 언어·빌드 문제다.

## 해결할 문제

언어 문법이 바뀌어도 라이브러리와 패키지 작성자는 하나의 소스가 여러 언어 버전에서 동작하기를 원한다. 버전마다 별도의 릴리스 브랜치와 소스 트리를 유지하는 부담을 줄이고 싶다. 소스를 배포하는 패키지는 사용자가 더 오래된 버전이나 새 버전으로 빌드하는 경우도 지원해야 한다.

## 반드시 고려할 조건

언어 버전에 따른 문법 차이를 처리한다. 별도 소스 트리를 늘리지 않는 방향을 고려한다. 소스 형태로 배포되는 패키지의 여러 버전 빌드에 도움이 되어야 한다.
