# AF-RES-078 범위와 사전 규칙

## 입력과 작업 경계

| 분야 | 선택한 작업과 통제 목적 | 식별자·필수조건 | 별도 진단·선호 |
| --- | --- | --- | --- |
| T 표 | SQLite에 이미 들어 있는 `TEXT`/SQL NULL 행을 CLI에서 CSV로 내보내고 Python `csv.reader`로 받아 형식 있는 행을 낸다. 픽스처 전용 JSONL은 그 행을 검사용 직렬화로 남긴다. | 문자열 행 키의 값·중복수, 논리 행 수, 동일 키의 NULL/빈 문자열/리터럴 `NULL` 타입과 값, 쉼표/큰따옴표/CR·LF가 든 값, 그 밖의 대상 문자값을 각각 확인한다. | 원본 DB 읽기 전용과 바이트 불변은 실행 가드다. 행 순서·헤더·CSV 및 JSONL 바이트 동일 여부는 보조 정보다. |
| I 파일 | 이미 있는 두 폴더의 동명 PNG를 Pillow로 RGBA→RGB 변환하며 표시 방향을 실제 픽셀에 적용하고, Info-ZIP으로 묶어 원래 상대경로 그대로 각 파일을 꺼낸다. | 상대경로 문자열, 경로별 정확히 1개 및 전체 멤버 수, 이름으로 개별 읽기, 원본 식별 마커별 예상 크기와 네 모서리상의 표시 방향을 확인한다. | 원본 PNG는 보존한다. 태그 값/유무와 픽셀 배열은 별도 관측이다. 원래 방향 값과 원시 모서리, 태그 적용 후의 모서리를 모두 남긴다. α 및 기타 EXIF 보존, 전 픽셀 동일성, 바이트 동일성은 필수조건이 아니다. |

PNG 확장자는 그대로 유지하며 앞단 파일 경로 정책은 Pillow 호출을 감싼 작은 스테이징 코드에 속한다. `flat`은 이름 매핑이 충돌하면 정렬상 마지막 출력으로 덮는 통제 예시다. ZIP 읽기 요구는 이 실행의 CPython 기본 이름 읽기에서 불변 경로로 읽는 것으로 구체화하고 Info-ZIP UnZip 및 ZIP Unicode 표기를 교차 확인한다. 원작업이 임의 로캘이나 모든 압축 해제기를 명시한 것으로 일반화하지 않는다. 대상은 합성 자료다.

표는 앞뒤 UTF-8, 정확한 열 이름, `newline=""`, 명시적 키 정렬, strict parser로 고정한다. 이미지에서는 입력의 상대 순서, 스테이징 시간(UTC 고정), `zip -X -q -@ -b <temp-dir>`, 로캘 C.UTF-8을 고정한다. 기본 도구 둘 다 확보되어 예비 조합 0개를 채택한다. 설정 바깥의 복구 시험은 원 격자의 점수에 넣지 않는다.

## 시나리오와 실패 위치

- `normal`과 `edge`는 각 셀에서 새 전용 임시 폴더 2개로 반복한다. 같은 픽스처와 설정을 쓰며 각 반복의 입력 지문과 종료값을 보존한다.
- `retry`는 별도 폴더에 유효한 과거 완성품을 넣고 이번 앞단을 마친다. 표는 첫 결과 행을 `.part`에 동기화한 Python reader를 외부 SIGTERM으로 멈춘다. 과거 완성품과 부분품을 검사하고 깨끗한 임시 출력으로 동일 요청을 전체 재실행한다.
- 파일은 실제 Info-ZIP 자식에게 `-@` 입력을 쓰고 표준입력의 EOF를 잠시 보류한다. 실행 중인 ZIP의 입력 대기를 확인한 뒤 외부 SIGTERM을 보내고 이전 완성품과 임시 디렉터리를 검사한다. 이후 동일 입력을 전체 재실행하며 기본 add/update의 동작을 관찰한다. 이 시작 위치는 ZIP 아카이브 쓰기 도중이나 전원 장애 시험과 구분한다.
- 빈 결과, 버전 대조, 픽셀/태그 대조, 어댑터, 메타데이터 대조 등 추가 실행은 본 평가에서 제외한다.
- 본 평가에서 셀×시나리오 24개, 정상·경계 완료 시도 32개, 중단 및 재시도 시도 16개를 계획한다. 재시도 판정은 재개 완료 결과를 사용하고 중단 상태는 Q5에서 별도 판독한다.

## 예측과 독립 판독

A에는 제품의 개별 설명과 각 설정의 단독 증거만 준다. B에는 그 정보에 실제 판, 중간 형식, null/경로 규칙, 변환 방향, 기본과 중단·재입력 계약을 더한다. 두 보기의 요건별 지지/배제/보류 및 이유를 연결 실행 전에 커밋한다. C의 정상·재시도는 관측 입력의 사후 판독으로 센다. 경계에 대해 추론하는 C는 별도 파일에 먼저 저장하며 결과 공개 뒤 사후 해석과 구별한다.

경계 생성기의 조작 범주와 판독 기준을 알고 있다. 미리 읽은 원자료와 정상·재시도의 결과는 C의 정보다. 분야별 별도 난수 시드를 작업공간 바깥 임시에 보관하고 SHA-256, 생성기, 검증 규칙을 앞서 커밋한다. 경계 결과의 실체화와 공개는 C 경계 예측 커밋 이후로 미룬다. 출력과 원장 재판독자는 같은 작업자다.

표의 정답은 원입력을 작성한 타입 명세와 Python DB 연결에서 별도로 읽은 행들이다. CSV reader가 내보낸 JSON을 다른 경로로 해석해 키·값·타입을 판정하며 중간 CSV의 quote 정보는 별도 스캐너로 읽는다. 파일 정답은 ZIP에 넣기 전 원래 경로와 EXIF 행렬에서 얻은 표시 크기·모서리다. ZIP은 독립 라이브러리로 멤버별 읽기·이름·중복을, PNG는 Pillow와 독립된 작은 판독기로 디코딩한다. 실행 종료값은 조합의 관측 성공을 입증하는 충분조건이 아니다. 같은 실행/설정에서 모든 필수조건이 맞을 때만 전체 지지를 부여한다.
