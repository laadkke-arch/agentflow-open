# 당시판 검증

고정 docs.rs 판은 최초 direct open 실패 후 crate 최신판의 Versions 링크→고정 crate→Documentation→Pod/bail 링크로 재시도 성공. 원 소스 3 tag blob 직접 읽음. GitLab tag는 실패했으나 0.3.9 패키지 README와 rustdoc 본문은 직접 읽음. crates.io JSON exact publication UTC는 4건 실패, docs.rs 공개 날짜만 확보. 범위의 최저 경계는 초기 릴리스 후보이지 실제 인용자가 읽은 버전이나 기능 최초판을 뜻하지 않는다. 최신판은 비교용만. R3에서 0.3.10 async, 0.3.11 Self-return은 인용 후 추가. 별도 테스트 미실행.
