## 산출물 검산

- 142 `11×22=242`, 독립 `4×12=48`. 142 고정표의 표시 132 = 1 + 131. 주 비교 자료층의 cap별 33/12자리와 순차 표시와 공석을 검산했다. 원본은 별도 4회와 총 10자리로 재개봉했다. 직접 회복률 분모가 0인 경우 산출 불가로 남겼다.
- 새 모집 첫 글 60, 채택 4. GitHub 웹 배열과 연결 도구 순서 일치. 147 출처 레코드 중 고유 counted `work_id` 27. 항목 4 요청/10 공급자/6 별도 시험/4 원리 지침/3 사례이며 각 기관의 지침 2. 공급자 원전 10 중 두 안내와 두 프로젝트의 독립 기능 구현 6, 하부 제공자 별도 문서 2다. 자료 접근 실패 및 같은 매뉴얼의 다른 절은 세지 않았다. [출처](sources.jsonl)
- 실제 개봉과 cache hit 합이 각 대조 수와 같다. 수치와 지문 비교는 [재생 명령](replay/README.md)에 재현할 수 있다. 순위, 단계 출력, 전환, 원본 결과에 시간 필드를 섞지 않았다. 독립 판독의 결과 전파는 [④ 커밋](https://github.com/laadkke-arch/agentflow-open/commit/3b13248b8447589463af602391c1d907bce9ae73)에 처음 포함된다.
