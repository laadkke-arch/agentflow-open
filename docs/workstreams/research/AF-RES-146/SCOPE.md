## 모집 및 재고

1. **재고 먼저.** OCRmyPDF/OCRmyPDF와 paperless-ngx/paperless-ngx는 각각 2023-12-31 23:59:59 UTC 이전 GitHub Releases에서 공개한 마지막 정식 태그의 공식 사용자 문서/목차를 고정한다. 태그의 배포 시각과 실제 커밋을 단다. OCRmyPDF 카드의 부문은 기본 파일 입력→출력, 기처리 OCR 선택, PDF 출력 형식, 텍스트 sidecar다. Paperless 카드의 부문은 consume 입력, original/archive의 보존·식별, OCR 모드, 원본/파생의 조회 또는 export다. 각 부문에서 공식 사용자 문서의 첫 명시 계약을 따르고 문서상 순서와 검색 동률 순서를 기록한다. 확대판이나 독립 구현은 외부 대조 증거로만 사용한다.
2. NARA와 Library of Congress의 저자/발행권이 확인되는 지침에서 각 두 원리를 고정한다. NARA는 보존 사본과 접근 사본의 목적 구분, 디지털화 산출물과 원 레코드 관계를 명시하는 지침을 본다. Library of Congress는 fixity 원리와 PREMIS 표현/파생 관계를 본다. 각 기관에서 별도 저작 2개를 찾고 원절과 적용 범위를 기록한다. 시대 제한은 공급자판에 적용한다. 기관은 장기 원리를 추출하며 기준일 이후의 이슈 기술을 카드에 더하지 않는다. 카드 12개는 이슈 검색 전에 별도 불변 스냅샷과 함께 커밋한다.
3. **각 저장소 첫 30개.** GitHub 공개 issue의 생성시각 `2024-01-01..2025-12-31` UTC를 `is:issue is:public`과 저장소 이름으로만 제한한다. `sort=created&order=asc&per_page=30&page=1`; 동시각은 issue 번호 오름차순, 경계 동률만 검증한다. 제목·본문 검색어, 라벨, 상태 필터를 쓰지 않는다. first author body로 설계 또는 사용 동작과 입력 대상, 원본 보존 또는 파생 산출물의 사용 조건이 실제 목표에 함께 걸리는 순서의 최초 2개씩을 채택한다. 단순 장애·설치·버전 보고, 시도/로그에만 있는 조건, 반복 URL·복제, 최초 글 삭제/확인 곤란, 알려진 선행 사건은 제외한다. 공개 이슈 API에 노출된 현재 최초 게시물과 생성/갱신 시각을 기록하며 당시 편집판 확인 가능 여부는 분리한다. 후속 댓글이나 유지관리자 해법은 채택/등급 판독 전 열지 않는다. 기존 노출 대조는 시작판에서 명시된 기존 기록과 고정 138/142/시제품 원장에서 확인 가능한 범위다. 가능한 모든 미통합 분기의 모든 과거 세션을 읽었다는 주장을 남기지 않는다. 각 30개를 넘겨 빈 분모를 채우지 않는다.

## 순위, 판독 및 표시

- **142 재생.** K22/L에서 원래 점수와 동률 순서, 양점 상위 3/8, 표시 최대 3. K16/L, K16/R, K22/R은 별도 민감도다. 142 보수적 표시 봉인과 동일하게 입력→반환·요구 보존값을 링크가 입증하거나 독립적으로 요청한 하위 출력 자체가 뒷받침될 때만 표시한다. 잠정적 단어 적중·미확인·충돌로 슬롯을 채우지 않는다. 142에서 판독했다고 기록한 셀과 이전 판독이 없는 셀, 파생 전수 등급, 이번 공급자 절 재개봉을 분리한다. 이전 2 direct의 alternative를 partial로 재집계하며 교정 신규 편입은 없다. 138 원장과 판독에 필요한 판의 원문 지문이 일치한다는 근거를 확보하지 못하면 그 판을 미확인으로 두고, 이어지는 비교는 고정 점수/동결 텍스트를 사용했다는 사실을 붙인다.
- **새 순위.** 첫 글에서 추출한 목표·대상·보존을 합쳐 영어 소문자로 정규화하고, 문자/숫자 토큰의 붙은 연속 일치만 센다. 카드별 별칭을 이슈 검색 전에 고정하며 중복 출현은 1회다. 작동 구절 적중당 2, 제목/대상 어휘 적중당 1, 합계 내림차순, 동률은 고정 카드 ID 순서다. 동일 alias는 같은 카드에서 두 번 세지 않는다. 양점 순위만 cap 3/8에 자른다. 0점 강제 채우기는 분리된 탐색 대조다. 새 Q4 표시 판독 때 기준표를 숨긴다. 별도 판독자는 점수·조사 깊이·표시 결과가 제거된 4×12 입력에서 원문으로 등급을 작성한다. 역할 분리가 실패하면 접근 시각과 노출 내용을 공개하고 동일 작업자의 판독으로 집계한다.
- **새 등급.** 직접은 요청된 대상·반환·유지 조건을 원절에서 확인. 조건부 참고는 정확히 맞는 하위 동작이나 다른 분야 이전 원리를 전제와 함께 제시. 충돌은 요청의 명시 조건을 동작·반환·부수효과가 위반. 미확인은 연결 근거 부족, 원문 접근 실패 또는 실제 입력 계약 불명. 충돌의 근거는 적합 증거 없음과 구분한다. 표시 가능한 직접/조건부를 원순위에서 앞 3개 채택하며 보존/식별 가정을 카드별로 공개한다. 이 규칙에서는 prefix 동등성이 유지될 때 기존 링크 밀림이 논리상 발생하지 않는다. 실제 순위·슬롯으로 검산하고, 품질 우선 재정렬을 한다면 다른 정책으로 붙인다. 목록 밖 가능성은 판정·표시 봉인 후 원출처 확인이 있는 경우에만 상한에 추가한다.
- **비용과 중단.** 원래 순위, 절단, 재생 판독, 최종 표시를 SQLite에 분리하고 각 요청의 3칸을 표시 또는 공석으로 회계한다. 문서(또는 고정 사본) 내용 접근을 동반한 정책과 표 조인만 한 산술을 따로 계측한다. cap 8 고정 열람, cap 8 이내에서 3개 적격이 확인되면 중단, 양점 소진, 접근 실패를 구별한다. 캐시 없이 시작해 같은 요청 순서로 한 바퀴, 같은 캐시로 같은 순서를 다시 실행한다. 실제 파일 열람·바이트·캐시 hit·CPU/벽시계의 비교 가능한 범위를 적고 사람 판독 시간과 기계 재생 비용을 섞지 않는다. 두 빈 실행 폴더에서 입력 지문·결과를 대조하며 시간값은 동등성 검사에서 제외한다. 자료가 부족하면 빈 분모와 정확한 재개 입력을 기록한다.
