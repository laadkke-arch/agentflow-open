## 구조와 주장 대조

- CSV 파싱으로 표제·열 수·조인 키를 확인했다. 원문 20, 요청 8, 보류 6, qrels 120, 고정 순위 72, 별도 순위 300, 시도 248, 비용 153이다. 표 1/2/3은 각 9열이고 데이터 행은 24/144/8이다. 조회 자료 56행 중 최소량에는 20계보를 산입했다. 가장 긴 카드는 61단어였다. [검산 도구](audit.py)
- 오프라인 두 번에서 `cmp` 종료 0을 확인했다. 순위와 표시/선택 원영수증은 바이트 단위로 일치했다. 실제 HTTP는 49건, 완전 48건, 지문 일치 48건, 달라진 본문 0건, 리다이렉트 0건, 재시도 0건이었다. 적격 둘째 열람이 없었던 068과 달리 L에서 둘째 시도가 6건 있었고 그 중 세 건의 상위 순서가 바뀌었다. 072에서는 첫·둘째 모두 적격 회수가 0이었다. [재생 영수증](evidence/replay-comparison.json) · [시도 원장](fetches.jsonl)
- 순위와 정답은 별도 커밋에 먼저 남겼다. qrels 때 원문의 이름을 문장에서 유추할 수 있었으며 한 작업자의 모집·카드 제작 기억이 남는다. 수치 가중치를 구현한 작업자도 앞선 판정 내용을 알고 있었다. 보류 순위 생성 프로세스는 채점 파일을 갖고 있지 않았다. 독립 추가 판정은 미실시다. L·I의 파일 열기를 분리해 확인했고 두 검색 비교군은 채점용 원문의 추가 읽기를 공유하지 않았다. [가림](evidence/qrel-seal.json) · [순위](evidence/rank-seal.json) · [파일 접근](evidence/input-access.json)
- 보류 확정 뒤 발견한 메뉴 소스, 번역판과 가짜 도착 실패, CLI 양성 대조는 별표로 해석하고 주 분모에서 제외했다. 그 분모에서 확인하지 못한 분야 간 채택·추천 안정성, 작성자 최초 본문과 실행 버전, 원 요청 환경의 UI 동작은 재개 항목이다. [출처](sources.jsonl) · [다음 세 쟁점](RESULT.md#가장-중요한-불일치약점-3건)
- GitHub 검증판을 받은 명령·대상 SHA·응답 및 결과 비교는 마지막 인계에 둔다. 이전 판의 검사 종료 0을 후속 인계의 화면 증거로 사용하지 않는다. [인계](HANDOFF.md)
