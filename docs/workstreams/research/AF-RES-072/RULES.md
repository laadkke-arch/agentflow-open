# 검색과 채점 규칙

## 고정 비교

L은 작품 ID·공개 주소 목록을 적재한다. URL 경로만 소문자 정규화하고 하이픈·CamelCase·밑줄로 분할한다. 호스트, 리비전, 확장자와 공통 경로 단어는 BM25에서 제외한다. L의 첫 원문은 제목과 저자 조건에서 얻은 질의의 URL BM25 최상위다. 둘째부터 이전에 표시한 문장의 단어가 나머지 URL에 드물게 등장하면 보너스를 준다. 표시 범위의 실제 링크가 자료집의 공개 주소와 정확히 일치하면 추가 보너스를 준다. URL 및 열린 창의 점수는 함께 사용한다. 미열람 주소도 후보지만 원문 확인은 기권이다.

I는 목적·입력·동작·실패/제약을 원자료만 읽고 한 카드에 최대 80단어로 기록한다. 이름을 포함해 동일 BM25로 검색하고 출처 판·절은 포인터로 남긴다. H는 I 카드에서 출발한다. 가장 높은 미열람 카드 하나를 먼저 확인한다. 다음 열람은 카드에서 다른 단어 행동을 많이 포괄하는 후보와 현재 선두 부근의 낮은 점수 차에 우선권을 준다. 표시문에서 compare/ignore/error/only 등 경계 표현의 유무, 질의 겹침과 카드 겹침을 구분해 기록한다. 근거가 약하거나 반박이 포함될 수 있는 창을 반환 후보 표시에 연결한다. H의 점수는 카드와 실제 확인한 창을 합친다. P는 I의 그대로 투영된 이름·목적만 검색한다.

질의는 이슈 제목과 범위·긍정·경계·환경에 대한 원 작성자 의미를 보존한 입력이다. 번역은 후속 별도 실행이다. 부정 단어는 보존한다. 일치 점수는 부정의 논리 범위를 해석하지 않는다. 점수 동률은 `sha256("AF-RES-072-tie:" + work_id)` 오름차순이다. 점수 0의 동률도 같은 규칙을 쓰고 각 슬롯에 점수를 기록한다. L/H는 실제 열람에 실패한 슬롯을 내린다. 빈칸은 유효 후보가 부족할 때 표시한다. 외부 검색 색인을 사용하는 경로는 실행하지 않는다.

## 열람·비용

- 공통 한도는 요청·방식·캐시 조건당 논리 원문 시도 4회, 실제 표시 1,200단어, 실시간 응답에서 읽은 본문 1,048,576 bytes다. 하나의 URL 시도는 결과와 관계없이 논리 1회다. 같은 경로에서 같은 URL을 다시 선택하지 않는다. 논리 2회와 HTTP 추가 시도는 다른 계수다.
- HTTP 주소는 무로그인 공개 HTTPS다. 오류 문자열·최종주소·리다이렉트·받은 bytes·시각을 기록한다. 시간초과·429·5xx·CONNECT 거절에도 자동 재시도는 0이다. 다음 후보는 남은 시도와 예산 안에서 계속 평가한다. `Content-Length`가 남은 전송 한도를 넘으면 본문을 받기 전에 중단하고, 길이가 없으면 남은 바이트까지만 읽는다. HTTP 헤더, TLS·프록시 오버헤드 및 이미 서버가 보낸 미소비 바이트는 미측정이다.
- L/H의 선택된 문서만 메모리로 구문 분석한다. 질의와 겹치는 절의 최대 220단어 창을 먼저 표시하며 동률은 원 순서다. 창을 고르는 기계 스캔의 단어와 소비자에게 표시한 단어는 별도 기록한다. 두 주소의 본문을 합쳐 새 문서처럼 인용하지 않는다. 카드 이름을 포함해 최종 3장만 사용자에게 표시한다. 기계가 점수 계산에 사용한 20개 카드는 별도다. 따라서 H는 최대 880+240단어를 표시하는 설계다. URL·행·판·기계 상태 같은 영수증 필드는 본문 표시량에 합산하지 않는다.
- 재생 두 번은 별도 프로세스·빈 캐시다. 파일 바이트·표시 문자열·순위가 같은지 검사한다. 라이브는 경기마다 빈 응용 메모리 캐시를 사용해 먼저 실행한다. 같은 요청의 즉시 반복은 앞서 성공한 해당 경로 원문만 응용 메모리에 보존한다. 디스크와 CDN 캐시는 비우지 않는다. 캐시 조작에서 성공한 본문의 저장량 증가와 네트워크 비용을 분리한다.
- 실시간과 고정판의 응답 SHA-256이 다르면 별도로 기록한다. 보류 집계의 분모는 봉인된 본문이다. 깨진 접근의 동작은 별표 민감도에서만 주입할 수 있다.

## 증거

보류 문서 판정과 본문 노출 판정은 다르다. 문서가 직접 후보여도 해당 경로에서 같은 한 판의 두 조건과 사용 환경이 인용되지 않으면 공동확인은 기권이다. 명시적 불일치는 반박으로 기록한다. 제작자 요약과 원문 절 포인터는 인용 가능한 원문 표시로 환산하지 않는다. 경로에서 직접 채택 주장은 두 조건과 환경을 모두 지지하는 같은 구성의 원문을 요구한다. 근접 오답이 반환되었는지와 실제로 잘못 채택했다고 선언했는지를 별도로 센다.

직접은 요청된 환경의 두 조건을 충족하는 후보, 일부는 적어도 한 필수 조작 또는 검증 가능한 부분을 뒷받침하는 후보, 반박은 적용하면 경계를 거스르는 명시 동작, 무관은 해당 조작을 확인할 관계가 없는 본문, 미확인은 식별 가능한 접근·판·동작 근거 결손이다. 동종 여부와 원거리 전이 자격은 별개다. 원거리 자격에는 구체적인 공여·수신 역할, 옮기는 조작, 전이 실패 조건과 원문 위치를 남긴다. 업무 영역만 비슷한 경우는 자격이 없다. 회수율의 분모가 0인 곳은 해당 없음이다. 아직 읽을 수 없는 쌍 및 실제 관측 0은 서로 다른 값이다.
