# AF-RES-072 · 요청 때 여는 링크와 사전 목적·동작 색인

보류 6건, 공개 원저작 20편의 고정판에서는 **카드가 동종 부분 후보 1/6과 원거리 원리 1/14를 상위 3에 올렸다.** URL만 보관한 L은 각각 0/6, 0/14였다. H는 원문을 더 열어서 한 부분 후보의 실제 효과와 한 근접 오답의 범위를 확인했다. H의 회수 수는 I와 같았다. 직접 후보 분모는 0이다. L/I/H의 18경로, 54슬롯에서 같은 판의 두 조건·환경 공동확인은 관측 0이었다. [고정 순위](ranks.csv) · [판정표](qrels.csv) · [집계](evidence/metrics.json)

I/H는 링크 목록 외에 카드 파일 10,832 B를 보관했고 20회, 응답 본문 2,087,664 B를 들여 원문을 확보했다. 이 보류 요청의 라이브 한 건당 평균은 L 28,260 B, I 0 B, H 485,044 B였다. H의 한 원문은 HTTP 200까지 확인하고 전송 한도에서 중단했다. 처음부터 빈 캐시인 100회 시나리오에서 I 구축과 요청의 바이트 합계가 L보다 작았다. 같은 요청을 즉시 반복한 시나리오에서는 L의 순서가 앞섰다. [비용](costs.csv) · [실제 전송](fetches.jsonl)

표 1의 D는 직접, P는 동종 부분, R은 검증 가능한 원거리 전이다. `P` 경로는 명칭과 목적만 보여 주는 투영이다. 첫 순위는 반환된 3슬롯 안을 뜻한다. 근접 오답은 독립 판정에서 반박인 반환 슬롯이다. 공동근거와 오채택은 실제 표시를 확인해 판정했다. 원문을 열지 않은 카드의 절 주소는 재열람 단서다. 표 2의 HTTP —는 해당 전송의 HTTP 응답 관측이 없다는 뜻이다. 표 3의 표시 단어 합계는 요청 표시량이며 구축 표시량은 미측정이다.
