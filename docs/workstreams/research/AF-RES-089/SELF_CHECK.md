## 검산 절차와 경계

- [cases](cases.csv) 12자리와 [runs](runs.jsonl) 12자리의 이름, 입력 SHA와 G/L 바이너리 SHA를 일치시켰다. 검산기는 정식 GUI action/모델 command 순서와 실제 주소 목록, 변경 객체, 저장·재열기 22건, 화면 64장 지문을 재계산했다. G/L의 11개 대응 저장 쌍은 바이트도 같다.
- 46개의 고유 원자료 계보를 만족하며 자료별 발행·열람, 판·절, 주장·한계를 남겼다. 발행 UTC가 페이지나 소스 메타데이터에서 확인되지 않는 행은 null이다. 참고 계보 및 접근 제한 9행을 따로 보존했다. [원장](sources.jsonl)
- Q6 보조를 정식 결과와 별개로 계산했다. 복제 후 NONE으로 수렴한 사전 예상 차이, L의 색·bit 잔존, master/part 링크 보존, 같은 값에서의 Undo 인덱스 차이를 실제 기록에서 재검산했다. 현재 링크 전파 관측의 대상은 Note/Chord 및 해당 fixture에 들어 있는 기존 part다. [보조 대조 결과](evidence/verify.json)
