## Q5. Lamp PNG, BasisU, 그리고 두 종류의 실패

원본 GLB·분리 PNG의 required는 0, 재질 확장 5개는 used다. 원본 KTX2 JSON은 `/extensionsRequired/0=KHR_texture_basisu`, `/textures/{0..3}`에 core `source`가 없으며 확장 source만 있다. PNG판은 별도 전달물이다. KTX2 네 파일은 각각 2048×2048, level 1, `vkFormat=0`, scheme 2(Zstandard), DFD model 166(UASTC LDR 4×4)이다. BaseColor DFD transfer 2(sRGB), 나머지는 1(linear). SwiftShader는 BPTC 지원을 보고했고 네 decoded texture에서 format 36492(`RGBA_BPTC_Format`)를 관측했다. [원본 KTX2 JSON](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/AnisotropyBarnLamp/glTF-KTX-BasisU/AnisotropyBarnLamp.gltf), [DFD/헤더 원값](receipts/python-static.json), [BasisU 규정](https://github.com/KhronosGroup/glTF/blob/da88a3bbbe168cc728eddf71fa5e1915cc2c0629/extensions/2.0/Khronos/KHR_texture_basisu/README.md#L30), [KTX 2 scheme](https://github.com/KhronosGroup/KTX-Specification/blob/ac39917e8240f51db97715a2453134a42ff959fd/ktxspec.adoc#L620), [디코드 영수증](receipts/round-1/ktx-on.json)

- 디코더 등록과 JS/WASM이 있으면 KTX2 4×200→4 decode→기하 일치·draw다. PNG판과 비배경 픽셀 수는 같고 13,772 px에서 최대 채널차 ≥3이다. 미등록이면 `setKTX2Loader must be called before loading KTX2 textures`로 onError이고 KTX2 요청/mesh/draw 0이다. [등록](receipts/round-1/ktx-on.json), [미등록](receipts/round-1/ktx-off.json)

## Q6. 선언, eager 접근, 실제 선택의 반례

BoxTextured의 material에서 `baseColorTexture`만 제거하면 JSON image/texture를 그대로 둬도 이미지 요청·decode·binding 0이었다.
