## 보정 이력
3단계 RESULT/paths는 공유 열람 및 9개 경로 재실행 결손으로 기록했다. 4단계에 A 6개와 B 1606/1834/2049 각각 tagged README→#126→해당 원문(126은 aggregate 종료)을 직접 다시 읽었고 aggregate body에 해당 링크 있음을 확인했다. B 126/13/1190은 tagged README 첫 읽기, FFmpeg homepage, 각각 Streamcopy / -ss / read_intervals 절을 직접 재열람. 홈페이지에서 특정 매뉴얼 주소는 알려진 주소로 선택했다(중간 Documentation 목록까지 열면 예산 초과, 직접 hyperlink click이라고 주장하지 않음). 새 문서 추가 열람 1~2개, repeated source는 중복 산입 0. 최초 검색은 A/B 묶음 응답이라 query별 최초 hit는 회복하지 못함. 재실행은 사후 보강이지 blind test 아님. 
## 반례와 관점
- 편집자: 이미 시작이 독립 랜덤 접근점이고 끝/오디오/자막 경계가 적절하며 해당 컨테이너가 지원하면 F01 단순 복사가 충분. L03 exact-keyframe 분기 자체가 이 반례(관측 아님). 반대로 C13은 재생 가능해져도 다음 처리에서 실패/최대 8 s 이동. 편집 UI seek는 output 첫 표시와 다름. [C13](https://github.com/mifi/lossless-cut/pull/13) (GitHub REST issues/13 body; comments 261183359,261189277,261669828,287701068); [L03](https://github.com/mifi/lossless-cut/blob/v3.44.0/src/smartcut.js) (getSmartCutParams L12–end); [F01](https://ffmpeg.org/ffmpeg.html) (3.1 L207–235; -ss L968–969; accurate_seek L2631–2637).

C1190은 좁은 probe뿐 아니라 확대 probe도 empty; 실제 keyframe 부재와 검색/시간 기준 오차는 구별. TS의 서로 다른 start_time과 probe 구간은 관측, 원인 단정 금지. [I01](https://avidemux.org/admWiki/doku.php?id=using:cutting) (Intra frames and SmartCopy; Example L77–104); [I02](https://github.com/skeskinen/smartcut/blob/master/README.md) (Usage Basic Commands, Audio Export, Testing, Version History); [F05](https://ffmpeg.org/ffmpeg-bitstream-filters.html) (2.15 L547–556; 2.16 L557–561); [F03](https://ffmpeg.org/ffprobe.html) (3.4 read_intervals L651–683; show streams/frames/packets); [C1190](https://github.com/mifi/lossless-cut/issues/1190) (Description command/log, cutSegments L312ff; activity L447–585).

[C1834](https://github.com/mifi/lossless-cut/issues/1834) (Description; activity L155–200); [C2049](https://github.com/mifi/lossless-cut/issues/2049) (Description L142–164; author JSON L192ff and L749–784; follow-up L788–852); [C13](https://github.com/mifi/lossless-cut/pull/13) (GitHub REST issues/13 body; comments 261183359,261189277,261669828,287701068). ## GDAL 유비와 금지할 유추
[G03](https://gdal.org/en/stable/tutorials/geotransforms_tut.html) (Introduction, transformation L7–27): 원점 픽셀 모서리와 중심은 다르다. 정렬된 정수 srcwin은 원본 샘플의 부분 선택, 관심영역 CRS 좌표 projwin은 변환 후 창으로 양자화; 3.11은 전체 extent 변환(예전 두 꼭짓점만), nearest 시 창 확대 vs 구판 반올림, 다른 resampling 방식은 그 창 수정 규칙이 다름. [G01](https://gdal.org/en/stable/programs/gdal_translate.html) (-srcwin/-projwin/-projwin_srs/-r L116–168). [G04](https://gdal.org/en/stable/programs/gdal_raster_clip.html) (Description L54–60; bbox L75–81; geometry L83–93; window L111–115): raster clip bbox는 원 격자/CRS/해상도 유지하고 whole-pixel 포함 쪽 확장; geometry는 격자 밖 부분을 nodata 처리. [G02](https://gdal.org/en/stable/programs/gdalwarp.html) (-tr/-tap/-ts/-ovr L195–205): target-aligned-pixels는 목표 grid 정렬이지 source grid 일치 보장 아님; 3.7 동일 CRS 무해상도지정의 source-res 유지 규칙, 3.8 blank edge 처리. 설계상 비유: index-aligned 선택/경계 양자화/재표본화의 선택 비용을 명시한다. 압축 TIFF bytes 그대로 복사와 픽셀값 보존은 또 다른 조건이다. 영상의 시간 참조, decode 순서, audio/subtitle clock을 GDAL 사례로 증명하지 않는다. 실제 래스터 출력은 이 작업에서 만들지 않았다.
## 대안의 비용
alternatives.csv A1–A5. copy는 처리량/품질 보존에 유리하나 random access/트랙 검사 필요. 경계 재인코딩은 인코딩 부분 품질 변동, 합치기 호환·오디오 priming/자막 retiming 검증 비용. 전체 변환은 출력 경계 제어를 넓히지만 계산량 및 원래 패킷/일부 품질 희생. 숨은 preroll 방식은 개념 후보만: 삭제 요청이면 과거 내용 남기는 위험. 후속 작업은 선택 가정과 보존 대상을 명시하고 실제 입력 제공시만 검증.
