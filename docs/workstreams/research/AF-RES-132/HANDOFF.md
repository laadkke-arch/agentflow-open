## 막힌 이유와 첫 재개 행동

GitHub 웹 커넥터만으로 실제 저장소 checkout 및 workbench.session 실행 환경을 제공받지 못했다. jq/Python 원문 재현을 하는 것도 이번 연구 범위가 아니다. 이미 봉인한 데이터는 바꾸지 말고 **첫 행동은** checkout 환경에서 현재 배정 브랜치 및 시작판을 대조한 후 기존 manifest가 있다면 확인·재사용, 없다면 아래 start 명령으로 계약 생성(고정 결과의 입력·허용 경로 일치 검사). 필요 시 검사 실행은 별도 검증 단계로 수행하고 결과를 새 evidence 파일에 남기되 독자 답을 재작성하거나 사후 자료를 사전 증거로 승격하지 말 것.

```sh
python -B -m workbench.session start af-res-132 --allow docs/workstreams/research/AF-RES-132/ --dependency work/research-af-res-128=cdf5522ccfad9c240ded4e658b6fcc638ee14199 --output docs/workstreams/research/AF-RES-132/manifest.json --fetch
python -B -m workbench.session check docs/workstreams/research/AF-RES-132/manifest.json --fetch
```

실제 출력·종료값·검사 대상 SHA 미관측. 위 명령은 미실행. 가능한 검사 입력은 고정 결과 `99be7bebb9561756fea04621120dd020cecf40b3`와 위 dependency, 기존 branch 및 허용 경로이다. 검사 성공 여부를 별도 기록 후 상태 재판정. 본 인계 파일은 마지막 별도 커밋.
