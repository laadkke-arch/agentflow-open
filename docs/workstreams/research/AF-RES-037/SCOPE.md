## A · 결정 우선 표집

## 공통 판정 코드북

각 사슬은 입력, 유지할 동일 객체, 결정 주체/권한, 상태 전후, 출력/제약을 대응한다. 발행일(P), 당시 공개 증거(V), 당시 검색색인(I), 저자 실제 읽기/인용(A)을 독립 열로 둔다. P만으로 V/I/A를 채우지 않는다. 날짜가 같으면 일 내 순서는 미확인이고 회고는 회고 시점과 주장된 과거 구간을 모두 기록한다.

- C0: 용어/인용만; 작동 대응 미확인 또는 충돌.
- C1: 작동 대응 가능/기존 결정 설명. 수신 원안에 이미 같은 선택이면 반드시 여기 또는 더 낮은 판정.
- C2: 저자/결정권자가 제공 원리와 선택 변경을 직접 연결했으나 당시 원문/변경 전/반영 중 하나 이상 미확인.
- C3: 당대 가용한 특정 원문, 저자 연결, 구체적 선택 변경, 같은 목적의 고정 명세/수락 시험/병합 변경이 모두 직접 확인. 엄격 사슬 완결·역사적 양성 대조 후보.
- R: 사후 회고·연구자의 유추를 허용하면 연결 가능하지만 C3 요건 부족. C3와 따로 집계한다.
- N/U: 반증/미확인. 공개 기록에서 못 찾음은 실제 부재나 독립 발명의 증명이 아니다.

실제 반영은 동일 기능/목적/설정의 규범 변경·합병 코드·수락 시험·릴리스 기록까지다. 회의 종료와 issue closed만으로 반영으로 세지 않는다. 정적 코드/명세 확인과 런타임 실행을 분리한다. 전체 설계와 독립 부분을 구분한다. 관점은 개발자·표준 편집자·최종 사용자가 확인할 수 있는 기록을 각각 표시한다.

집계는 A8/B4 목표, 실제 고유 사건, 당대 가용, 저자 인용, 명시 변경, 반영, 완결, 반증에 의한 원판정 정정 수를 층별로 계산한다. `미확인`을0으로 숨기지 않는다. 엄격 양성 적격0이면 조건부 회수율은 `해당 없음`; 검색 실험을 하지 않으므로 회수 성능 수치는 만들지 않는다. 넓은 회고/유추 집계도 별도 표시한다.
