- 공개 서비스가 언제나 잘못된 선택이라는 가설 반례: A01 Websites and Apps는 명시 제출 및 적은 합산 사용 조건에 부합하는 경우 가능하지만 운영자·정책 변경과 일반 노코드/LLM 플랫폼 금지 및 책임 조건이 남음. A02 Photon demo도 기능 제공과 지속 보장 분리. C08/C06은 실제 이용 지연/오류와 운영자 처분, 현행 장애/성능은 아님.
- 자체 운영이 언제나 즉시 가능한 가설 반례: B02 reverse-only import는 forward search index 없음; B06 SQLite 변환은 import와 의존성 필요; D01/D02 원천 파일은 검색 서비스 아님. D03 배포판 버전/ES·OS 인덱스 일치 확인 필요. C05는 이전 앱이 Photon으로 이전 준비, 성공 미확인. C07/C09 자체 사양 경험은 관측만, 가격·원인 보장 없음.
- F01 동일 blob 재열람 L805–945: localGeocoderOnly에서 원격 geocoder 호출 전에 분기, local 결과 구성; 입력 이벤트마다 서버 호출하지 않아도 후보 표시 가능하다는 원리. 로컬 자료가 없으면 결과도 없음. 전체 네트워크 차단 시험 아님, 위젯 UI 세부는 제외.
- Open Library E01/E04 단건 조회, E03 복수 검색, E02 월별 덤프와 E05/E06 스키마 분리. E07 실제 독립 인덱싱 사례: TSV 정제, PostgreSQL 적재 및 SQL 질의; 과거 M3 약 5시간이라는 자체 보고는 비용 예측이나 현재 처리시간 아님. 데이터 배포일과 자체 인덱스 적용일, API 반영일을 분리. 책 목록 이용자에게 검색 사이트 링크 하나면 충분할 수 있으나 오프라인 전수 검색에는 파일+스키마+적재가 필요.
