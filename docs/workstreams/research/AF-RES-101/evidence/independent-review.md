### TY-A1과 TY-U1의 추가 경계

TY-A1 최초 코드는 grid를 쓰지만, 요구는 항목마다 선을 표시하는 출력이다. grid 함수 자체를 보존하라는 조건은 없다. `table` 같은 다른 호출을 처음부터 부적합으로 배제하면 원 요구에 없는 제약을 추가한다. 현재 initial.csv가 내용과 격자 배치 보존으로 명료화된 것은 적절하다.

TY-U1의 첫 제안은 pagebreak라는 자연어 조작과 page 컨테이너의 구체 코드가 같이 있다. pagebreak 표기는 그대로 실행 가능한 전체 프로그램이 아니며 align의 범위도 구체 코드와 분리되어 있다. 두 후보의 ‘공식 연산이 존재함’과 ‘원 요구 전체를 충족함’을 구분해야 한다. 세 번째 my-fig는 page 동작을 감싼 조건부 helper다. 새 wrapper가 별개의 결과를 보장하는 것은 아니지만, 인자에 따라 branch를 선택하는 제안 자체는 원문에 존재한다. 현재 두 방식 모두 이 세 번째를 반환 2위 밖으로 두므로 wrapper 분할 여부가 이 사건의 A/B 실제 반환 차이를 만들지는 않는다.

## 봉인과 전송 정규화

SCOPE.md의 현재 바이트는 ① 봉인과 같았다. 초기 CSV와 frame CSV, 후보 CSV는 **현재 로컬 CRLF와 Git 봉인 blob의 LF 차이**가 있었다. CSV로 파싱한 모든 필드·행은 각각 8/87/24행 완전히 같았다. 이를 사후 판단 변경으로 보지 않는다. 하지만 raw SHA-256만 비교하면 다르므로 재현 문서에 LF 정규화와 Git blob 기준을 밝혀야 한다. root가 기록하는 [전송 정규화 영수증](seals/transport-normalization.json)과 함께 읽는다. 봉인 이전 로컬 bytes hash를 원격 LF bytes hash와 동일하다고 표현해서는 안 된다.

## 이 검토가 확인하지 않은 것

공식 구현의 실제 성공, 원 입력 복구, 입력과 예상 출력의 연결, 원 필수조건 전부의 만족, 사용자 시간 절약, 과거 비공개 시도는 이 단계 검토 대상이 아니다. 현재 API로 안 보이는 삭제 댓글·수정 전 댓글도 복구하지 않았다. 표 각 행의 원주소가 있다는 사실만으로 댓글의 과거 본문 동일성이 입증되지 않는다. 원 링크의 현재 콘텐츠가 2024년에도 같았다고 주장하지 않는다.

이번 재계산에서는 산술·자리·시간창·기록된 규칙의 반환 오류를 찾지 못했다. 위 민감도와 주장 범위를 RESULT 및 재현 절차에 반영한 뒤 최종 산출물의 분자·분모와 표현을 다시 대조해야 한다.
