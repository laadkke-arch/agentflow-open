# 실행 계측 보정

기대표를 봉인한 커밋은 `877aa0c16691ae3827e4902cec72e8850dda6beb`다. [첫 실행 원장](runs-first-pass.jsonl)에 실제로 종료한 참조판 8회와 정확판 차단 8자리 모두를 보존했다. AC02 양성의 첫 시도는 원문의 모듈 스코프를 함수 지역 스코프로 옮긴 계측에서 `NameError`로 종료 1이었다.

두 번째 실행 코드는 AC02의 타입을 원문의 모듈 이름 공간에 둔다. CC02는 옵션을 생성자 `params`에 직접 넘긴다. AC01은 조회 실패를 딕셔너리의 실제 `KeyError`에서 수집한다. 사전 기대, 모드, 배포판 요건, 입력 이름과 값은 같다. 두 회차 모두 4자리의 동일 양성·경계 입력을 실행하는 계획이다.
