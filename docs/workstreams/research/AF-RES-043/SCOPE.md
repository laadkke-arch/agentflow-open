## 두 과업과 기대 기준

현재 과업 C: 소비자의 관측된 목적을 지금 수행하려 할 때 이 참조의 주장/방법을 유지·교체·보류하는가? 특정판 재현을 명시한 소비자의 목적은 최신판으로 바꾸지 않는다. 최신 수치를 쓰는 목적과 최초 발표값을 재현하는 목적은 같은 계열에서도 별도다. 소비자의 시간 의도가 명시되지 않았으면 그 불확실성을 보류 근거로 남긴다.

과거 과업 H: 소비자가 가리킨 그 판의 해당 절에 카드 주장이 실제로 쓰였는가? 이후 정정은 당시 출판 사실을 지우지 않는다. `local_redisplay`, `publisher_edition_match`, `publisher_conflict`, `unverified`를 구분한다. 정정판과 다르다는 이유만으로 옛판 주장에 conflict를 주지 않는다.

대조키는 소비 원문·옛판·현행/정정판·별도 발행기록을 읽어 ②에서 봉인한다. 날짜는 소비 출판일/대상 릴리스일/통계 기준기간/개정일/논문 원문일/정정일로 분리한다. 별도 발행본 기준이 없으면 `criterion_confirmed=false`; 연구자 해석을 외부 정답으로 부르지 않는다. 기준 URL·정확한 절·기대 행동·판단 근거를 key에 둔다.

## B/L/X 작성과 정보 통제

- B: 실제 소비자가 남긴 원 href·원문 문맥·목적·명시한 판. 연구자가 새로 판/정정 사유를 끼워 넣지 않는다. 관측 문장과 목적 해석을 라벨로 구분한다.
- L: 추가된 당대판 전용 공개 URL 및 해당 절. 그 URL이 당시 존재했다는 증거와 지금 찾은 대체 locator를 별도 필드로 둔다. 판 고정의 확인 불가는 그대로 남긴다.
- X: 같은 옛 절의 한 문장 또는 최소 발췌. 정답·후속 정정 이유·해설은 넣지 않는다. URL/판 단서가 우연히 들어 있으면 표시한다. 발췌는 저작당 총25단어 이내의 짧은 핵심을 원칙으로 하며 재표시는 중복 인용이다.
- B, L, X의 문자열과 B→L→X 순서는 각 구성에서 바이트 동일. 8×4 카드를 SHA-256으로 봉인한다. 출처 ID/locator는 key에 둔다. B에 이미 고정 href가 있거나 X가 B를 그대로 반복하면 정보 증분 없음으로 표시한다.

## ③ 실제 판독 규칙

각 사례의 카드 순서는 공개 교차 순서: 사례1·5 `B,LX,L,X`; 사례2·6 `L,X,B,LX`; 사례3·7 `X,L,B,LX`; 사례4·8 `LX,B,X,L` (L=B+L, X=B+X, LX=B+L+X). 각 카드에서 C→H / H→C를 사례 홀짝으로 번갈아 읽는다. 32카드·64과업의 논리적 시작 상태를 분리한다. 기억은 완전히 지울 수 없으므로 작성자/판독자 키 노출 및 앞 카드 노출을 기록한다.

각 카드·과업은 발행자 원문 최대2회 open. 실패도1회다. 첫 URL은 보이는 B/L/X 문자열의 URL 중에서 목적에 맞게 선택한다. 두 번째 URL은 첫 열린 문서에 실제로 있는 href에 한한다. 카드의 다른 URL로 바로 점프하지 않는다. 주소 추측, 검색, key에만 있는 URL, 사후 발견 URL은 판독 성공에 넣지 않고 진단 원장에만 둔다. fragment 이동/같은 로드 본문 내 찾기는 새 fetch가 없으면 추가open이 아니며 위치를 기록한다. 도구가 캐시 본문을 반환하면 실제 네트워크 왕복이라고 하지 않는다. 로컬 X 표시는 별도 행이며 publisher open을 소비하지 않는다. 첫 열람만으로 충분하거나 두 번째 허용 href가 없으면 조기 종료한다.

현재의 `action_match`와 `supported_correct`를 분리한다. 같은 행동을 찍었어도 실제 열람이 필요한 주장을 지지하지 않으면 근거 성과는0이다. `hold_reason`: normative(보류 자체가 기준 답), access_failure, evidence_insufficient, time_intent_unknown, criterion_unknown. 자료 미확인은 빈값/0으로 바꾸지 않는다.

과거의 엄격 성공은 지정 판의 본문/절을 대조한 `publisher_edition_match`다. X 재표시는 별도 성공 종류며 원판검증 분자에 더하지 않는다. X가 정확하지만 현재 틀린 값을 유도할 수 있는 문서상 위험과 실제 카드 판정에서 오류를 유발한 사건을 분리한다. 현행 유지나 교체도 실제 문구/판/위치만 근거로 센다.

## ④ 집계·감도·반례·수용

사례×과업별 네 짝: B↔L, X↔LX, B↔X, L↔LX. 8×2×4=64짝. 자연4와 정정우선4, C와H를 따로 집계한다. 전체 슬롯 분모/기준확인 분모/쌍방 판정 가능 분모를 보존하고, 둘다맞음·왼쪽만·오른쪽만·둘다틀림·보류·기준미확인을 배타적으로 센다. 보류가 정답이면 supported_correct로, 단순접근불가는 보류로 센다.

감도는 각각 원규칙과 따로 계산한다: S-X는 X에 판 또는 URL 단서가 들어간 사례 제외; S-I는 별도 독립 발행본으로 기대 기준을 직접 확인한 사례만. 교집합을 기본 감도로 바꾸지 않는다. 적격 분모0은 **해당 없음**. 문서상 가능한 판단과 실제 사용자 행동·시간·비용은 구분한다.

반례 탐색: (a) L이 옛판 대조를 가능하게 함 (b) 원 B가 이미 영속 주소여서 L이 불필요함 (c) X가 옛판에는 맞지만 현재 목적의 값/방법에는 틀림 (d) 같은 URL의 전후 의미 변경 (e) 정정이 인용 핵심을 건드리지 않음. 찾지 못한 반례도 검색 경로와 첫 재개 자료를 남긴다. 처음 정한 표본을 반례에 맞춰 교체하지 않는다.
