# ② 고정 입력의 별도 방법·출처 감사

이 감사는 같은 모델 계열의 별도 에이전트가 수행했다. 고정 입력 커밋 `b3aa200fce66f0635e74aa39c4cb008cafd86eff`의 SCOPE·출처·키·판/표집 원장과 수집 메모를 읽었다. 진행 중인 `readers/`, `reads.csv`, `judgments.csv`와 실제 카드 결과는 읽지 않았다. 새 외부 원문을 직접 읽었다고 주장하지 않으며, 수집 원장의 관측 범위와 내부 연결을 감사한 결과다. frozen input을 수정하지 않았다.

## 1. 읽은 고유 원문 수와 필수 구성 수는 다르다

엄격 필수 산입은 **소비자7/8 + 대상8/8 + 별도 공지4/4 + 공식 규칙4/4 = 23/24**다. 산입된23개 행은 `source_id`와 `duplicate_group`가 모두 다르다. 전체99개 출처 행에도 중복 source ID나 필수14개 필드 누락이 없다. `evidence/source-count-audit.json`은 입력 해시, 모든 산입 ID, URL·위치·원장 행을 보존한다.

**전체 직접 읽은 고유 발행자 1차 문서의 보수적인 하한은28개**다. 필수23개에 다음5개 별도 저작만 추가했다. 이 값은 문서를 전부 정독했다는 뜻이 아니며, 원장에 적힌 실제 범위의 직접 열람을 뜻한다. 미러·실패·같은 대상의 옛판/현판/PDF·검색 스니펫은 추가하지 않았다.

## 2. 표집 추적에서 남는 약점

- 자연 원장 N-P25행, N-S25행이 각각 있고 첫 적격 문서는1·2 및5·10이다. 정원 뒤 미검토와 병렬 링크 스캔11·12는 선정과 구별되어 있다.
- 통계 원장은25개 슬롯을 보존했지만 첫4개 검색을 함께 보낸10개 노출의 query 귀속·개별 순위가 없다. `collection/statistics/search-metadata.json`의 미충족을 그대로 수용 기록에 반영해야 한다. 소비자 검색 일부도 완전한 호출 문자열이 미확인이다.
- 학술 원장은31개 노출, 최초25고유 결과의 끝은 raw26이다. raw14는 raw8 정정의 PMC 미러이고 중복 제외가 맞다.
- 별도로 `collection/journals/consumer-search.csv`의 J02 발견 경로에는 첫 system1 요청 실패, 둘째 검색의 상세 결과 목록 미보존, system2 재시도가 있다. 정확 제목과 재시도 순서는 남지만 **처음부터 완전히 재현 가능한 소비 검색 기록**으로 보고할 수 없다. 통계 편차만 쓰고 이 추적 한계를 생략하지 말아야 한다.
- 두 통계 소비자는 대상과 같은 발행자의 별도 분석/월간 문서다. 별도 저작이므로 중복 산입은 아니나 외부 기관의 독립 수요나 사람의 사용 행동을 관측한 사례는 아니다.

## 4. 반례의 실제 관측 강도

문서상 반례는 충분히 다양하다. Python release의 문서 href가 exact patch를 보장하지 않고, French는 옛 수치와 현행 수치가 다르며, ONS의 최초와 현재 수치가 다시 같아진다. J01은 옛 문구가 당시 출판사실에는 맞고 현재 수치 사용에는 틀린다. J02는 정정이 있다는 사실만으로 선택된 좁은 인용 주장을 버릴 수 없다. 각각의 출처 ID와 한계가 원장에 연결되어 있다.

다만 **같은 URL이 두 시점 모두200이면서 절 의미가 바뀌었다**는 직접 반복 HTTP 관측은 없다. ONS의 발행자 제공 superseded-v1/current 문구 차이는 좋은 판 관계 증거지만 두 시점의 동일 URL 응답 측정과 다르다. 이 조건을 이미 충족했다고 쓰지 말고 탐색·미확인 조건으로 남긴다. 또한 L/X가 실제 판독 결과를 바꿨는지는 이 감사가 아직 보지 않은③원장에서만 집계해야 한다.

## 5. 파일 표현의 최소 정리

고정 입력의 `frame.csv`에는2,035개 공란이 있다. 대부분 서로 다른 원장을 합친 union schema의 비적용 필드이며, 자연 미선정 슬롯의 case_id46개도 비어 있다. `versions.csv`에는 reference_period/vintage_values/L_work_specific 각6개, 총18개 선택 필드 공란이 있다. 공란을0으로 세지 않았다는 것만으로 확인 불가를 명시한 것은 아니다.

최종 표현에서는 적용되지 않는 필드를 `해당 없음`, 적용되지만 확보하지 못한 값을 `미확인`으로 구분하는 것이 적절하다. 관측·분모를 바꾸지 않는 표현 정리임을 기록하고, ②커밋 및 이 감사의 입력 SHA-256으로 원래 공란을 재구성 가능하게 보존한다. 실제 자료를 확인하지 않고 빈값을 true/false 또는0으로 채우면 안 된다.

## 감사 결론

출처 원장의 엄격 최소 산입과 기본 판별 구조는 보수적으로 유지되어 있다. 전체 직접 원문 수의 하한28을 명시할 수 있지만 필수 구성23/24, 완전 자극7/8, 소비판 미확인 및 표집 추적 편차는 남는다. 결과가 좋게 나오더라도 이 수용 조건을 자동으로 충족시키지 않는다. 최종 판단은 원 규칙의 수치, 별도 감도, 근거 수준과 한계를 함께 제시해야 한다.

## 후속 감사: 카드의 연구자 해설과 정답 단서

이 후속 감사도 `components.jsonl`과 frozen `cards.jsonl`의 자극 및 과업 문구만 읽었다. 판독자 원장·판독 결과는 계속 읽지 않았다. 본문이나 키·기준·표본을 수정하지 않았다.

**Q3의 연구자 해설 분리 조건은 미충족으로 표시하는 것이 맞다.** N-S-01 B의 마지막 문장인 “원출력 복원과 오늘의 수정 계열 중 사용할 시간 의도는 명시되지 않았다”는 소비자의 실제 문장을 그대로 보존한 것이 아니다. 수집자가 소비 문서에서 시간 의도를 찾지 못했다는 부재 해석이며, 두 가지 목적을 비교하도록 하는 연구자의 틀도 포함한다. 특히 '오늘의 수정 계열'은2023 소비 문맥 자체에서 확인된 목적을 넘어서는 현재 연구의 표현이다. frozen key의 규범적 보류 이유와 가까워 판독자에게 C 답을 암시할 수 있다. 별도 키 파일을 보지 않았다는 의미의 가림과 **정답 단서가 없는 자극**이라는 의미의 가림은 같지 않다.

영향 자극은 `N-S-01-B`, `N-S-01-BL`, `N-S-01-BX`, `N-S-01-BLX`의 네 카드다. 네 C 과업 모두 같은 문장을 포함하며, C 질문도 원출력 복원과 현행 수정 계열의 구별을 명시하도록 요구한다. 따라서 C에서 규범적 보류가 관측되더라도 소비자의 원 요구만 읽고 독자가 스스로 시간 불확실성을 발견한 성과라고 해석해서는 안 된다. 문장이 네 구성에 동일하다는 점은 요소 동일성 조건을 충족하지만 중립성을 회복하지는 않는다. 공통 단서가 B의 성과를 높이거나 추가 L/X의 차이를 보이지 않게 했을 가능성이 남는다. 실제로 어떤 영향을 줬는지는 이 감사가 판독 결과를 보지 않았으므로 **미확인**이다.

수용 기록에는 최소한 `q3-neutrality.met=false`, 직접 영향을 받는 사례1/8 및 C판독4/32를 명시할 수 있다. 이는 **연구자 해설 분리 위반을 식별한 범위**이며 나머지7사례가 완전히 중립적이라고 실험으로 검증했다는 비율이 아니다. 동일 요소·순서·내용 해시의 적합성과 이 중립성 미달은 별도 수용 조건이다.

현재 자료는 그대로 보존하고 원 규칙으로 집계해야 한다. 다음 최소 조사는 해당 부재 해석 문장과 C 질문의 추가 시간 구분 지시를 제거한 N-S-01 자극을 별도 사전등록한 뒤, 기존 판독이나 키를 보지 않은 새 독자에게 같은 예산으로 네 C판독을 수행하는 것이다. 해당 조사는 기존 관측을 대체하지 않고 분리 보고해야 한다. 그때 규범적 보류 비율이나 근거 수준이 달라지면 현재 B 성과 및 L/X 무차이의 해석이 달라진다.
