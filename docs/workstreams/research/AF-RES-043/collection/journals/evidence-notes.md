수집 단계: ② 소비자 목적·판 이력·채점 기준 수집. 이 디렉터리에는 카드별 과업 실행이나 그 성과를 기록하지 않았다. 작성자 `/root/journals`는 원문과 정정 내용을 모두 보았으므로 후속 판독에서 이 작성자가 참여하면 키 노출 상태다.

## 선정 경로와 표집 한계

사전 범위 `SCOPE.md`에 고정한 네 검색어를 그 순서로 실행했다. `frame.csv`는 반환 순서의 31개 노출을 모두 보존한다. raw14의 PMC 정정은 raw8의 발행자 PDF와 같은 저작이어서 중복으로 표시했다. 그 결과 최초 25개 고유 결과는 raw26에서 끝난다. 최초 25개 원시 노출과 고유 결과를 각각 표시하여 분모를 바꾸지 않았다. raw27 이후는 추가로 반환된 노출이며 사례 선정에는 사용할 수 없다. 목차·정책 페이지는 대상-정정 사슬이 아니며, 두 사슬을 얻은 이후의 나머지 논문 본문은 심사하지 않았다. 미검토는 부적격을 뜻하지 않는다.

첫 적격 사슬은 raw2에서 발견한 Ubon-sepsis이며, 둘째는 raw5의 mTERF22다. 두 결과는 검색 엔진이 반환한 저자 소속기관 기록이었다. 기관 기록이나 스니펫을 발행자 원문으로 세지 않고 DOI를 통해 PLOS의 원문과 별도 정정 본문을 직접 열었다. 두 사슬을 채운 뒤 eLife 대체 원장은 사용하지 않았다. 검색 도메인 연산자가 실제 반환 도메인을 완전히 제한하지 않았다는 점도 결과에 남긴다.

J01의 정확한 원문 제목 + `site:pmc.ncbi.nlm.nih.gov` 검색에서 첫 결과는 대상 논문 자신이었고 두 번째가 실제 소비 문서였다. 이 BMJ Open 2021 논문의 PMC 전문에서 본문 목적과 참고문헌 16을 연결했다. 발행자 DOI, HTML, full HTML, PDF 요청은 403이었다. 직접 셸 요청도 같은 403이었고 인증·접근제한 우회는 하지 않았다. 앞서 선택한 소비자를 접근이 쉬운 다른 소비자로 바꾸지 않았다.

J02의 첫 정확 제목 + PMC 검색 호출은 도구가 결과를 주지 않는 오류였다. 정해 둔 다음 단계인 발행자 도메인을 제외한 제목 검색은 원문·원문 서지·정정만 노출했다. 같은 PMC 검색을 두 번째 검색 엔진으로 다시 실행하여 원문, 정정, 2019 OGE 리뷰, 2021 mTERF27 논문 순으로 노출을 얻었다. 2019 리뷰는 PMC 접근 실패 뒤 발행자 MDPI 전문과 참고문헌을 직접 읽었지만 대상 논문 인용이 확인되지 않아 탈락했다. 다음 2021 mTERF27 논문에서 실제 인용과 목적을 확인했다. 이는 유리한 정정 내용으로 소비자를 교체한 것이 아니라 먼저 노출된 비인용 후보를 본문 심사로 제외한 것이다. 엔진 변경과 도구 오류를 숨기지 않으며 이 경로는 독립 사람이 똑같은 순서를 얻을 것이라는 보장이 아니다.

## J01: 당시 문구 보존과 현재 수치 재사용이 갈라진다

- 소비자: BMJ Open 2021-02-18, 11(2):e041022. [PMC 전문](https://pmc.ncbi.nlm.nih.gov/articles/PMC7896572/), Study design L251–265와 reference16 L480. 코호트 설명을 원 논문에 맡기면서 SFT 프로그램 효과를 후향 평가한다. Abstract Results L224와 Results L298–299의 실제 소비자 값은 **3,806**이다.
- 원문: [PLOS 2018 발행저작](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0204509), Abstract L171과 Results L259는 **3,716(74%)**을 지금도 표시한다. [발행자 PDF](https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0204509&type=printable)의 1쪽 Abstract L27–28도 같은 옛 값을 표시한다. 원문 HTML의 상단 L152에는 2024 정정으로 가는 실제 href가 있다.
- 정정: [PLOS 2024-03-21 별도 공지](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0301218), L123–126은 3,716/4,989를 잘못된 값, **3,806/4,989**를 맞는 값으로 명시한다.

직접 관측은 원문 HTML·PDF·별도 정정에 서로 다른 값이 있다는 것이다. 저자 진술은 2024 공지가 옛 값의 오류와 새 값을 명시한다는 것이다. 연구자 해석은 현재 수치를 재사용할 과업에서는 원문의 3,716을 3,806으로 교체해야 하지만, 2018 발행 저작이 어떤 문구를 냈는지 확인할 과업에서는 옛 문구가 정답이라는 것이다.

이 사례로 실제 소비자가 저장 발췌에 속았다고 주장할 수 없다. 선정 소비자는 정정 공지가 나온 2024년보다 앞선 2021년에 이미 3,806을 사용했다. 따라서 X의 위험은 “현재 목적에 쓰면 틀리는 오래된 문구”라는 문서상 반례다. 실제 카드 판독에서 X가 오류를 유발했는지는 후속 원장에 발생한 행만으로 셀 수 있다. 현재 과업의 행동 대상도 “소비자의 이미 맞는 3,806을 바꾸는가”가 아니라 “원문에 남은 3,716을 현재 수치로 재사용하는가”로 명확히 해야 한다.

## J02: 정정의 존재가 인용 핵심 전부를 무효화하지 않는다

- 소비자: [MDPI 2021-02-02 논문](https://www.mdpi.com/1422-0067/22/3/1466), §1 Introduction L181은 mTERF22의 여러 미토콘드리아 유전자 발현 역할을 mTERF27 연구의 배경으로 쓴다. reference26 L318의 실제 CrossRef href가 원 2018 PLOS DOI다.
- 원문: [PLOS 2018-07-30 발행저작](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0201631), Abstract L169–170에 선택한 발현 주장이 있다. Data Availability L178도 읽었지만 소비자의 첫 인용 목적은 자료 위치가 아니다.
- 정정: [PLOS 2019-03-25 별도 공지](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0214558), L111–117은 블롯 그림 문제를 다루고, L130은 GFP 자료만으로 미토콘드리아에 **배타적으로** 존재함을 확정할 수 없다고 좁힌다. L132는 여러 증거를 종합한 미토콘드리아 내 존재를 지지하고, L133은 원래 자료 가용성 문구의 문제와 Figshare 제공을 밝힌다. L134는 원자료가 보고한 결과와 결론을 지지한다는 저자 진술이다.

선정한 좁은 발현 주장을 유지한다는 판단은 위 범위 대조에서 나온 해석이다. 모든 실험 결론이 독립적으로 검증되었다는 뜻은 아니다. 정정 공지는 원문과 다른 DOI·날짜의 발행물이지만 저자들이 일부 동일하므로 독립 실험으로 분류하지 않는다. 소비 문서는 정정 이후 출판되었지만 정정을 실제 읽었다고 명시하지 않으므로 인지 여부는 미확인이다.

반대로 과업이 배타적 위치의 확언 또는 공개 원자료의 위치라면 정정이 중요하다. “정정이 있으니 전부 폐기”와 “선택 X가 유지되니 정정은 불필요”는 모두 이 사례가 허용하지 않는 일반화다. 이 추가 대조는 처음 선정한 소비자의 발현 목적을 교체하지 않는 진단이다.

## L과 X를 읽는 세 증거 수준

두 B는 이미 2018 발행저작 DOI와 서지 판을 갖고 있다. 두 L은 현재 직접 확인한 발행자 HTML URL와 실제 `abstract0` anchor를 추가한다. raw HTML의 anchor와 correction href, MDPI의 원 DOI href는 `raw-web/*.links.json`에 저장했다. L은 특정 발행저작을 식별하지만 immutable 바이트 버전 주소라고 단정할 수 없다. 이 직접 HTML URL 및 fragment가 실제 소비 시점에 존재했다는 근거는 **미확인**이다.

실제 소비자 DOI를 눌렀을 때 두 사례 모두 resolver 경로에서 오류를 보였고 직접 PLOS HTML은 열렸다. 이 수집 진단은 향후 카드별 열람 성과에 넣지 않는다. 후속 L 효과가 나타나더라도 “추가 판 정보”와 “다른 주소 경로의 접근 성공”이 함께 달라질 수 있다.

X는 원문에 있던 짧은 발췌의 지역 재표시를 가능하게 한다. J01의 X는 현재 목적에는 틀리지만 옛판 대조에는 맞다. J02의 X는 선택한 좁은 주장에 한해서 현재 목적과 원판 대조에 모두 맞는다. 어느 X도 자체적으로 발행자 판 대조를 수행하지 않는다. 또한 두 X에는 URL·연도·판번호가 들어 있지 않아 S-X 제외 대상이 아니다.

J01의 별도 정정 공지는 원문 오기 3,716까지 명시하므로 현재·과거 주장 모두 별도 발행본 기준을 직접 확인할 수 있다. J02의 현재 범위 판단에는 별도 정정 공지를 사용하되, 과거의 정확한 발현 문장 자체를 독립된 날짜 발행본이 인용했는지는 미확인이다. 따라서 S-I의 역사 과업에는 J02를 넣지 않는 보수적 구분을 `cases.json`에 뒀다.

## 첫 재개 자료와 결론을 바꿀 조건

1. J01 소비자 직접 발행자 기준을 재개할 첫 자료는 [BMJ 원문](https://bmjopen.bmj.com/content/11/2/e041022)이다. 해당 공개 HTML 또는 원문에 실제 연결된 PDF를 인증 변경 없이 읽고 Study design과 reference16을 대조하면 엄격 소비자 산입 조건이 달라진다. 403 상황 자체는 논문 내용의 부정 증거가 아니다.
2. J02 역사 독립 기준은 [2018 발행자 PDF](https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0201631&type=printable) 또는 발행자가 제공하는 날짜가 고정된 버전 기록부터 확인한다. 현재 HTML과 다른 표현이 나오면 “옛 문구 보존” 판정 및 S-I 분모가 달라진다.
3. 두 L의 당시 존재와 불변성을 입증할 첫 자료는 해당 발행자의 원문 버전 기록이다. 그런 기록 없이 DOI resolver 성공 여부만 달라지면 L의 이득은 주소 경로·절 위치의 이득으로 제한해야 한다.

다음 명령으로 이 묶음의 JSON·CSV 연결을 검사할 수 있다. 이것은 외부 주장 검증이나 카드 실행을 대신하지 않는다.

```sh
python -B - <<'PY'
import csv, json
from pathlib import Path
p = Path('docs/workstreams/research/AF-RES-043/collection/journals')
cases = json.loads((p / 'cases.json').read_text())
sources = [json.loads(line) for line in (p / 'sources.jsonl').read_text().splitlines()]
frame = list(csv.DictReader((p / 'frame.csv').open()))
assert [c['case_id'] for c in cases] == ['J01', 'J02']
assert len(frame) == 31
assert sum(row['within_first25_unique'] == 'true' for row in frame) == 25
assert len({s['source_id'] for s in sources}) == len(sources)
assert sum(s['counted'] for s in sources) == 5
print('2 slots, 31 exposures, 25 unique-frame slots, 5 strict-counted sources')
PY
```
