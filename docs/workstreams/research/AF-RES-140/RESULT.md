### Q5. 질문이 필요한 경우와 불필요한 경우

공통 입력/첫 절 동일, 판독자 동일. 질문 경로는 한 문장 A/B 후보를 미리 작성한 가상 분기(발송 0회). 추가 절은 코드포인트 예산, 질문은 개수 예산이다. 서로 다른 실제 시간 비용을 같은 것으로 간주하지 않는다. 두 답 모두 추천이 같은 Y4는 질문하지 않는 쪽으로 판정했다. C4의 정확한 플래그 유무와 C3의 Python escape 동작도 문서에서 확인할 기술 사실이므로 그 자체를 저자에게 다시 물을 필요가 없다. 반대로 C3의 bare quote 출력 허용 기준은 기술 문서를 더 읽어도 저자 의무를 정해 주지 않는다. Y3의 LF 정규화 허용 여부도 그렇다.

원저자 관점: C3의 단순 escape 답은 실제 요구와 어긋남; Y2의 null 처리 질문은 당시 결함 해결을 늦출 수 있음. 구판 사용자 관점: C3 첫 문서 1.1.0과 사후 보고 1.0.7/Python 3.11.2 차이가 실제 empty quotechar 동작에 관련된다. C4 1.0.5 정확판 사용법 우선; upgrade 허용은 별도 질문. 문서 편집자 관점: 제약을 먼저 링크의 짧은 위치로 노출하고 잘못된 입력별 주장(다른 fixture/판)을 표시한다. 동일 연산자에서 서식·문자·값이 갈리면 별도 예를 적는다. C3 RFC 4180 §2 (A1)는 CSV의 인용부호 규칙이지 TSV의 모든 규칙이 아니다. Y3 YAML 1.2.2 §5.4 (A2)는 scalar line break 정규화 규칙을 명시하지만 원저자의 CRLF 허용 여부는 정하지 않는다. 둘 다 사후 읽은 별도 반례이며 사전 두 경로 결과에 합산하지 않는다.
