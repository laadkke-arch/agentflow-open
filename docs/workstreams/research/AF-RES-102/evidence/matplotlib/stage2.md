# Matplotlib 2단계: 경로·소스 신호와 예측 봉인

신판 전체 디렉터리 트리는 10,170개 항목이며 truncated=false다. 신판 본문·그림·개별 CI 로그를 열지 않은 상태에서 이전 적격 40개를 대조했다. 외부 상대 그림 경로가 있는 28개는 모두 정확한 경로가 신판에도 남아 있다. 나머지 12개는 JS data URL이라 경로 부재층 후보가 아니다. 그러므로 A층의 두 자리는 결원이다.

일반층과 겹치는 행을 뺀 뒤 그림 경로가 남고 Download Python 소스 blob이 바뀐 C 후보는 6개다. 기존 hash 순서로 첫 두 개인 HBoxDivider와 Inset Locator를 골랐다. 두 이전 소스 경로는 신판에도 남지만 blob이 다르다. 신판 소스 내용은 읽지 않았다.

일반층 2개와 C층 2개의 U 예측은 모두 YES다. exact-path 규칙은 남은 파일을 절이 실제 사용하는지, 새 이름·내장 그림으로 역할이 이어지는지, 같은 바이트의 용도가 바뀌는지를 의도적으로 보지 않는다. 이 한계는 예측 반증의 대상이다.

추가 반례 탐색은 주 표본을 제외한 같은 40개 목록의 동일 hash 순서 첫20개로 미리 고정했다. 주 표본에 사후 편입하지 않는다. 상세 노출 시각과 읽은 필드는 stage2-exposure.json, 전40행 신호는 all40-signals.json에 있다. root의 두 번째 원격 봉인 확인 전에는 신판 본문을 읽지 않는다.
