## 모집틀·표본·노출 경계

논리 예제 한 단위는 이전 발행판의 실제 Examples/gallery 본문 절에서 참조하는 **첫 설명용 그림과 그 설명 목적**이다. 같은 페이지의 두 번째 그림으로 표본을 교체하지 않는다. 이전판 공식 페이지 경로를 POSIX 사전순으로 정렬하고, 적격 예제 40개에 도달할 때까지 앞선 모든 경로의 포함·배제 이유를 남긴다. 40개 미만이면 전수다. 제목·절 식별자·그림 참조·대응 소스 경로를 이전 판에서 읽는다. 자동 경로 열거만 한 자료를 직접 자세히 읽은 원문으로 세지 않는다.

제외 대상: 로고·배지·색인/설명용 그림 없는 페이지, 098 주 예제 `animation_demo`, `pause_resume`, Python logging-flow와 BLAKE2 tree, ggplot2 `aes`와 `aes_colour_fill_alpha`. 기존 asciicast SVG 둘·Cole EPUB·Moby-Dick·Data Citation Corpus도 신규 사례/최소 자료수에서 제외한다. 098의 보조 반례를 재사용하면 상속 사실을 표시하고 신규 성과로 세지 않는다.

해시 입력을 다음처럼 고정한다. `옛 절 경로`는 버전 루트 기준 상대 페이지 경로와 실제 fragment를 연결한 `page.html#fragment`다. 버전 접두어나 URL 호스트를 붙이지 않는다. UTF-8 바이트에 SHA-256을 적용하고 64자리 소문자 hex 오름순으로 정렬한다. 동률이면 옛 절 경로 순이다.

```text
SHA256('AF-RES-102|' + project + '|' + old_relative_section_path)
```

| 층 | 후보 조건 | 선정 규칙 | 자리 ID |
|---|---|---|---|
| 일반 G | 이전판의 처음 40 적격 예제 | 새 판 목록을 보기 전에 해시순 첫 2개 | GG-G1/G2, MP-G1/G2 |
| 옛 자원 없음 A | 완전한 다음 발행판 tree에 옛 상대 자원 경로가 없음 | G를 제외한 해시순 첫 2개 | GG-A1/A2, MP-A1/A2 |
| 경로 잔류·소스 변경 C | 옛 자원 경로가 남고 대응 본문 소스 경로가 없어졌거나 blob이 다름 | 앞서 선택한 예제를 제외한 해시순 첫 2개 | GG-C1/C2, MP-C1/C2 |

층당 부족분은 결원이며 다른 층이나 사후 보조 예제로 채우지 않는다. data URL 또는 JS 내장 그림도 실제 첫 설명용 그림이면 모집에서 임의 제외하지 않는다. 비교할 옛 상대 파일 경로가 없는 경우에는 경로 규칙 적용이 불명확하므로 예측 유보로 기록하고, '경로 없음' 음성으로 바꾸지 않는다.

대응 본문 소스는 이전판에서 먼저 정한다. ggplot2는 각 reference 페이지의 같은 이름 `man/<page>.Rd`를 렌더 입력으로 삼고 저자 R 파일 링크를 별도로 남긴다. Matplotlib은 발행 HTML의 Download Python source가 가리키는 `_downloads/<hash>/<example>.py`와 배포 tree blob을 삼는다. Matplotlib 발행판의 표시 revision이 릴리스 tag와 다르므로 release-tag `.py`로 실제 발행 소스를 대신하지 않는다. 소스 코드 저장소 tag와 docs revision은 별도 필드에 보존한다. 이 정의는 새 목록/결과를 보기 전에 적용한다.

1. **묶음 ①:** 이전판 모집틀·일반층과 판 선정 근거를 저장·원격 커밋. 이때 다음판의 개별 본문/그림/CI 로그는 열지 않으며 일반층 선정 전 새 배포 tree도 열지 않는다.
2. **묶음 ②:** 새 tree 경로와 대응 소스 path/blob만 읽고 A/C층·12개 자리를 고정한다. 예측은 정확 옛 상대 경로 있으면 YES, 완전 tree에서 없으면 NO, 불완전/모호하면 미확인이다. 새 본문/그림/개별 CI를 열기 전에 두 번째 원격 커밋을 확인한다.
3. **묶음 ③:** 두 판 본문·payload·발행/빌드 자료와 보조 반례·타분야 실물을 읽는다.
4. **묶음 ④:** 층별 혼동표·목적별 반환·자료수·Q별 자기검토·재현 절차를 저장한다. 실제 검사/고정판 재열람 영수증은 후속 근거 커밋으로 추가할 수 있다. 마지막 HANDOFF는 별도 단독 커밋이다.

각 조사자의 열람 시각과 노출 필드를 기록한다. 작업자 분할은 병행 수집이며 연구 전체의 노출 순서는 모든 작업자의 첫 접근 시각을 합쳐 확인한다. 상속 098의 다음판 source/publication SHA 등 이미 알려진 metadata도 사전 노출로 밝힌다. 예측 봉인 파일을 사후 결과에 맞게 고치지 않는다.

## 사후 관측 단위와 반증 기준

한 쌍마다 이전/다음판 2자리, 전체 12쌍/24자리를 유지한다. 결원 자리도 원인·재개 입력을 갖는다. 각 자리에서 실제 절 fragment 또는 동급 제목 경계, `src`, `srcset`, `picture`, 상대 base, data URL, script/JS 참조와 실제 package member를 추적한다. 참조의 끝 파일은 응답 상태·MIME/실제 형식·길이·지문을 기록하고 그림/소스의 목적을 직접 대조한다. hash만으로 목적을 판정하지 않는다.

| 축 | YES에 필요한 직접 근거 | NO에 필요한 범위 | 미확인 예 |
|---|---|---|---|
| P: 실제 따라간 자원이 해당 발행판에 포함 | 완전 배포 tree의 경로와 실제 payload 또는 문서/패키지 내부 멤버 | 고정 완전 tree/package의 정확 범위에서 부재 | 불완전 tree, 접근 실패 |
| U: 같은 논리 예제를 정확 절이 이용 | 절 내부 실제 참조와 이어지는 payload/소스의 역할 | 정확 절의 동급 경계·대체 URI 표현·이동/후계 가능성을 조사해 같은 목적의 이용 없음 | 절 접근 실패, 후계/의미가 모호함 |
| G: 바로 그 빌드가 해당 바이트를 새로 생성 | 실제 실행 ID와 단계·입력·출력 digest가 연결 | 그 실행의 복사/재사용 경로가 출력과 직접 연결되고 신규 생성되지 않았다는 실행 근거 | job 미보존, source/env/output 연결 누락 |

`legacy_path_P`는 옛 자원 경로의 다음판 생존 여부다. 본표 P는 **실제로 따라간 자원**의 포함 여부이므로 이름 변경 후 P=YES·U=YES와 legacy_path_P=NO가 함께 가능하다. 파일 존재 P가 YES여도 해당 절 U는 NO일 수 있다. 같은 이름·같은 hash도 목적이 바뀌면 U의 근거가 되지 않는다. 새 이미지 바이트와 같은 설명 목적은 함께 성립할 수 있다.

공개 job 검색의 저장소/commit·기간·event·페이지 범위, 0건·접근 오류·출력 manifest 누락을 기록한다. 규칙과 실행을 구분한다. 로컬 재빌드는 과거 생성 실행을 입증하지 않는다.

보조 반례는 주 표본 밖 남은 목록의 고정 순서(각 프로젝트 동일 해시순, 이미 선택한 논리 예제 제외)에서 **최대 20예제씩**만 탐색한다. 이미 확보한 유형과 미확보 유형, 조사 중단 위치·이유를 기록한다. ① 경로 있음/절 미사용 ② 경로 없음/새 이름·내장으로 계속 사용 ③ 이름·hash 동일/목적 변경 ④ 바이트 변경/목적 유지 유형을 구별한다. 보조 성과는 주 표본 분모에 넣지 않는다.

## 집계와 반환

각 프로젝트×층별로 TP, FP(오귀속), FN(놓침), TN, 유보, 결원을 각각 센다. U 실제 양성/음성 분모와 유효 예측 분모를 따로 둔다. 분모0은 비율 '산출 불가'이며 0%로 쓰지 않는다. 표집 조건이 다른 세 층의 비율을 합산해 일반 링크 오류율을 만들지 않는다. 자료 완비 여부를 연구 사실의 양성 여부와 구분한다.

반환 선택은 옛판 유지 / 새 위치로 교체 / 두 판 병기 / 본문 절만 제공 / 유보다. 주 사례별로 당시 인용·비교 대상 새판 이용·재현 목적 URL과 볼 절, 더 싼 확인으로 충분한 조건, 틀렸을 때 보여 줄 경고 한 줄을 남긴다. raw HTML은 HTML 소스 주소이며 렌더된 옛 웹사이트로 부르지 않는다.

타분야는 IDPF/epub3-samples의 새 EPUB 하나(Cole·Moby-Dick 제외)와 entry_points를 포함한 실제 공개 wheel 하나다. EPUB container/OPF·spine·XHTML과 자원 참조, wheel RECORD·entry_points·실제 모듈을 읽는다. package 포함으로 reader에서 실제 보였거나 entrypoint가 실행됐다고 추정하지 않는다.

## 자료 원장·완료 조건

`sources.jsonl`은 직접 연 URL/고정 URL·UTC·발행자·저작/사건 계보·판/위치/지문·관측·지지/반박·한계·산입/중복 이유·영수증을 가진다. 같은 저작의 단순 재발행/앵커/미러와 동일 바이트를 합친다. 실패·미리보기·안 읽은 링크는 최소수에서 제외한다. 자동 tree 파일수는 외부 자료수로 세지 않는다. 공개 원문은 필요한 짧은 근거와 정확 위치·지문만 커밋한다.

최소는 고유 외부 1차 자료28: 실제 예제 본문8, 직접 읽고 식별한 자원 또는 예제 소스8, 발행·변경·릴리스·빌드8, EPUB 규격/새 패키지2, Python 규격/새 wheel2. 범주와 계보를 모두 공개하고 각 본표 행에서 원주소와 관측 영수증으로 이동할 수 있게 한다. 필수 자료나 핵심 비교를 확보하지 못하면 PARTIAL과 결손·재개 입력을 명시한다.

결과 SHA를 커밋한 뒤 명시적 session check와 공통 cloud_check를 실제 실행하고, UTC·종료값·대상SHA·자동 확인 세션 수를 기록한다. 공통 검사에서 manifest 검색이 생략됐으면 명시적 검사와 구별한다. GitHub 고정 결과판에서 필수표·대표 원자료/출력·재현 절차를 다시 연 뒤에만 마지막 HANDOFF를 작성한다. 자기검토와 별도 AI검토·사람 검토를 구분한다.
