## 수치·수정 교차 확인

- 주12쌍 자리 = 실제8 + 결원4. 판24자리 = 실제16 + 결원8. 실제 예측YES8과 새판U YES8을 case_id로 결합했다.
- 실제 음성0의 FPR/특이도와 양성2의 FNR0/2를 구별했다. 결원을 실제 음성·유보 분모에 넣지 않았다.
- 최종 신규111개 = 본문46 + payload45 + 발행/변경/규칙15 + EPUB2 + wheel3. 근거477행과 고유111개는 다른 수다.
- [source-reconciliation.json](evidence/source-reconciliation.json)은 GG 계승 규칙5개(동일 SHA2개 포함)의 정확 대응과 잠정116→검토111을 보존한다.
- 경로 존재·바이트 일치·HTTP 성공·설정·빈 CI 결과를 각각 좁은 주장에만 사용했다. copy 규칙을 실제 복사로, 실행 가능성을 실제 실행으로 바꾸지 않았다.
- 정확 결과 SHA에서의 계약·공통 검사와 GitHub 재열람은 결과 커밋 후 실제 실행 영수증으로 남긴다. 이 자기 점검 문서는 실행 영수증을 대신하지 않는다.
