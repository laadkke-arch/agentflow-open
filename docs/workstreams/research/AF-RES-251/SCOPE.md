## 제품 출력 전 신호 판정

- `fixtures/generate.py`에서 A, B, 두 입력의 정확한 정수 합 `AB-calibration.wav`, 전부 0인 `Silence.wav`를 만들고 `inputs.json`에 WAV·PCM SHA-256을 고정한다. 합과 무음은 분석기 교정 입력에 사용한다. GUI 기초 시험에는 A와 B를 따로 불러오고, 추가 반례에만 B 대신 무음 입력을 쓴다.
- 각 파일 로컬 매초의 0.25~0.75초, 즉 `[11025,33075)`와 `[55125,77175)`를 분석한다. 두 주파수의 사인/코사인 직교 투영 크기를 `2|Σ|/22050` LSB peak로 구한다. 0.5초는 440 Hz 220주기, 880 Hz 440주기다. [1,3)와 [2,4)는 프로젝트 [2.25,2.75) 창을, [3,5)와 [2,4)는 [3.25,3.75) 창을 공유한다. 창의 원시 두 크기와 880/440 비율을 남긴다.
- 성분 ≤8 LSB는 없음, ≥2000 LSB는 있음, 사이는 판별불가다. 전체 파형 peak ≤2 LSB이면 무음, 첫 유효 샘플은 처음 `abs(s)>100`인 0기반 프레임이다. 첫 샘플 값·근접 full-scale 개수·peak·RMS도 남긴다. 예상 샘플과 최대 절대 오차 ≤3 LSB인 입력 참조(A, B, 합, 무음)와 정수 초 시작 후보를 모두 기록한다. 440/880 절대 크기 변동이나 여러 참조 후보가 있으면 존재 판정과 경계 확정을 별도로 기술한다.
- Python 파서로부터 각 WAV의 프레임 수·PCM 해시를 산출하고 `ffprobe` time base 단위 변환 및 `ffmpeg` PCM16 원시 바이트로 맞춰 본다. 이름, 라벨 타임라인, 원음의 초별 진폭 지문, 실제 출력 프레임 수를 함께 써 경계를 정한다. 전체 WAV SHA는 헤더·태그를 포함하므로 PCM SHA와 따로 적는다.
- 반전 관측은 (a) 기본·라벨 교환에서 880 부재면 코드 예측 반전, 존재면 위쪽 제한 예측 반전, (b) 위치 이동만으로 880이 바뀌면 위치 제한 지지, (c) mute 상태인데 880이 남으면 음소거 예측 반전, (d) 라벨 교환에서 L 파일 유지/2초 외 범위/첫 참조 초 불일치면 경계 예측 반전이다.

교정 PCM [원값](receipts/calibration.json)에서 각 조건의 5개 창, 총 20개를 제품 내보내기 전에 읽었다. 비표적 성분 최대 0.026 LSB 미만, 최저 표적 성분 3,999.98 LSB, 합 PCM peak 15,636 LSB, 무음 peak 0 LSB였다. 비무음 첫 유효 프레임은 세 파일 모두 1이다.
