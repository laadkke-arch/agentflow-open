# 공개 대화 판독과 Git 대조

[현재 본문 색인](public-index.jsonl)은 본문 자체 대신 ID, 링크, 길이와 해시를 보존한다. 본문이 있는 PR 설명·이슈 대화·제출 리뷰·인라인·답글은 각각 23 (#9580), 14 (#9588), 16 (#9589), 276 (#9618), 12 (#7575), 50 (#7576), 7 (#7579), 42 (#7589)개를 읽었다. 151개 빈 제출 리뷰는 별도 식별했다. #9618의 276개 중 첫 18개 뒤인 19–276까지 시간순으로 읽었다. 선행 작업의 통합 정렬과 이번 독립 정렬은 달라질 수 있다. 19–65는 기본 해상도·float·coder, 66–128은 namespace·스칼라·과거 달력, 129–191은 변환 경계와 회귀, 192–238은 수정·후속 요청, 239–276은 타입 정의·fork 적용·배포 전 선택으로 검토했다.

[편집 영수증](edit-history.jsonl)은 PR 본문 8, timestamp 차이·선정 인라인 등 145개를 공개 HTML UI와 같이 XMLHttpRequest 헤더로 조회한 기록이다. 90개 표시 버전의 fragment를 열었다. [#9580 생성판](https://github.com/user_content_edits/UCE_lAHOAMm_X86Y9hA0zmaJjPQ)과 바로 뒤 편집은 전역 `set_options` 선택이 Decimal 제안 전에 있었고 옵션 예시 오자가 바뀌었다는 점을 확인한다. [#9618 생성판](https://github.com/user_content_edits/UCE_lAHOAMm_X86aCDxezmcp5HQ)은 자동 추론과 pandas 범위를 이미 제안했다. [11-27 전후 편집](https://github.com/user_content_edits/UCE_lAHOAMm_X86aCDxezmssVl0)에서 coder 전달 문구가 본문에 들어왔다. [#7579 생성판](https://github.com/user_content_edits/UCE_lAHOAB6-0c6Z3WAjzmcSXqQ)에 병렬 기능 링크와 8개 작업에서 약 9→6분 보고가 이미 있었다. 웹 UI가 표시하는 버전의 일부를 직접 대조했으며 삭제된 발언, 리뷰 draft의 수정 이력 및 UI 미표시 기록은 미확인이다. [원래 페이지 구획](coverage.md)이 조사의 현재 공개판을 고정한다.

[Git 객체 영수증](git-objects.jsonl)에서 8개 PR의 REST 커밋 241개를 실제 Git 객체로 확인했고 모든 커밋이 그 PR head에서 도달 가능했다. 311 인라인 원시 앵커의 original_commit_id·파일 blob을 확인했다. #7576 27개와 #7589 9개의 앵커는 최종 head의 조상 집합 밖이며 객체는 읽혔다. #9588·#7579의 fork ref 삭제 이벤트 뒤에도 PR head로 객체를 fetch했다. #7576은 head가 직접 부모인 2-parent merge. 병합된 나머지 고정 PR 5개는 head 조상이 아닌 1-parent squash로 트리 내용을 대조했다. #9580의 API merge_commit_sha는 병합이 이루어졌다는 근거로 쓰지 않았다. REST created와 리뷰 submitted 중 늦은 값을 인라인 공개 가능한 시각의 하한으로 사용한다. author/committer 시각은 객체 내부 시계다. 공개 푸시가 timestamp별로 소거된 경우 저장 시각을 단정할 수 없다.
