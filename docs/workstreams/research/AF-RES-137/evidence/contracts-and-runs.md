## 배포

[배포 색인](../releases.csv) 8행과 [archive 원장](release-artifacts.jsonl) 18행을 대조했다. PyPI sdist는 선언 SHA-256과 실제 파일을 맞췄다. GitHub v0.26.0rc0 archive의 gallery 파일은 Git tag와 PyPI v0.26.0rc1·0.26.0의 동일 파일과 SHA-256 일치. v0.26.0rc0의 PyPI 레코드는 wheel만 있다. [GitHub release 발표](https://github.com/scikit-image/scikit-image/releases/tag/v0.26.0rc0)는 2025-11-26T04:57:19Z, 첫 동일 PyPI sdist는 0.26.0rc1 2025-12-09T09:07:28Z. v0.25.2의 소스 예제는 이전판이다.

#7576과 #7579의 첫 소스 파일은 PyPI 0.25.0rc2 2024-12-10T19:47:13Z, 안정판 0.25.0. #7579 병합의 >=0.17 literal은 확인한 출시판에 없고 extra를 보존한 >=0.18이 들어갔다. #9588·#9589는 PyPI xarray 2024.10.0, #9618의 해당 타입과 완전한 coder 전달은 2025.1.2. [릴리스 노트](https://github.com/pydata/xarray/blob/d8d1d9e5f721561b22c46e371c14de44ccead922/doc/whats-new.rst#L70)는 #9618과 후속 작업을 묶어 기여자를 밝힌다. #7575는 미병합. #7699가 들어간 v0.25.2rc0 Git 태그에서 workflow를 열었고 [PyPI 0.25.2rc0](https://pypi.org/pypi/scikit-image/0.25.2rc0/json)의 첫 확인 cp313t Linux wheel은 2025-02-15T05:31:07Z다. wheel의 메타데이터는 [영수증](cp313t-wheel.json)에 있다.

## 실행

모든 입력은 [inputs.json](../replay/inputs.json)에서 고정했다. SHA-256 `85178890410f13165ad1b29bd6e159673243c4c67330bbd24447f533c158183e`. 4회 실행 종료값 모두 0. Linux x86_64와 Python 3.12.14, NumPy 1.26.4. 고정 venv 패키지 버전은 이 폴더의 *-requirements.txt에 있다. 실험 코드는 [experiments.py](../replay/experiments.py). 본 작업 초기 Matplotlib은 캐시 디렉터리 경고와 임시 경로를 출력했다. 최종 재실행은 `MPLCONFIGDIR=/tmp/af137-data/mpl-cache`에서 수행했다.

릴리스 archive는 `python -B replay/archives.py /tmp/af137-source > /tmp/af137-release-artifacts.jsonl`에서 복구할 수 있다. `--gallery`에는 이 경로의 `scikit-image/0.26.0rc1/doc__examples__filters__plot_deconvolution.py`를 넣는다. 파일 SHA-256은 `3892698be96bda587a63a00f8f4f3c080c652c376bc74712d7a529a38aa2c921`. 전체 예제는 시드를 지정하지 않는다. 같은 실행에서 draw가 끝난 배열을 반복 사용해 복원 경로를 검증했다. 독립 실행의 원본 출력 합계는 비교 대상에서 제외하고 형태·범위를 확인했다. 소형 고정 입력 실험은 공개 예제의 AST에서 최대값 정규화와 호출문을 골라 clip을 설정했다. 비교별 이미지·PSF·반복 수를 같게 했다. 소형 값은 연구자가 구성한 post-noise 입력이고, 리뷰어의 어두운 화면 보고는 별도다. 사용자 실측·빌드 재현·작성자 노동 측정은 미실시다.
