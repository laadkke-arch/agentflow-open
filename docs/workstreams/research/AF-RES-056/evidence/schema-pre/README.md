# Schema 사전 입력 원장

40개 메타데이터와69개 개정 레코드에서 최초40본문을 직접 읽었다. 전문은 공개 저장하지 않는다. revision-fetch-receipt.json의 정확 공식API URL과 revision-audit.json의 GUID/hash로 원문을 재조회할 수 있다. build_pre.py는 최초 API본문을 임시 revisions-p1.json으로 받은 경우 원장을 생성하는 기록용 스크립트다. root assemble_inputs.py는 제출된 compact 원장만 사용한다.

표본선정 및 단어대응 전에 후보 목적지/순위는 읽지 않았다. 단 최초 진단에서 비선정28번 후속rev3 일부가 노출되었음을 SCOPE와 sources에 기록했다.
