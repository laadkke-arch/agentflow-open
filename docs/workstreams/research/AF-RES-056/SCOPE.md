## L/V와 검색 범위

동일 판의 동일 게시 필드만 사용한다. 필드는 제목, 편집자가 명시한 별칭, 기능 설명, 기능 분류 표제이다. 언어/소속 범주 표제는 기능 주장으로 취급하지 않는다. 어떤 필드가 실제로 존재하는지는 목록 소스·화면에서 따로 고정한다. 목적지에서 발견한 기능·시험 결과를 목록으로 역기입하지 않는다.

원문에서 작동을 말하는 최소 독립 기능구를 vocabulary.csv에 원문·정규화·조건ID와 함께 고정한다. L 정규화는 casefold, 연속 공백 축약, 하이픈을 공백으로 바꾸기뿐이다. 어간추출·단복수·동사명사 변화·번역·제품명 교정은 없다. 게시 문자열 안의 단어 경계를 갖는 연속 기능구 일치가 retrieval hit이며 어떤 구가 어떤 필드와 맞았는지 보존한다. 여러 기능구는 OR 후보 생성에 사용하되 조건1·2의 충족 판정은 AND다. 검색 매치를 두 조건 만족으로 간주하지 않는다.

V는 L을 포함하고, 표준 정의/공식 입출력에 근거한 동일 의미·정의적 기능명만 추가한다. 상하위/관련/반대/모호 관계는 보류한다. 방향·부정·초안·언어 제약을 제거하여 넓은 기능명으로 바꾸지 않는다. 해당 기능구의 일부를 넓은 `validation` 또는 `transformation`으로 바꾸는 행은 같은 의미라는 근거 없이는 허용하지 않는다. 후보 조회 이후 추가한 단어는 주표를 바꾸지 않는 사후 진단이다.
