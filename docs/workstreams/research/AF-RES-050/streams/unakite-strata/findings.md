## 판정

**확인:** 두 군 모두 원 논문에서 공개 자료 또는 구체적 파일 경계까지 추적했다. Unakite에는 실제 공식 도구 소스의 이벤트 스키마가 있고, Strata에는 원 논문 제작용 차트의 외부 workbook 이름과 셀 참조가 남아 있다. 그러나 배정·시간·점수를 잇는 참가자 비식별 대장은 이 경로에서 얻지 못했다. 사람이 총 얼마를 덜 일했는지 또는 추후 재작업이 줄었는지는 계산할 수 없다. 이 판단은 자료가 세상에 없다는 선언이 아니다.

## Q1 · 개입과 배정

S05-E1은 독립군, S05-E2는 다른 참가자 코호트의 교차설계, S06-E1은 독립군이다. S05-E2에서 같은 사람의 두 관측은 **다른 과제**이므로 과제와 기간을 지우고 짝을 만들 수 없다. S06-E1에서 서로 다른 조건의 사람들을 임의로 짝지으면 안 된다. 정확한 배정 순서·군 크기를 논문 그림이나 소수점 패턴으로 역산하지 않았다. [US-01 pp.8–9; US-02 p.23; `baseline.json`, `studies.json`]

세 비교 모두 링크 자체를 통제한 측면은 있으나 링크에 붙인 설명 한 요소만 조작하지 않았다. 특히 Strata는 기존 표가 유지되어도 출처로 돌아갈 비용, 문맥 스냅샷, 검색 이력, 신뢰 신호, 새 대안 후보가 함께 달라진다. 과제 중 실제 원페이지 열람·채택은 참가자 선택이므로 노출량별 비교는 별도 교란을 갖는다. S05-E1의 훈련은 비교 전에 실험군만 받았으며 대조군은 공통과제 뒤에 받았다. [US-02 §5.4.2 pp.21–22 및 §6.1]

## Q2 · 실제 파일/키 경계

Unakite 공식 설명서의 dashboard 링크를 따라 공개 HTML→bundle→source map을 읽었다. 932개 번들 파일 중 `task_functions.js`는 task별 `instrumentV1Data`, `instrument_v1_functions.js`는 `eventAuthorId`, `taskId`, `timestamp`, 일부 이벤트의 `pieceId`, `tableId`, `url`을 정의한다. 소스맵 한 패키지를 독립 도구 구현1건으로 센다. 단, 공개 구현 코드가 실제 참가자 데이터는 아니며 연구2019판과 동일하다는 release 연결도 없다. 계정·데이터베이스·실제 task URL은 열지 않았다. [US-12; `reproduced-unakite.json`]

Strata arXiv v2 source tar의 `assets/images/ppt/charts/chart1.xml`에는 Unakite/Strata×Python/Deep/Cloud의 recall 평균6개가 있다. `main.tex`의 표6그룹과 `(condition,task)`로 1:1 연결했다. 6키 모두 유일하며 결측/중복/미연결은 **관측0**이다. 이는 개인 관측이 아니라 발표용 집계의 계보 확인이다. 원 XML의 관계 파일은 `CSCW 2020 Participants Tracking.xlsx`를 외부 참조하며 값 셀은 `together!G54:I55`, 범주 `G53:I53`, 오차 `G56:I57`이다. tar 안 CSV/TSV/XLS/XLSX/R/Python 파일은 **관측0**이다. 저자 컴퓨터의 개인 경로는 보존하지 않고 필요한 파일명만 남겼다. [US-11; `audit-arxiv-source.json`, `aggregate-join-audit.json`]

## Q3 · 시간의 의미

S05-E1의 도구 상호작용 분율은 작업 전 과정의 활성 노동이 아니다. 대조군 정의에는 Docs 탭 체류도 포함되어 생각·열람을 분리하지 못한다. S05-E2의 종점은 코드 제출이 아니라 세 번째 정당한 설명이다. S06-E1도 상황 적합성을 평가한 설명 작성 시간이며 실제 소프트웨어 수정 완료 시간이 아니다. 원점·pause·대기·지연 계측 규칙은 미확인이다. [US-01 pp.8–9; US-02 pp.23–25]

US-12 정적 소스에는 `tasks_timer`의 `startTimestamp`/`endTimestamp` 함수가 있지만 이 배포본의 비정의 소스에서 호출 참조가 발견되지 않았다. 입력 `time`의 단위도 해당 함수에서 명시되지 않는다. 다른 이벤트의 Firestore server timestamp나 브라우저 focus/sidebar 경계는 실제 활동·인지적 열람·업무 전체의 노동을 뜻하지 않는다. Strata 본문 §5.4.1의 웹 체류와 scroll-visible 비율 또한 작성자 탐색의 출처 신호이며 소비자 실험 시간 원행과 동일하지 않다.

## Q4–Q5 · 채점과 계산 가능성

S05-E2의 공통 문턱3개는 제한된 과제에서 유용한 품질 통제다. 그러나 실제 gold 목록과 이유별 판정은 열지 못했으므로 동일 기준 적용을 독립 검증하거나 더 높은 수준의 품질 동등성을 선언하지 않는다. S06은 사전 gold와 대조한 고품질 이유와 사후 조건 가림 유효성 판정을 구분한다. 전원600초 내 완료했다는 진술을 전원 정답이라는 값으로 바꾸지 않는다. 무효 이유가 표에서 생략되었다는 진술은 무효 이유가0이었다는 진술이 아니다. [US-01 p.9; US-02 pp.24–25]

새 개인 추정치는 **미산출**이다. `joins.json`은 참가자 row count를 미확인으로 남기고, 방법으로부터 기대되는 대상시행40/32/60만 분리한다. 기존034에 있었던 요약 숫자는 저자 집계·배경으로 표시하며 다시 계산한 결과를 새 핵심 성과로 세지 않는다. 새로운 실행은 정적 소스 판독과 발표용 aggregate join뿐이다. 정확한 행 대장이 생기면 독립군은 군별 분포, 교차는 사람 cluster와 과제/기간을 보존하여 재개한다.

## Q6 · 자기 결론에 대한 반대 점검

시간 이득의 역전, 더 오래 걸린 정답, 설명을 읽고 거부한 **실제 참가자 행**은 미확인이다. 살핀 자료는 논문의 시간/품질 집계, 완료 진술, 질적 사례, 구현의 highlight/save/evidence/focus 이벤트, Strata 차트 캐시다. 행을 못 찾았다는 이유로 반례가0이라고 쓰지 않는다.

질적 반대 근거는 있다. Unakite에서는 자료를 수집해 저장소에 넣고 즉시 비교표에 쓰지 않는 사용 패턴이 관찰되었으며, 긍정 표시가 많다고 더 좋은 대안은 아니라는 사용자 지적이 있다. 자체 사례 ID `US-QC-01`은 이 의미상 차이를 가리키며 원 참가자 가명을 복제하지 않는다. 정적 이벤트에도 저장하지 않은 highlight와 저장·표 삽입이 구분되지만 실제 빈도는 없다. [US-01 p.10 Evaluation Discussion/Usage Patterns; US-12]

첫 결론을 무조건 긍정하지 않도록 품질 표도 원 제작 자료까지 대조했다. Strata Python/Strata precision은 Table2/TeX90.1%와 Figure7/SVG91.0%가 다르다. Deep/Strata는 gold11, 고품질 평균6.90, recall64.5%의 관계가 표 정의와 맞지 않는다. source 차트 캐시는64.5%를 재현하므로 캐시를 열었다고 문제가 해결되지는 않는다. 어느 값을 임의로 고치지 않았다. [O-US-05]

## Q7 · 설계자에게 옮길 수 있는 범위

**조건부 제안:** 자료의 출처와 비교 이유를 함께 보존하면 후속 독자가 특정 평가 과제에 도달하는 시간을 줄일 가능성을 시험할 수 있다. 이 제안은 독창성·기능 충족·전이·재작업 절감을 보장하지 않는다. 설계자는 자료 선택 후 채택/구현/검증/재수정의 흐름, 참가자는 훈련·읽기·중단을 포함한 실제 시간, 채점자는 독립 루브릭과 실패를 포함한 전체 배정 분모를 필요로 한다.

Unakite의 자가선택 과제 중 한 사례에는 일주일 뒤 도구 채택을 확인한 질적 후속 인터뷰가 있다(`US-QC-02`, US-01 p.9). 이는 동일 명세의 대조군·노동·수정 기록이 없으므로 재작업 절감이 아니다. 이 사실 때문에 추적이 전혀 없었다고 일반화하지도 않는다. Strata에는 지연 재작업을 측정한 관측이 확인되지 않았다. 분야 대조군의 판정은 root 담당 자료와 합쳐야 하며 이 두 군으로 대체하지 않는다.

## 직접 열람 수·재현·재개

`source-counts.json`: 직접 열람 성공 원장12행 중 중복/메타데이터를 제외한 실질적인 독립 1차 저작은5건(원논문2, 공식 설명서1, 정책1, 공식 구현1)이다. 엄격 배당은 원논문2+도구 구현1=**3건**이며 별도 부록/복제자료는0건이다. 공식 설명서·정책은 엄격 과제/루브릭/구현 배당에 억지로 합치지 않았다. 학위논문은 이 연구 관련 부분이 원 논문 재수록이므로 배당0, TeX·차트·PDF도 한 논문으로 묶는다. 실패9행은 직접 열람 수에서 제외했다.

다음 두 읽기 전용 명령은 실제 실행하여 각각 종료코드0을 얻었다. 출력과 SHA는 `reproduced-strata.json`, `reproduced-unakite.json`에 있다. 외부 자료는 메모리에서 읽고 연구 원자료·개인 식별정보를 복사하지 않았다.

```bash
python -B docs/workstreams/research/AF-RES-050/streams/unakite-strata/inspect_public_artifacts.py strata
python -B docs/workstreams/research/AF-RES-050/streams/unakite-strata/inspect_public_artifacts.py unakite
```

다음 첫 행동은 **공개된 비식별 workbook/export가 존재하는지 그 정확한 파일명을 기준으로 다시 확인**하는 것이다. Strata는 해당 workbook의 배정·과제·순서·시간·이유별 채점 열과 gold 목록, Unakite는 실험별32/40시행의 비식별 배정·영상코딩·설명 채점 내보내기가 최소 입력이다. 해당 파일 없이 조인 명령을 실행하지 않는다. 공개되지 않은 데이터베이스를 읽는 방식은 사용하지 않는다.
