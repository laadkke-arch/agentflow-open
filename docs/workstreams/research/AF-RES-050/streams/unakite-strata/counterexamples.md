## 민감도별 실행 가능성

| 축 | 현재 가능한 것 | 실행하지 못하는 것과 이유 |
| --- | --- | --- |
| 실패 포함/성공자만 | 논문의 전원 완료 진술과 이유 무효 판정 분리 | 실패의 운영 정의·reason별 mask 없어서 재계산 불가 |
| 부분/전체시간 | 분율, 설명 문턱, 적합성 평가를 별 종점으로 분류 | 전체 업무 시간과 원단위 active labor 미계측/미공개 |
| 초보/숙련 | 모집 집단 평균경력과 전문경력 인원 기록 | 경력변수와 조건·시간·점수 행 연결 없음 |
| 도구 소개 포함/제외 | 튜토리얼 구조·시점 확인 | 훈련을 포함한 개인 총시간 원행 없음 |
| 같은 링크/다른 후보 | 기본 링크 통제와 새 대안/문맥 기능 차이 식별 | 실제 열람·채택 노출량 및 구성요소 분리 배정 없음 |

통계적으로 양성 결과를 억지로 반전시키려는 재분석을 하지 않았다. 현재 경계는 공개 자료가 허용하는 주장과 허용하지 않는 주장을 나누는 것이다. 실제 반례 관측이 없는 항목은 **미확인**이며 **관측0**으로 치환하지 않았다.
