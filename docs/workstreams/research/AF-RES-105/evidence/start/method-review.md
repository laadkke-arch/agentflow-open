# 별도 방법 검토 — 최초 선정 봉인 전

별도 모델 분담자 `contract_prior_audit`가 AGENTS/운영계약/선행 고정 자료와 SCOPE·research_io를 읽었다. 새 사건 본문·답·후속은 읽지 않았으며 최초판 캐시의 키·번호·GUID·시각 메타데이터만 검사했다. 사람이 검토한 결과나 인지 결과의 독립 맹검이 아니다.

1. 80번째 시각 경계 확인 누락을 발견했다. ±1초 또는 다음 페이지의 마스킹된 ID/시각으로 보완한다. fromdate=todate의 빈 응답은 알려진 마지막 항목도 빠져 있으므로 '동률없음' 증거에서 제외한다.
2. 사전과 엔진 질의의 불일치 세 구문을 모두 질의에 추가했다. 엔진·응답·페이지 경계, 후보 풀 완료 후 정렬, 중복 사건 할당 순서를 SCOPE에 명시했다.
3. 인지 분모의 진입·부분지식·충돌/미확인 규칙을 추가했다. 보조 진술의 지시 대상이 첫 스레드 제안과 다르면 두 대상을 분리한다.
4. 답 수정에서 나중에 추가된 조작을 생성시각으로 소급하지 않는 규칙을 추가했다. 최초판 투영의 중복 GUID 방어도 추가했다.

검토한 현재 최초판 구조: 각 사이트80개 post·80개 revision1, body/title/tags 누락0, 중복revision1=0. 프레임 키는 creation_date/link/owner/question_id/tags/title만 있어 채택·점수·답변수가 출력되지 않았다. 초기 본문 적격 판정은 각 사이트의 별도 최초판 판독자가 한다.

필수 자료 계산은 요청8 + 공식문서/구현8 + 상류예제4 + Calc/Audacity 각2(합4)=24다. 같은 사건의 댓글·수정·답을 추가 독립 사건이나 자료로 부풀리지 않는다. 전체 원문은 공개 URL로 다시 읽고, 커밋에는 위치·지문·판독·짧은 발췌와 제한을 남긴다.
