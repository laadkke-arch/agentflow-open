## 실제 범위

네 고정 사례에서 first proposal부터 180일 이내의 공개 작성자 사건을 owner.user_id로 매칭했다. question revision은 user.user_id를 사용했다. 검증된 댓글 네 개, 질문 revision 한 개, 자기 답변 영 개다. 댓글 요청은 두 배치에서 각각 100+94, 51개를 받았고 마지막 has_more는 false였다. 질문 수정 응답은 100+100+22개, 마지막 has_more=false다. Stage 3 Stack Exchange 추가 호출은 영 회다.

QG-T1은 작성자 공개 user_id가 없어 동일인 범위 자체가 미확인이다. 매칭 사건과 수정 메타데이터가 비어 있어도 확인된 무후속으로 해석하지 않는다. 익명/삭제 사용자 이름을 동일인 증거로 쓰지 않는다. QG-T2/QG-T3/QG-T4는 해당 공개 ID가 일치하는 발언만 작성자 후속으로 기록했다. 댓글 수정 이력은 없어 본문이 생성 당시와 동일한지는 미확인이다.

## 지시 대상과 시간

QG-T2의 두 댓글은 후속 답473595에 달린 것으로, 최초 반복 라벨 댓글의 실패 보고가 아니다. revision 2는 원 텍스트를 유지하고 VTPEH 이미지를 붙였다. 이미지를 직접 읽어 Geometry Generator, Point/MultiPoint, Map Units, interval=50, direction=0을 확인했다. 원 텍스트 no=20과 다른 나중 화면이며 초기판에 소급하지 않는다. 이후 답변의 공식 문서 링크는 보존하되 새로 열지 않았다.

QG-T3의 댓글은 후속 답473601에 달렸지만 최초 she_weeds 링크 예제가 상황을 잘 보여 준다고 명시한다. 이 말은 조건을 실행했다거나 배웠다는 진술이 아니다. 후속 답의 bh6KA 그림은 추가로 열지 않았으므로 내용은 미확인이다. QG-T4의 말은 감사뿐이다. 네 사례 모두 전체 첫 제안의 신규인지와 동일인 실행 결합 판정은 미확인이고 판정가능 분모는 영, 비율은 산출 불가다.

공식 구현(D2), 다른 합성 입력의 현재 QGIS 실행(D3), 원 작성자 발언/첨부(D1)는 분리했다. 본 follow-up의 자료는 모두 기존 요청 에피소드에 속하므로 최소 고유1차자료 수를 추가하지 않는다. 실제로 읽은 부모 답변도 기록했으며 시간순 첫 제안을 바꾸지 않았다.
