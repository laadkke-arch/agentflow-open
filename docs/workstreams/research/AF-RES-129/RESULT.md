## Q3 양시점의 가용성
공급 구현 및 공식 문서의 정확한 판: [3.10 pairwise](https://github.com/python/cpython/blob/v3.10.0/Doc/library/itertools.rst#L479), [3.12 batched](https://github.com/python/cpython/blob/v3.12.0/Doc/library/itertools.rst#L167), [3.13 strict](https://github.com/python/cpython/blob/v3.13.0/Doc/library/itertools.rst#L165); C 구현/test도 같은 tag에서 열었다. 안정판 날짜 [3.10 2021-10-04](https://www.python.org/downloads/release/python-3100/), [3.12 2023-10-02](https://www.python.org/downloads/release/python-3120/), [3.13 2024-10-07](https://www.python.org/downloads/release/python-3130/). 공급 최초 구현 commit 시각은 아직 미확인(최초 stable tag 상한과 consumer 당시 pre-release 인용만). 3.13 What's New strict 항목 확인; 3.10/3.12 What's New 해당 항목 정확한 위치 미확보. MI local pairwise ≤2020-10-30, #497 2021-01-31, 8.7.0 2021-02-08, 3.10 stable 2021-10-04. pyproject와 실제 PyPI published requires가 다를 수 있음: batched integration parent/commit >=3.7, [10.0.0 published >=3.8](https://pypi.org/project/more-itertools/10.0.0/). CI alpha 존재가 실제 안정 가용은 아니다. MI batched fixed recipe 2022-10-08, 9.0 2022-10-18, integration 2023-07-17, 10.0 2023-07-24, supplier stable 2023-10-02. strict 2024-01-02 → 10.2 2024-01-08 → stable 3.13 2024-10-07.
