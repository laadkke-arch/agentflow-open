To convert all values of an array, you need to map its elements:

.DailyForecasts | map(.Day.RainProbability)

map(f) is equivalent to [.[]|f], so the above can be rewritten to the equivalent:

[.DailyForecasts.[].Day.RainProbability]

Output:

[
  2,
  1,
  7,
  6,
  9
]

Similarly for your second query:

.DailyForecasts | map(.AirAndPollen[1].Value)

or

[.DailyForecasts.[].AirAndPollen[1].Value]

Output:

[
  12,
  12,
  13,
  29,
  69
]

Note that your code is very sensitive to the order of the elements in the array. It looks like you are interested in the "Grass" value (the second element in the array, .[1]), so I would suggest to filter for this element specifically:

.DailyForecasts
| map(.AirAndPollen.[] | select(.Name=="Grass").Value)
