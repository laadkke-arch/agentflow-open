# R0 사전 판독 봉인

두 목록 각30건을 최초 공개 본문으로 읽고 적격60, 선정8, R0후보32행을 작성했다. R1 본문과 답·채택·댓글을 의미 판독하지 않았다. 원 API의 후속 본문은 수집기가 함께 저장했지만 모델에게 출력하지 않았으며, `sealed/*.json.gz`는 접근통제된 저장소가 아닌 연구상 노출분리 표시다.

`r0_packet.json.gz`는 API HTML과 메타데이터만으로 만든 R0패킷이다. gzip은 저장 압축이며 원본 SHA는 `snapshot_archives.json`의 uncompressed 값으로 검사한다. 생성시각 동률은 양태그30번째/31번째 사이에 없었다. 이력 jq72행·Pandoc57행 모두 page1 has_more=false였다.

R0 판정은 root가 선정8건과 Pandoc30건을 읽고 작성했다. 문서 담당 보조자는 R0 jq30건의 적격·선정과 16후보를 검토했다. 독립 이중맹검이나 전체 독립 재현이 아니다. 보조자 제안과 root의 경계 분류 차이는 JN1/group_by와 JE2/sort_by 두 행으로, root는 문서의 출력 배열 구조가 요청 출력과 다르다는 직접 근거로 `명시 반박`을 채택했다. 범위 밖 대체 분류에서도 두 행은 후보 단독 정답이 아니므로 긍정/변경 결론은 유지된다. JN2는 파싱과 version 추출이 하나의 목적이므로 독립 C2를 만들지 않았다. 이 결정들은 R1/답 노출 전이다.

원문 시점 메타데이터와 read timestamp를 구별한다. 원 질문의 현재 title은 API 수집물에 있지만 R0 독해에는 출력하지 않았다. R0 안의 map/select, JSONLoader, 기존 답 링크, code-fold 같은 단서는 sources/frame/requirements에 노출로 기록했다. 다른 링크를 열어 답을 미리 보지 않았다.

판정은 고정 참조 문서에 대한 논리적 적합성이다. 이 묶음에서 jq/Pandoc 실행은 없었고, 사용자 환경의 성공이나 현재 채택을 사전 판정으로 삼지 않았다. 사전 분모는8자리·32R0행·후속32쌍을 유지한다.
