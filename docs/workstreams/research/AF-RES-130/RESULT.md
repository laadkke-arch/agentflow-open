## Q1 접근 장애 및 반증

- 64개 /t/topic/{id} 주소 중 6027만 열렸다. 나머지 63개는 웹 도구가 접근 불가를 반환했다. 6001은 /t/6001, /t/6001.json, /t/-/6001도 실패했다. 컨테이너 curl은 discuss.pytorch.kr DNS 해석 실패(HTTP 000). 6027 성공은 전체 호스트가 폐쇄됐다는 주장의 반례다. slug가 다르거나 색인·웹 도구 제한일 수 있다. 실제 HTTP status와 ID 존재 여부는 미확인.
- 네 /search.json?q= 질의가 모두 실패했다. /search?q=가중치 및 /search?expanded=true&q=복사본도 실패했다. 검색엔진 도메인 검색에는 126의 3885·4588 및 답글 발췌가 섞였다. 사이트 자체 반환 순서나 원저자 표면 근거를 대체하지 못하므로 버렸다. 외부 검색 조각만 보았으며 이들 답글을 새 적격 원문으로 판독하지 않았다.
- 모집 A와 B의 분모를 섞지 않았다. 정확한 초 단위 UTC는 도구 결과에 없었으므로 원장은 2026-11-24 UTC 날짜만 표시. 원문/검색 순위 가림과 두 별도 커밋은 새 원문 확보 이후 시행해야 한다.
