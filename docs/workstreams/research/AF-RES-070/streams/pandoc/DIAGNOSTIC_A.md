# Pandoc 진단 A 사전 봉인

주 표본 세 자리는 보존하고, 정해진 다음 큐 9–16을 순서대로 읽었다. 8개 전부 최초 본문을 GH Archive에서 복구했다. 최초와 현재가 다른 #7045·#7094·#7101은 편집 정보 노출을 보존했다. 특히 #7101의 현재 글에만 시험·버전 본문이 크게 추가됐으므로 그것을 최초 값으로 사용하지 않는다.

댓글이 아직 가려진 진단 3개는 초기 큐 #7057(ICML 완전 문서 목적이 이미 A에 있음), #7039(이미지 파일 추출과 출력 참조가 별개이며 class 보존 금지조건은 미확인), 다음 큐 #7113(EPUB에 대한 -f/-t 실제 방향이 불명)이다. 각 후보·선택 필드·당시판·예상 권고·예산은 `diagnostic-pre.json`에 고정한다. 주 사례와 같은 세부 동작·선택 필드를 공유하는 엄격한 짝이라고 주장하지 않는다. 다른 보존 조건과 무응답·동일 판정 가능성을 찾는 진단층으로만 쓴다.

새 댓글을 보기 전에 ROOT의 별도 원격 봉인 완료 신호를 기다린다. 초기 주 표본의 A와 후속 선정 결과는 수정하지 않는다.
