# Pandoc 진단 B와 실제 짝의 한계

C03 `39eec0e2cff033c9d34b55ae20e52880378ac4ef` 봉인 뒤 2026-11-23 08:53:24 UTC에 #7057·#7039·#7113 댓글 2·8·4개를 처음 읽었다. raw REST의 UTC·numeric actor ID와 총 댓글 수를 대조했다. 선택한 필드에 대한 새 OP 값은 세 사례 모두 없었다. 따라서 새 A/B 개선·동일·악화는 관측 불가다.

## 다른 필드의 반례는 실제로 있었다

[#7113의 OP 후속786070320](https://github.com/jgm/pandoc/issues/7113#issuecomment-786070320)은 wrapping div만 제거했을 때 p가 HTML로 처리된다고 보고했다. 이후 [유지보수자786089685](https://github.com/jgm/pandoc/issues/7113#issuecomment-786089685)는 앞서 출력을 자세히 보지 않았음을 인정하고 native_divs와 markdown_in_html_blocks의 상호작용으로 설명을 고쳤다. 이것은 후속 정보가 설명을 바꾼 실제 공개 사건이다. 그러나 봉인한 한 필드는 실제 epub 옵션의 -f/-t 방향이므로 이 다른 필드를 B로 소급 투입하지 않았다. 두 설정의 OP 보고는 원문 시험이며 연구자 실행이 아니다. 유지보수자의 후속 AST와 권고도 고정 A/B 판별 절에 추가하지 않았다.

#7113의 A에 -f라는 문자열이 있기는 하다. 다만 제시된 명령과 실제/기대 출력이 서로 맞지 않아 확인 질문이 단순 중복인지 독립적으로 판정하지 못했다. 이를 임의의 오탐 1건으로 만들거나, 유용한 질문 1건으로 확정하지 않았다.

[#7039 유지보수자762396233](https://github.com/jgm/pandoc/issues/7039#issuecomment-762396233)는 class 유무의 두 native 입력과 출력을 실제로 제시했다. [762401036](https://github.com/jgm/pandoc/issues/7039#issuecomment-762401036)·[762402353](https://github.com/jgm/pandoc/issues/7039#issuecomment-762402353)은 transformInlines/flatten에서 내용이 사라지는 원시험을 남긴다. 이 작성자는 원 질문자가 아니므로 OP의 class 유지 필요성이라는 B로 사용할 수 없다. [원 질문자762690474](https://github.com/jgm/pandoc/issues/7039#issuecomment-762690474)의 감사는 수정판의 명령·결과를 제공하지 않는다.

[#7057 유지보수자769171719](https://github.com/jgm/pandoc/issues/7057#issuecomment-769171719)는 standalone 플래그를 안내했다. [원 질문자769182359](https://github.com/jgm/pandoc/issues/7057#issuecomment-769182359)는 감사와 과거 안내문을 읽었다는 기억을 남겼다. 완전 문서 목적은 A에 이미 있었고, 이 발언은 새로운 목적 값이나 실제 출력이 아니다. 두 댓글은 작성 뒤 수정되었으므로 현재 공개판만 확인했음을 기록했다.

## 정해진 큐에서 실제 짝을 찾은 결과

주 표본과 진단 6개 모두 선택한 B 값이 없다. 따라서 실제 B가 있는 쪽과 무응답 쪽의 엄격 일치짝은 0개이며, 정보 추가 무효와 개선을 비교할 짝도 0개다. 이 0은 그런 효과가 없다는 뜻이 아니라 정해진 표본에서 비교 가능한 쌍을 구성하지 못했다는 뜻이다.

- #7013–#7113은 모두 EPUB 출력을 다루지만 리소스 수집과 HTML 파싱으로 동작이 다르고 양쪽 B가 비었다.
- #7039–#7057은 보존이라는 넓은 목적을 공유하지만 RST 이미지 참조와 ICML 문서 포장으로 동작이 다르다.
- #7006–#7057은 선택 조건이 이미 A에 있어 질문 생략을 설명하는 예지만 같은 동작의 응답 대비는 아니다.

각 후보와 탈락 이유는 `diagnostic-pairs.json`에 있다. 강제 질문 정책의 효과·비용, 실제 사용자에게 이 질문을 했을 때의 응답은 미측정이다.
