# 원장 읽기와 판정 경계

## 주 키와 계층

`issue_id`는 기존 조사자의 ID를 그대로 유지한다. RCL- / RG- / pandoc- / jq- 접두는 같은 열에서 공존하며, 저장소·이슈 번호로 검증한다. `ENROLLMENT.csv`는 64개 접근 이슈, `CASES.json`은 주12+진단12의 상세 판독, `VIEWS.csv`는 그24건의 A/B48행이다. `EVENTS.csv`에는 최초글24행과 댓글103행이 있다. `PINS.csv`는 후보별 공식판 절66개 연결이며, 같은 문서·절을 여러 후보가 공유한 연결 수를 원저작 수로 세지 않는다.

`OUTCOMES.csv`의 `row_type=case` 24행만 표3 슬롯 분모다. 반사실, 최초글에 이미 있던 비교, 다른 필드의 실제 비교, 다른 사람이 실행한 비교는 별도 행이고 `slot_denominator=false`다. 사건 링크에는 event_id, 문서 근거 링크에는 source_id를 쓴다.

주 슬롯은 각 저장소의 교대 큐에서 최초글의 부분 동작·목적이 식별되는 첫3개다. 후대 본문을 먼저 본 사실, 문서 예산 이탈, 후속 응답 유무를 이유로 슬롯을 교체하지 않았다. 초기32행 중 적격31, 단순 충돌 재현 jq2276은 탈락 보존했다. 다음32행은 진단 모집이며 주 슬롯 대체가 아니다.

## 원저작과 최초판은 서로 다른 수

원저작 최소량에 산입되는87개는 원 이슈63개와 공식 문서·코드·원시험24개다. 같은 이슈의 댓글·GH Archive 사본·다른 매뉴얼판은 재산입하지 않는다. 접근한 이슈64개 중 jq2329는 긴 빌드 로그의 일부만 읽었으므로 최소량에서 제외했다.

최초 본문 복구는56/64개다. ripgrep의 확장 큐9–16은 현재 본문만 읽었고 최초판을 복구하지 못했다. 이8행은 시간순 최초판 분석에서 제외한다. 주12와 선정 진단12는 모두 opening event의 최초판을 복구했다. `initial_body_verified`는 최초판 복구 여부이며, 본문 주장의 독립적인 사실 검증이나 실행 성공을 뜻하지 않는다.

공개 원장은 최소 발췌·원위치·SHA256·opening event ID/JSONL 위치를 보존한다. 분석 중 받은 완전한 원문은 비공개 임시 캐시에 있었으나 커밋 산출물이 아니다. 재개자는 아래 원출처 복구 명령으로 같은 본문을 얻어 해시를 대조해야 한다. GitHub 현재 이슈 링크만 열어 최초 글과 같다고 가정하면 안 된다. jq의 과거 repo 이름은 stedolan/jq이고 현재 이름은 jqlang/jq이며 stable repo ID는5101141이다.

## A/B와 노출 상태

주 A 및 ripgrep 진단 A는 C02 `a6e2f47e6cfa52e249f4d648016cf9d324eccae9`, 나머지 진단 A는 C03 `39eec0e2cff033c9d34b55ae20e52880378ac4ef`에 봉인됐다. `cutoff_A_utc`는 해당 보기의 자료 종료 시각, `first_comment_read_utc`는 봉인 후 댓글을 연 시각이다. pandoc7003의 이미 노출된 댓글 두 구절과 후대 본문·제목 노출은 예외를 숨기지 않고 재구성층으로 남겼다.

원 stream의 `preread`라는 이름은 의미가 일치하지 않는다. 일부는 가림 유지 여부, rclone 진단은 사전노출 여부로 사용했다. 통합 원장은 이 Boolean을 그대로 합산하지 않고 `clean_packet`과 `layer`로 명시적으로 정규화했다. 후대 문맥 비노출과 실제 지정절 예산을 함께 충족한 packet은 주12 중2, 진단12 중5다. `strict_budget_compliant`는 실제 사전 열람에 대한 판단이며, `PINS.packet_budget_valid`의 후보당 문서2개·문서당 지정절1개라는 설계 예산과 별개다. rclone 주3, ripgrep6, pandoc7013, jq2267은 추가 사전 열람을 표시했다. rclone4914도 후대 문서링크 선노출을 확인해 재구성층으로 낮췄다. 여기의 예산 준수는 기록된 대상절 판독에 한정하며 분석자의 모든 사전 지식을 통제했다는 뜻이 아니다.

`B_value`는 사전에 고른 한 필드에 해당하는 같은 작성자의 값만 담는다. 값이 없거나 특정 시점에 연결되지 않는 다중 상태 발화이면 빈 값과 `data_absent`/`data_ambiguous`로 남긴다. 다른 사람의 추정, 다른 질문에 대한 대답, 사용자가 적용해서 바뀐 설정, 인접 단계의 새로운 조건을 대신 넣지 않는다. `values_copied_into_B`는 최대1, `new_information_values`는 이미 A에 있던 값이면0이다.

`same_direction` 2건은 RG1808과 jq2349의 중복 조건에서 권고 방향이 유지됐다는 기록이다. 두 행 모두 엄격한 정답 동일로 세지 않는다. RG1840은 조건부 두 후보가 C2로 좁혀졌지만, A가 틀린 단일 선택이었다는 독립 기준이 없어 엄격 개선으로 세지 않는다.

## 분모와 미확인

표3의 분모는 SCOPE에서 봉인한 슬롯 수다. 개선+동일+악화+관측 불가가 그 분모에 합산된다. 현재 엄격한 개선·동일·악화로 분류할 수 있는 행은 없고,24행 모두 관측 불가다. 표의 각0은 해당 분류에 들어간 행의 개수이며, 개별 사례의 효과를0으로 대입한 값이 아니다. 효과를 추정할 독립 판정 가능 분모는0, 효과율은 N/A다. 실제 질문의 인과효과·질문비용·새 사람의 행동은 측정하지 않았다.

질문 오탐은 제안한8개 중 독립 판정 가능2개(PAN7013, RG1840)가 분모다. 둘 모두 공식판의 서로 다른 분기를 가르는 조건이므로 오탐 분자는0이다. 두 행 모두 실제 읽기 예산 이탈을 포함하므로0/2는 기술층 수치다. 엄격 예산 준수층의 오탐 분모는0, N/A다. 남은6개는 판정 불가로 제외한다. 이0/2를 전체8개의 오탐률로 쓰거나, 질문을 보내지 않은16건을 실제 제안 분모에 넣지 않는다.16건은 선택 조건이 최초글에 있어 생략할 수 있었다는 기술적 판독이다.

반사실1건 RCL4911-CF1은 개별 버퍼 종료와 모든 전송 종료가 같은 조건인지 미확인이다. 반사실의 유효성까지 보장하지 않으며 실제 B와 합산하지 않는다. `observed_pair`는 작성자의 보고라는 관측 수준을 함께 읽어야 한다. 완전한 원실행 출력이 없는 버전 비교나 여러 변수 동시 변경을 통제 실험으로 부르지 않는다.

## 비용과 재생성

비용은 문서 계보 수·고정판 수·기록된 지정 줄 구간 수로만 보고한다. 후보별 연결 수66은 읽기 비용이나 원저작 수가 아니다. 탐색 중 추가 노출의 모든 절을 완전하게 계량하지 못했으므로 기록된 절 수는 전체 작업 비용의 완전한 측정값이 아니다.

저장소 루트에서 실행한다. 각 스크립트는 이 owned_path만 쓴다.

```bash
python -B docs/workstreams/research/AF-RES-070/tools/build_ledgers.py
python -B docs/workstreams/research/AF-RES-070/tools/merge_sources.py
python -B docs/workstreams/research/AF-RES-070/tools/validate.py
```

최초 본문 재확인은 `tools/recover_opened.py`의 CLI 인수와 원장에 있는 repo·이슈 번호·created UTC·출력 경로를 사용한다. 공개 아카이브 접근 실패는 접근제한을 우회하지 말고 미실시로 남긴다. 생성 과정의 사적 캐시가 없어도 봉인된 stream JSON에서 통합 원장을 재생성할 수 있다. 조사된 rclone/ripgrep/pandoc/jq 자체를 실행하는 명령은 이 스크립트들에 없다.
