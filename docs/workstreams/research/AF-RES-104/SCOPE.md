# AF-RES-104 연구 범위

동일 파일의 실재 문자 수와 파일 접근 원장을 고정하고, 처음 일치 중심 연속 구간과 질의 균형을 높인 두 구간이 필수조건의 문서 근거를 얼마나 다르게 보이는지 비교한다. 원 질문자의 실행은 별도 미확인으로 둔다. 이 묶음은 제품 설계자가 반환 링크와 필요한 절을 선택하는 근거다.

- 착수 시 알려진 F/S 완결 9/14 및 0/14, 표시 문자 270,609 및 74,400, 추가 이동 102 및 0, P3-B 공석과 P1 해석 민감도를 숨길 수 없다. 배정문과 등록 인계에 집계와 지목 사례가 있었다. 원 질문 재열람은 최초 revision으로 제한한다. 선택기에는 사전 토큰·원 슬롯 및 원문 바이트만 입력한다. 판정에는 질의 점수와 이전 개별 판정·인용 위치를 제공하지 않는다.
- 새 독립 판독자는 배정되지 않았다. 한 작업자가 설정, 질문 재열람, 32개 불투명 판독, 후속 감사를 수행한다. 같은 파일과 질문을 되읽고 한/두 구간 경계를 볼 수 있으므로 눈가림은 제한적이다. 최초 판정 뒤에만 선행 세부 판정 원장을 읽는다.

## 실험의 단위

파일당 W1에서 실제로 표시된 코드포인트를 W2의 예산으로 사용한다. 두 구간을 잇는 표시는 별도이며 인용 경계는 각각 보존한다. 실제 UTF-8, 표시 위치, 인덱싱 검색량과 시간도 기록한다. 8건의 모집과 고정판을 보존하고 P3 공석은 같은 비용으로 남긴다. W1/W2와 A/B 대응은 각각 16개를 배정한다. SQLite와 CSS Grid 보조 사례는 주 대응에 산입하지 않는다.
