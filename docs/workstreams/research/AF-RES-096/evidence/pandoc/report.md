# Pandoc 모집 봉인 입력

- 2025H1 질문은 API 전체 결과31건(`has_more=false`), 생성UTC/ID 오름차순. 모집 응답에는 question_id/tags/creation_date만 있다.
- 최초 보존본문은31건에서 revision1과 생성 timestamp가 일치한다. 프로그래밍 어댑터는 리비전 응답51항목 중 각 질문의 가장 이른 body만 보존/출력하며, 나중 body는 연구자에게 노출하지 않고 폐기했다.
- 연구자가 읽은 R0는 원순번1–10. 선택은 원순번1/3/4의 경계3건과 원순번2의 대조1건에서 충족한다. 순번5–10을 읽은 것은 추가 선정 근거가 아니며11–31은 raw retrieval/metadata만 확보하고 연구자가 읽지 않았다.
- H2 확장은 불필요하여 하지 않았다. jq agent의 H1 45ID와 pandoc31ID는 tag 중복도, ID중복도 없다.
- 기존 제외ID는 `../intake/intake.json`의088/092 합집합60ID. 이번31건과 교집합0. 알고 있던 정답 ID0.
- Docker는 명령 실행 호스트이고 문서의 생산자/소비자 기능을 요청한 것이 아니므로 인접 프로젝트로 선정하지 않았다. P2의 Word는 결과 DOCX 설명이며 독립적인 소비 동작이 명시되지 않는다. P1은 Asciidoctor, P3는 R Markdown, P4는 명시적으로 호출된 diagram.lua를 인접으로 고정한다.
- 네 요청 모두 독립된 둘째 조건은 공석이다. 입력 속성이나 실패한 시도는 새 요구로 만들지 않는다. `selected.json`에 C1과 접합부/입력 문맥을 따로 기록했다.
- 답·댓글·채택·점수는 미열람. 도구문서·구현·시험은 이 하위과제에서 열지 않았다. 검색토큰은 최초 본문/명령의 행동·대상·입출력 표현만 사용한 제안이며 최종 protocol은 루트가 봉인한다.
- 원문 통복제는 공개 산출물에 포함하지 않는다. `_cache/`는 이 폴더의 `.gitignore`로 제외되며 short excerpt/자체요약/원 URL/GUID/hash만 커밋한다.
- 문서적 적합과 원 사용판 성공은 별개다. 비교 Pandoc3.6은 부모가 게시전 메타데이터로 확인했다. P3의 원 사용판2.11.2/3.1.11과 다른 점을 유지한다.
