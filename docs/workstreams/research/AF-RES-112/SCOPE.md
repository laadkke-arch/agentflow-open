## 가림과 역할

모집 담당자는 분야별 서로 다른 보조 문맥. 패킷 제작자는 root, 자료는 봉인된 요청·링크만. 기준 판독자는 별도 문맥에서 전체 원문·판·원 예제를 읽고 gold를 작성하며 패킷 B를 보지 않는다. 기준 파일의 내용은 12개 수신이 끝나기 전 root가 열지 않는다. 해시·행 수만 확인한다.

각 사건×A/B는 `fork_turns=none`의 새 에이전트 한 개에 배정한다. 과거 대화·모집·gold·상대 답을 전달하지 않는다. 한 에이전트를 다른 방식·사건에 재사용하지 않는다. 모델 설정을 변경하지 않고 동일 도구와 한국어 답 형식을 준다. G1 A/B, G2 B/A, G3 A/B, L1 B/A, L2 A/B, L3 B/A 순으로 시작한다. 공유 파일시스템은 보안 격리가 아니므로 열람 허용 파일과 도구 호출 기록으로 절차적 가림을 증명한다. 위반하면 해당 쌍 독립 비교에서 제외한다. 독립 문맥이 없으면 동일인 재판독/위치 재생으로만 기록한다.

A=원 응답의 URL 그대로. B=같은 URL + 원 요청으로 작성한 최대 140 Unicode codepoint 한 줄(찾을 대상·다음 확인·보존 조건). 답·검증 상태·추가 URL·후계 위치 금지. 제작자 시작/종료 UTC와 실제 한 줄 codepoint/UTF-8 비용을 별도 기록한다. 공통 요청은 양쪽 같은 바이트. 누락된 조건을 사실로 추가하지 않는다.

## 수신 예산과 관측

- 시작 URL 포함 최대 3번의 본문 개봉, 매 개봉 최대 1,500 Unicode codepoint, 총 4,500. 이는 배정의 총한도 안에서 동일한 단계별 최대치를 구체화한 것이다.
- 독자는 실제로 다음 행동과 이유를 정한다. 가능한 행동은 현재 문서의 다음 구간/이전 구간/직접 보인 내부 anchor/보인 동일 사이트 링크. 외부 검색·보지 않은 주소 추측·로컬 gold·다른 패킷 접근은 금지한다. 다른 사이트 링크는 열지 않는다.
- 원 HTML의 본문/목차/링크 label을 정해진 텍스트로 변환한다. 링크 target은 본문에 같이 표시하며 4,500자에 포함한다. 도구가 노출하는 모든 판단 가능한 제목·목차·링크 목록을 계수한다. 보이지 않은 전체 문서의 검색이나 목차 덤프는 허용하지 않는다.
- 새 HTTP 문서·문서 내부 anchor 이동·스크롤로 새 구간 노출·같은 구간 재노출 모두 1개봉. 동일 문자의 재노출도 다시 과금하고 별도로 중복 교집합을 계산한다. 자동 redirect chain은 사용자 한 번 개봉이지만 각 hop/실제 도착/fragment를 기록한다. 실패도 개봉 1회, 오류 본문 노출을 과금한다. 메타데이터의 상태코드/URL/비용 수치는 본문 비용과 별도이다.
- fragment 있으면 그 anchor에서 시작하고 없으면 정해진 본문 첫 글자에서 시작. 없는 anchor는 명시하고 첫 본문으로 돌아간다. 나중에 연결된 `stable`/`latest`의 판이 달라지면 유지·기록한다. 과거판으로 몰래 교체하지 않는다.
- 매 단계 잠정 등급(바로 사용/조건부/부적합/보류), 근거 URL·fragment·문자 좌표, 반대 해석, 미확인, 다음 행동·이유. 조기종료 가능, 남은 단계는 early_stop으로 기록한다. 최종 답은 한 개. 본문만으로 지지되지 않는 선행 지식은 분리한다.
- 전체 기대/기준은 수신 궤적·답을 원격 봉인한 뒤 공개한다. 실제 노출 구간에서 필수조건·근거를 역추적한 것만 근거 있는 성공. 맞는 결론과 충분한 인용을 별도 집계한다. 엔진/조판 실행은 실제 수행한 경우에만 확인으로 쓴다.
