# Reader transport refinement — before case packets or reader results

The shell could not retrieve docs.godotengine.org (403) or lists.gnu.org (timeout). The first protocol expected normalized HTML; raw HTML is not currently available. Readers will therefore use the existing web service's rendered source view through a bounded programmatic wrapper, not a crawler and not a browser session. This difference is fixed before packet construction and any reader observation.

The wrapper retains line markers and link handles from a web `open`/`click` result. It reveals at most 1,500 Unicode codepoints per action, including heading/link labels and handle markup. The service may fetch more text internally, but the model receives only the emitted slice. A full tool payload in a program variable is not counted as model exposure. The wrapper saves the exact slice and its source-view line/character coordinates. Every slice, including repeated material, is charged. UTF-8 bytes are recorded separately.

First open uses the original URL byte-for-byte. Subsequent actions are `next` or `back` on the returned view, or a link handle already visible in the current document's emitted text. The wrapper requests another service view only when the retained view ends. No `find`, search, unseen URLs, source code, hidden packet, or arbitrary offset is available to the reader. Off-site link arrival is recorded as a failed allowed-site check and its document body is not exposed. It consumes an opening.

The service's interpretation of an original fragment is retained. If true browser anchor landing cannot be established, `fragment_resolution=unverified` is reported; a matching heading is not fabricated. Source view line positions are not asserted to be DOM coordinates. A raw URL containing the same fragment in A/B does not prove identical anchor landing across later service calls; rendered-view hashes allow that difference to be audited.

Each action requires the prior step's provisional judgment before a new opening. Judgment is saved immediately. Ended sessions have one final answer and unexecuted positions are marked early stop; vacancies are not run. The model sees its common request, URL, optional one-line hint, and general operation syntax only. This is a real separate model-context reading observation with programmatically bounded source views, not a human user study or a live-browser scrolling study. Shared disk is instruction-level blinding; access histories are retained.

The reader cannot substitute knowledge for shown evidence: claims not supported by an exposed span must be labeled prior knowledge or unverified. A correct answer without adequate exposed support is reported separately from a supported success.

Generic GitHub transport probe: the web service returned DisabledError for a public Werkzeug source page, while the connected GitHub reader returned the source. Therefore GitHub URLs use the GitHub connector. A repository/tree URL is rendered as the default-branch directory entries from the corresponding contents endpoint; names and full child URLs are charged. A visible child blob URL opens its file via the connector. A repository root is thus a directory source view, not a screenshot or automatic README selection. This adapter is fixed before all reader trials, is identical in A/B, and records its API transport URL. It does not follow a link until the recipient chooses it.

Public GitHub ZIPs were confirmed accessible to the shell before trials. A bounded `urllib` download (28-second process limit, 15 MB archive cap) preserves original URL and redirect hops. First open displays a neutral directory list, with member filenames and byte sizes charged. A recipient may choose any member whose link was previously visible; each UTF-8 member opening consumes one of the three. No archive extraction or code execution occurs. A member decoded by the transport but not emitted by the wrapper is not model exposure. Member bodies are transported up to 10,000 codepoints (above the whole 4,500 budget), and oversized/binary failures are explicit. The chosen member and archive hash make the exact original position recoverable.

`click` accepts `from_step` to follow a link that was already shown on an earlier directory/source view without re-showing the directory. This is a remembered link choice, not a new source search or a free unseen table of contents. All such choices save the prior step and link id. `back` remains a charged re-exposure of the current source text.
