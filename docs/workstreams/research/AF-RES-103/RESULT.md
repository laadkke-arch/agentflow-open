## 경로별 관측과 반복

30자리는 전부 시도했다. **그림/페이지·해당 본문 약속 충족 20/30, 실패 10/30, 미실시 0/30**이다. K 2/10, M 8/10, P 10/10이다. T0/T1 교정은 10/12, 자연 T2는 2/6, 구성 T3/T4는 8/12다. K 실패 8자리의 자식은 각각 pdflatex 1과 바깥 Pandoc 83으로 종료했다. T2 M 두 자리는 Pandoc reader 0 뒤 선언/그림 매핑 경계에서 멈췄다. 자식 컴파일은 미실시다. 30개 실행과 14개 보조 실행의 기록 파일 1,049개를 내용 지문으로 다시 확인했다. [원장](runs.jsonl) · [검산](evidence/verification.json)

**의미 반복 15/15쌍**이다. 출력이 생긴 **10/10쌍**의 모든 SVG와 HTML이 바이트 일치했고 대표 Chrome 화면도 같다. 나머지 5쌍은 HTML/SVG 산출물 부재다. PDF는 생성된 **0/10쌍**이 바이트 일치하며 생성 시간 값이 다르다. PDF 객체 전반의 차이 귀속은 미확인이다. Pandoc AST는 해당 경로 10/10쌍에서 바이트 일치했다. [반복 검산](evidence/verification.json) · [PDF 메타데이터](evidence/pdf-repeat-metadata.json)

K/M은 Pandoc 3.6 writer와 pdf2svg 0.2.4를 사용했다. P의 공개 명령은 페이지 SVG까지만 실행하고, HTML 안에 넣은 단계는 이번 연구 구현이다. 최종 화면은 같은 Chromium 156.0.8078.79의 DPR 1에서 로컬 파일 바이트와 오프라인 컨텍스트로 열었다. 099와 네 주요 실행 바이너리의 지문은 같았고, pdfLaTeX는 같은 LaTeX 버전의 시스템 fmt를 사용해 파일 지문이 달랐다. 파일 URL은 관리 정책에서 차단됐다. 새 탭으로 교정한 루프백 이동 결과는 첨부 이미지의 외부 요청 여부를 보여준다. ## Q7과 자료 범위

WPT 원 fixture와 기대 PNG는 픽셀이 같았다. fixture의 동일한 SVG 바이트를 녹색 호스트에 inline하면 녹색이고 외부 img면 검정이다. 외부 SVG에 녹색을 명시한 대조도 녹색으로 열렸다. Graphviz 원 fixture는 두 클러스터의 배경 차이를 재현했다. 연구자 DOT에서 같은 label을 줘도 공유 ID의 최초 색과 간선의 생성 위치에 따른 촉이 갈렸다. 전역으로 평탄화하면 붉은 vee와 검정 normal이 푸른 dot으로 바뀌었다. 두 분야 대조는 주 30자리와 분리했다.
