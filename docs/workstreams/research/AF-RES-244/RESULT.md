최소 링크 라벨은 '1.6.1 / 실제 연산 / 입력·대상 / 소비된 반환 / 공개 결과 유무'로 구성한다. 예: N1 'NN 설명 참조; TSNE embedding 출력, 거리·인덱스 tuple 없음'; C1 'KNN k3 특징 선택; 열명 출력, 새 레이블 없음'; C2 'KNN k3 fit·score; 내부 predict→정확도, 개별 label 없음'; G1 '표본 k30 연결 CSR→군집 labels; 거리 mode 없음'; G2 '표본 k3/2 연결 대칭화→Ward/average; 거리 mode 없음'. 링크 하나당 사실·근거 위치 1개를 펼침, 사용 목적과 조건을 분리한다. 단순 설명/호출/반환 소비/결과의 네 단계와 argument/mode/query/entity 축, 근거 판/원위치/role을 별도 저장한다. 사용자 목적이 TSNE 성능 또는 특징 선택 또는 분류 정확도라면 본표 조건부 링크가 오히려 적합해진다. 순위 자체로 추천 실패/성공을 판정하지 않는다. 별도 검증층 없이 텍스트 관계를 강한 의미로 승격하지 않으며, 다른 분야처럼 major flag를 제공하되 검증 목적/판에 종속시키고 자동 추론에 근거를 요구한다.
