# 검색 봉인 뒤의 반대 관측과 외부 분야

읽기 시작은 전체 검색 봉인 `628e33709b0be7a19486f1bfeaef93f42e129394` 이후다. 이 디렉터리와 `counterchecks.csv`, `external-transfer.csv`의 자료는 A/B의 검색 발견 수에 더하지 않는다. 모든 최소 입력은 연구자의 **미실행 시험 제안**이며 자연 모집 요청에 값을 삽입한 것이 아니다.

독립 반례 원저작은 GNU gettext, Playwright, Kubernetes, Qt, Cytoscape.js, W3C UI Events의6건이다. 요청마다 유리한 전이가 깨지는 조건을 하나 이상 남겼다. 외부 배당4건은 OCFL·공식 PREMIS3 XSD(기록보존)와 NIST LASP·MIL-STD-1916(제조 품질검사)다. PROV-DM도 직접 읽었지만 추가 보조 독해로만 기록하고 필수 배당을 늘리지 않는다.

PREMIS PDF는403/429/timeout으로 읽지 못했다. 공식 발행자 LibraryOfCongress 저장소의 고정2016 XSD에서 event·outcome·agent·object·relationship 심벌을 직접 읽었으며 PDF 설명을 대신 읽었다고 하지 않는다. GNU 문서는 웹 도구 timeout 후 공식 원점의 작은 HTML 페이지를 직접 받아 전체 내용을 읽었다. DLA는 아이콘→공개 redirect→WMX→실제 PDF 경로를 기록했다. 웹 도구가 PDF 결과를 rewritten summary로 표시했으므로 그것에는 1차 독해 점수를 주지 않았다. 내려받은33쪽 원 PDF의 본문 p10/11/17/26과 렌더된 PDF15/22쪽을 직접 확인했다. 임시 PDF URL의 수명은 미확인이고 재현에는 안정된 WMX 문서 링크를 사용한다.

이 기록은 넓은 비유가 직접적인 동종 대안보다 좋다는 전제를 지지하지 않는다. 예를 들어 Cytoscape의 자동 parallel routing은 일부 R5 해석에 곧바로 대응하지만 원문이 fan-out이면 여전히 빗나간다. Kubernetes의 omission 규칙은 partial-update 비유가 프로토콜 차이 때문에 반대로 작동할 수 있음을 보인다. NIST와 MIL의 무작위 표집 전제는 이 웹 탐색의 전역 recall 추정을 허용하지 않는다.
