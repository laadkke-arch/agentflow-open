# AF-RES-021 작업 기록

| 묶음 | 원격에서 찾는 위치 | 완료·다음 입력 |
| --- | --- | --- |
| ① 동결 | 이 파일 최초 변경 커밋 (`git log --diff-filter=A -- PROGRESS.md`) | 통합·의존·계획 SHA 및 표집, A/P/M, 예산, 판독·채점 규칙. 다음은 세 프로젝트 원 질문의 판·시각과 선정 목록 확정. |
| ② 입력 | 대기 | 네 질문씩 질문·소스·카드·분리 키·준비 이력. |
| ③ 실행 | 대기 | 각 묶음에서 판독 전 입력 해시, 4절 로그, 통제 재생. |
| ④ 집계·점검 | 대기 | 동일 두 판정원과 1/2/4절, 반례, 교차 분야, SELF_CHECK와 수용 근거. |
| ⑤ 인계 | 대기 | 점검 커밋 이후 HANDOFF 단독 커밋. |
