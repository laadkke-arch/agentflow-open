## 자료·산출물 검산

- 최소 자료: 원 질문8 + 주 공식16 + 인접 공식10 + 독립 상류시험5 + 타 분야 공식5/fixture2 = **46개**. `sources.jsonl`의303행(재개160+원래143 비산입)에는 실패·중복·후속 비산입도 남아 있다. 고유 fixed_url 중복을 검사한다.
- 원 요청8×정책2×읽기2=32자리, 각4슬롯=128자리, 공석4슬롯. 8×읽기2=16쌍 중 P3두쌍을 제외한14쌍을 비교한다.
- 모든 필수 표는 `recompute.py --write`로 원장에서 생성하고 `--check`로 같은 바이트를 재현한다. 주요 외부 본문과 압축 원장은 checksum으로 복원한다.
- `protocol.json`, `packets.jsonl`, `judgments.jsonl`, `pairs.csv`의 봉인 해시는 ③까지 불변이다. 후속 자료를 주 인용·완결에 추가하지 않았다.
- 실제 작업 계약/공통검사의 최종 대상 SHA·종료값·건너뛴 범위와 GitHub 결과판 재열람은 마지막 단독 `HANDOFF.md`에 기록한다. 계획된 검사를 성공한 검사라고 쓰지 않는다.
