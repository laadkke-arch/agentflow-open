# 판정 전 창 수정

원격 `34be54e4423c6683b59c1e79e8646cca395cb0b2`의 JS-3/SC-027 W03·W04를 첫 독해 때 확인했다. Docutils가 선택 의존성 Pygments의 부재로 RST 두 `code-block`을 경고 노드로 생성했고, 표시기가 경고 노드를 제외하면서 실제 코드가 빠졌다. 출처 및 목적지 고정과 기존 두 창은 위 커밋에 남아 있다.

구문 강조를 끄고 문서 prose에는 영향을 주지 않는 이미지 배지 alt를 Markdown과 동일하게 제외했다. 같은 원문 바이트, 동일 A·B·P 시작, 동일 둘째 행동 규칙으로 다시 생성했다. 변경된 표시 텍스트는 W03·W04 두 창이며 기존판을 실제로 보았던 연구자가 정정판도 읽는다. 대상 두 창의 과거 노출과 정정판 노출을 중복 독해 기록으로 남긴다. 수정은 조건 판정 봉인과 세 엔진의 검증 실행 전에 이루어졌다.

중간 정정판 `cb6935dd693afdfe3ef963059340c0b51716a33c`을 재독해할 때 doctest 블록이 별도 노드라는 점과 첫 Python 코드의 Docutils 행이 본문 끝을 가리킨다는 점을 확인했다. 최종 교정은 doctest를 포함하고 소스 줄 텍스트로 코드 시작을 대조한다. 첫 import는 실제 L39이며 출력 예제는 L71에서 시작한다. 이전 층 142/118단어와 중간판 277/269단어의 읽기를 보존한다. 정정 전후 목적지와 분기는 같다.
