# 판이 필요한 쪽 주소

같은 제목과 인쇄 쪽수에 판과 스캔을 연결할 수 있는 경우를 비교했다. 항목 시작으로는 Wikisource의 판별 Index를, 직접 경로로는 해당 Index의 페이지 격자에서 고른 인쇄 33과 vii의 Page revision을 열었다. 문학 텍스트에 대한 표와 소프트웨어의 조건 확인 집계는 독립이다.

1818년판 p32 마지막 줄과 p33 첫 줄에서 한 단어가 이어졌다. 개정판 p32는 Krempe의 권유를 설명해 p33의 반응에 배경을 준다. [1818 p32](https://en.wikisource.org/w/index.php?oldid=7539016&title=Page%3AFrankenstein%2C_or_the_Modern_Prometheus_%28First_Edition%2C_1818%29_Vol_1.djvu%2F48) · [1831 p32](https://en.wikisource.org/w/index.php?oldid=8868221&title=Page%3AFrankenstein%2C_or_the_Modern_Prometheus_%28Revised_Edition%2C_1831%29.djvu%2F50)

인쇄 33의 상단 제목과 숫자는 같았다. 쪽수 하나를 키로 정하면 다른 판의 다른 텍스트로 이동한다. 쪽 주소를 검산할 때 판·권·원본 ID도 확인한다. IIIF의 Manifest가 복합물 설명을 담고 Canvas가 뷰를 별도 주소화한다는 역할 분리가 이 비교에 대응한다. [IIIF §5.2–5.3](https://iiif.io/api/presentation/3.0/#53-canvas)

공개 Web 도구로 네 고정 Page를 읽고 두 스캔의 JPEG 목적지도 열었다. Wikimedia의 셸 직접 JPEG 취득은 프록시 403이었고, Cloud Desktop의 두 호출은 “Browser Use could not read requirements.”로 끝났다. Archive PDF 두 링크의 CDN 리디렉션도 웹 도구에서 읽히지 않았다. 해당 페이지는 validated 전사이며 이미지 픽셀과의 직접 대조는 미확인이다. LOC 판 후보는 안내 색인에서 확인했으나 항목/리소스 직접 취득이 403이어서 수에 넣지 않았다. 두 실제 출판판의 스캔 대응 자료는 둘이며 Shelley 저작 계보는 하나다.
