## 모집과 판독 순서

1. 이 계약과 16자리·별칭을 첫 커밋으로 원격에서 확인한 뒤에만 discuss.pytorch.kr의 공개 카테고리 목록과 opening을 확인한다. 질문·도움 카테고리 ID와 포함한 하위 카테고리의 유무를 기록한다. 공개 목록·공식 메타데이터로만 2025-01-01T00:00:00Z 이상 2026-01-01T00:00:00Z 미만 창의 생성 시각과 topic ID를 확보한다. 핀 고정 순서, 최신 활동 정렬, 목록·검색 제목, 득표·응답은 선별 기준에 넣지 않는다. 기간 경계 페이지와 접근 공백은 별도 기록한다. 정렬을 검증할 수 없는 발견은 정규 모집 자리에 넣지 않는다.
2. 생성 UTC 오름차순·동률 topic ID 숫자 오름차순이다. 초기 최대 240건에서 원 작성자의 한국어 문장으로 데이터 공급·표본 선택·배치 또는 텐서의 shape·축·반복·확장·복사·계산 관계 변형의 구체적 목적과 대상이 확인되는 첫 4건씩 채운다. 후보 심벌이 이름으로 있거나 동작이 검색 자료집에 존재해야 한다는 조건은 없다. 훈련 손실·장치 이동·설치·단순 결과 불만·텐서와 관계없는 크기·분류 모델 선택 등은 그 군의 요구가 본문 핵심일 때만 포함한다. 양쪽이 명확하면 먼저 나온 핵심 요구를 택하고 애매하면 보류한다. 코드뿐인 글, 번역 연습, 재게시, 강의 예제는 제외한다. 두 군이 채워지면 해당 지점에서 그해 개봉을 멈춘다. 2025년 부족 군만 2024-01-01T00:00:00Z 이상 2025-01-01T00:00:00Z 미만의 같은 앞 240건에서 이어 선별한다. 판 미상이나 다른 판은 선별과 별도로 표시한다.
3. 가능하면 공개 Discourse opening-only 응답 경로를 통해 작성자 첫 post 번호만 판독한다. 일반 topic 응답이면 응답 작성물은 추출 전에 버리고 선택용 화면에 첫 post만 보인다. 편집 이력 표시와 본문 판을 기록하고 첫 판이 안 열리면 현재 공개 첫 게시물로 판단하며 차이를 명시한다. 제목은 사례의 위치 정보이고 검색 입력은 opening 본문이다. 공개 원문의 전체 복제를 피하기 위해 원문과 진단 사본의 해시는 실제 사용한 본문에서 만들고, 공개 저장소에는 위치와 심벌별 최소 diff, 조회에 관여하는 본문 어절·일치 위치를 가리키는 파생 검색 입력을 남긴다. 본문 스냅샷을 다시 검증할 때 위치·해시로 대조한다. 작성자 식별 정보나 비공개 편집은 저장하지 않는다.

## 네 조회

- 조건은 `raw-off`, `raw-on`, `masked-off`, `masked-on`이다. 한글 어절은 NFC 뒤 `[가-힣]+`이며 어미·조사를 제거하지 않는다. 유효 별칭 문구는 통째로 경계에서 맞아야 하며 여러 어절은 사이의 공백을 한 개로 본다. 코드, 본문, 오류의 텍스트는 같은 가중치다. 한글 띄어쓰기 교정, 번역, 의미 확장, 정답 필터는 없다.
- 영문 공통 설명의 어절은 ASCII 영숫자와 밑줄의 최대 연속 문자열이며 소문자로 비교한다. 개별 카드와 질의에 공통으로 있는 서로 다른 어절마다 1점이다. 영어 표제는 대소문자까지 일치하는 API 심벌 일치에 사용한다. 심벌이 한 번 이상 맞으면 카드당 12점이다. 완전한 PyTorch 경로·`Tensor` 메서드·등록한 `torch` 자유 함수, 완전한 짧은 이름, 텐서 수신 객체의 메서드 호출을 허용한다. 더 긴 ASCII 식별자, URL·파일 경로 내부, `np`/`numpy`/`tf`/`jax`/`pandas`/`pd`/`torchvision` 등의 타 패키지 명시 호출은 제외한다. 이름 없는 수신 타입은 추정 한계로 남긴다. 텐서 인스턴스 메서드에서 수신 객체·점은 남기고 API 토큰만 같은 길이의 ASCII 공백으로 바꾼다. 완전한 등록 이름으로 인용된 메서드·자유 함수·데이터 API는 해당 심벌 전체를 가린다. 비명시 심벌과 인자·판·부정 표현은 남긴다. 코드포인트 범위·가리기 전 토큰·대체 공백을 기록한다. 이름이 없으면 양쪽 바이트 해시가 같아야 한다. 가림으로 문법이나 ‘이미 시도한 방식’의 의미가 깨질 수 있다.
- 별칭 ON에는 유효한 서로 다른 표면형 일치당 4점이 추가된다. OFF는 영어 카드 필드를 그대로 사용한다. 모든 16자리 점수를 저장하며 0점은 조사 후보로 뽑지 않는다. 내림차순 점수, 동률이면 기능 ID 오름차순이다. 조사 8, 표시 3 상한. 역할·근거의 후처리로 순위를 거르지 않는다. 0·상한·공석의 사유를 별도로 집계한다. 같은 사본의 OFF→ON, 같은 별칭 상태의 가림→원문을 각각 비교한다.
- 순위를 만드는 프로그램에는 사본별 영어 어절·정확 심벌 검사 결과와 한국어 일치 확인에 필요한 어절열만 넣는다. `truth.csv`, 작성자 후속, 요청 해석 및 가림 사유는 입력에서 제외한다. 사본들과 실제 조회 투영은 각각 SHA-256으로 남긴다. 두 새 경로에서 같은 고정 입력을 사용해 점수·후보·비용 출력을 바이트 단위로 비교한다. 후보 전수 비교와 별칭 확인 횟수, 읽은 출처 수와 UTF-8 저장량은 계수하며 검색 시간·클릭·만족도는 관측이 있을 때만 수치를 적는다.
