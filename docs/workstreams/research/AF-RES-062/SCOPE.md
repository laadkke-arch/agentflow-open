## 1. 질문·판정 경계

동일 항목·주장/권고를 받은 사람이 독립 원문을 검증할 수 있는 접근 조건 때문에 정권고·오권고 수락과 최종 정확도에서 어떻게 달라졌는가? 링크 제공, 배정된 노출, 선택 클릭, 실제 독해와 오류 선별을 서로 다른 사건으로 취급한다. 새로운 참가자 실험·제품 구현·배포·총 노동시간 추정은 범위 밖이다.

판정 값은 `미확인`(확인 못 함), `관측 0`(실제 집계 영), `해당 없음`(그 분모/종점이 정의되지 않음), `미실시`(검사를 하지 않음)으로 구별한다. 공개 자료 접근 실패는 자료 부재의 증거가 아니다.

## 2. 모집틀과 고정 검색 절차

발행 완료 연도 2018–2025. 학술지는 출판사의 최종 권호/서지 발행일을, 학회는 proceedings 발행일을 우선하고 최초 온라인 완료판 날짜도 별도 보존한다. 권호가 없는 온라인 전용 VoR는 그 발행일을 쓴다. 이 선택으로 2017 online/2018 issue 논문이 포함될 수 있으므로 경계 논문은 날짜 민감도를 적는다. 날짜의 정밀도(일/월/연도)를 보존한다. 연도만 확인되면 정렬용 YYYY-01-01로 두되 실제 발행일로 주장하지 않는다. DOI는 소문자 정규화한다. DOI가 없으면 ACL ID 또는 고정 저장소/사전등록 ID를 사용한다. 동일 DOI·미러·개정·동일 참가자 코호트는 한 번만 배정한다.

| 틀 | 시작점 | 사전 질의 묶음 | 고정 자리 |
| --- | --- | --- | --- |
| A | ACM CHI(정식 CHI EA 포함, subtype 구분)/IUI/SIGIR 공식 논문/검색 목록, ACL Anthology | citations/source links + user study + answer verification; evidence/source access + search/question answering/recommendation + experiment; attribution/citation + trust/accuracy/verification | A01–A03 |
| B | 출판사 원저, Civic Online Reasoning/Digital Inquiry Group 저자 연구목록 및 그 원논문 링크 | source access/lateral reading + experiment + accuracy; source credibility/evaluation + same claims; fact checking + web search/source links + experiment; library information literacy + source verification | B01–B03 |
| S 보강 | 저자 replication package·사전등록에서 시작(OSF/Dataverse/Zenodo/GitHub) | source/citation/lateral reading/web search + experiment + data/preregistration/replication | 최대 S01–S02, 주 표본과 별도 분모 |

각 native query의 URL, 실제 UTC, 정렬/필터, 실제 보이는 반환 수·총수 제공 여부, 접근 실패를 기록한다. 한 질의당 최대 첫 100개 서지 레코드 또는 검색 도구가 실제 반환한 전체 레코드까지 본다. native 검색이 실패하면 동일 의미의 도메인 한정 검색엔진 질의로 대체하며 이 경로와 한계를 기록한다. 검색엔진 정렬은 엔진 관련도이며 시간순 전수검색으로 부르지 않는다. 인용추적·추가 저자판 회수는 별도 경로로 남긴다.

각 틀에서 발견한 범위 내 연도·학회/분야에 맞는 후보를 DOI·코호트 중복 제거한 뒤 발행일·DOI(없으면 고정 ID)순으로 정렬한다. **그 첫 25건**의 방법을 검토한다. 실제 후보가 적으면 그 수만 기록하며 다른 틀로 채우지 않는다. 적격/제외 판단 전 후보 메타데이터를 고정 커밋한다. 25건보다 앞선 미해결 방법이 있으면 뒤의 적격을 확정된 '최초'라고 부르지 않고 순번 불확실성을 남긴다. 결과 방향·유의성·데이터 공개 여부는 주 모집의 선정 요건이 아니다. 검색 스니펫에 결과가 우연히 노출된 경우 완전 눈가림이라고 주장하지 않고 결과표 비열람 상태의 절차 고정으로 기록한다.

## 3. 적격성과 비교 강도

필수: 실제 사람의 최종 판단, 같은 항목/주장·권고가 제공됨을 방법/자극에서 연결, 검증 가능한 외부 독립 원문에 접근할 수 있는 조건 차이. 같은 모델이라는 말이나 화면 예시 하나는 모든 문항 동일성의 증거가 아니다. 초기 3개 적격을 각 주 틀에 배정한다. 부족하면 빈자리를 유지한다.

비교 강도: I1 같은 라벨의 클릭 가능/불가 또는 같은 텍스트+링크 접근만 변경; I2 같은 주장에 검색/원문 열람을 배정·유도하지만 시간/작업 지시도 바뀜; I3 교육·다른 보조자료를 포함한 원문 접근 묶음. 접근은 모두에게 같고 교육만 달라진 연구는 접근효과 적격이 아닌 인접 반례로 보존한다. 홈페이지·로고·출처명 배지·다른 AI 설명은 독립 원문 자체와 구별한다. 원문 없는 설명/잘못된 배지 실험은 진단층이며 주 자리를 대신하지 않는다.

보강층은 원래 배정·문항·참값·최종 판단을 연결할 수 있는 공개 참가자 원행을 추가 요건으로 한다. package-first 발견 순서와 날짜·ID 정렬을 고정한다. 주 틀와 DOI/코호트가 겹치면 새 연구 수를 늘리지 않고 해당 주 연구의 원행 보강으로 표시한다. 별도 최대 2개 코호트의 분모는 주 표본과 합산하지 않는다.

## 4. 노출·참값·수락·결측

항목 ID·주장/권고 방향·후보·순위·배치·문구·시간/추가 교육/신뢰도 변화를 각각 기록한다. 출처는 실험 당시판 URL/절을 우선한다. 당시판이 없으면 현재 확인만 표시한다. 실제 링크 도착 원문을 지지/반박/무관/접근 불가로 판정하되 저자 정답키와 원문 판정이 다르면 양쪽을 보존한다.

배정 단위(사람/항목/세션), 조건·순서·기간과 event dictionary를 읽는다. 제공, 자동 열림, 선택 클릭, dwell/scroll은 독해 이해와 다르다. 공개 이벤트가 없으면 실제 열람은 미확인이다. 자발 클릭자는 별도 기술표이며 배정 효과로 인과 해석하지 않는다.

필요 시행키: 공개 코드북의 실제 participant/item/condition/period 키 + advice/claim direction + truth + final choice + inclusion/withdrawal/missing. 초기 답이 있으면 최초 일치 시행과 변경 시행을 분리한다. 필요한 스키마를 발견한 실제 열 이름처럼 쓰지 않는다. 정권고/오권고 각각 배정 N, 판정가능 D, 권고와 같은 최종 선택 a, 최종정답 c, 기권·결측 m을 구별한다. 다지선다에서 권고 거절은 정답과 같지 않다. 신뢰/개별 문항 평정/군 평균/반올림 백분율을 이산 수락 정수로 역산하지 않는다.

관측 분자/분모는 저자 원행의 재현 가능한 결합 또는 직접 정수 교차표만 인정한다. 등급 J1=동일 시행키 결합; J2=저자 직접 정수 교차표; J3=주변 평균/그림만; J4=수락 종점 없음; JU=자료 미확인. 행 결합 등급은 무작위화/인과 증거 등급이 아니다. 배정 비교 우선, 자발 클릭층 별도. 반복 사람·항목을 독립으로 간주한 p값은 만들지 않는다.

N,a,m이 모두 확인된 때만 미관측 포함 수락 범위 `[a/N,(a+m)/N]`를 보고한다. m까지 모르면 범위도 미확인. 단순 기술 조건차는 `100*(a1/D1-a0/D0)` %p; 서로 다른 층/과제/분모를 합치지 않는다. 원개수 대비는 양 조건 각 1건 이상 원행/원표 손검산을 남긴다.

## 5. 자료 수와 종료

최소 서로 다른 외부 1차 저작 20: 원 연구 보고서 8 이상(정보검색·사실확인/정보문해력 각각 2 이상), 독립 발행 원 자극/과제/사전등록 3 이상, 저자 응답자료/코드북/분석패키지 3 이상, 저자가 실제 사용한 독립 참값 원전/정정 2 이상. 한 논문의 부록·미러·개정 또는 한 저장소 파일을 여러 저작으로 세지 않는다. 별도 원자료는 독립 ID와 기능이 있어야 별도 계보로 세며 같은 코호트임을 표시한다. 참가자/사건/비교 셀 수는 저작 수와 별도다. 검색·초록만·접근 실패·내부 인수·생성 진단은 독해 최소량에서 뺀다.

직접 읽은 각 자료는 sources.jsonl에 ID, 저작/코호트 계보, 종류·작성 주체, 원본/고정 URL, 판/날짜, UTC, 직접 읽은 위치, 확인·한계, Q/사례, 최소량 산입을 기록한다. 공개 개인 응답 원행은 재게시하지 않고 위치·해시·필드·집계/재현 절차를 보존한다.

묶음 커밋: ① 이 모집/적격/결측 규칙 ② 방법·자극·참값·노출 ③ 원개수·반대 결과·계산 ④ 두 표·주장 경계·수용 원장. 중간 목록 고정도 별도 커밋 가능. 최종 자체 검토와 실제 `workbench.session check ... --fetch`, 결과/수용 원장의 고정판 재열람 이후 HANDOFF.md만 마지막 커밋한다. 공개 자료·절차 또는 결합 결손이 남으면 **부분 인계**라고 명시한다. Git 계약 검사 통과를 연구 내용 수용으로 바꾸지 않는다.

## 6. 역할

root는 계약·통합·독립 참값 검증·검산·공통 원장·GitHub 저장을 맡는다. 보조 AI frame_a, frame_b, supplement는 서로 다른 소유 stream에서 독립 조사를 수행한다. 동일 세션 도구를 사용하는 AI 보조 검토이며 인간 독립 심사·새 참가자 복제라고 부르지 않는다. 공통 진행표는 변경하지 않는다.
