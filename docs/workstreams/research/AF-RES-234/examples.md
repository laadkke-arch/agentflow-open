## EPUB 대조
- W3C [E01](https://www.w3.org/TR/2026/REC-epub-33-20260113/) §3.6 resource locations: font resources may be hosted outside container; local encouraged for offline; exempt fonts can fall back via CSS. [E02](https://www.w3.org/TR/2024/REC-epub-rs-33-20241017/) CSS support requirements: support core font formats referenced through @font-face, should apply publisher styles; font obfuscation handling conditional. Support requirement ≠ observed reading outcome.
- Accessible EPUB 3 (Matt Garrish, 2012-02-20, sample repo 7651e2002b631e6577fadf7e9e0692fa6efb8746): [E03 OPF](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/accessible_epub_3/EPUB/package.opf#L32-L65) manifest includes css/epub.css and fonts/UbuntuMono-R.ttf (epub.embedded.font.3). [E04 CSS](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/accessible_epub_3/EPUB/css/epub.css#L831-L836) defines Ubuntu Mono, normal, src ../fonts/UbuntuMono-R.ttf; L244 references Ubuntu Mono then monospace. [E05 bytes](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/accessible_epub_3/EPUB/fonts/UbuntuMono-R.ttf) fetched actual TrueType sfnt header and 205748 bytes, blob fdd309d716629f4e5339d5e5508225ed857a3ede. FreeSerif.otf fetch content empty; not counted. No font file distributed separately from original in this repo, no rendering/reader test. File location and exact resource relation verified, actual glyph selection not verified.
- Children's Literature (Curry/Clippinger, package modified 2010-02-17): [E06 OPF](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/childrens-literature/EPUB/package.opf) manifest has epub.css/nav.css but no font items; [E07 CSS](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/childrens-literature/EPUB/css/epub.css#L3-L10) body calibri, arial, helvetica, sans-serif; L49 Calibri,Arial,sans-serif; [E08 nav CSS](https://github.com/IDPF/epub3-samples/blob/7651e2002b631e6577fadf7e9e0692fa6efb8746/30/childrens-literature/EPUB/css/nav.css) uses arial, helvetica, sans-serif. No @font-face in either read CSS, tree contains no font file for book. Reader may select installed family/generic fallback, no proof which on device. Distinct sample title; not same work repackaged.
- Transfer scope: CSS declaration is a *reference/policy*, manifest is an inventory, bytes are physical resource, reading system chooses. MapLibre equivalent is layer property→asset namespace/index/URL→bytes→renderer; analogy stops at EPUB container rules vs remote tile features, glyph SDF ranges, map zoom/filter and sprite atlas. EPUB manifest does not guarantee embedded file is selected; remote fonts allowed and local fallback possible. Do not prescribe EPUB manifest semantics to map styles.
