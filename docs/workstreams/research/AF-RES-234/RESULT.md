## Q1. 무엇을 재사용하는가
고정된 대상은 이름이 아니라 (publisher, revision, style path 또는 generator+input, layer ID, property, viewport/조건)의 튜플이다. MapLibre Demotiles의 고정 트리 13,500개 항목(비절단)에서 JSON 경로순으로 TileJSON을 제외하면 debug-tiles/style.json이 첫 공개 스타일이다. README도 Debug라고 지칭한다(M01,C02). 단색·icon-image·text-field는 각각 실제 0개. 숫자 9 PNG(M06)는 문자처럼 보이지만 text-field가 아니다. Protomaps 트리 295개(비절단)에서 공개 완성 style JSON을 확인하지 못했고 render-test의 metadata JSON은 sources/layers 없는 fixture다(C08,C10). 공식 viewer와 versioned layers endpoint를 열었으나 전체 배포 JSON을 얻지 못했다(F01,F02). 코드의 first 후보(P01–P04,P06,P07)를 배포된 배열 위치로 바꾸어 적지 않는다. OSM Bright의 3개는 별도 대조군이다. 고정 스타일과 생성기/소비자 예제의 판이 다를 수 있다.
- 디자이너의 색상 규칙 읽기는 격리된 background-color면 style#layer가 충분하다. 전체 화면과 같은 색은 다른 layer/opacity/raster/renderer도 관여한다.
- 아이콘 추출은 이름·조건·sprite namespace·index·PNG·pixelRatio를 구별한다. 앱의 HTML marker는 별도 객체(C04).
- 주소·언어 재현은 실제 feature의 문자열, locale/zoom/filter, glyph stack 또는 local font 정책을 결정해야 한다. 예제 카메라가 minzoom보다 낮으면 후보가 실제 화면에 있다고 할 수 없다(C03,C04).

## Q5. 복사·해석·오프라인
두 제품의 스타일만은 조건·이름·색 규칙을 해석할 수 있고, 메타를 더하면 출처·범위·atlas rect·폰트 요청 후보를 좁힐 수 있으나 실제 픽셀 및 feature 값은 확정되지 않는다. 실제 파일까지 갖춘 경우라도 renderer/version, protocol, camera, DPR, locale, local fonts, source revision, 전체 dependency를 고정하고 네트워크를 차단한 실행 영수증이 있어야 동일 화면의 offline 성공이라고 한다. M01 Debug는 PNG와 hillshade/terrain source가 필요; OSM contrast는 M08–M12의 tile/sprite/glyph 체인. Protomaps는 생성기+flavor+language+source를 고정한 JSON이 먼저, 실제 범위에 대한 PMTiles와 P08/P09/P13 등의 해당 자원 및 protocol/renderer가 뒤따른다. C02의 World offline ZIP 안내는 게시자의 안내일 뿐 이 연구의 실행 영수증이 아니다. C06의 Monaco local example은 local file을 쓰더라도 remote CDN JS/CSS를 참조하므로 모든 네트워크 자원을 제거했다는 뜻이 아니다. C08/C09/C10에서 Athens expected PNG와 test camera/light/en/z7을 연결했으나 당시 생성 commit/renderer/tiles build를 확정하지 못했다. 웹에서 현재 열람한 고정 Git 파일·공식 주소·게시 당시 실제 배포 상태는 구분한다. 실측 offline 성공 0건.
 
## Q6. EPUB 교차 영역
E01 EPUB 3.3의 리소스 위치/manifest 규정과 E02 Reading Systems의 CSS font support를 구분. Accessible EPUB 3(Matt Garrish) E03 package.opf의 manifest의 href=fonts/UbuntuMono-R.ttf, E04 css/epub.css @font-face src ../fonts/UbuntuMono-R.ttf(L831–836), font-family Ubuntu Mono, monospace(L244), E05 실제 TTF 205,748 bytes의 sfnt 파일을 연결했다. 다른 FreeSerif 파일 조회는 F05 실패로 산입하지 않았다. Children's Literature E06 OPF에는 해당 font 파일 선언이 없고 E07/E08 CSS는 calibri/arial/helvetica/sans-serif 등의 시스템 폰트 후보; 트리/해당 CSS에 embedded font 확인되지 않았다. 이는 이름 선언과 포함 파일이 다름을 보여 주는 실제 반례이며 어느 reader가 실제 어떤 font를 선택했는지는 미확인. EPUB에서도 외부 font 자원 허용 및 fallback 정책 존재. MapLibre에는 glyph ranges, tile feature, sprite index, runtime addImage라는 별개 조건이 있어 EPUB manifest와 1:1 등치하지 않는다.

## Q7. 최소 링크 조합의 조건
bundles.csv의 baseline 9행 및 24 통제 행(두 비교 대상 O/P × 4 × 3)은 역할을 필수/택일/설명/보류로 나눴다. strict Debug 3공석과 Protomaps artifact 결측을 대조군으로 대체하지 않는다.
- C1 격리된 단색 배경: style anchor 필수, source/sprite/glyph 생략 가능, 전체 화면이면 추가. background-pattern 또는 raster인 경우는 별도 조건이다.
- C2 존재하지 않는 sprite 이름: name, namespace와 실제 index가 필수; 다른 atlas 또는 런타임 제공은 택일(확인 필요), 원 PNG만으로는 해당 이름의 그림 보류. 없는 이름 0개와 실패한 endpoint를 같은 값으로 저장하지 않는다.
- C3 local glyph: 정책·renderer version·실제 font 가용성 필수, remote PBF 또는 로컬 rasterization은 조건부 택일; exact appearance 보류. 테스트 원파일은 기대값이다.
- C4 source 범위 밖: 실제 TileJSON/bounds 또는 고정 archive header 필수. OSM bounds 밖 London에서는 피처 부재/요청 억제 기대(S05)이며 실행 관측은 아니다. 새 범위의 tileset은 필요 시 추가; 단색 배경은 그대로. P에서는 실제 archive header가 미확인되어 범위 밖의 확정 판정은 보류.
네 통제의 링크 설명과 정적 근거는 4/4, 실제 한 조건 변경 실행은 0/4. 자료 공개 주소·고정판 내용·현재 서비스 응답·당시 배포 기록을 각기 기록한다.

## 비용·대안 및 검색기 설계
첫 링크는 읽을 목적의 가장 작은 증거 단위(색상: style#layer; icon: style#layer + sprite index/rect + atlas; text: style#layer + source/feature + glyph/local policy). 사용자 목적이 '규칙 읽기'면 원본 몇 개만 제공하고 정확한 byte 다운로드는 추가 링크로. '오프라인 동일 화면'이면 viewport/renderer와 provenance, package/asset license를 함께 묶고 필요한 공간·zoom으로 타일을 제한한다. v4 전체 planet 다운로드는 D02의 약 120GB 규모 안내에 비추어 먼저 권하지 않는다(실제 전송량·비용 미계산). 발행자에게는 generator inputs + release/commit/build hash + asset namespace·variant·DPR + bounds와 라이선스 링크를 묶는다. 자원 접근 실패/만료, 이름 불일치, 데이터 밖, 의도 불일치는 독립적으로 판단한다. 후보 관계의 유효성을 특정 화면·버전·언어로 한정하고, 정확한 주소/리소스 묶음이 비면 추천 옆에 보류 표시. 본 연구는 탐색기 설계 후보이며 DB 계약·실행 환경은 정하지 않는다.
