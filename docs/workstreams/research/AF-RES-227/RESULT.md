### 순정 관측

기본 64/64와 완전교차 표시 통제 112/112가 유효했다. 모든 기본 Git exit는 1, Breezy는 0이었다. 공개 시험 5개 suite의 종료 코드는 모두 0이었다. Breezy의 C extension 등 시험 skip은 [공개 로그](receipts/public.jsonl#L5)에 별도 표시된다. R1 grep, R2/R3 정확한 hunk, R2 개수, R4 원래 좌표를 각자의 단위에서 [직접 대조](receipts/public-crosschecks.json)했다. 두 Git 정책과 Breezy는 R2의 hunk 본문이 일치했고 Myers는 같은 hunk 헤더 아래 변경 본문이 달랐다.

진단과 반례를 같은 옵션에서 재생한 뒤 내부 판정과 Q1–Q7의 자체점검을 채운다.
