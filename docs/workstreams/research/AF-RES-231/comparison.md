# 조건별 링크 제안 (Q7; 검증된 개선 아님)

현재 본표의 A/B destination 및 답은 모두 미확인. #138641의 HTML duplicate label은 접근 보정으로만 기록. 따라서 특정 경로에 우선권을 주거나 개선/동률/수렴 0이라고 주장하지 않는다.

| 조건 | 카드 표현 | 순위 판단 | 내용 판단 |
|---|---|---|---|
| A 상위 자기 질문 | 원 raw 위치 보존; 자기 제외 첫 외부 적격; 없으면 공석 | 제외, 삭제 아님 | 원답과 자기 인용은 별도 |
| B 첫 대상 자기/재게재 | 원 배열 보존, 자기·동일 내용 분리, 편집 표시 시각/판 명시 | 동일 링크라도 중복 개수와 수렴 구분 | 별도 근거 없으면 직접 충족 아님 |
| A/B 동일 목적지·같은 답 | 한 URL + 두 경로 출처, 선택 답 ID | 수렴 1건(관측했을 때만) | 같은 답은 독립 증거 두 개가 아님 |
| 채택 답 | 채택 표시·득표·생성일 메타데이터 | 채택 우선, 없으면 score DESC/date ASC/id ASC | 채택은 계약 적합성 증명 아님 |
| 단독 결정성 요구 | tie 키와 방향 및 NULL 정책이 명시된 답 | 후보 적격과 별개 | 누락 시 조건부/불일치 |
| 공동 최고 전체 | rank peers 또는 max join, NULL 계약 검토 | 순위 관련도와 별개 | DISTINCT ON/ROW_NUMBER 단독 출력은 불일치 |
| 동률 계약 없음 | 허용 후보 결과 집합을 병기 | 추가 질의로 순위 수정 금지 | 가정 붙인 조건부, 명시된 부분만 직접 충족 |
| 원격 실패·빈 응답 | HTTP/has_more/array와 오류 분리 | 미관측 vs 관측 0 | 미확인; 추정 링크 금지 |

원작성자는 원행/열/업무 의미를 정하고, 중복 편집자는 유사 문제를 연결하며, DB 사용자는 입력의 동률/NULL/버전을 실행 검증한다. 세 역할의 성공 판정이 다를 수 있다. 검색 1질문+1답을 넘겨 보조 사례를 따라가면 다른 실험이다. 현재 API는 metadata와 body fetch도 분리될 수 있으므로 네트워크 요청 비용과 실제 본문 읽기 예산을 둘 다 기록한다.
