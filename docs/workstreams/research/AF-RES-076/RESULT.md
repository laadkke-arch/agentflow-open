## Q7. 구축, 사용량, 반복

S와 E의 첫 카드 구축은 같은 원문 20회·958,588 B를 실제 공유 취득했다. 별도 방식으로 운영한다면 각각 그만큼을 구축 비용으로 계산한다. L은 주소 직렬화 2,383 B, S는 5,275 B, E는 7,555 B였다. 고정판과 전송 주소를 확인하는 공용 연구용 파일 8,423 B와 캐시 본문 저장량은 별도다. 구축 벽시계 구간은 약 117초였으며 원문 열람, 카드 논의 및 파일 작성의 흐른 시간이다. 창에 보인 단어와 기계 스캔 단어를 분리했고 실제 사람의 접근·활동시간은 측정하지 않았다. [구축 지문과 시간](evidence/card-seal.json) · [구축 수치](evidence/build-fetches.jsonl) · [비용 원장](costs.csv)

빈 캐시에서 세 방식 모두 요청당 HTTP 3회였다. 자연군 평균 본문 전송은 L 31,565.0 B, S 99,673.2 B, E 32,762.7 B다. 교정군은 L 27,430.3 B, S 29,311.5 B, E 85,282.7 B다. 자연군과 교정군의 비율을 고정하면 전송량은 `구축 B + N × 그 층의 빈 캐시 평균 B`다. 이 관측에서 L은 두 층 모두 구축 비용과 기울기가 작아 양의 N에서 S/E와 교차하지 않는다. S/E는 구축량이 같고 자연 요청 비율이 45.55%인 조합에서 관측 기울기가 같다. 비율이 더 높으면 E, 더 낮으면 S의 평균 전송량이 작다. 라이브 요청 표본의 분포를 그대로 적용한 산술이다. [비용의 12개 합계 행](costs.csv)

즉시 같은 요청을 반복하면 관측된 HTTP 전송은 0 B 및 캐시 읽기 3회였다. 같은 원문 집합을 유지한다는 가정하에 첫 비용 뒤에 추가 전송량이 붙지 않는다. 20개 원문 전체를 958,588 B로 사전 채워 유지하는 별도 가정에서는 전송량만 비교할 때 두 층을 절반씩 섞은 빈 캐시 L의 평균 약 29,497.7 B에 대해 32.50회에서 같고 정수 33회부터 역전한다. 요청 수로는 20/3 뒤인 7회부터다. 전체 캐시의 수명·HTTP 비용·저장 관리와 사용자 분포는 미측정이다. [합계와 캐시 저장량](costs.csv)

실제 짧은 응답은 D07 900 B, 큰 응답은 X03 330,991 B였다. NP03/S는 큰 파일을 열어 부적격 창을 보는 데 요청 합계 335,296 B를 받았다. 총 접근은 빈 캐시 HTTP 108회, 즉시 반복 원문 캐시 조회 108회였다. 요청 전체 최대 335,296 B·415단어를 기록했다. 본문 payload만 계산했으며 프록시·응답 헤더·네트워크 패킷 비용은 미측정이다. [라이브 원장](fetches.jsonl) · [예산 검산](evidence/audit.json)

[길이와 레이아웃 원절](https://github.com/python-pillow/Pillow/blob/693df7b42c666f88c719f9973be0ad71607328e0/src/PIL/ImageFont.py#L298-L363) · [NP01 원 요구](https://github.com/python-pillow/Pillow/issues/6871)

CSS는 `visibility: hidden`으로 상자의 자리와 요소를 유지하며 출력만 제한할 수 있다. `display: none`은 상자 생성에 관여한다. 이 차이는 렌더링 층에서 유지할 상태를 표시하는 예이고 접근 제어는 별도다. 도서관 MARC 245도 제목 그대로의 `$a`와 정렬 때 무시할 글자 수를 분리한다. 앞의 관사를 출력 문자열에서 삭제하면 보존해야 할 원 제목을 바꾸게 된다. 정렬용 파생값과 원값을 따로 유지한다는 원리는 관계 표 문제로 옮길 수 있다. MARC의 지표는 SQL NULL 배치를 다루지 않는다. [CSS visibility 원절](https://github.com/w3c/csswg-drafts/blob/ccb66ec19e37a98ac26c16f5474f1011c93cb05b/css-display-3/Overview.bs#L1516-L1562) · [MARC 245 두 번째 표시자와 $a](https://www.loc.gov/marc/bibliographic/bd245.html)
