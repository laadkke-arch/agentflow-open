# AF-RES-036 집계·비용 해석 계약

이 파일은 N/H 수집 중이며 48결정과 기준판정이 작성되기 전에 고정한다. 초기 SCOPE·reading-plan의 사례·목적·순서를 바꾸지 않는다.

## 결정 칸과 채점

주 비교는 같은 case의 BN→BNH이다. B→BH와 B→BN을 보조로 낸다. 각 보기의 행동은 KEEP/REPLACE/HOLD이고, 목적·대상·필요 판을 원 인용에서 고정한다. '교체'는 같은 목적을 위한 다른 도착지가 필요하다는 판단이다. 검증된 대체 URI가 있는지는 별도 필드다. 단지 최신판을 선호한 이유는 정답 기준이 아니다.

기준판정 confirmed KEEP에서는 KEEP=옳은 유지, REPLACE=오교체, HOLD=보류다. confirmed REPLACE에서는 REPLACE=옳은 교체, KEEP=잘못 유지, HOLD=보류다. 기준 HOLD/UNRESOLVED인 모든 칸은 미확정으로 따로 세고, 판독자가 똑같이 보류해도 정확도 분자에 넣지 않는다. 전체 12행 분모와 confirmed 조건부 분모를 동시에 표시한다. 목적 층이 애매하다는 표시는 시간 의도가 명시되지 않았다는 뜻이며, 원문의 최소 목적 자체가 충분히 명확하면 자동 보류하지 않는다.

행동이 같은 경우와 이유/대체주소만 풍부해진 경우를 구별한다. 이 연구는 판단 칸의 행동 일치와 근거절만 비교하며 실제 사람의 클릭 피해·작업 완수·정답의 객관적 참값을 측정하지 않는다. 단일 내부 모델계열·사례12·각view1판독이므로 통계적 일반화나 인과효과의 추정치를 만들지 않는다.

## 노출과 민감도

1. 전체12의 사전 고정 새 문맥 판독.
2. 목적지 사전 노출 G06/R04 제외(분모10). 표본을 새 것으로 교체하지 않는다.
3. 같은 프로젝트의 다른 소비자 문서 또는 다른 사례가 같은 목적지/대상을 설명하는 간접 단서 제외. 단순한 같은 도메인만으로 중복이라고 하지는 않는다. 최종 case-overlap.json에 관계·근거를 넣는다.
4. N 카드 자체에 과거판·새판 관계가 이미 서술된 사례 제외. 단순한 판 번호 표기와 판 간 관계의 설명을 구분하고, 더 보수적으로 판 번호만 있어도 제외한 값은 별도 낸다.
5. 판독 이유가 제공되지 않은 배경 사실에 의존하거나 카드 작성자의 권고/해석이 들어간 경우 제외. B의 한국어 최소 목적은 사전 작성자의 번역·해석임을 표시한다. 이 목적 문장까지 모두 '해석'으로 제외하는 가장 엄격한 민감도는 분모0이 될 수 있으며 '해당 없음'으로 보존한다.
6. 기준판정이 추가 자료 없이 동일 발췌만 의존하는 사례 제외. 판정자와 수집자가 같은 연구팀인 사실은 다른 절을 추가 읽어도 사라지지 않는다.

각 독립 필터 및 주요 결합 필터의 분모를 기록한다. 분모0은 효과0의 관측이 아니다. 새 문맥에는 다른 보기·수집 메모·정답·prior 연구를 주지 않는다. 실제 입력/출력 hash와 순서·작업자·선행노출을 보존한다.

## 비용 단위와 두 번째 요청의 모의 비교

실제 취득 비용은 요청 원장의 body bytes·저장 bytes·GET 호출·redirect exchange·실패·재시도·elapsed 합이다. 동시 요청 경과의 합은 노동 시간이나 벽시계가 아니다. 압축 전송 wire bytes와 사람 노동/모델 요금은 미계측이다. 임시 archive/전체HTML의 디스크 바이트와 원격에 보존한 excerpt/card 바이트를 나눈다. 물리 fetch와 공유 참조의 논리 사용을 나눈다.

2회차는 우선 **모의 재취득**으로 만든다. 실측 1회차의 같은 URL/동일 응답 hash/본문 크기가 유지된다고 가정한다. C1은 B 문맥+href만, C2는 B+H+H provenance를 보관한다. 둘 다 동일하게 현재 증거를 새로 확인해야 한다. C0의 제품 최초 발견 비용은 이 실험의 표집 검색비로 대체하지 않는다.

두 비교 과업을 분리한다. (a) 원 최소 목적의 현재 판정: N만으로 해결될 때 두 구성 모두 같은 현재 조회를 하며 H 재취득 비용을 C1에 억지로 추가하지 않는다. (b) 동일 N/H 입력의 재구성: H가 요구된 경우 C1은 그 원자료를 다시 취득하고 C2는 저장된 정확한 H bytes를 읽는다. (b)는 현재 판정에 H가 유용했다는 관측이 아니며 증거 재구성 요구의 조건부 계산이다.

예산은 참조당 최대2회 명시적 retrieval operation, 각30초라는 SCOPE를 유지하고 HTTP exchange 수(redirect 포함)를 별도로 센다. 엄격하게 exchange≤2로 해석한 예산 충족 여부도 낸다. 여러 현재 문서·PDF·소스가 있어야 N을 복원하는 경우 2회 안에 재구성됐다고 하지 않는다. 탐색 과정에서 실패한 중간 요청을 이미 주소를 아는 재생에 그대로 강제하지 않는다. 대신 C1의 재발견/경로 선택 비용을 미측정으로 표시하고, URL을 미리 안다고 가정한 계산은 C1의 낙관적 하한이다.

같은 과거 archive의 두 참조는 물리1회/논리2회로 센다. 저장 excerpt만으로 복원하는 C2의 로컬 읽기는 네트워크0이지만 판독 노동0이 아니다. 두 번째 응답 상태·시간·bytes는 실측하지 않았으므로 실제 성공/시간 절감으로 보고하지 않는다.
