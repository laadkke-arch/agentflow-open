<h1><span class="header-section-number">1</span> Introduction</h1>
<p>The <em><a href="https://bioconductor.org/packages/3.11/GenomicRanges">GenomicRanges</a></em> package serves as the foundation for
representing genomic locations within the Bioconductor project.
In the Bioconductor package hierarchy, it builds upon the
<em><a href="https://bioconductor.org/packages/3.11/IRanges">IRanges</a></em> (infrastructure) package and provides
support for the <em><a href="https://bioconductor.org/packages/3.11/BSgenome">BSgenome</a></em> (infrastructure),
<em><a href="https://bioconductor.org/packages/3.11/Rsamtools">Rsamtools</a></em> (I/O), <em><a href="https://bioconductor.org/packages/3.11/ShortRead">ShortRead</a></em> (I/O &amp; QA),
<em><a href="https://bioconductor.org/packages/3.11/rtracklayer">rtracklayer</a></em> (I/O), <em><a href="https://bioconductor.org/packages/3.11/GenomicFeatures">GenomicFeatures</a></em>
(infrastructure), <em><a href="https://bioconductor.org/packages/3.11/GenomicAlignments">GenomicAlignments</a></em> (sequence reads),
<em><a href="https://bioconductor.org/packages/3.11/VariantAnnotation">VariantAnnotation</a></em> (called variants), and many other
Bioconductor packages.</p>
<p>This package lays a foundation for genomic analysis by introducing
three classes (<em>GRanges</em>, <em>GPos</em>, and <em>GRangesList</em>),
which are used to represent genomic ranges, genomic positions, and groups
of genomic ranges. This vignette focuses on the <em>GRanges</em> and
<em>GRangesList</em> classes and their associated methods.</p>
<p>The <em><a href="https://bioconductor.org/packages/3.11/GenomicRanges">GenomicRanges</a></em> package is available at
<a href="https://bioconductor.org" class="uri">https://bioconductor.org</a> and can be
installed via <code>BiocManager::install</code>:</p>
