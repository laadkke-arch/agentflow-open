# AF-RES-003 독립 반론 검토

상태: **별도 검토자의 원문 대조와 수정된 통합 원고 검토 완료**. 검토한 내용은 §4의 파일 해시로 한정한다. 저장안 채택, 사용자 효용 또는 실제 조합의 성공 판정이 아니다.

## 1. 검토의 독립성과 범위

- 검토자: 이번 작업의 별도 하위 작업자 `independent_review`.
- 기준: `9d728dfe2c2f3a13d9995b5fdc14a252aeddfdad`의 작업 규칙, 연구 운영 규칙, 연구 브리프와 AF-RES-003 범위.
- 검토 대상: 저장 A(링크+설명), B(대상+출처), C(범위 있는 주장+근거)의 비교에서 발생할 과잉 추론과 불필요한 분해. 최종 스키마·DB·검색기를 설계하지 않는다.
- 별도 역할의 원문 대조이며 블라인드 판정, 새 사용자 웹 Pro 대화의 인계 시험, 실제 사용자 시험, 제품 실행 검증이 아니다. 이전 대화·작성자의 결론을 전혀 보지 않았다는 의미의 독립성은 주장하지 않는다.
- 외부 원문 재열람: 2026-11-19 15:42–15:44 UTC (한국 2026-11-20 00:42–00:44). 아래 여섯 자료의 관련 절을 직접 열어 읽었다. 본 조사자가 이미 읽은 자료와 중복되므로 전체 원문 수에 여섯 개를 추가하지 않는다.
- 통합 원고의 수정 전·후를 읽고 세 출처 원장과 대조했다. 총 33개 원문 모두를 이 검토자가 독립 재열람한 것은 아니다. V03의 §§1.3, 2.3, 3.1은 최종 기록 직전 다시 열어 직접 포착·순효과·추출 이후 세션 유지 설명을 재확인했다.

## 5. 남은 이견과 다음 확인

- 저장 구조의 표현력과 운영상 누락 위험은 별개다. 정규화된 C가 항상 더 정확하거나 관리 비용이 작다는 실측 근거는 없다.
- 제품 identity는 목적·범위가 있는 카탈로그 판단이다. 같은 제품군 아래 범위를 나누는 안과 개별 배포 대상을 나누는 안을 모두 보존할 수 있다.
- 관측 시점이 새롭다는 이유만으로 옛 버전의 설명을 철회하면 안 된다. 서로 다른 범위의 설명은 둘 다 유효할 수 있다.
- 여섯 원문의 사실 대조는 데이터 구조가 방지해야 할 오류를 좁힌다. 실제 추천 효용·사용자 이해·운영 비용을 검증하지는 않는다.
