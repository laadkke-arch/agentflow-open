# 조건별 링크 카드
## 1. 웹 제목·짧은 caption — 직접 규격만
조건: browser에 자연 분리 선택을 맡김, 짧은 제목, 폭/폰트 고정 안 해도 됨. 먼저 [CSS Text4 §5.4](https://www.w3.org/TR/2026/WD-css-text-4-20260814/#text-wrap-style)와 §5.1/§6. 직접 규격의 목표/강제 줄/5줄/10줄을 안내. 정확한 결과를 원하면 [Chromium fixed width bisect](https://github.com/chromium/chromium/blob/92e20e6bf834eefeaf9ea656c73bfcecccc49160/third_party/blink/renderer/core/layout/inline/paragraph_line_breaker.cc), [WebKit cost and count](https://github.com/WebKit/WebKit/blob/fcbbc8e862aa3253991de9d5e0bd87c77bc9e69e/Source/WebCore/layout/formattingContexts/inline/InlineContentConstrainer.cpp), pinned WPT and measured geometry. P01 link only if custom global scoring/print-like justification is a requirement. Counterexample [3,3,3] W8 tie; browser specific tie needs implementation rather than more general paper. 
## 2. 인쇄 본문 — 조판 원리도
조건: 양끝 정렬·글루 조정·금칙·하이픈·품질 vs 비용, 문단 전체. First [Knuth–Plass 1981 pp1123–29, 1155–62](https://gwern.net/doc/design/typography/tex/1981-knuth.pdf), then [TeX code L2317–46](https://github.com/TeX-Live/texlive-source/blob/aa25ef99712b0d281b8df62f0e288818b5169da7/texk/web2c/tex.web#L2317-L2346). For multiple incomparable metrics [Holkner §3.2/3.3.6](https://gwern.net/doc/design/typography/tex/2006-holkner.pdf); page variants [Mittelbach §2.1.2](https://matrix.latex-project.org/publications/2019-FMi-coin12165-final.pdf). C1 fixed k balance vs free last+glue incompatible choices; don't reuse K-P to claim CSS exact. Need actual measured advances, stretch, shrink, penalty, tolerance, final glue; missing means conditional not exact.
