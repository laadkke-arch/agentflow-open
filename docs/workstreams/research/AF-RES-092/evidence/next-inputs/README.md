# 후속 실행 입력의 출처와 지위

- J1-reference.json: R0-J1 첫 JSON 예를 API 본문에서 추출. 원저자·GUID·라이선스는 ../r0/J1.json.
- J3-reference.json: R0-J3의 세 키 입력을 한 줄 JSON으로 옮김.
- P2-original.qmd: R0-P2 코드 블록을 HTML unescape해 추출. 원저자·GUID·라이선스는 ../r0/P2.json.
- P2-sealed-macros.qmd: 원 Qmd 본문 앞에 사전 봉인한 두 빈 재정의를 추가한 연구자 파생 입력.
- P2-answer-macros.qmd: 같은 위치에 공개 최초답의 [2]{} 재정의를 넣은 별도 파생 입력. 답 저자/최초 GUID는 ../outcomes/answer-first-receipts.json의78314393.
- P3-reader-minimal.md: R0의 네 footnote 정의를 활성화하려고 연구자가 첫 줄 footnote 참조를 추가한 **합성 최소 입력**. 원 전체 문서가 아니며 bib/CSL도 포함하지 않는다.

이 파일들은 명령과 입력을 구체화하기 위한 실행 대기 자료다. 현재 바이너리로 변환하거나 A/B 근거에 소급 사용하지 않았다. 자체 생성/추출 사본을 외부 원자료 수에 더하지 않는다. 원 사용자 실행을 대신하지 않는다.
