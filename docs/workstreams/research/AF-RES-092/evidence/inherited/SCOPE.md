## 공개판·가림

R0는 끝 페이지까지 조회한 이력 중 가장 이른 확인 가능한 **본문을 가진 공개 리비전**이다. R1은 생성 뒤 30일 이내 마지막 확인 가능한 본문 리비전이다. 원 문자열은 API의 HTML 그대로 UTF-8 SHA-256, LF 정규화 SHA-256을 별도로 계산한다. Markdown과 HTML 해시를 같은 척도로 비교하지 않는다. 의미 코드는 바이트 지문과 별개다.

이력 전체를 기계적으로 수집·해시할 수 있으나, R0 사전 판정 커밋까지 모델에게 출력하는 것은 R0 본문 및 리비전 메타데이터(본문 존재 여부·시각·작성 주체·롤백)뿐이다. R1 의미·답·채택·댓글은 그 커밋 후 연다. 이 제한은 접근통제나 독립 이중맹검이 아니다. root가 두 판을 읽으므로 기억효과가 남고, 역순 자체 점검도 독립 판독으로 세지 않는다. 보조 조사자는 매뉴얼·플랫폼·타 분야만 읽는다.

creation_date와 R0 시각이 같아도 grace-period 내 수정이 합쳐질 수 있다. 동시대 별도 바이트 증거가 없으면 `strict_initial_bytes=unknown`이다. 모든 페이지를 확인했을 때만 별도 본문 수정 없음과 R0=R1을 쓴다. 30일 밖 본문 수정, 제목·태그 전용, rollback, 작성자/타인 편집은 따로 센다.

## 고정 후보와 실행 가정

jq `jq-1.7.1` → `71c2ab509a8628dbbad4bc7b3f98a64aa90d3297`, `docs/content/manual/v1.7/manual.yml`: select L1182–1198, map L989–1049, sort_by L1510–1551, group_by L1553–1571. Pandoc `3.1.11` → `c3038dcd54152c4e18e49db31676b79ee7cc29b2`, `MANUAL.txt`: --metadata L647–658, --template L752–762, --lua-filter L623–645, --standalone L744–750. 정확한 링크·동작·반례는 `candidates.csv`에 고정한다.

각 후보 **하나**가 제공하는 동작을 판정한다. CLI의 보통 파일/stdin/stdout, 형식 reader/writer 선택은 공통 배경이다. 다른 고정 후보를 명시적으로 더하거나 외부 프로그램을 붙여 얻는 성공은 후보 단독 충족으로 세지 않는다.

- jq는 후보의 인수 안에서 필드 접근·리터럴·기본 산술·비교·불리언·기본 객체/배열 구성만 허용한다. 배열 순회로 이미 모든 변환을 외부에서 끝낸 뒤 select(true)를 붙이는 식의 무의미한 후보는 금지한다. 추가 named helper, reduce, 재귀, 다른 후보 호출, 임의 전처리·후처리는 범위 밖이다. `map`의 인수는 구성 코드지만 문서화된 매핑 자체에 속하며, 구체적 구성이 증명될 때만 충족이다.
- Pandoc --template는 사용자 템플릿이 필요한 경우 그 내용을 명시한 조건부 링크다. 암묵적으로 --standalone을 켜는 동작은 후보 고유 의미로 허용한다. --lua-filter는 Lua 파일을 실행하는 기능이며 임의 요구를 자동 해결하지 않는다. 사용자 Lua 구현을 별도 조건으로 남기고, 문서의 AST 처리 범위까지 입증할 때만 조건부 판정한다. --metadata는 키/값 설정이지 임의 본문 편집 기능이 아니다. --standalone은 출력 wrapper이며 특정 형식에서는 이미 자동이다.
- 실제 질문자의 사용판·OS·writer·실행 성공을 참조판에서 추론하지 않는다. 실행이 없으면 문서 적합 판정으로만 보고한다. 좋은 실제 답이 후보 밖이어도 풀을 사후 확대하지 않는다.

## 조건과 판정

C1은 원문 주목적, C2는 원문이 말하는 독립된 제약이다. C2가 없으면 `해당 없음—명시 제약 없음`으로 쓰며 임의 제약을 만들지 않는다. 입력 구조·보존값·출력·도구판·환경·명시 금지는 위치와 연결하고, 해법명 노출은 요구와 다른 칸에 둔다.

후보별 필수 판단 상태는 `충족 / 명시 반박 / 범위 밖 / 미확인`이다. `충족`에도 추가 사용자 코드/자료가 필요한 `조건부` 반환을 분리한다. 원문과 문서가 직접 모순이면 명시 반박, 해당 후보의 기능 경계를 넘어선다면 범위 밖, 필요한 사실/본문/절이 없으면 미확인이다. C1 일부만 맞고 C2를 못 맞추면 완전 충족이 아니다. 종합 반환은 정합·오답·조건부·보류로 쓴다. 모든 행에 원문 위치, 고정 절, 실패 기준과 다음 최소 입력을 둔다.
