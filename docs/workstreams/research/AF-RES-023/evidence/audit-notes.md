# 내부 별도 감사 기록

감사자는 `/root/audit`, 부모와 같은 모델 계열이다. 파일·Git 변경 없이 읽었으며 외부 독립 심사나 인간 검토가 아니다. root와 감사자는 원문/키에 노출되어 있다. 첫 판독자에게 감사 결과나 키를 보내지 않았고, 보강 판독자는 새 문맥에서 지정 카드만 읽도록 했다.

## 발견해 수정한 항목

1. SW02 v1의master URL과404 main 관측 경로가 달랐다. 최종 공통 입력을 실제 관측 URL로 맞췄다.
2. MB04의 현재target이saved UUID와같다는표시,MB06의전체현재UUID가보기마다균등하지않았다. 모든표현의공통조회에같은값을명시했다.
3. ②에제안·변경·사후이유가일부섞였다. v3에서역사필드와③관계/판단을분리했다.
4. WD-C01의required_function_version은자료부족이아닌normalizer누락이었다. P910 category 목적을채웠다.
5. v3③의MB05생존target/SW03정정후6.2.4는원문에는있지만카드가생략했다. 감사자가collector before/after와source위치를재확인했다. v4에서2건만재판독하고나머지16건은해시/공통질문동일성을검사해이어받았다.

## 최종 읽기전용 확인

감사자는 RESULT의처음4표 데이터행18/54/3/7,맨끝약점3행,원문38/사건18/외부독립소비자7/비교54, v3 48+v4 6계보를확인했다. MB03①의WRONG_FOR_REQUEST는B4관계미검증단서를달면서retained2:32를선택한답의범위와맞는다고판단했다. ROR06②는현재정답단정이아닌역사판제한선택이므로HISTORICAL_ONLY가맞는다고판단했다. 추가실질오류를발견하지못했으나원자료의미확인과REVIEW_READY_WITH_GAPS는유지했다.
