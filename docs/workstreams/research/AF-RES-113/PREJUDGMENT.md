# AF-RES-113 추가 열람 후·원전 대조 전 판정 봉인

이 문서는 추가 열람 3회와 두 독자의 판정이 끝난 뒤, 원 논문 방법·구현 본문·사후 외부 분야를 열기 전에 고정한다. 원 요청 6건, 공통 시작 절 4건과 공석 2건, 예정 자리 12개를 그대로 유지한다.

## 사전 결론

A는 독립 예제 링크 2개, B는 원저작 링크 1개가 노출되었다. A의 두 링크는 본문에 도달했다. B는 초록·구독 미리보기에 도달했으며 방법 본문에 도달하지 못했다. 실제 추가 열람은 각각 3,000 유니코드 문자와 그림 0개다. 나머지 9자리는 링크 또는 시작 문서가 없어 공석이다.

원 요청의 변경과 보존조건을 함께 만족시키는 새 구현 선택 0개, 새 판별 시험 0개다. A의 R4/R5는 요청 목표와 맞지 않는 초반 예제 내용이다. B의 R3은 원래 알고 있던 대역폭 선택을 바꾸기에 불충분한 초록이다. 이는 두 경로의 일반적 우열이나 무효를 뜻하지 않는다. 양쪽 추가 본문을 모두 읽을 수 있었던 요청은 0/6이다. 여섯 요청의 쌍별 판정은 모두 비교불가다.

새 자동 문맥의 판독자는 A와 B가 서로 다르다. 각 독자는 같은 원글·공통절·기지안과 자기 경로의 추가 내용만 읽었고 외부 열람·목표 라이브러리 실행은 0회다. 각 독자가 실제 읽은 파일·범위·지문은 evidence/arms/{A,B}/judgment.json에 있다. root는 두 경로를 종합해서 읽었으므로 root 자체를 독립 독자로 세지 않는다. 인간 설계자의 학습효과·후속 채택은 측정하지 않았다.

## 이미 봉인한 선택·시험

13개 기존 안/구별 입력은 evidence/common/baseline-tests.jsonl에 고정돼 있다. R1의 디코더·표본율·블록 패딩·자원 해제, R2의 원글이 이미 제안한 NaN 누적, R3의 스칼라/개별 대역폭 책임과 시간 제외 조건, R4의 차원 검사·정상 차원 보존, R5의 경계 값·footprint 방향·분해가 여기에 속한다. 이 목록을 추가 링크의 새 시험으로 다시 세지 않는다. R6의 원글에 이미 있는 dtype별 roundtrip 회귀도 새로운 시험이 아니다. 원 입력이 없는 항목은 예상값 또는 조건부 구성 입력이며 실행 결과가 아니다.

## 다음 대조에서 반박할 내용

1. 현장 사용자 관점: 첫 연결 예제의 초반이 원 오류를 직접 해결하지 못해도 뒤 절에는 작동값·예외가 있는가? 뒤에서 찾은 답은 원래 3,000자 경로 성과와 구별한다.
2. 구현자 관점: R1 inline STFT의 stream frame/hop과 분석 기본값이 실제로 맞는가? R5 min/ignore 설명의 maximum 문구가 실제 구현의 중립 경계 값과 맞는가? 현재 판의 해결을 2023년 원 상태로 소급하지 않는다.
3. 원 분야 저자 관점: R3 논문의 표본 그래프·정규화 가정이 빈 이웃 행의 스칼라 예외 처리까지 정당화하는가? 원전 전체를 읽고도 목표 차이를 지지하지 않으면 새 선택은 0으로 유지한다.
4. 분야 전이: 연속·규칙 표본, 시불변성, 픽셀 중심/면적, 반사 경계 가정이 불규칙 입력이나 시간 방향에서 깨지는 사례를 별도 검증한다. 외부 원전은 발견 링크나 두 번째 클릭 수에 합치지 않는다.

이후의 정정·보류는 사후 검증 원장에 이유와 새 근거를 남긴다. 원 판정과 시점은 이 커밋으로 보존한다.
