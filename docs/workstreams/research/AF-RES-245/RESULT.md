## Q1. 주석 정의와 표집 (A01–A07)
[원논문 §3.1–3.2](https://program.ismir2020.net/static/final_papers/127.pdf)와 [고정 README](https://github.com/fosfrancesco/asap-dataset/blob/afc815c75c42e83a79c03feb6da8a35e77d4c6b8/README.md), [metadata](https://github.com/fosfrancesco/asap-dataset/blob/afc815c75c42e83a79c03feb6da8a35e77d4c6b8/metadata.csv), [JSON](https://github.com/fosfrancesco/asap-dataset/blob/afc815c75c42e83a79c03feb6da8a35e77d4c6b8/asap_annotations.json)을 대조. MIDI score는 MusicXML에서 변환된 악보의 시간축 초, performance는 연주의 시간축 초이며 절대 악보 beat index나 동일한 물리적 시계가 아니다. b=beat, db=downbeat(마디 첫 박), bR=정확 위치 확정 어려운 beat(예: 중간 pickup, 루바토, 장식음; 개별 원인은 별도). 같은 시간의 key/meter marker는 하나의 라벨에 쉼표로 붙는다. 원발행의 알고리즘은 score annotation 근방 20ms 안의 음 대응과 performance onset 중앙값, 쉼표 보간, 수동 확인/약 3% 문제 마디 교정을 설명한다. 이것이 음별 일치의 독립 정답을 보장하지 않는다. 반복은 펼친 score와 연주 순서의 대응이 전제; 모든 원래 인쇄 악보가 그대로 단조라는 뜻이 아님.

## 비용, 대안, 추가 검증
선형 map O(1)/query; 2D full DP 시간·메모리 O(NM) (dense matrix 보존 가정), band가 가능한 셀을 줄여도 실제 메모리 절약은 구현 확인 필요. bounded band DP, multiscale/coarse-to-fine, streaming prefix, partial/repeat graph, 3D voices는 서로 다른 목표·대가. Online은 미래 끝점 및 backtracking 불가/지연 허용을 명시; offline 전체 정보와 동일 성능 가정 금지. 추가 제약은 경로의 다양성을 희생하고 정보 부족을 해결하지 못할 수 있으므로 confidence/ties/abstain 계약. 
재현 입력: ASAP pinned SHA/cohort.csv 2쌍 MIDI+원음 사용 가능 여부·라이선스 확인, 각 crop offset 정의, sample rate/hop/window/feature normalization/feature version(예: 22050Hz, hop220 sample 약9.977ms는 제안), score MIDI 음향 합성 또는 symbolic chroma의 출처, 비용 metric/chroma+onset weights, exact endpoint/subsequence/graph policy, band radius frame 단위 고정, path→beat interpolation과 동률 집계 규칙을 먼저 별도 봉인. 기존 14개 주석은 이미 노출됐으므로 새 독립 구간을 표집. 각 case 별 local C 또는 checksum, feature timestamps/shape, D[-1,-1], 모든 최적 경로/정해진 tie policy, beat별 예측/잔차 및 run version/command/exit code를 원영수증으로 저장; 50/100ms 기준의 affine 대비 비교. Control 입력은 paths.md의 행렬 그대로; 라이브러리 실행/feature extraction은 이번 범위에서 미실행. 라이브러리 설치/환경 변경은 별도 승인. 
원장 분모: 28 records, counted 24 work/case units(S5/M7/A6/I4/D2), 9 lineage IDs. M05는 직접 읽은 공개 평가 리소스 안내(실제 WP 파일 미열람); M04/M07 PDF 화면 실패에도 본문 성공; 이를 모두 보수적으로 제외하면 M4, 전체21, 음악 하한 5 미달. M05와 M07만 제외해도 M5 전체22; M04의 텍스트 판독은 산입 근거. ASAP의 A03–A06는 서로 다른 4개 연주쌍이지 별도 논문/계보 아님.
