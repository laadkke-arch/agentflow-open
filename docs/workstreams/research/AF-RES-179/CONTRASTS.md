## 반례 3 — 문법은 정상, 값은 NULL
U1 §4.10/§4.20 provides semantic examples: `SELECT '{"a":null}' ->> '$.a'` => SQL NULL; `SELECT '{"a":2}' ->> '$.missing'` => SQL NULL by rule. `json_type(...,'$.a')` => SQL TEXT 'null' for present JSON null, SQL NULL for absent path. Python None should be distinguished from exception, invalid JSON, string "null", and empty result set. These are document expectations, not local runs. ## 경쟁설명 우선순위와 비용
Publisher sees features/opt-in and versions; package producer sees build targets, bundled library and backports; Django consumer sees actual interpreter, loaded module, extension registration, migration SQL/values. Preserve all three, no single authority wins for every question. Option A links + conditional sentence (low capture, low confidence); option B package + per-connection operation evidence (extra lookup, no raw data retention mandated); option C request a minimal typed probe at time of use (higher user effort, resolves current conditions); option D full migration/legacy BLOB/invalid and NULL data suite only when purpose requires it (cost larger). None establishes prior first use, and no decision on product DB/collector/output schema. Avoid installing unsupported historical Python, overwriting production DLL or using global loader override just to get JSON; isolate and verify supported artifact/ABI/bitness, backups, source authenticity, and repeat actual app path.
