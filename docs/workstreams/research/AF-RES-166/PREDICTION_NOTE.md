# ③ 비교 규칙 봉인
이 커밋은 향후 후속 원전 재개를 위한 규칙·조건부 예측의 고정판이다. 이미 본 최초 본문/검색 스니펫/스레드 답변의 결과는 노출층. 자연층 확정 0, 무노출 실제 쌍 0, 독립 평가 0. 이 파일을 만들어도 사전 비교 적격으로 승격하지 않는다. 네 규칙을 각 12행에 적용했으나 구체적 불가 시 첫 결측을 기록했다. R1의 backfill은 R3과 동형일 수 있다. R2의 당사자 보류 권한/만료는 소프트웨어 readiness 실패와 동치가 아니다. R3은 실제 기상 제약을 eligibility로 옮기되 보장 슬롯을 원전이 부여하지 않으므로 별도 가정으로 표시. 결과 재열람은 다음 커밋.
