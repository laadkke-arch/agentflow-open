# 단계 2 · 입력 목록 영수증

2026-11-24 UTC, Codex Cloud Linux x86_64. Git 2.52.0, Python 3.12.14, curl 8.14.1. 명령은 이 저장소의 작업 브랜치에서 실행했다.

```sh
git clone --no-checkout --no-tags https://github.com/gsarti/divemt.git /workspace/af195-input/divemt
git -C /workspace/af195-input/divemt checkout --detach 934c4106001adeaa982a882d063f33ce0a398217
git -C /workspace/af195-input/divemt rev-parse HEAD HEAD^{tree}
git -C /workspace/af195-input/divemt ls-tree -r --long HEAD data/raw/ita.zip data/raw/tur.zip
(cd /workspace/af195-input/divemt && sha256sum data/raw/ita.zip data/raw/tur.zip)
git fetch --no-tags origin refs/heads/work/research-af-res-181:refs/remotes/origin/work/research-af-res-181
d=docs/workstreams/research/AF-RES-195
python "$d/extract.py" inventory --upstream /workspace/af195-input/divemt --prior-repo . --out "$d"
curl -fsSL --max-time 30 -o /workspace/af195-input/hf/main.tsv https://huggingface.co/datasets/GroNLP/divemt/resolve/9abd1d1cea118ad7a9946e7f1f5a1a29c2a01762/main.tsv
```

Git clone/checkout/fetch/rev-parse/ls-tree/sha256sum, inventory 종료 코드는 0이다. `02-inventory.stdout`는 추출기 원로그고 stderr는 빈 파일이다. `02-git-input.stdout`는 rev-parse/ls-tree/sha256sum 출력을 모았다. `02-hf-tsv.stderr`는 shell resolve 요청(22, HTTP 403)이다. 고정 트리 API shell 요청도 403, HF git ls-remote는 종료 128(CONNECT 403), 웹에서는 고정 메타데이터와 스키마가 열렸으나 고정 TSV resolve CDN 파일은 읽지 못했다.
