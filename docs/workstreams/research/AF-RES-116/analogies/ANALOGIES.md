# Q6 보조 비교: 부품 식별자와 기록관 위치 표지

## 범위와 관측 수준

이 파일은 자연 6사건의 A/B/C 실험에 들어가지 않는 보조 조사다. `/root/cross_domain` AI 하위 작업자가 2026-11-24 UTC에 공개 발행자 자료를 읽었다. 자연 사건, 공통 요청, 한 줄 문구, gold, 수신 기록을 읽지 않았다. 독립 인간 판독·수리 실행·기록관 방문·원 개발자의 채택·시간 절약은 관측하지 않았다.

확인한 것은 **위치를 가리키는 표지와 실제 적합성을 결정하는 조건이 갈리는 발행자 사례**다. Prusa에서는 식별자·모델·작업 단계·방향 조건을, Yale에서는 상자/폴더·개별 이미지·접근 조건·이관을 구분할 근거가 있었다. 단서를 추가하면 자연 실험의 성공률이 높아진다는 증거로 사용하지 않는다.

초기 조사에서 Yale 발행자 **항목 레코드와 finding aid의 교차 확인**까지만 수행했고 연결된 원 편지 facsimile은 403으로 열리지 않았다. 이 미관측은 그대로 남긴다. 후속 보조 조사에서는 Eisenhower Library의 공식 상자·폴더·항목 안내를 실제 공개 원문 PDF 두 종과 맞춰 읽어 원 항목 판독 결손을 별도 사례로 보완했다. 낭독본 1–2쪽과 보도자료 1쪽을 직접 렌더해 시각 판독했으며, 이를 Yale 편지 내용이나 자연 실험 관측으로 대체하지 않는다.

## 설계 대안에 주는 제한된 함의

**위치만 필요한 요청**에는 기관·판·상자/폴더 또는 부품번호를 포함한 시작 링크가 충분할 수 있다. 이때도 이번 자료는 실제 수신자의 도달률이나 시간 절약을 증명하지 않는다. 원장 AN-C01과 AN-C03은 위치 정보의 구체성을 보여 주는 예다.

**적용 가능성까지 묻는 요청**에는 단서와 함께 다음에 확인할 조건을 지정하는 안을 보존할 수 있다. Prusa의 방향·작업 단계, Yale의 원본/대체본·보관처처럼 위치와 별개인 조건이 원문에 존재했다. 이는 추가 검사 후보이며, 한 줄에 언제 얼마나 써야 유리한지는 자연 실험의 실제 노출과 판정을 통해 따로 판단해야 한다.

처음의 가설은 “정확한 부품번호 또는 폴더번호면 충분히 구체적인 안내가 된다”였다. 읽은 근거 때문에 **항목의 식별에는 유용할 수 있으나, 해당 상태에서의 사용·열람 적합성까지 보장하지는 않는다**로 한정했다. 특히 조립/보수의 단계 차이(AN-C02)와 특정 원본의 이관·제한(AN-C04)이 그 한정의 직접 근거다. 이는 정정된 해석이며 실험 효과 추정이 아니다. 후속 Eisenhower 원문 대조(AN-C08)는 번호가 정확해도 같은 폴더의 다른 원 항목이 서로 다른 속성을 드러냄을 직접 확인했다. FDR 공동 성명(AN-C09)은 발행자 자신이 비슷한 사본과 수정 흔적을 과잉 해석한 기존 식별에 반박한 자료다. 후자는 이번 작업자가 원본을 재감정한 결과로 격상하지 않는다.

## 자료와 개봉의 대사

`sources-analogies.jsonl`은 웹 open/find/click/screenshot, 직접 HTTP, 로컬 원문 이미지 확인마다 한 행을 갖는다. 누적 **67개 작업**은 웹 문서 작업 54회, 직접 HTTP GET 7회, 로컬 이미지 열람 요청 6회다. 이미지 요청 중 2회는 문맥 압축 뒤 결과가 보존되지 않아 내용 주장에 쓰지 않았고, 해당 두 쪽을 다시 열어 확인했다. 서로 다른 시작 URL은 37개다. 검색은 `discovery-queries.jsonl`에 별도 10회 호출·24질의로 기록했으며 검색 요약은 고유 저작 수에 넣지 않았다.

고유 산입은 **13개 발행자 저작**이다. 초기 10개는 Prusa 조립 설명서, 특정 Y축 교체 절차, 정기 보수 글, 360 viewer 안내, LOC finding-aid 사용 안내, Bell family finding aid, IKEA 부품 안내, Yale finding aid, Yale 전시 항목 레코드, Duke 연구 안내다. 후속으로 Eisenhower 항목 안내/주제별 finding guide 1개, Eisenhower 고별 연설 1개, FDR 관련 공동 성명 1개를 추가했다. 같은 연설의 낭독본과 보도자료를 **서로 다른 원 항목 2종이되 고유 저작 1개**로 보수 산입했다. 동일 설명서의 절, PDF와 HTML, 같은 전시의 해설, 반복 열람도 다시 산입하지 않았다. Yale 항목 레코드는 발행자의 목록 저작으로 산입했고, 원 편지 자체는 산입하지 않았다. 본래 지정된 자료 배당과 합칠 때 이 층 전체는 `cross_domain_supplement`다.

접근 실패와 대체 시도도 보존했다. LOC 최신 finding-aid 페이지와 Bell 원 항목은 403, 신 PDF 경로는 404였고, 공식 2015판 PDF의 행정 설명은 열렸다. 이후 세부 위치 조회는 429였다. Smithsonian 항목 페이지는 500/520, 다른 요청은 대상과 다른 Research Centers 페이지로 이동했다. Yale 항목 레코드는 열렸으나 연결 원 자료는 403이었고 공개 API 대체 경로도 실패했다. 오류 응답이나 대체 경로 시도에서 대상 내용을 읽었다고 기록하지 않았다. Eisenhower 공식 PDF 세 개는 HTTP 200으로 내려받았으며 원문 두 종의 3쪽과 finding guide 1쪽을 렌더해 직접 보았다. 읽지 않은 1월 7일 초안 PDF는 개봉에만 넣었다.

각 UTC는 해당 도구 묶음의 반환 뒤 실제 시계 관측값 또는 직접 HTTP 요청 시작값이다. 한 묶음 안 URL별 실행 순서는 따로 관측하지 않았다. 직접 HTTP 요청에는 측정 가능한 요청 시작 시각과 monotonic 경과 초를 기록했다. 성공한 Eisenhower PDF 세 개의 수신량은 6,416,882바이트이며 경과 합계는 약 27.7643초다. 이는 네트워크 수신 시간이며 읽기·분석·제작 시간이나 사람의 절약 시간이 아니다. 능동 준비 시간은 측정하지 않았다. `metrics-analogies.json`은 분모와 미관측 범위, `count-change-receipt.json`은 추가 전후 수치와 이유를 보존한다.

## 재검토 방법

1. `claims.csv`의 각 행에서 `source_rows`를 찾아 `sources-analogies.jsonl`의 URL·판·실제 읽은 절을 대조한다.
2. 자연 실험의 성공 분모에 이 보조 행을 합산하지 않는다. 문서에 제시된 예외와 실험에서 실제 발견한 예외도 합치지 않는다.
3. 실제 원문 비교를 재현하려면 `eisenhower/READING_NOTES.md`와 보존된 PDF·렌더를 먼저 연다. 공식 항목 안내의 NAID·상자·폴더와 PDF의 해당 쪽을 대조한다.
4. Yale 원 편지 내용이 필요한 후속자는 [Yale 원 항목][yalecatalog]의 Image 9/104를 열어야 한다. 이번에는 그 내용이 미관측이다.
