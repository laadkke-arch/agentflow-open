## 키와 판정

- 교통은 포함 효력일에 `calendar.txt`의 요일과 기간을 적용한 후 `calendar_dates.txt`의 1 추가와 2 제거를 승계한다. 두 정의가 모두 없거나 같은 키의 모순 예외면 보류한다. `routes.txt`에서 키를 확인하고 `trips.txt`의 고유 `trip_id`를 세며 `stop_times.txt`의 stop_sequence 정렬 stop_id·도착·출발 HH:MM:SS를 집합의 대응 근거로 쓴다. 24:00 이후 GTFS 시각을 같은 서비스일의 연장으로 유지한다. 빈 시간은 빈 것으로 남긴다. `frequencies.txt`의 실제 출발 횟수, 열차 실운행, 설치판 사용 이력은 별도 질문이다.
- 동일 키가 유효하나 그날 필터 결과가 비면 예정 0이다. 키 삭제는 `routes.txt`, `directions.txt` 또는 옛 패턴과 발행자 공식 대응이 확인될 때만 개명으로 연결한다. 다른 route/방향 대응이 미확인이면 보류한다. 새 trip_id는 1:1 정류순서·동일 일정 지문이 유일할 때만 재발급 대응으로 센다. 동일 지문 중복이면 집합 대응을 보류한다. 수 동일, ID 집합 동일, 서비스 동일, 변경 여부의 단위를 각각 보존한다.
- 시간대 키는 고정 UTC 순간과 IANA Zone 이름, 산식은 UTC→현지 변환이다. 오프셋은 부호 있는 초, 현지는 ISO 날짜·시각과 약칭의 순서쌍이다. 존재하지 않는 이름은 별칭 또는 개명 연결 근거가 없으면 보류한다. 관측 예시의 일치가 Zone/Link나 Rule의 동등성을 보증하는 범위는 정해진 순간뿐이다. 반복되는 현지 벽시각을 UTC로 되돌리는 것은 별도 질문이다.
- 같은 판독 질문으로 옛 값의 복원 여부와 다음 연속판에서 옛 이유의 유지 여부를 각각 판정한다. 수와 집합, 오프셋과 현지 표기 각각을 별도 요구로 둔다. 독립 판독은 CSV 조인/SQLite의 공통 CSV와 zic 출력/zdump·명시 파일 Python의 공통 TZif를 공유한다. 도구 버전·절대 경로·해시·독립 경계와 선별 중 누락을 기록한다. 판독의 불일치, 잘못된 키·해시·판, 자료 결손은 미확인이다.

## 보기와 계측

- 각 8개 요구의 세 보기에 공통 판 쌍 규칙·선별 기준과 동일한 원본 조회 권한을 준다. V0은 발행자의 현재 진입 URL과 해당 질문에 맞춘 짧은 이유, V1은 옛 원 URL·판과 멤버 해시, V2에는 옛 날짜/UTC·키·단위·산식·입력행과 사용 범위 영수증을 더한다. V2의 현재값·판정 필드는 비운다. 새 원본 조회와 실제 판독을 거쳐야 유지·교체를 기록할 수 있다. 옛판 재계산은 귀속된 원본 또는 질문에 충분한 옛 입력 영수증과 독립 확인이 필요하다. 발행 URL만으로 옛 답 가능과 다음판 유지라고 하는 판정은 별도의 지름길 대조로 계산한다.
- 호스트 정책을 그대로 쓴 원격 URL GET을 1회씩 시도한다. 한 보기·캐시 조건 내에서는 요청 URL 기준으로 중복 제거하고 GET 오류도 시도 수에 넣는다. (HTTP redirect의 내부 요청은 redirect 수로 따로 기록한다.) 캐시는 실행 전 빈 냉 캐시와 판·해시에 결박된 미리 확보한 파일을 모든 보기에 똑같이 열어 둔 온 캐시를 서로 분리한다. 비용은 원격 GET/실패/수신 body bytes, compact UTF-8 JSON 기록 바이트, 벽시계 밀리초다. GET 시간과 계산 시간을 따로 둔다. 웹 직접 열람의 수신 바이트가 도구에 없으면 미확인으로 쓴다. 원본이 없는 슬롯, 웹·일괄 준비 GET, 외부 배포 재구성과 로컬 읽기 비용을 실행된 원격 GET과 혼합하지 않는다.
- 두 보기 목적의 비교 단위는 각 보기당 1개이며 총 48개 판정 칸이다. 대상 판 쌍과 두 독립 검산이 제공하는 기준값이 있을 때만 오판율의 분모에 넣는다. 자료 부재는 미확인으로 적는다. 주소만 보고 단정한 지름길, 성공한 추가 조회, 보류를 각각 기록한다.
- 음성 대조는 달력 예외 무시, 현지 자정과 UTC 혼동, 변환 방향 반전, 캐시의 같은 Zone 이름에 다른 판 주입을 구분한다. 실제 배포판은 수정하지 않는다. 이름 재발급·같은 수/다른 구성·같은 표기의 Zone/Link 차이와 비전환 사례를 탐색하되, 표본 밖 대조 자료는 종합 분모에 산입하지 않는다.

## 봉인 시점과 알려진 제약

이 기록을 작성할 때 본 것은 저장소 선행자료, IANA 목록·공지·전환 Rule의 발효시각, MBTA 아카이브 목록 투영·정책, 클라우드 환경의 목록 GET 결과다. IANA 및 교통의 판독 결과는 아직 산출하지 않았다. 탐색에서 BART/HSL 안내의 위치가 보였으며 그 기관의 대체판 채택은 MBTA 실패 기록 이후에 판단한다.
