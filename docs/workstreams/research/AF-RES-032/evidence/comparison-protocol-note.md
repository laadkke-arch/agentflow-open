# 비교 해석 한계

A12와 B6은 각각 다른 내부판독자가 L1→L2→L3 입력을 순서대로 읽었고 결정파일을 봉인했다. 원문을 읽은 수집자의 기준판정과 나중 비교했다. 이는 실제 이용자 실험이나 외부 검토가 아니다. L3카드 자체에 수집자의 사실요약과일부해석이 포함되므로 독립 원문 검증으로 부르지 않는다.

L1/L2는현재전달증거가 없어전원보류. L3에는현재응답·내용과배포이력을동시에추가하므로보류해소를이력만의효과로분리할수없다. 의미상유지판정만을위해서는A-D01/03/05,R01/02의목적과현재본문이면충분하다는사후분석이가능하지만,실제L1/L2에서판정을냈다고보고하지않는다. 최소정보만으로도보류가충분했던A-R04/B04는정답분자로올리지않는다.

별도판독의추가외부웹조회는전단계0이다. 카드50(A)/23(B)는새로연페이지가아니다. 자료수집자의원문열람과archive의member상태관측은sources/editions/costs에별도단위로남긴다. A-D04사전B05노출과B03판독자의잠정curl배경노출을제외하는민감도는A11행(유지8/교체2/보류1),B5행(유지3/교체1/보류1)이다. B05중복도제외한독립B평가가능소비자는4개다.
