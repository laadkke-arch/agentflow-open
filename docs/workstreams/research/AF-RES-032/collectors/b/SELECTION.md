# B 사건 봉인과 탐색 한계

A 원격 봉인168d90b8519bcb4f673acc659bbaae895f79fca5 재독 뒤, SCOPE의 2020–2024 공식 이전 공지 탐색을 시행했다. 일반 쿼리의 관련성이 낮아 발행자별 공식 도메인 검색으로 좁혔다. b-sealed.jsonl의 직접 읽은 적격 공지 후보군에서 날짜순 첫6개를 고정했다. 이는 웹 전체의 최초6사건이라는 뜻이 아니다. 검색엔진 색인의 완전성은 미확인이다.

B01 Yarn / B02 GitHub / B03 curl / B04 Google / B05 IETF / B06 HashiCorp. 각 공지의 원 URI와 새 URI, 공지·시행의 차이를 분리했다. 소비자 질의는 원격 봉인 재독 뒤에만 시작하며 사건별3개, 후보 출판 문서5개를 상한으로 둔다. 같은 문서의 전후판은 하나의 후보 문서 계열로 집계하고 실제 열람 판수는 별도 기록한다.

GitHub gh 패키지 changelog 검색요약은 공지 탐색 중 우연히 노출됐지만 아직 직접 읽지 않았다. 잠정 제외 표본 curl4.3.1의 새 curl.se 링크는 앞서 읽었으므로 B03 소비자로 사용하지 않는다. 이러한 노출을 감추지 않으며 성공 사슬을 보고 소비자를 고른 것으로 간주하지 않는다.

B03 공지는 검색 서비스에서 원문54–58행을 직접 열어 읽었다. 동일 URL의 로컬 urllib GET은503이므로 status와 파일 해시는 null이다. 검색 요약을 원문 열람으로 대체한 것이 아니다. 그 밖의5공지는 urllib GET 원 bytes와 해시도 확보했다. 실패한 추정 URL /2020/11/04/curl-se-the-new-official-home-of-curl/ 은 근거에서 제외한다.

IETF 공지는2026-10-29 편집으로 RFC Editor 문장이 추가됐으므로 그 부분은2022시행 근거에 사용하지 않는다. Yarn·Google·IETF 공지의 예정 문장은 실제 완료 일시가 아니다. HashiCorp는 병행 beta공개이지 옛 사이트 폐쇄가 아니다.
