<p>To switch to OpenSSL, you need to set an environment variable <a href="https://curl.se/libcurl/c/libcurl-env.html"><code>CURL_SSL_BACKEND</code></a> to <code>&quot;openssl&quot;</code> when starting R. A good place to set this is in your <code>.Renviron</code> file in your user home (Documents) directory; the <code>?Startup</code> manual has more details.</p>
