<p>In v1.9.8 released Nov 2016 there is an ability to turn on new behaviour: <code>options(datatable.WhenJisSymbolThenCallingScope=TRUE)</code>. It will then work as you expected, just like data.frame. If you are a new user of data.table, you should probably do this. You can place this command in your .Rprofile file so you don’t have to remember again. See the long item in release notes about this. The release notes are linked at the top of the data.table homepage: <a href="https://github.com/Rdatatable/data.table/blob/master/NEWS.md">NEWS</a>.</p>
