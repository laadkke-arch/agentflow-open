<p>That concludes the major features of DBI. For more details on the library functions covered in this tutorial and the <code>vignette(&quot;DBI&quot;, package = &quot;DBI&quot;)</code> introductory tutorial see the DBI specification at <code>vignette(&quot;spec&quot;, package = &quot;DBI&quot;)</code>. If you are after a data manipulation library that works at a higher level of abstraction, check out <a href="https://dplyr.tidyverse.org">dplyr</a>. It is a grammar of data manipulation that can work with local dataframes and remote databases and uses DBI under the hood.</p>
