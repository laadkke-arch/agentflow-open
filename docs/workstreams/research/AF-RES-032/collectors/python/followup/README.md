# Python 후속 결과

19개 archive의 38개 본문을 실제 열었다. 반복 본문은 한 그룹으로 묶으며 변경 bugs.html 3.8.15만 새로운 소비자 본문으로 산입한다. 3.8.14→3.8.15가 이 계열의 최초 관측 변경이며 그 사이 누락판은 0이다. 전체 Python 모든 계열의 최초나 배포 순간을 뜻하지 않는다.

3.8.15 공개판 날짜와 tarball mtime은 서로 다른 시계다. 공식 /doc/versions/와 release page는 날짜를 주지만 exact bytes first-public UTC를 증명하지 않아 엄격 상류→배포 지연은 미확인이다. 2022-04-08 18:15 UTC는 공식 read-only 상태 보고의 표시 시각이며 실제 서버 시행 시각은 미확인이다. 이 표시 시각에서 3.8 소스 committer 시각까지의 nominal 차이 13,480,547초만 계산한다. 분 단위 표기를 실제 시행의 60초 구간으로 해석하지 않으며 lower_seconds와 upper_seconds는 null이다. 현재 HTTP 관측과 당시 공식 상태 보고도 구별한다.

실제 독자 진술 1개는 넓은 문서 오류 보고 목적만 겹친다. 봉인된 정확한 docs-query를 클릭했는지는 미확인이며, 노출도 live /3/ 웹이므로 offline 3.8 표본과 같은 매체가 아니다. 따라서 동일 목적·동일 매체 실패 분자에 넣지 않았다. 이후 자동 생성된 3.12.1 preview 제목을 2022판으로 역투사하지 않았다. 소스→배포→독자 사슬의 마지막 단절은 unknowns에 남겼다.
