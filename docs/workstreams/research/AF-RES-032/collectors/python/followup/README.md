# Python 후속 결과

19개 archive의38개 본문을 실제 열었다. 반복 본문은 한 그룹으로 묶으며 변경 bugs.html 3.8.15만 새로운 소비자 본문으로 산입한다. 3.8.14→3.8.15가 이 계열의 최초 관측 변경이며 그 사이 누락판0이다. 전체 Python모든계열 최초나 배포순간을 뜻하지 않는다.

3.8.15 공개판 날짜와 tarball mtime은 서로 다른 시계다. 공식 /doc/versions/ 와 release page는 날짜를 주지만 exact bytes first-public UTC를 증명하지 않아 엄격 상류→배포 지연은 미확인이다. read-only→3.8 source는 별도 계산된다. 현재HTTP와2022명시적시행보고를 구별했다.

실제 독자 진술1개는 live/3/web출처이므로 offline3.8표본의 실패 분자에는 넣지 않았다. 이후 자동 생성된3.12.1preview제목을2022판으로 역투사하지 않았다. 소스→배포→독자 사슬의 마지막 단절을 unknowns에 남겼다.
