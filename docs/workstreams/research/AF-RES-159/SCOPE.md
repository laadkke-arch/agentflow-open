## 모집과 판정 단위

- GIMP는 `po/POTFILES.in`, Inkscape는 발행판 업스트림 `po/inkscape.pot`의 원문·참조와 고정 소스에서 직접 쓰인 키를 사용한다. GNU xgettext로 GIMP의 C/C++ 목록을 산출한다. XML/.ui 등 비-C 자산과 생성 키는 실제 인벤토리에서 유형을 표시하고 가능하면 생산 파일로 역참조한다. 상세 추출 입력과 범위를 남긴다.
- msgid를 C/gettext 및 XML의 실제 UTF-8 문자열로 비교한다. NFC, 대소문자, 버튼 mnemonic, 콜론, 공백, 개행을 정규화하지 않는다. 비어 있지 않은 단수 msgid에서 서로 다른 **명시적이고 비어 있지 않은 msgctxt** 두 개 이상이 있는 그룹을 찾는다. 같은 msgid의 무문맥 키가 있다면 기본 조회·추가 후보로 기록한다. 서로 다른 PO 행이나 범용 매크로 두 곳만으로 생산자 둘을 인정하지 않는다.
- msgid·msgctxt·참조 파일을 UTF-8 바이트 오름차순, 같은 파일의 줄은 숫자 오름차순으로 정렬한다. 앞 12 후보를 제품별로 전수 보관한다. 각 그룹에서 정렬 첫 두 키를 고정하고 실제 호출 또는 리소스 바인딩이 두 자리에 확보된 적격 순으로 최대 6그룹을 봉인한다. 세 번째 문맥을 빈자리에 대입하지 않는다. 단일 명시 문맥에 무문맥 유사 키가 없는 첫 2그룹/제품은 대조로 따로 두고 호출·기능 결측도 보존한다. 무문맥 재등장·추가 명시 키·plural·generated-only와 탈락 이유를 기록한다. fuzzy·obsolete·빈 번역·fallback은 개봉 뒤 표시하며 소스 표본 순서를 바꾸지 않는다.
- 자연 짝의 단위는 제품·판·목적·선택 바이트가 같은 두 실제 생산 문맥이다. 두 목표 언어는 짝마다 서로 독립된 조회 자리다. 기능은 호출과 직접 신호/등록/표시 갱신·소비 상태가 증명하는 동작으로, 문자열은 같은 판의 PO+조회 결과로 각각 채점한다. 여러 호출이 동일 기능을 가리키면 호출 신원과 의미상 등가를 따로 쓴다. UI를 실행해 보지 않은 것은 코드 관측으로 표시한다.

## 사전 패킷·조회 규칙

- A는 UTF-8 선택·목적·제품·판·목표 언어. A+위치는 커밋 고정 원문 앵커. B는 실제 객체의 호출 역할 또는 직접 참조 하나이며 번역·msgctxt 값·정답 URL은 주지 않는다. C는 같은 생산 파일의 다른 객체에서 얻은 무관한 원문 구간이다. B 추가값과 같거나 짧은 UTF-8 예산으로 선택하고 범위·전달 길이를 별도로 남긴다. 어색한 절단은 표시하며 의미 없는 합성 채우기를 하지 않는다. 직접 키는 A에 msgctxt를 더한 상한 실험이다. 반환 후보 링크 집합·유일/여럿/보류·후속 질문 한 개를 ②에서 동결한다.
- 기능 채점은 현재 표시/액션의 목표 호출 위치를 판별할 수 있는지를 우선한다. 같은 문자열이지만 의미가 다른 후보를 하나로 단정하면 오승인, 이미 목표까지 연결되는데 추가 입력을 기다리면 불필요한 보류다. 직접 키가 같고 소비자가 여러 개면 카탈로그 신원과 기능 신원을 구별한다. A+위치 역참조로 충분하면 B의 필수성을 부여하지 않는다. 개인 응답 시간·선호·질문 감소는 별도 사람 시험이 필요하다.
- 같은 GNU gettext 판으로 ko/de의 고정 PO를 각각 컴파일한 독립 작업공간 두 곳에서 문맥 조회와 기본 조회를 실행한다. locale·도메인·도구·입출력 지문과 종료 코드를 남긴다. 없는/다른 문맥과 기본 도메인은 별도 구성 대조다. 배포 MO가 확보되면 독립 층으로 조회한다. 자연 그룹, 언어별 호출 조회, 반복, 구성 대조의 분모는 별도다. 분모 0의 비율은 산출하지 않는다.
- 외부 자료의 최소 고유 저작 수는 20이다. UI 변경/당사자 6, 처리 계약/구현 4, 발행 시험/번역판 결정/호환 6, 실제 지명 2, 문화자료 2 이상의 판독을 목표로 한다. 같은 이슈·배포·계보를 번역 언어/파일/형식으로 세지 않는다. 서로 다른 지명·문화 사례군마다 동명 원레코드를 대조한다. 공식 레코드 한 주소만으로 역참조되는 반례도 확인한다.
