## 사전 판정 대비 실제 반례
- 단일 파일이라고 외부 의존이 0이라고 결론 내리지 않는다. Box/B-T GLB 두 건은 실제 JSON+BIN과 외부/내장 byte-for-byte 비교(C01–C03)로 좁게 확인했다. BarnLamp GLB는 tree만 확인. [N01](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) §3.6.1.2의 GLB-stored buffer와 두 번째 external.bin 허용이 규범 반례. 실제 external URI GLB fixture는 이번 validator 경로에서 확보 못했다. [C11](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/buffer/valid_placeholder.glb), [C12](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/glb/json_and_two_buffers.glb), [C14](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/image/data_uri.glb), [C15](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/buffer/data_uri.glb)는 이름/URI 종류/실제 JSON이 다름을 확인한 반증 탐색 기록; data URI는 외부 URI 아님. [L08](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/buffer/data_uri.glb.report.json)는 기존 validator 보고서(새 실행 아님).
- 이미지가 있으면 모두 쓰인다는 판정은 [L06](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/root/unused_objects.gltf)의 image1 미참조 및 [L07](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/root/unused_objects.gltf.report.json) UNUSED_OBJECT, [C13](https://github.com/KhronosGroup/glTF-Validator/blob/40a561dad1bfaee4f1adbcb3d0fb0718fdf6b200/test/base/data/glb/two_images.glb) 이미지 2개/mesh 0으로 반박된다. 그러나 [L05](https://github.com/donmccurdy/glTF-Transform/blob/8e2a94a2616d293c4b503d0fb6a4b42e6ec7c62f/packages/core/src/io/platform-io.ts)의 _readResourcesExternal은 배열을 읽는 경로이므로 '화면 비소비=파일 접근 불필요'도 일반화 금지. 전체 loader와 부분 reader를 분리.
- UV/외관 동일성: [C04](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/BoxVertexColors/glTF/BoxVertexColors.gltf)는 vertex color, [C05](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/TextureCoordinateTest/glTF/TextureCoordinateTest.gltf)는 한 모델 내 factor-only와 UV texture material, [C06](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/TextureEncodingTest/glTF/TextureEncodingTest.gltf)은 factor vs texture 및 색 인코딩, [C07](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/TextureSettingsTest/glTF/TextureSettingsTest.gltf)은 9 textures/3 images, sampler 선택을 확인. [C08](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/BoxTexturedNonPowerOfTwo/glTF/BoxTexturedNonPowerOfTwo.gltf) NPOT는 BoxTextured와 JSON/BIN 동일 blob, 이미지 이름 동일하지만 PNG blob 다름; 파일명이나 JSON 해시만으로 외관 식별 불가. Box With Spaces [A04](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/Box%20With%20Spaces/README.md)는 URI percent decoding·literal spaces를 확인해야 하는 사례.
- required vs used: [N02](https://github.com/KhronosGroup/glTF/blob/da88a3bbbe168cc728eddf71fa5e1915cc2c0629/extensions/2.0/Khronos/KHR_texture_basisu/README.md) 두 이미지 소스 규범 fallback 예; [L01](https://github.com/mrdoob/three.js/blob/084ec06444244980752a420f0e1af5cd8f112aa1/examples/jsm/loaders/GLTFLoader.js) three loader는 required인데 KTX2Loader 없으면 throw, optional이면 null 반환으로 core loader 경로. [L03](https://github.com/BabylonJS/Babylon.js/blob/0880a7fcc6d772bb428cd5d551fbd8faaa5a919e/packages/dev/loaders/src/glTF/2.0/Extensions/KHR_texture_basisu.pure.ts) Babylon 확장 경로, [L04](https://github.com/donmccurdy/glTF-Transform/blob/8e2a94a2616d293c4b503d0fb6a4b42e6ec7c62f/packages/core/src/io/reader.ts) glTF-Transform required 검사도 별도. J07는 core source 없음; J06 PNG 직렬화를 별도 내려받는 것은 런타임 fallback 아님. geometry-only 분석에는 decoder 불필요할 수 있지만 표준 전체 로더 성공으로 둔갑시키지 않는다. Draco Box J02도 compressed required, ordinary accessor의 bufferView 없음; geometry decoder 필요.
