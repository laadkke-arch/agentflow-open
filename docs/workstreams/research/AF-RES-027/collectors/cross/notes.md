# Q7 · 옛 식별자를 보존해야 정확한 두 용도

이 묶음은 Q7의 목적 있는 보조 조사다. 소프트웨어 A·B의 표본 수, 정정률, 지연 분모에 더하지 않는다. **독립 사건 2개, 최소수에 보수적으로 넣은 고유 원문 4개(분야별 상류 1 + 소비자 1), 추가 직접 판독 8개**다. 현재 페이지만으로 소비자 수정 날짜를 추정하지 않았다. 여기서 날짜 있는 후속 인용/원장 고정판은 확보했으나, 다섯 시점의 소비자 정정 사슬은 두 사건 모두 완성되지 않았다.

## 1. X-BIB01: 정정 공지가 생겨도 연구의 DOI를 바꾸면 인용 대상이 달라진다

| 역할 | 직접 확인한 고정 단위 | 확인과 한계 |
| --- | --- | --- |
| 상류 시행 | [X-S01, PLOS 정정 공지](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0165166), Notice of Republication | **2016-09-06 재발행**, **2016-10-21 정정 공지 발행**을 따로 명시한다. 원인은 조판 과정의 제목 오류다. 공지일을 시행일로 대입하면 45일 어긋난다. 이는 공지·시행 날짜 차이이며 소비자 지연이 아니다. |
| 옛 연구 대상 | [X-S02, 연구 DOI .0159614](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0159614) | 2016-08-22 연구 논문의 현재 본문은 정정 표식을 갖고 같은 DOI를 유지한다. 정정은 다른 DOI .0165166의 별도 저작이다. |
| 실제 후속 인용 | [X-S03, Piwowar 외 PeerJ 2018 최종 PDF](https://jevinwest.org/papers/Piwowar2018peerj.pdf), p.5·p.22 | p.1의 발행일은 2018-02-13. p.5는 엠바고 뒤 공개된 논문의 인용효과를 논의하며 Ottaviani 연구를 사용한다. p.22는 수정된 제목과 **원 연구 DOI .0159614**를 인용한다. 정정 공지 DOI로 갈아끼우지 않는다. |
| 다른 도착 화면 | [X-S11, PubMed](https://pubmed.ncbi.nlm.nih.gov/27548723/), Title·Erratum in | 현재 제목은 `Its`, PLOS는 `It’s`로 표시하고, PubMed도 정정 공지로 연결한다. 현재 metadata 불일치다. 미수정 상태가 2016년부터 연속됐다는 증거는 없다. |

**직접 관측:** 소비자는 같은 연구의 결과를 인용하며 원 DOI를 사용한다. 상류 공지는 구판·정정판 첨부 파일을 별도로 보존하고 다시 내려받으라고 안내한다. 이 두 역할이 다르므로 “후계 주소가 생기면 옛 인용을 전부 후계로 치환”하는 규칙은 이 사례에서 부정확하다. 연구 결과의 출처를 정정문 한 쪽으로 대체하기 때문이다.

**연구자 해석:** 현재 결과를 읽는 용도에는 원 연구 DOI와 정정 링크가 충분할 수 있다. 그러나 “처음 발표된 제목/본문을 재현”하려면 S1 구판, “정정 뒤 정확한 판을 인용”하려면 S2와 재발행일이 추가로 필요하다. DOI 하나가 같은 연구를 식별하는 것과 정확한 PDF 판을 고정하는 것은 다르다.

**부족한 근거:** PLOS S1/S2의 본문은 객체 저장소 접근 실패로 직접 비교하지 못했다. 따라서 정확한 조판 전후 문자열 차이와 연구 결과의 바이트 동등성을 확인했다고 하지 않는다. PeerJ에 이 인용이 처음 삽입된 날짜, 정정 공지를 읽었는지, 그 전의 오인용을 고쳤는지는 미확인이다. 2016-09-06→2018-02-13 차이를 “수정까지 걸린 시간”으로 계산하지 않는다. 후속 논문의 발행일은 수정 커밋 날짜가 아니다.

**반증 시도:** 원 DOI가 전혀 다른 저작으로 이동했는지와 정정 DOI로 바꾸어야 하는지를 X-S01–03에서 확인했다. 원 DOI가 연구를 가리키므로 일괄 치환 필요성은 지지되지 않았다. 동시에 PubMed의 현재 제목 차이(X-S11)는 상류 정정과 모든 소비자 표시의 동시 일치를 가정할 수 없음을 보여 준다. 제목 불일치를 과학적 결론 오인용 피해로 확대하지 않았다.

## 2. X-LIB01: 분리된 국가의 옛 표목은 과거 전체 영역을 기술하는 책에 맞는다

| 역할 | 직접 확인한 원문 | 확인과 한계 |
| --- | --- | --- |
| 당대 상류 결정 | [X-S04, LC Cataloging Service Bulletin 60, Spring 1993](https://www.loc.gov/aba/publications/FreeCSB/CSB_060.pdf), 인쇄 pp.2–4 | Czech Republic `n90718759`, Slovakia `n50075233`를 승인하고 각 적용 시기를 설명한다. 새 국가·지리 코드는 **1993-05-24 시행**이라고 명시한다. 옛 전체 국가에 `Czechoslovakia`와 `e-cs`를 계속 쓸 조건도 명시한다. |
| 실제 소장목록 고정판 | [X-S05, Harvard 20220215_017.bib.mrc, offset 295257330, length 2338](https://openlibrary.org/show-records/harvard_bibliographic_metadata/20220215_017.bib.mrc:295257330:2338) | 책은 Weisskopf의 1968년 *The agony of Czechoslovakia ’38/’68*. 001=`990068819680203941`; 651의 1968 침공 주제는 `http://id.loc.gov/authorities/subjects/sh85035319`; 043=`e-cs---`. **852/876에 WID·Slav 7340.95 소장 정보**가 있어 단순 주제 소개 페이지와 구별된다. |
| 범위 확인 | 같은 X-S05의 245·260·505 | 제목, 발행년, 목차가 1938과 1968의 사건을 다루므로 현재 체코 한 나라의 안내서와 구별된다. |
| 보강 규칙 | [X-S07, LC H710, July 2015](https://www.loc.gov/aba/publications/FreeSHM/H0710.pdf), §3.a.(1)·(2), §4 | 분리 전 전체 영역에는 옛 표목, 분리 뒤 전체를 묶을 때 옛 이름이 더는 쓰이지 않으면 후계 표목들을 적용한다. 지방명에 대한 지리 세목 규칙은 별도다. |

**직접 관측:** LC의 실제 분리 후 결정은 모든 옛 이름을 폐기하라는 것이 아니다. Harvard의 명시된 2022 snapshot record는 역사적 사건 주제와 옛 지역 코드를 보존하고 실제 소장 위치도 담는다. 이 기록을 단일 후계 국가로 바꾸면 역사적 전체 영역을 좁힐 수 있다. 이것은 해당 책의 제목·목차와 당대 표목 규칙의 대응에 대한 판정이며, Harvard 담당자가 언제 어떤 이유로 보존을 선택했는지의 직접 진술은 아니다.

**같은 옛 이름에 상반된 답이 나오는 반례:** CSB60 p.2는 `Slovak Republic (Czechoslovakia)`가 1990–1992 구성 공화국의 **기술목록 접근점**으로 유효하다고 한다. p.3은 그 표목을 **주제목록**에는 쓰지 말라고 한다. 이름과 시기만 같아도 참조 역할이 달라지면 허용 답이 달라진다. 또한 같은 p.3은 지역명을 Czechoslovakia 아래에 간접 세분하지 말고 현재 국가 아래에 두라고 한다. 그러므로 “역사 자료면 옛 이름을 무조건 유지”도 이 사례가 지지하는 규칙이 아니다.

### 날짜와 고정성에 대한 보수적 처리

- X-S05는 **명시된 dump 파일 + byte offset + 길이 + 레코드 ID**로 읽은 버전을 특정한다. 현재 HOLLIS 검색결과를 과거판으로 부르지 않았다.
- 파일명의 `20220215`, MARC 005의 `20020606163548.3`, IA 파일 목록의 `2026-03-12 03:48`은 각각 snapshot 표기, record timestamp, mirror file modification이다. 어느 것도 651의 첫 수정 시점으로 간주하지 않았다.
- X-S06의 2015 snapshot은 **다른 책**이므로 X-S05의 전후 판으로 사용하지 않았다.
- 보강에서 IA public API와 XML manifest를 읽고 원 dump의 **2338바이트 구간을 HTTP 206으로 직접 확보**했다(X-S12). `harvard-2022-record.mrc`의 SHA256은 `6ce2142a32f7fe98f815cc62de767efdf6312571da20814c65a1fb6170d5e4e6`이며 decoded 651·852·876은 렌더링과 일치한다. 전체 파일의 manifest MD5는 `b2ebb2d2a54b9e48589e8e5f459920e3`, SHA1은 `34e06a9a1c3cbdc680bc23819574955297f47abb`이다. 전체 357,206,833바이트를 내려받아 해시를 재계산한 것은 아니며, 원 발행자 최초 배포 영수증도 미확인이다. 정확한 획득 결과는 `integrity-attempts.json`에 있다.
- 040의 `DLC/DLC/UKM/HLS`는 원 기록에 LC·UKM·Harvard가 관여한 계보를 보여 준다. Open Library와 Internet Archive는 별개 소비자 두 곳으로 세지 않는다. Harvard adoption도 LC 판단의 독립 검증으로 쓰지 않는다.
- 국가 분리 시점, 코드 시행일, 표목 시행일, consumer snapshot, 실제 catalogue UI 최초 배포일을 분리했다. 정확한 표목 시행일과 소비자 수정/배포일은 **미확인**이다.

## Q7에 남길 제품 조건

| 이용 목적 | 보존할 최소 항목 | 자동 치환을 보류할 조건 |
| --- | --- | --- |
| 과거 연구 결과를 찾아 읽음 | 연구 DOI + 인용 근거 절 + 정정 관계 | 정정문 DOI가 다른 역할의 문서인 경우 |
| 발표 당시의 정확한 판을 재현 | 원 DOI + 구판/정정판 locator + 그 판의 날짜 | 동일 DOI가 현재 본문만 제공하거나 구판 파일을 못 읽은 경우 |
| 역사적 전체 영역을 다룬 소장 자료 검색 | 기관 catalog record와 판 + subject URI + 다루는 영역/시기 + subject/descriptive/subdivision 역할 | 후계가 둘 이상이거나, 이름은 같아도 접근점 역할의 규칙이 다른 경우 |
| 현재 국가 또는 지방 안내 자료 검색 | 현재 목적·영역 + 적용 역할 + 새 표목 관계 | 역사적 주제와 지금 사용하려는 목적을 구별할 원문이 없는 경우 |

이는 사례에서 도출한 **설계 제안**이다. 최소 기록의 실제 저장 비용, 전체 전파율, 사람의 피해는 측정하지 않았다. 읽은 URL·판의 목록은 sources.json과 search-log.jsonl에 있고, 열람 도구가 자동 생성한 화면 경과시간을 사람의 판독 시간으로 보고하지 않았다.

## 재개할 가장 작은 확인

1. 학술: 공식 S1/S2 두 PDF의 title·DOI·본문을 직접 비교하고 초기 PeerJ preprint v1의 참고문헌을 확인한다. 후속 인용의 최초 관측을 앞당길 수 있지만, 여전히 정정 커밋이 없으면 전파 지연이라고 부르지 않는다.
2. 도서관: 현재 원 record 바이트와 IA manifest는 확보했다. 추가로 Harvard 2022 export의 원 발행 영수증 및 같은 001의 이전 snapshot을 확보한다. 651·852의 판 차이를 확인하기 전에는 2002나 2022를 정정 날짜로 채우지 않는다.
