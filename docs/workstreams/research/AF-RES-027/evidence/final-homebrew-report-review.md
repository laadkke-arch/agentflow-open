# AF-RES-027 최종 보고서 Homebrew·날짜·범위 판독

- 확인 UTC: 2026-11-22T06:09:28Z
- 검토 대상: [RESULT.md](../RESULT.md), SHA256 `b1499920173ca5913287fdd703b5fe951275867b922391300c42c6604c788f1d`.
- 판독자: `/root/homebrew_a`. Homebrew A 원장을 수집한 동일 에이전트의 최종 보고서 대조이며, Homebrew B 원장은 다른 수집자가 작성했다. 같은 모델 계열의 내부 내용 QA다. 외부 사람의 독립 검토나 새로운 실행 재현이 아니다.
- 이번 작업에서는 새 외부 자료를 수집하지 않았다. 이미 직접 읽은 원문에 대응하는 [sources.json](../sources.json), Homebrew `historical/upstream/chains/verdicts` 원장, Homebrew B `cases/sources` 원장, 집계·재열람 원장을 읽었다. RESULT와 생성기·수집 원장은 수정하지 않았다.

## 결론

Homebrew A 6행과 Homebrew B 3행에서 상류 source/merge 시각을 실제 최초 시행 Tu로 바꾸거나, H02의 asset metadata를 적격 배포 지연으로 되살리거나, H05의 다른 API 이동을 음수 정정 지연으로 계산하는 오류는 발견하지 못했다. H01의 문서 안내 삭제 범위와 H04의 2023년까지인 소비자 확인 범위도 유지된다. 아래 표현·인용 보강 2건은 판정·분모·지연 값을 바꾸지 않는다.

초기 판독 때 존재하던 C04 상류 작성 근거의 C-F15 연결과 C05의 C-F70을 1.12 후계로 부르는 오류는 root가 따로 지적·수정한 건이다. 최신 검토 대상에서 C04는 C-F33, C05는 옛 안정 1.11.4 C-F70 → 1.12 C-F60으로 바뀐 것을 확인했다. 이 수정은 새 발견으로 세지 않는다.

## 필수 표·근거 연결·날짜 산술

이번 기계적 검사는 원문 주장을 새로 검증하는 실험이 아니라 보고서와 원장의 정합성 확인이다.

- 제목 바로 아래 첫 네 표의 데이터 행 수는 각각 **18 / 6 / 14 / 8**이다. 표1은 A12+B6, 표2는 계열·전체 집계, 표3은 A12와 대조 2행, 표4는 Q1–Q8에 대응한다.
- 마지막 약점 표는 문서 끝의 **정확히 3개 데이터 행**이다. 공급 artifact와 실제 실패 환경, source 수정과 최초 실제 배포, 도서관 ID 역할·snapshot 공개 시각을 각각 구별한다. Homebrew 관련 두 번째 약점의 H06/H02 예시와 다음 불변판은 원장과 일치한다.
- source ID를 라벨로 한 **175개 URL 연결 / 서로 다른 ID 106개**를 확인했다. 통합 sources에 없는 ID **0개**, 해당 ID의 original/read/related URL과 불일치하는 연결 **0개**다. URL 문자열 대응은 링크의 현재 가용성이나 문장 의미를 자동 증명하지 않는다.
- 보고서에 수록된 6개 적격 초 단위 산술을 UTC datetime으로 다시 계산해 모두 일치함을 확인했다: C04 RC 76,027초; C04 stable 1,004,454초; C06 source 863,997초; B-C03-R2 source 응답 19,700.839초; branch 통합 86,726.839초; 복귀 source판 6,487,807초. 실제 CI·GUI 정상화나 원래 Qt 5.12 참조의 지연으로 확대하지 않았다는 문장도 확인했다.
- H02 metadata 산술과 C04의 조건부 약 5.3시간은 적격 주 지연에서 제외돼 있다. Homebrew A 사건 4개의 Tu 미확인, 무사건 관측 2개, A Homebrew 6행의 소스 유지 2/보류 4, 형식적인 R/L 검열 0/0은 collector와 맞는다.
- Q8의 348 source 행 / 보수적 최소수 87 / 직접 판독 URL 286 / 고정 Git판 134 / root 재열람 영수증 16은 retrieval-metrics 원장에 기록된 값과 일치한다. 사람 시간·최소 클릭 수·저장 비용으로 서술하지 않았다.

## 한계와 종료

이 검토로 원문 수집의 완전성, 당시 실제 brew 설치, 공개되었다가 사라진 CI 결과, 최초 사용자 노출을 새로 확보한 것은 아니다. Homebrew A 자체 수집자가 자기 자료와 최종 문장을 대조했으므로 외부 독립 확인이라고 표현할 수 없다. 이미 존재하는 별도 판독·47/47 원장 검산과 이번 보고서 문장 QA의 역할도 구별한다.

root에 HR-F01·HR-F02를 전달했다. 알려진 C04/C05 연결 수정은 최신 판에서 확인했다. 현재 확인 범위에서 추가적인 Homebrew 날짜/지연/범위의 필수 오류는 발견하지 못했다. 이 파일만 작성했고 보고서·생성기는 수정하지 않았다.
