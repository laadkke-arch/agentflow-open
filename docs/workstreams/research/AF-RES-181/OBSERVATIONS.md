# 관측 중간판

D18은 **처리판의 한 실제 HT 제출 묶음**이지 고정 raw 판의 사건이 아니다. TUR doc1, tur_t1, 5개 분절, 111 원문 단어. unit_id와 item_id와 FLORES ID와 최종 target 존재를 같은 표시 행에서 확인했다. 원문/출력 문자열 및 개인 속성은 재게시하지 않았다.

- E1–E5 event_time 100306 + 560332 + 86699 + 1270943 + 43573 = 2061853 ms = 2061.853 s = 34.3642 min. 111 / 34.3642 ≈ 3.23 words/min. 동일한 5개 행의 edit_time 합도 2061.853 s. 원 이벤트별 t는 아직 미확인.
- E4 1270943 / 1000 = 1270.943 s. pause_ge300=1249440 ms(≈98.3%); ge1000=1238877 ms는 그 부분집합. ge300 전체를 빼면 21.503 s이나 이는 **유효 활동 인시가 아니다**. 읽기/생각/조회와 자리비움을 판별하지 못한다. 45분 기준에서는 제외되지 않을 수 있다.
- D03은 per2metrics에서 FINISHED만 남기고 마지막 annotation의 target을 쓰며 editing indicator를 합하고 event_time은 각 annotation의 마지막 t를 합한다. 비어 있는 이벤트는 0으로 파서 합산하므로 0을 실제 무노동으로 해석하지 않는다. edit_time vs event_time 불일치 경고는 값 교정이 아니다. 재방문 합산이 문서 전체 wall clock 또는 중첩 제거를 보장하지 않는다.
- D01의 동일 문서 조건 배정은 세 명 교차. 사람×문서 내 삼중 반복측정이 아니다. 8개 슬롯×3명은 설계상 24개 예정 행이며 1개의 처리판 문서×사람×조건만 관측, 나머지 23개는 실제 배정 매핑 미확인. 원자료 기준 24개 모두 미확인. 5개 세그먼트 행은 독립 사람 5명이 아니다.
- doc 후보 1..4를 임의 확정하지 않았다. D08에 doc3 세그먼트 31/32 제외가 있으나 정렬 모집표 없음. 8개 슬롯은 유지한다.
- 직접 원문 시간 이벤트와 판 일치, ITA 행, 동일 doc PE1/PE2, 독립 심사표의 정확한 키는 아직 확보하지 못했다. 전체/조건 효과 미산출.
