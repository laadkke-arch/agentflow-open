## 보관·주소·평가 정책

보기 A0는 연락 주소와 당시 추천 이유만 가진다. A1은 발행판·전체 파일 지문·출력 스냅샷을 추가한다. A2는 A1과 실제 읽은 구간/선택 조각·위치·순서·변환 설정·출력 셀 간 연결을 더해 SQLite의 로컬 단위로 보존한다. 재생 때 A2가 저장한 스냅샷을 독립 재계산에 사용하지 않는다. A0·A1의 입력 사용은 확인 가능한 재계산/공개 목록의 범위를 등급으로 표시한다.

모든 보기에서 동일한 합성 주소 해석기와 2회 조회 및 64 KiB 한도를 적용한다. 현재 URL은 현재 합성판을 돌려준다. 보존 조건에서는 태그로 보관판을 재요청할 수 있고, 이전 주소가 분리된 T1에는 오래된 URL이 해당 보존판을 직접 가리킨다. 소실 조건에서는 보관 주소 및 판 조회가 실패한다. 현재 주소가 같은 값이나 지문을 반환하더라도 그 결과에 과거 실행을 숨겨 실어 보내지 않는다. 모든 보기에서 실제 확인이 끝난 A0 주소 복원을 인정한다. 규칙의 사전 버전과 그 실제 사용 여부를 구분한다. 원 발행 서버는 출처 대조에만 연다.

변경 시 A0의 재확인 정책은 이유의 조건 뒤집힘과 주소 이동을 따른다. A1은 출력 스냅샷과 지문·주소·통지 설정을 비교한다. A2는 저장된 셀과 새 실행 셀의 연결을 비교한다. 보류와 거짓 확정을 섞지 않는다. 사전 합격선은 동일 연산 중복 0, 과거 응답 변조 0, 롤백 잔존 행 0이다. 결과 우세는 합격선이 아니다.
