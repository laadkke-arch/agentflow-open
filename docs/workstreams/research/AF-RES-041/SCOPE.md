## 다섯 접점과 강도

접점은 `exact_donor`, `available_then`, `author_link`, `change_same_baseline`, `same_purpose_reflection`이다. 각 값은 `참 / 거짓 / 미확인`이며 근거 ID·정확한 판과 위치를 함께 둔다. 미발견·접근 실패는 거짓이 아니다.

1. **정확한 제공 원전**: 원저작/판/쪽·기호 또는 규칙을 직접 본다. 목록만 있으면 서지만 참이며 본문은 미확인이다. 이름이 같은 후대판은 대체하지 않는다.
2. **당시 가용성**: 해당 판이 결정 전에 발행/배포됐다는 독립 발행·기관 또는 당대 기록. 저자 실제 독서는 별도다. 파일 mtime와 현재 웹 접근 시각은 과거 공개일이 아니다.
3. **저자 연결**: 저자 원문이 정확한 자료/규칙과 선택을 연결한다. 포괄적 영감·후대 회고·선택적 모방·알고리즘 독립 구현을 구별한다. 같은 진술의 재인쇄는 한 증언 계통이다.
4. **같은 기준선 변경**: 전후가 같은 목적·기능·대상이고 원문이 순서를 뒷받침한다. 최초 구현에서 이미 채택돼 있으면 더 이른 미공개 원안을 추정하지 않는다.
5. **같은 목적 반영**: 고정된 작성 소스·설명·출력 예 중 무엇을 봤는지 기록한다. 저자 출력 보고, 저장 출력의 직접 판독, 코드만 확인, 역사 실행을 구분한다. 이번 역사 실행은 하지 않는다.

`인용만 입증`은 저자의 명명/영감 진술까지, `같은 기능 반영까지`는 대응 기능의 소스·예시까지, `같은 최초 결정의 인과 확인`은 동일 최초안에서 다섯 접점 모두 참일 때만 쓴다. 나머지는 미확인 접점을 명시한다. 코드 기준 완결도 다섯 접점을 만족해야 하며 단순 교체를 인과 완결로 올리지 않는다.

주 판정은 당대 명시 인과+최초안 기준이다. 회고 허용(동일 기준선 유지), 기존 코드로 기준 이동, 특정 판을 출판사 계열로 완화한 경우는 별도 열에서만 보고한다. 마지막 완화는 엄격 완결 수에 포함하지 않는다. 핵심 접점 하나를 제거한 재판독은 B01 `author_link`, B03 `exact_donor`를 빼고 원판정과 비교한다. 사후 재판독은 자체 점검이다.

## 예상 반례·경쟁 설명

- B01: hz가 영감을 주었어도 내부 알고리즘을 공개하지 않아 독립 구현했을 수 있다. Gutenberg의 약자·합자·대체 글리프는 문자 폭 스케일과 동일하지 않다. optical margin과 paragraph expansion을 하나의 선택으로 묶으면 틀릴 수 있다.
- B03: 본보기의 직선/곡선, 글리프 특성을 일부러 따르지 않았을 수 있다. 음악 글꼴 교체와 후기 spacing 개선은 같은 사건이 아니다. Schubert/Hofmeister 이름만 같고 다른 판·재조판일 수 있다.
- 네 가설을 모두 검사한다: 독자 구현, 이미 정한 방향의 정당화, 선택적 모방, 후대 회고. 각각 지지·약화 자료를 연결하며 모든 사건에 억지로 단일 가설을 택하지 않는다.
- 인쇄 조판자의 회색도·광학 정렬, 연주자의 판독성, 구현자의 변경 범위, 서지 담당자의 판 식별을 별도 관점으로 비교한다.
