## 과장을 찾으려 했으나 통과한 지점

1. **BA5635와 BA5527**: RESULT L7·35·99는 둘을 후보로 남기고 사용판을 미확인으로 둔다. BA5635가 BA5527에서 발췌됐다는 공식 서문 관계와, 별책과 전집이 동일한 물리판이라는 주장을 혼동하지 않았다. ED001 title/III, ED003 Werkdaten/Literatur, ED004 NCID BA27399877와 일치한다.
2. **1988과 2008**: ©1988을 2008쇄의 발행일로 바꾸거나 2008자료를 1997 저자 열람물로 소급하지 않았다. “3쇄”는 원문의 “3rd Printing 2008”에 부합한다.
3. **Müller 6064/6065**: 현행 후보, 두 권의 서로 다른 제목·편집 표기, 연도 미확인, URL의2023 경로를 출판일로 삼지 않는 구분이 정확하다. op64 한 저작 산입도 중복 배제에 보수적이다.
4. **판매자 raster**: RESULT L39는 파일의 이미지 성질만 사실로 쓰고 scan/re-engraving을 미확인으로 남긴다. 최소수 제외와 원본 미재게시도 실제 처리와 같다. ‘BA5635 판매자 연결 발췌’라는 표현은 내부 간기 확인보다 약한 연결임을 유지한다.
5. **B03 카드의 두 링크**: cards L26–29는 모두 수신 프로젝트 자료라고 명시한다. 정확 donor 악보를 제공한다고 속이지 않고 2003 Fig5도 1997 출력으로 소급하지 않는다.
6. **판독성 목적**: cards L24의 판독성과 질감은 독자가 검토할 사용 목적이다. 통제된 가독성 개선 실험이 있었다고 쓰지 않아 과장이 아니다.
