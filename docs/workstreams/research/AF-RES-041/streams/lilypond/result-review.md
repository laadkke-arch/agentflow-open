# B03 결과 초안 반증 검토

검토 대상: root의 `RESULT.md`와 `cards.md` 초안. 아래 줄 번호는 폭 용어 정정 전 초안에서 읽은 위치다. 검토자는 B03 수신 기록을 작성한 같은 연구 세션이며 **자체 재검토**이다. 독립 인간 검토나 새로운 독립 목격 증언이 아니다. B01 기술 내용의 재판정은 하지 않고, 공통 분모 표시만 읽었다.

## 결론

**필수 정정 1건:** ‘단일 flat 폭9/12→.8 interline’는 두 번째 상자 인자의 변화이며 전체 문자 상자 또는 실제 잉크폭을 계측한 값처럼 제시하면 부정확하다. 같은 변경에서 첫 번째 인자도 바뀐다. 정밀한 인과·기준선·후대 출력 제한은 초안에 잘 유지되어 있다. 다음 제안은 판정을 상향하거나 분모를 바꾸지 않는다.

### R1의 정확한 의미

같은 두 판의 `autometric.mf`는 `charbp`와 `charwd`를 별도로 저장하고, pixel 변수 b·w를 각각 `hround`한다. proof 상자는 -b와 w를 양 끝으로 삼고 `chardx`에 10×(w+b)를 대입한다. 그러므로 명목 상자 가로 범위를 비교하려면 두 인자가 모두 필요하다. `w#` 하나의 수치를 전체 도형의 폭이라고 부를 수 없다는 정정이다. 여기서 TFM advance, ink bounding box, 실제 인쇄물의 폭을 새로 측정했다고 주장하지 않는다.

이전 표현을 결과 없이 지우지 않기 위해 위 표에 남겼다. `sources.jsonl`의 B03-L011·012, `mechanisms.json`의 B03-M02, `evidence.md`의 flat 비교표를 매개변수 관측으로 정밀화했다. 새로운 원문 범위는 B03-L031·032로 별도 기록하고 기존 배포의 중복 재독이므로 `counted=false`로 두었다. 원래 산입 8저작과 사전 판정 규칙은 변하지 않는다.
