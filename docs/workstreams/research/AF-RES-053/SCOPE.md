## 1. 읽기 조건과 허용 원전 목록

- N: 해당 시점 제품 공식 API 한 절. I: N + 같은 분야의 앞선 공식 예제 한 절. D: N + 다른 분야의 앞선 원전 한 절.
- 추가 창은 I/D 각각 원문 한 절, 최대 200 whitespace 단어, 그림 최대 한 점. 실제 단어 수와 절단 문장·그림 유무를 기록한다. 예산 상한 동등과 실제 단어 수 동등을 구별한다. 가능하면 두 창을 같은 단어 수로 절단하되 의미 단위를 훼손하면 더 짧은 완결 문단을 쓰고 불균형을 보고한다.
- Vega-Lite N: 해당 tag의 axis/scale/text 문서 및 공개 타입 주석. I의 탐색 순서: 해당 tag의 공식 examples/specs에서 제목·파일명에 대응 단어가 있는 최초 적격 예제; 이어 같은 시점 Vega 공식 axis 예제. libass N: 해당 tag의 public API/ASS 문서; I: 해당 시점 libass 공식 예제·ASS 태그 설명(Aegisub 문서) 순서. 같은 매뉴얼 다른 절은 독립 저작으로 중복 계수하지 않는다.
- D 허용 순서: 인쇄는 W3C CSS Paged Media 2013 §6/§8, XSL 1.1 2006 페이지 영역·줄 처리, 필요하면 판이 고정된 인쇄 편집 매뉴얼. 지도는 QGIS 2.18 Labeling/Rendering 및 QGIS Training Manual 지도 라벨 실습, 다음으로 Ordnance Survey 판별 가능한 cartographic label 원전. 각 사례에서는 제목/색인 용어의 첫 적격 절을 사용하고 탈락 이유를 저장한다.
- 도너의 문구가 보장하지 않는 수신 속성(값 대응, 발화 시점, 실제 폰트 측정, 엔진 기본값)을 별도로 적는다. 수신 매뉴얼의 다른 장을 D로 세지 않는다.

## 2. 봉인과 채점

- 단계 ① frame·제외·A/B 규칙을 원격 커밋한다. 단계 ② 6자리×N/I/D=18행의 카드와 정상/경계 예측을 원격 커밋한다. 그 전에는 후속 댓글·PR·릴리스·시험 출력에 접근하지 않는다.
- 예측값은 A만/B만/둘 다/둘 다 미달/판별불가다. 방향·단위·허용차를 당시 근거로 정할 수 없으면 숫자를 만들지 않고 범주 예측으로 둔다.
- 이후 결과는 실제 출력, 작성자 수락, 패치 존재, 시험 기대값을 구별한다. 판·입력·조작·정상/경계가 맞지 않으면 해당 예측 채점에 쓰지 않는다. 한쪽 정상 출력으로 다른 쪽 경계 실패를 추론하지 않는다.
- I 대비 D 신규 정답은 서로 다른 사전 예측 및 이를 가르는 후속 1차 자료가 모두 있어야 한다. 동률·새 오답·판정 불가를 함께 센다. 전체 6자리와 실제 충원·채점 분모를 나눈다.
- `관측 0`: 적용된 분모에서 수가 0. `해당 없음`: 조건부 분모가 0. `미확인`: 자료 부족. `미실시`: 절차를 실행하지 않음.
- 이후 수정은 사후 정정이며 사전 예측을 덮어쓰지 않는다. 결과 전에 노출된 답이나 원문 밖 지식은 카드별로 기록한다.
