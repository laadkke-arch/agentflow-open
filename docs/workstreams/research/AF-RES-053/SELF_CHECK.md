[사전 방법 검토](streams/donors/method-review.md)와 [후속 원장 교차 검토](streams/vega/final-ledger-review.md), [최종 서술·수용 원장 교차 검토](streams/libass/final-report-review.md)는 실제 수행됐지만 같은 모델이고 일부 원작성자가 다시 검토했다. 독립된 사람 검토, 참가자 배정, 독자 가독성·시간·창의성·채택 관측은 **미실시**다.

## 실제 수행한 검산과 수정

- source ledger의 필수15필드, 고유 source ID, work_id 계보, 실패/metadata/자체 재생 제외, 역할 배당의 중복 부재를 검사했다. 188열람행/71보수적 고유저작이다. 역할별5/6·5/4·4/4·0/6·2/2이며 수신 문헌의 초과1건을 후속/요청자 결손과 상쇄하지 않는다.
- 같은모델 교차 검토에서 #7372의 pointer-only 본문을 총수에서 제외해72→71로 보수화했다. 원frame annotation은 보존하고 집계 정책과 전후 수치를 SCOPE에 남겼다. 필수 배당·선정·예측 결론은 바뀌지 않았다.
- 최종 서술 검토에서 L01-D의 최소너비와 L02-D의 겹침 회피 문구를 실제87단어 창의 범위로 좁혔다. 전체원전에서 읽은 것과 표시창에 보인 것을 구분했으며 사전 선택/예측은 바뀌지 않았다.
- V02의 연구자 정상 통제를 historical normal로 읽지 않도록 outcomes/replay comparison 문구를 좁혔다. 집계의 상수를 원행 계산으로 바꾸고 다시 검사했다. [원장 교차 검토](streams/vega/final-ledger-review.md)에 수정 전후와 검토 snapshot hash가 있다.
- 카드·예측·결과는 각각18개의 같은 ID를 갖는다. I/D 추가 예산5쌍은72/68/114/87/87단어 및0/0/0/1/1그림으로 일치한다. 18보기·5요구·20논리셀·6renderer변형·추가2버전변형을 서로 바꾸어 세지 않았다.
- 원격 예측 seal의 일곱 파일을 Git blob 기준으로 대조했다. frame의 CRLF/LF 기록 차이만 있으며 내용·예측은 같다. 출력 후 선택지/예측 수정은 없다. 2.7.0은 별도 사후 탐색으로 표시했다.
- replay의 JSON/SVG·원출력 hash·local link 검산은 [replay/validation.json](replay/validation.json), 실행 stdout/stderr/exit/UTC는 replay/logs에 있다. render exit1은 지정 B의 실제 compile 실패다. 접근 실패와503 재시도 기록도 남겼다.
- 최종 결과 고정 SHA의 원격 RESULT/acceptance 재열람 및 지정 session check는 결과 커밋 뒤 수행하고 실제 기록을 evidence에 추가한다. 수행 전 문서에 성공으로 선기재하지 않았다. 최종 상태는 HANDOFF의 고정 SHA·검사 영수증을 참조한다.

## 재개 우선순위

첫 행동은 [outcomes.csv](outcomes.csv)의 needed_to_resume와 각 분야 outcomes.json의 missing 항목을 읽어 **같은 조건의 공개 출력으로 바꿀 수 있는 결손**부터 찾는 것이다. 원작성자의 runtime과 최초 입력판이 없으면 새 연구판 재생을 더해도 역사판 분모는 채워지지 않는다. L01/L02는 B의 숫자 자체가 미고정이므로 추가 출력 이전에 수치와 측정 규칙을 새 프로토콜로 고정해야 한다.

같은 표본에서 I/D 예측이 같다는 기록은 새 후속 그림이 나와도 바뀌지 않는다. 따라서 D의 독자적 추가 예측을 시험하려면 결과가 유리한 사례로 현재 표본을 교체하는 대신 별도의 사전 선택·노출·판정 프로토콜이 필요하다. 이 작업의 RESULT/카드/예측은 그대로 보존한다.
