# 모집 기록

전체 공개 이슈의 opening body를 확인해 Excalidraw 60위 `#4906`, MuseScore 60위 `#12369`까지 기록했다. 첫 웹 목록은 검색 API와 별도인 GitHub issue 화면이다. 첫 MuseScore 목록은 1,000건 제한까지 열었을 때 적중 57건이었다. 동일 날짜 범위를 겹치지 않는 UTC 분기로 나누고 같은 문자 규칙으로 다시 확인했다. 초기 목록 및 재계산용 요청과 순번을 함께 둔다. 이 변경은 모집 대상이나 우선순위를 바꾸지 않는다. [목록 위치](evidence/frame-pages.jsonl) · [초기 순서](evidence/frame-scan-original.csv) · [확정 순서](evidence/frame-scan.csv) · [60+60](frame.csv)

원 이슈 안의 링크 52, 공개 대체 경로 48을 합쳐 100개 URL을 조회했다. 99건의 터널 403과 M60 원 blob 주소의 HTTP 503을 관측했다. ZIP이 향하는 GitHub 호스트 및 Dropbox·공유 장면·MuseScore 첨부 호스트는 현재 환경에서 해당 응답을 받았다. 이 관측으로 원 첨부가 만료되거나 원저작이 없어졌다고 단정할 수 없다. ZIP과 다른 주소의 ZIP이 같은 바이트인지도 미확인이다. [응답·도착 호스트](evidence/attachment-attempts.jsonl)

| 줄 | 원글에서 보이는 입력 | 선정 상태와 보류 근거 |
| --- | --- | --- |
| E05 | 일부 클립보드 JSON 한 개 | 같은 사각형·글꼴 크기를 붙여 넣고 추가할 텍스트를 편집하는 재현 조건이 있다. 이 실제 직렬화 조각은 판독할 수 있다. |
| E08 | 장면 공유 URL, 코드샌드박스, 기대/실패 화면 | 기대 이미지와 장면 로딩은 원글에 있다. 배포 SDK 판은 후속자 답변에 있으며 원 장면 바이트는 미확인이다. |
| E16 | 저자가 사용한 EXCALIDRAW ZIP과 GIF | 선택한 요소 안의 부분 문자열을 드래그하는 사건이다. 유지 조건과 실제 ID 집합은 원글에서 확정할 수 없다. |
| E26 | 원글에 포함한 실제 SVG 구문 | 사용자가 바란 링크 내보내기 형태다. 내보내기 전에 편집하던 장면과의 대응이나 Excalidraw 원 ID는 미확인이다. |
| E51 | ZIP, 저자가 설명한 영상 | 원글은 동영상을 첨부했다고 한다. ZIP 내부 구조는 미확인이고 `files` 예는 원글 뒤의 후속 글이다. |
| M01 | 저자가 올린 score ZIP, 3.6.2와 backend 비교 | 가사 배치와 동일 점수의 보존 대조다. 원 파일 미확인이다. |
| M02 | 제3자 악보 Dropbox, MS3 열기 성공 | 악보 전체 열기 문제다. 후속 발췌의 이미지 두 개와 손상 MMRest 지목은 원글 대상의 확정으로 쓰기 어렵다. |
| M03 | 같은 작성자의 예제 악보 두 개 | 빈 UI 옵션과 범위 번호가 대상이며 MMRest가 유지 조건이다. 비교판 두 원본 모두 미확인이다. |
| M04 | 저자 첨부 mscz ZIP | 줄 간격과 조표 임시표 위치를 분리한다. 3.6.2 재현과 첨부 2.6.2 추정은 후속자 관측이다. |
| M60 | 작업자가 링크한 저장소 공식 MSCX 고정 시험 | 본문 주소는 이동하는 master다. 공개 release의 동일 파일은 별도 판으로 확보해 조사한다. 작성자 설계 첨부와 별도 층이다. |

중복 라벨은 E01·E27·E55와 M07이다. M12/M13, M15/M16/M17, M28/M29, M43/M46, M50/M53의 파일명 재사용은 원 URL이 서로 다르므로 동일 바이트 재게시 수에 넣지 않았다. 구조 후보 URL이 복수인 M03·M37·M38·M55의 각 판/경로를 보존했다. 그중 M37의 GP는 악보 소스의 다른 형식이다. 내용상 복수 대상 판단은 열지 못한 파일에서는 미확인이다. [원글 원장](frame.csv)
