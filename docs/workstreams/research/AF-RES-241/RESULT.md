표 1의 한 행은 독립 초기 상태에서 출발한 한 여정이다. S는 지정 변경 후 저장, B는 첫 편집 폼에서 저장 없이 앱 Back이다. Apply의 표시 경로는 공통 /candidate/application 접두사를 줄였다. 두 호스트와 정확한 URL·필드 name/id·리소스 ID·AX 순서·U+00A0 및 중간 단계는 [journeys.csv](journeys.csv)와 각 원영수증에 있다. 표의 AX 이름은 공백을 접었다. 16/16에서 실제 AX 원문은 `Change\u0020\u00A0\u0020{suffix}\u00A0`이며 description 필드가 없었다.
