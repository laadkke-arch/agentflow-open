- P3: 빈 셀 자체는 distinct header에서 빈 문자열로 유지, duplicate key는 하나로 축소, short row는 restval None, 완전 빈 행은 skip. 원 첨부 접근 실패로 81→54의 원인 확정 금지.

완전 근거 수 0은 판정 결과이고 미확인 원저자 실행 건수를 0 성공/0 실패로 바꾸지 않았다. 가까운 공식 시험의 올바른 이름·제목이 곧 해당 입력 조건의 증명이 아님. 추가 링크가 있었으나 열지 않은 자연 C 사건은 없음(3/3). 미개봉 효과 비교는 불가능. 선택 교정 K1 및 K2/K2-neg는 자연 답 봉인 뒤 정답을 열었으므로 추가 독자 측정하지 않음.

동일 문서의 처음 노출 UTC는 jq N11과 CPython N33 모두 첫 출력 batch 07:53:51.714Z, 실제 출력 순서는 J2,J3,J1,P2,P3,P1. 같은 batch 모든 첫 면을 본 뒤 중간 답을 저장했으므로 사건별 독립 독자와 같은 실험 아님. N42는 N33과 본문 완전 동일, N43의 Writer 시작 부분은 이미 본 P1 N27과 겹침. J3 final은 J1 N5 if 계약을 다른 사건에서 읽었으나 의도적으로 증거 제외. 새 정보의 문서간 학습 가능성을 제거할 수 없다.

**별도 계보의 반대 설계.** [D-GO](https://github.com/golang/go/blob/6885bad7dd86880be6929c02085e5c7a67ff2887/src/encoding/csv/reader.go#L1-L54)는 마지막 newline 선택과 default writer LF 및 blank/whitespace 구별, [R-GO](https://github.com/golang/go/blob/6885bad7dd86880be6929c02085e5c7a67ff2887/src/encoding/csv/reader_test.go#L1-L112)는 no-EOL/semicolon/multiline test. [R-RUBY](https://github.com/ruby/csv/blob/afbee5e3548d38914706ae0de8a6cf421ba43187/test/csv/parse/test_header.rb#L1-L140)는 first-row header와 explicit header의 다른 소비 동작, [R-RUST](https://github.com/BurntSushi/rust-csv/blob/05612e87e6e92910d40d7214b70952b8434fef9b/src/reader.rs#L1-L100)는 기본 has_headers=true인 builder와 예제 assertion. 다른 라이브러리의 같은 reader 명칭이나 CSV라는 키워드로 Python SEP·duplicate·EOF 동작을 보장하지 않는다. [R-PYYAML](https://github.com/yaml/pyyaml/blob/29d7735966c3dbb9043bb3975a372d12f3e2fe75/tests/legacy_tests/test_constructor.py#L1-L100)은 custom loader/tag 테스트 구성의 참고, 실제 assertion 확인·실행 없음. 정답을 추측한 독자의 상황과 달리 이 자료들은 모두 봉인 후 조사로 자연 효과에서 제외했다.

### 채택·보류·조합 가능한 설계 원리
1. 직접 절에 대상·조작·보존 조건·예외를 짝짓는 최소 메타데이터를 붙인다. 관련 단어가 아니라 적용 대상·판·입력·출력 방향을 대조. 첫 면의 지지가 충분하면 끝낼 선택지를 유지한다.
2. 추가 시험 링크는 선택형이며 해당 시험이 증명하는 좁은 계약(예: explicit semicolon)과 못 증명하는 경계(SEP 해석)를 함께 반환한다. 해당 입력을 검증하지 않는 테스트는 탐색 후보/반례로 표시한다. 읽지 않은 두 번째 링크는 근거 수에 합산하지 않는다.
3. 다른 조건의 자료는 대안/조합 가능성으로 분리하되 실제 검증 요구를 명시한다. 원전 계약 vs 실제 실행 vs 원저자 환경이 다른 층이다. 예산 초과 시 더 많은 링크 대신 보류·확인해야 할 최소 자료를 반환한다. 이 설계 후보는 6건 관측으로 인과효과가 증명된 제품 결론은 아니다.
