# Two-part score

`two-parts.mscx` is the original synthetic score in this packet, dedicated to the public domain under CC0 1.0. It carries no content from an upstream musical score. Two untransposed instruments each have a single whole note. Flute has a fingering child. Oboe has an explicit small horizontal offset. The same bytes are input to all 36 operations.

The historical references stay upstream. [part-fingering.mscx](https://github.com/musescore/MuseScore/blob/f4fcf53ff65c56f0efb616a3af209d3faba9b342/mtest/libmscore/parts/part-fingering.mscx) shows an original Note→Fingering fixture. [part-breath.mscx](https://github.com/musescore/MuseScore/blob/f4fcf53ff65c56f0efb616a3af209d3faba9b342/mtest/libmscore/parts/part-breath.mscx) and its references show the original breath/link/undo tests. Their digests and test assertions are in the source ledger.
