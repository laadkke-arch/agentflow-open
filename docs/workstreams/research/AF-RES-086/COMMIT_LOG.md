직접 git push는 인증수단 부재로 실패(exit128). 승인된 GitHub connector로 같은 tree를 원격 커밋하고 public git fetch로 되읽었다. 초기 로컬 임시 커밋6ad39f3은 배포된 결과 SHA로 사용하지 않는다. 후속 원격 SHA는 다음 묶음에 기록한다.

묶음4b는 고정 결과6b7cb060의 원격9파일 전체 재열람과 검사 영수증만 추가한다. 두 공통 검사 환경 실패와 마지막 exit0을 모두 보존한다. 묶음4b의 SHA는 마지막 HANDOFF에서 기록한다. HANDOFF는 그 뒤 별도 단독 커밋이다.
