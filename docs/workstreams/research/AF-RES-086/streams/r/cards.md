# R 부분 사용자 반환 카드

## R1 — archive 1.1.12의 archive_read

- **지금 반환:** [고정 생성 HTML 원문](https://github.com/r-lib/archive/blob/45e0d9ebc168cf3632bc2d737c9db2318668a826/reference/archive_read.html). [파일 다운로드](https://raw.githubusercontent.com/r-lib/archive/45e0d9ebc168cf3632bc2d737c9db2318668a826/reference/archive_read.html)도 가능하다. 이 링크는 보존된 HTML 소스이며 렌더링된 옛 사이트를 재현하는 링크가 아니다.
- **볼 절:** `archive_read`의 Usage·Arguments·Examples, Released version 1.1.12 표식. GitHub 원문에서 해당 절을 찾아 읽는다.
- **입증 가능한 시점:** 발행자는 생성 커밋 `45e0d9eb…`에 2025-03-24T12:34:38Z를 기록했다. 이번에 직접 받은 14,289-byte 파일의 SHA-256은 `0c0efbe4b86a97aa6d5662af71fa2dd8bf04a91e6caf6793c08c5ccd407722b3`이며 발행자의 Git blob SHA-1과 직접 계산한 Git blob SHA-1도 같다. 이것은 생성 파일의 식별이다.
- **보류한 주장:** 2025-03-24~26의 `archive.r-lib.org/reference/archive_read.html`가 이 파일을 제공했다는 주장, 배포 `2328795124`의 과거 success, 구판 영구 보존. 현재 공개 사이트는 1.1.14다.
- **다음 최소 확인:** 선택 배포의 과거 상태/로그와 주창의 정확한 URL 응답에서 UTC·최종 URL·1.1.12 본문 지문을 확인한다. inactive는 앞선 성공이나 파일 소실을 직접 증명하지 않는다.

## R2 — asciicast 2.3.1 예제

- **지금 예제를 읽으려면 반환:** [현재 예제 페이지](https://asciicast.r-lib.org/articles/asciicast-demo.html). 2026-11-23T14:49:25.040842Z의 200 응답에서 2.3.1을 읽었으며 선택 2024년 생성물과 15,974 bytes 전체가 같다.
- **역사 자료를 고정해서 인용하려면 반환:** [고정 생성 HTML 원문](https://github.com/r-lib/asciicast/blob/92fecbc0ce019cc03086d5fc3f5b9e1a788a84c1/articles/asciicast-demo.html), 또는 [파일 다운로드](https://raw.githubusercontent.com/r-lib/asciicast/92fecbc0ce019cc03086d5fc3f5b9e1a788a84c1/articles/asciicast-demo.html). 이것은 보존된 HTML 소스이며 렌더링된 옛 사이트가 아니다. 현재 사용 목적과 고정 자료 인용 목적을 별도로 고른다.
- **볼 절:** `init_knitr_engine` 예제, Caching, Using SVG files, Released version 2.3.1 표식.
- **입증 가능한 시점:** 생성 커밋은 2024-01-21T20:53:46Z를 기록한다. 직접 읽은 파일 SHA-256은 `c812426f5a97f8361e64a7a3beb8a35d5dde4bd2270b70dc1f1567080471ca0c`이며 Git blob도 일치한다. 생성 당시와 현재 조회 두 지점의 파일 식별이며 그 사이 연속 제공 증명이 아니다.
- **보류한 주장:** `[2024-01-21T20:53:46Z, 2024-01-24T20:53:46Z)`의 도메인 경로 제공, 배포 `1283145596`의 과거 success, 영구 유지·사이트 전체 assets의 실행. 현재 바이트 일치로 이 공석을 메우지 않는다.
- **다음 최소 확인:** 고정 3일 창의 경로 응답 또는 날짜가 붙은 발행 산출물 기록에서 URL·2.3.1 본문 지문을 확인하고, 과거 배포 상태 원행을 별도로 확인한다.
