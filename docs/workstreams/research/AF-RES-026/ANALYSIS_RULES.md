# AF-RES-026 · 집계와 보정의 뜻

이 문서는 전체 T0 봉인(68fc97fadceb46f9945a71fcc53730e29f6c62bf) 후 통합자가 사용하는 집계 사전이다. 최초 표집·문구·변수는 바꾸지 않는다. 세 계열 담당자가 후속을 읽기 시작한 뒤 작성했으므로 사전 등록된 분석 계획이라고 부르지 않는다. 봉인 전 규칙은 SCOPE.md의 최초 커밋이 정본이다.

## 서로 합치지 않는 수

| 항목 | 산입 조건 | 산입하지 않는 것 |
| --- | --- | --- |
| 최초판 확정 | 첫 요청의 전문과 고정 artifact 또는 Message-ID, 시각·응답 관계를 확인 | 현재 게시글만 읽고 수정 이력 추정; Date를 서버 수신 시각으로 대체 |
| 엄격 미열람 | 최초판 확정에 더해 답 본문·답 요약 노출 없이 해당 I/C/Q를 봉인 | S01 검색 답 문장 노출; 이를 삭제하거나 다른 성공 사례로 교체하지 않음 |
| T0 사실 충분 | 선언된 제한 범위의 판정에 필요한 사실이 최초판에 있음 | 단지 잘 쓴 보류문; 원 목표 전체 해결과 제한된 동작 설명을 혼합 |
| 근거 있는 답변 | 당시 같은 후보·판의 공식 근거가 실제 문구의 주장 범위를 지지 | 질문자가 수행했다는 추정; 후보 문서에 관련 단어가 있다는 이유만의 승인 |
| 근거 있는 사용 승인 | 필요한 조건이 충족된 특정 사용을 허용 | 불가능하다는 근거 있는 부적합 판정, 조건부 분기 설명, 보류 |
| 조건부 답의 성립 | 각각의 조건과 그 조건 아래 제안하는 사용 또는 보류가 근거로 연결됨 | 어느 가지인지 사용자에게 묻지 않았다는 이유만으로 실제 해결 인정 |
| 오승인 | 승인한 사용이 필수 조건과 실제로 충돌함을 같은 판 근거로 확인 | 근거 누락만 있음, 사용자 결과 없음, 위험이 있을 수 있음 |
| 근거 부족 승인 | 사용을 허용했으나 필요한 조건·동등성 근거가 빠짐 | 이미 실패했다고 단정; 오승인으로 자동 합산 |
| Q 값 회수 | 실제 같은 변수 질문에 작성자가 답하거나 작성자가 명시한 기존 사실 | 제3자 추측, 모호한 감사, 새 요구, 시간적 성격이 불명인 늦은 선호 |
| 작성자 진전 보고 | 실행·재현·선택·수정·사용을 작성자가 구체적으로 보고 | 수락 배지·감사만, 유지관리자가 설명했음, 연구자가 문서를 확인했음 |

Q의 값은 **최초판에 이미 있음 / 실제 질문에 대한 직접 답 / 자발적 기존 사실 / 제3자만 / 새 요구만 / 늦은 선호의 시간성 미상 / 답 없음**을 보존한다. 한 사례에 여러 발화가 있으면 발화 행은 모두 남기되 사례 분모는 한 번만 센다. 직접 답을 했다가 새 요구를 추가한 경우도 두 발화를 섞지 않는다. Q 값을 알았어도 다른 필수 조건이 남으면 사용 승인은 보류한다.

### 전체 사용 승인 경계의 사후 교차검토

한정 근거 응답은 설명·부적합 답·조건부 안내를 포함한다. 별도 지표인 전체 사용 승인은 원래 목표의 필수조건을 포함하고 T0에서 어느 사용인지 정해진 문구에만 준다. 이 엄격한 경계에서 I는 S01/S03/S08/P01의4건, C는 S01/P01의2건이다. S08 C는 NOT NULL 조건을 빠뜨렸다. S03 C는 OFF 유지가 필수인지를 알 수 없고 다른 가지에는 참조 의미 확인이 남아 있다. S03의 drop/recreate 가지가 가능한 경로라는 넓은 해석이면 C3이라는 민감도를 별도로 남긴다. 계열 원래 태그·봉인 문구는 보존하고 이견과 교정은 adjudication-overrides.json에 기록한다.

## 판독 오류와 사용자 정보의 분리

처음부터 글에 있던 사실을 통합자가 나중에 발견한 것은 `original_reread` 보정이다. 작성자가 새 사실을 알려 준 Q의 이득으로 세지 않는다. P04의 기존 dump 입력 경계, P05의 단일 publication 목적, C01의 브라우저 요청 주체가 이 검토의 대상이다. 최초 코딩·봉인 메시지는 유지하고 보정 이유와 근거 위치를 따로 기록한다.

T0의 필수 조건을 T1에서 임의로 늘리지 않는다. 늦게 나온 선호의 발생 시점이 불명이면 기존 사실/새 요구 중 어느 쪽으로도 확정하지 않는다. 보조 민감도에서 그것을 T0 필수로 가정했을 때의 판정만 따로 계산한다.

## 분모·비용·검열

전체 질문 분모는 항상 24이고 전략 메시지는 72다. 메일의 답장 제목 metadata와 상한 이후 미심사 원장은 전체 frame 행에는 남지만 적격 root 심사 분모와 분리한다. 반복 발신자·같은 이동 프로젝트·다른 목록 재게시는 독립 사람이나 독립 채택 사건이 아니다.

실제 왕복은 공중 대화에서 확인한 추가 사실 요청→작성자 답의 쌍이다. 첫 답까지의 시간, 추가 질문 뒤 답까지의 시간, 전체 대화 지속 기간을 별도 이름으로 둔다. 답이 없으면 관측된 대기 시간을 무한대나 실패로 바꾸지 않고 최초 시각+30일의 우측 검열로 남긴다. 삭제/차단은 관측 실패다. 별도 구현은 90일 창에만 둔다.

가상 I/C의 추가 왕복은 문구 발송에 0, 가상 Q는 작성자가 답한다는 조건 아래 최소 1이다. 이는 실제로 보낸 전략의 효과나 절감 시간이 아니다. 원문 접근 횟수·링크 수는 연구 도구/문구의 대리 비용이며 사용자의 클릭·읽기 시간을 관측한 값이 아니다.

최초판 미확인 사례의 성립/불성립 양끝, 엄격 미열람 하위집합, 직접 답만인 하위집합을 별도로 제시한다. 해당 분모가 0이면 비율은 해당 없음이며 0%로 만들지 않는다. 기술적으로 보류된 사례의 사용 결과가 없다는 것을 실패로 합산하지 않는다.
