직접 읽고 중복을 제거한 최소수 산입 원문은 61저작(24대화+당시 제공자 문서/테스트32+타 분야5)이다. 날짜 불명인 현재 Census A2 지침을 빼면60저작/타 분야4가 남는다. 동일 대화의 댓글, 판, 재게시, 같은 파일의 여러 판을 새 저작으로 세지 않았다. sources.json은 재독·탐색·계보를 포함해159행이며 159개의 독립 원문을 주장하지 않는다. Census 보고서는 2025 발행이지만 면접 관측은 2023–2024다. 이를 2022 소프트웨어 T0 후보로 소급하지 않는다.

후속 통합137행은 실제 공개 발화114, 개정4, 검열 요약11, 원 사례와 연결되지 않은 인접 기록8이다. curl의 Date와 서버 수신시각 차이로 검열 요약3행의 끝 경계 표기가 달라지지만 실제 발화의 30일 포함 여부는 바뀌지 않았다(evidence/window-audit.json). 원문 클릭 대리량은 중복 제거61저작으로만 비교하며 도구 재시도·캐시를 포함한 총 HTTP 요청 수나 사용자의 클릭 수는 미확인이다.

현재 통합 코드의 집계 사전은 T1 뒤 작성했다. 한정된 근거 응답(I13/C14), 원 목표의 전체 사용 승인(I4/C2), 원 목표 판정에 필요한 T0 사실의 충분성(6/24; 비교판 가정 포함7/24)은 서로 다른 지표다. Q의 새 값은 엄격0/24, 직접 답 하위집합은0건이어서 비율을 계산하지 않는다. P03/S04/C05의 약한 해석을 모두 허용한0–3은 코딩 민감도이고 통계적 신뢰구간이 아니다.
