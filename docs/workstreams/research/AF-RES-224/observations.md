# ③ 주관측 (실제 카운티 수치 미확인)

- 표본: CA Alameda(06001), Alpine(06003), TX Harris(48201), Loving(48301). 2019–2023 ACS5, B23025. 목표 4개 GEO_ID, 48개 E/M/EA/MA 원값, 유도율 2개. 관측 0/4, 0/48, 0/2. GEO_ID는 공식 규칙으로 예상한 키이며 Harris 예시는 지리 가이드에만 확인, B23025 셀 직접 확인 아님.
- S01 사전: 005E 실업, 003E 민간 노동력, 001E 16세 이상 전체. S12 모집단 정의: 실업은 민간 16세 이상 중 기준주 미취업이며 구직·취업가능 등 정의 충족; 군인·비경제활동 제외. 005E/003E*100. S17의 별도 공표 사례: 2008–2012 ACS ZCTA 10001, 1196/13734*100≈8.708%, 표시 9%; 전체인구 분모 19026으로 잘못 바꾸면 ≈6.286%. 동일 표 이름이나 이 사례의 값은 2023 카운티의 대용값이 아니다.
- CA 및 TX 쌍 각각 (005E1+005E2)/(003E1+003E2)*100, 원 정수에서 계산 후 한 자리 반올림. 단순평균과는 일반적으로 다르다. 두 값 모두 미확인.
- S09 벌크 파일 크기 오류, S10 JS 화면, S11 API 읽기 실패. key 필요 여부는 직접 확인되지 않았다. 조회일 판과 발행 시점 판의 바이트 동일성 미확인.
- S14 공식 MOE 산식과 S15 replicate 지침을 구분. 원값 없는 경우 실제 MOE 추정도 보류.
- 수치 없는 상태에서 아래 별도 합성 통제를 통해 기록의 필요 조건만 확인한다. 실제 네 카운티에서의 탐지 성공률로 해석하지 않는다.
