## Q5. 결측·0·MOE
S13 API annotation 지침: N(-999999999), (X)(-888888888), **(-222222222), *****(-555555555, controlled), '-'(-666666666) 등 숫자 토큰은 필드별 의미와 원문을 보존한다. 통제값 MOE는 sampling error 없음이라는 뜻이지 일반 결측의 0 대입 허용이 아니다. 실제 네 카운티의 특수값은 미확인. E=0은 관측값일 때만 0, 분모 0이면 유효율 없음. S14 90% MOE를 1.645로 나누어 SE; 분리 지역 합 MOE의 근사 sqrt(ΣM²), 단 분산 공분산의 가정/한계 명시. p=U/L이며 U가 L의 부분집합인 경우 MOE(p)=sqrt(M_U²−p² M_L²)/L, 음의 근호면 지침상 ratio 근사(더하기) 사용; p=1 특례 및 계산 조건은 지침 확인. % 환산 시 100 곱함. 일반 비율은 더하기 근사. S18 worked example p6의 식·설명 간 plus/minus 및 번호 불일치 가능성: S14 수식과 대조하고 독립 재검토 요청. S15는 80 variance replicates로 covariance 반영, 실제 B23025 지원 여부 미확인. E+M을 추정치 합계로 쓰거나 MOE를 단순 선형합하지 않는다. 실제 MOE 계산 0/2.
