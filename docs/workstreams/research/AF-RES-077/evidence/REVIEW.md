# 재개 검토와 반영

검토는 봉인 후 같은 모델 계열의 세 별도 문맥이 수행했다. 원 A/B reader와 구별하며 인과효과 표본을 늘리지 않는다. 원 원문·실행·미확인을 구별하기 위한 감사다.

| 검토 | 확인·수정 사항 | 반영 |
| --- | --- | --- |
| resume-review-shotcut | 완료 시 replaceAllByHash fan-out이 producer scope 구현의 추가 지점; SC-X 복구 정책의 세부 차이 | RESULT Q4/Q8, ERRATA E6. core choice0/3을 완전한 구현 동일성으로 확대하지 않음. |
| resume-review-musescore | tracker 부분 캐시, v3.0.1 시간 순서, TEI 정확한 절 제목, Note::mark에 의한 색상 혼동 | RESULT Q1/Q3/Q5/Q7, CASEBOOK 추가 문단, ERRATA E5–E7, 새 SOURCES 행. 과거403 기록과 봉인 입력 보존. |

SELF_CHECK 띄어쓰기 검토는 사실·URL·수치·7열 질문표·명령을 보존한 편집이었다. source assertion·native test·역사적 채택을 한 종류로 합치지 않았다.

확인되지 않은 범위를 해소한 것처럼 바꾸지 않는다. target0/9, primary0/3, original execution receipt0/9, 최초 body revision0/3, 당시판 대상 독립자료3/6, causal denominator0이 최종 PARTIAL의 근거다. 실제 기계·계약·공통 검사와 원격 재열람은 별도의 acceptance evidence가 증명한다.
