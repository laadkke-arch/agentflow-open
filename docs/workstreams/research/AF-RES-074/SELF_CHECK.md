# AF-RES-074 자기 점검과 수용 경계

**연구 상태: PARTIAL.** 최초 요청8건, 자연8자리·대조4쌍, 전체108개 정책/점수 분기,65개 최소량 산입 원저작은 확보했다. Pandoc 고정판 실행도 완료했다. PARTIAL의 이유는 제한된 공통 열람 예산을 실제로 지키지 못한 경우, PAN-C1의 목적 질문과 조작한 설정 필드의 불일치, 기대값 선행 노출 후 대조 선정, GDAL-N3의 후보 혼합판이다. 자연의 후속 효과 미확인이나 새 사람 실험 미실시는 사용자 지침상 허용된 관측 한계다.

이 파일의 판정은 원장과 [acceptance-evidence.json](evidence/acceptance-evidence.json)을 따른다. 마지막 구조 검사는 [validation.json](evidence/validation.json), 고정 결과 SHA의 계약 검사와 GitHub 재열람은 최종 HANDOFF의 영수증을 따른다. 구조 PASS가 연구의 모든 조건 충족을 뜻하지 않는다.

## 검토 주체와 실제 수행 범위

Pandoc·GDAL의 별도 모델 조사자가 직접 원문을 읽고 각 원장을 작성했다. `crossfield` 모델 조사자는 별도 원문·fixture 회수와 판정·집계를 교차 검토했고, root도 최초 요청·기술 원절·다른 분야 절차와 추가 반례를 재열람했다. 같은 작성자의 재독은 자체 점검이다. 모델 간 검토는 공유 원장과 가설을 볼 수 있는 **비맹검 교차 검토**이며 통계적 독립이나 사람 검증을 주장하지 않는다. 사람 독립판독자0명, 새 사람 정책실험0건이다.

원본 캐시나 설치 바이너리가 없어져도 결과를 읽을 수 있도록 핵심 입력·출력·receipt를 커밋했다. 임시 캐시는 최소량·성공 근거로 단독 사용하지 않는다. `workbench.session check`의 실제 주체·커밋·exit와 GitHub의 결과 재열람은 마지막 HANDOFF가 가리키는 고정 결과 SHA로 확인한다.
