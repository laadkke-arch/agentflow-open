# GDAL 모집 확장 및 최초판 사후 확인

확인 UTC: 2026-11-23T10:37:43.117416+00:00

이 문서는 앞서 만든 `NOTES.md`와 `self-check.json`의 **최초판 접근 상태**를 갱신한다. 봉인 당시 원문 회수 403 기록과 세 사전 원장은 그대로 보존했다. 이후 같은 공개 GH Archive 시간별 URL에서 HTTP 200이 관측되어 원선정 4건의 최초판을 실제 확인했다. 성공 원인을 특정하지 않으며 인증·프록시·대체 경로는 쓰지 않았다.

## 원선정 네 건

`selected-initial-recovery-addendum.json`에 event ID, issue ID, 작성자, 생성 시각, 원문 SHA256과 대조 결과를 기록했다. #3346·#3386·#3427은 봉인 전에 읽은 현재 본문과 최초 본문의 바이트가 같다. #3378은 제목의 backtick과 재현 명령 안내 문장 표현만 바뀌었다. 목적·보존 조건·입출력·환경·사전 선택 필드는 달라지지 않았다.

이것은 **사후에 확보한 최초판 출처 확인**이다. 최초판을 봉인 전에 복구했다거나 사후 자료를 보지 않았다고 다시 쓰지 않는다. 후보·필드·A/B/C는 변경하지 않는다. 최초판 미복구는 이제 이 네 건의 남은 결손이 아니지만, 새 작성자 필드 값이나 독립 사용 성공, 질문 개입의 실제 효과를 추가로 관측한 것은 아니다.

## 고정 모집 경로의 다음 열두 건

기존 검색 합집합의 번호순 13–24번을 읽었다: 3542, 3566, 3592, 3594, 3622, 3627, 3628, 3634, 3675, 3677, 3695, 3757. `frame-extension.json`의 12행은 전체 본문·재현 명령·제시된 텍스트 산출물을 직접 읽은 기록이다. 댓글·연결된 첨부파일·이미지·외부 실행 기록은 열지 않았고, 새 정책 사례를 선정하지 않았다.

이 가운데 11건은 실제 opened 이벤트를 복구했다. #3566은 HTTP 200 이후 gzip EOF가 발생해 최초판을 회수하지 못했다. 이를 HTTP 403이나 미응답으로 바꾸어 기록하지 않았다. 내용상 #3592는 CI 불안정성 이슈이고, #3677은 목적을 보존하는 두 행동을 본문만으로 특정하기 부족하다고 분리했다. 나머지 10건의 두 행동은 screening 수준의 잠정 행동이며 공식판 후보 문서의 검증을 마친 새 실험이 아니다.

최초·현재가 달랐던 #3542는 처음의 NaN 점 생성 보고에 공간 필터 crash와 버전 비교가 나중에 추가되었다. #3627은 이미지 두 개와 오타 수정이 추가됐고 목적과 명령은 같았다. #3675는 최초의 format 교체 예시에 GML 결과와 DXF 오류가 추가됐다. 따라서 현재 본문의 성공·실패 전사를 모두 최초 정보로 간주하면 안 된다. `extension-version-comparison.json`이 이 차이를 기록한다.

원래 첫 열두 건 중 후순위 적격으로 남겨 두었던 3432, 3470, 3484, 3495, 3507, 3534, 3537도 실제 초기 이벤트를 확인했다. 일곱 본문은 현재판과 바이트가 같다. `frame-first12-provenance-addendum.json`은 원래 봉인한 `frame.json`을 덮어쓰지 않는 보강 기록이다. 초기 주 사례 네 건을 모두 복구했으므로 이 후순위 사례로 교체하지 않는다.

## 수량과 의미

GDAL 전체 screening은 24건이며 그중 opened 본문 회수는 22건이다. 남은 두 건은 내용상 제외하여 회수를 시도하지 않은 #3439와 gzip 전송 실패인 #3566이다. 원선정 네 건의 회수는 4/4, 사전 입력의 연구 관련 의미 차이는 0건이다. 새로 선택하거나 채점한 정책 사례는 0건이다.

`sources-extension.jsonl`은 24행이며 현재 원요구 12건만 새로운 독립 원저작으로 산입한다. 그 역사판 11회수·1실패는 같은 사건으로 묶는다. `sources-initial-recovery.jsonl`의 추가 11행도 기존 사건의 판 확인이므로 최소량을 늘리지 않는다. #3470의 긴 디버그 로그는 목적·명령과 일부 로그만 읽은 보수적 부분 판독으로 기존 최소량 제외를 유지한다.

## 재현

`verify_initial_archives.py`는 `selected-initial-recovery-addendum.json`의 네 정확한 공개 시간별 archive를 읽고 event ID·issue ID·SHA256을 대조하여 JSON을 표준출력에 낸다. 실행 예: `python -B docs/workstreams/research/AF-RES-074/streams/gdal/verify_initial_archives.py`. 이 새 스크립트 자체의 별도 재실행은 하지 않았다. 동일 알고리즘의 최초 실제 실행 및 종료 결과는 `opening-selected-retry-provenance.json`과 각 영수증에 있다. 과거 403이 다시 발생하면 해당 접근 실패를 그대로 남긴다.
