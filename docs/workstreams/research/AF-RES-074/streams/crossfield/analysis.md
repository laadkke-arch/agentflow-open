# 교차 분야 판독: 값의 소유자와 남는 다음 행동

이 보조층은 공개된 업무 절차·예시를 읽은 비교다. 자연8건 또는 구성대조4쌍에 산입하지 않는다. 직접 읽은 원저작7개, 동일 NCAT 계보의 추가 페이지2개, 접근 실패2개를 [sources.jsonl](sources.jsonl)에 남겼다. 실제 접수·질문 발송·변환 호출·배송 구매는 없었다. 따라서 사람 선택·성공·시간·응답확률은 **미측정**이다. 다음 표의 질문 문장은 연구자가 절차를 재표현한 예이며 실제 대화가 아니다.

## A/B/C 해석에 주는 반례

**CF-H1: 기술적 분기와 값의 소유자는 별개다.** 필요 산출물이나 목적은 사용자에게 질문할 수 있지만, 원CRS는 사용자가 모르고 생산자의 메타데이터에만 있을 수 있다. C에 답이 돌아올 것으로 가정하면 실제 남은 일을 숨긴다. 이때 공개 문서가 알려 주는 다음 행동은 Source 검사 또는 원자료 확인이다. 이는 위 절차에서 도출한 설계 추론이며 실제 응답확률은 없다.

**CF-H2/3: 조건 확인 경로와 링크 수를 따로 보아야 한다.** Esri의 단일 글 안에는 두 도구의 조건과 검사 위치가 함께 있다. 따라서 A의 링크 한 개도 조건부 절차를 운반할 수 있다. B의 링크 두 개가 더 많은 유효 정보를 보장하지 않는다. 반대로 원CRS가 없으면 올바른 두 링크라도 변환 결과를 확정할 수 없다. 이번 연구의 채점은 링크 개수뿐 아니라 독자가 확인할 수 있는 조건·다음 행동을 기록해야 한다.

**CF-H4: 알려지지 않은 모든 필드를 질문할 이유는 없다.** NCAT의 문서화된 zone 기본값과 산출물에 따른 height 요구는 서로 다른 종류다. 기본값이 목적에 허용되고 결과범위를 명시하면 질문 없이 행동할 수 있다. 이것은 비공개 값을 임의 부정으로 간주하는 정책과 다르다. 필요한 높이 산출물을 height 없이 약속하는 경우에는 같은 생략이 부적합하다.

**CF-H5: 두 값이 있어도 정답 후보가 배타적이지 않을 수 있다.** OS의 낮은 정확도 요구는 더 정확한 방법을 금지하지 않는다. Esri의 정의·변환은 연속 단계가 될 수 있다. 양성 대조를 구성할 때 단순히 옵션 이름이나 문서 절이 달라졌다는 이유만으로 권고가 반드시 뒤집힌다고 계산하지 않아야 한다.

## 남은 근거와 재개 입력

이7저작은 업무 규칙·예시의 원자료다. 실제 사람이 A/B/C를 보고 선택한 결과, 동일 과제의 시간, 회신 확률, 질문의 인과효과는 없다. 이를 채우려면 자연 사건의 별개 후속 관측이나 윤리·권한이 정해진 별도 실험이 필요하지만 이번 범위에는 새 사람 실험을 넣지 않았다. 페이지들의 현재 조회판을2021–2024 자연 이슈 당시 기능판으로 소급 사용하지 않는다. 특히 USPS는 March2024 판, NCAT는 표준 UI2.1과2020 API 문서의 명시된 범위에 한정한다.

## 출처 감사

각 URL의 직접 읽은 절·판·확인UTC·한계·독립저작 ID는 source 원장에 있고, [evidence.json](evidence.json)은 비교ID와 질문Q4/Q5/Q7/Q8 및 추론CF-H1–5의 연결을 담는다. 같은 NCAT의 UI·API 범위·llh 절은 한 저작으로 세었다. Esri 두 글은 별도 작성물로 세되 같은 조직 관점을 독립 검증 실험 두 건으로 세지 않았다. 실패한 추측 URL2개는 결과·원저작 수에서 제외했다. 별도 모델 조사자가 읽고 작성했으며 사람 독립 판독은 미실시다.
