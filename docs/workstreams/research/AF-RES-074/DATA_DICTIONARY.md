# AF-RES-074 원장과 판정 경계

## 서로 다른 네 질문

1. **동작 판별:** 같은 판·자료에서 필드 값만 달라질 때 후보의 출력/적합성이 갈리는가?
2. **답의 사용 가능성:** 공개된 조건·링크·행동으로 독자가 하나를 선택할 수 있는가?
3. **실제 후속:** 이 공개 사건의 작성자가 값을 밝혔거나 행동을 골랐거나 별개로 결과를 보고했는가?
4. **질문 정책 효과:** A/B/C를 실제 사람에게 제공했을 때 달라지는가?

본 연구는 1·2의 기술적 판독과 3의 공개 관측을 다룬다.4의 새 사람 실험은 하지 않는다. 표의 조건부 사용 가능은 기술적 설명의 충족이며 사용자 실험 성공이 아니다.

## 모집·판·노출

`frame.csv`: 고정 검색식 합집합의 원순번, 이슈 번호, 생성UTC, 읽은 현재판·opening 회수 상태, 선정/탈락 이유. 검색의 현재판 노출과 후속 댓글 노출을 분리한다. 최초판 회수가 실패해도 우연히 성공한 후속 사례로 슬롯을 바꾸지 않는다.

`packets.jsonl`: 자연8/구성4의 요구 단위. 목적·기지값·필드·값1/2·후보1/2·공통 문서 지정절·사전 답·봉인 커밋을 담는다. 원문 기대값을 선행 열람한 구성쌍은 `post_exposure_constructed`이고 엄격 사전검정이 아니다. 자연 현재판 재구성의 가상 분기는 실제 작성자가 발화한 값으로 바꾸지 않는다.

`criteria.csv`: 기준은 `spec_prediction`, `stored_test_expectation`, `public_execution_receipt`, `author_report`, `researcher_execution`으로 구분한다. 서로 다른 기대 파일은 곧 실행 영수증이 아니다. 양값 입력, 판, 자료/옵션 차이, 기대 산출물 원위치가 있어야 단일필드쌍 판단을 할 수 있다. 한 파일의 복수 시험은 원저작 수와 별개다.

## 정책과 분기

`policies.csv`와 `scores.csv`는 요구×정책(A/B/C)×응답(value1/value2/no_answer)108행을 목표로 한다. A/B는 질문을 하지 않으므로 세 행의 답은 같고, 이들은 같은 정책을 다른 숨은 값에 대해 점검하는 반사실 평가 행이다. C만 답에 따라 응답을 바꾼다. 자연 원문에 이미 값이 있으면 반대값 행은 `inconsistent_counterfactual`이며 실제 요청 정답 분모에서 제외한다. 통제대조에는 실제 질문자나 응답자가 없다.

`no_answer`는 값2 또는 false가 아니다. 최초 요구에 값이 이미 있으면 그 기지값을 여전히 이용할 수 있고, 가린 요청이면 불명 상태로 유지한다. A가 이유 있게 보류했다면 C의 정답 증가를 A의 오답 감소로 부르지 않는다. B가 두 유효 대안을 보존했다면 C가 한 개로 좁힌 사실만으로 B보다 정확했다고 쓰지 않는다.

### 판정 코드

| 코드 | 뜻 | 독립 판정 분모 조건 |
| --- | --- | --- |
| correct_single | 해당 조건에서 단일 행동이 요구를 충족 | 동작·판·입력 근거 확보 |
| conditional_actionable | 두 조건을 판별하는 방법과 각 실행행동이 명시; 독자가 하나로 좁힐 기술적 경로가 있음 | 조건 식별 방법과 각 행동의 해당판 근거 모두 확보 |
| enumeration_unresolved | 후보는 남지만 조건을 알거나 하나를 고를 경로가 부족 | 열거임은 판독 가능하되 성공 정오 분모에는 넣지 않음 |
| wrong | 같은 조건에서 요구를 어기는 행동을 단정 | 독립 반박 출력/명세 확보 |
| hold | 이유 있는 보류 또는 값 확보를 위한 한 단계 | 안전한 보류 판독과 완료 정오를 따로 표기 |
| unjudgeable | 해당판/입력/독립 기준이 없어 정오 판정 불가 | 정오 분모 제외 |

무응답에서 조건부 기술 경로가 있다는 것과 실제 조건을 이미 안다는 것을 구분한다. `condition_identification`은 `already_known`, `inspectable_with_named_step`, `owner_only_unobserved`, `unavailable`, `irrelevant` 등으로 기록한다. 추가 입력검사 한 단계를 정확 완료로 승격하지 않는다.

## 수량과 비용

표3의 `전체 자리`는 요구자리8 또는4이며 시나리오별 분모와 원문 수준 판정을 혼합하지 않는다. 알려진 양값을 합친 분모가 필요하면2×자리임을 명시한다. 분류합계에 포함되는 모든 행과 미판정 제외행을 ID로 연결한다. `judgment_basis_available`와 `strict_initial_budget_eligible`는 별도 Boolean이다.

`avoidable_question`은 원문에 답이 있거나 두값 모두 같은 행동임이 확인될 때만 true다. 기술적으로 갈리는 값이라는 이유만으로 실질 질문이 반드시 필요하다고 세지 않는다. B가 조건을 찾아 행동하는 경로를 제공한다면 실시간 왕복은 필수가 아닐 수 있다. 누락 질문은 불명 조건 때문에 잘못된 단정을 했고 다른 제시 경로도 없을 때만 확인한다.

링크 수, 독자가 추가로 확인할 링크/절 수, 입력 검사 단계, 왕복 수는 설계된 답의 구조를 센다. 연구자가 실제 읽은 문서/절 수는 별도다. 사람 소요시간·응답확률·유료비용은 자료가 없으면 `not_measured`이며0이 아니다.

## 발언과 원저작

`events.csv`: 실제 발언만, 원 ID·URL·생성/수정UTC·발화자ID·OP/maintainer/third-party·선택필드 대응·자발/질문응답/조언·별개결과 여부를 기록한다. 같은 발언을 신규값과 독립성공에 동시에 넣지 않는다. `later_value`와 C의 가상응답을 합치지 않는다. thanks/닫힘 상태만으로 사용 성공을 단정하지 않는다.

`sources.jsonl`: 직접 읽은 각각의 접근 행, `work_id`로 원작계보를 묶는다. 같은 이슈 댓글, 같은 매뉴얼 다른절·판, 원시험 input/output bundle은 독립 저작 수를 늘리지 않는다. 접근실패·미리보기·기준문서·중복열람은 최소량에서 제외한다. 현재판 원요구를 직접 읽은 것과 최초판 복원 성공은 별개다. 최소량은 요구8+시험/예제/검증6+명세/매뉴얼/공지4+다른분야4이며, 전체 수가 넘더라도 범주별 부족을 숨기지 않는다.

## 검토 주체

병렬 모델 조사자는 서로 다른 자료를 읽는 공동연구자다. 별도 모델이 원문과 원장을 교차 대조한 경우 실제 검토 범위를 기록한다. 같은 작성자의 재판독은 자체 점검이다. 사람 독립판독자와 새 사용자 실험은 각각0명/0건이며, 이0은 본 연구 수행 범위에 대한 관측값이다.
