# AF-RES-047 사전 범위와 판정 규칙

봉인 시점: 최초 외부 표본 원문 열람 전. 실제 시각과 SHA는 첫 커밋 및 evidence/session-start.json에 남긴다. 아래 규칙은 결과를 본 뒤 조용히 바꾸지 않는다. 변경은 amendments.md에 원문·이유·영향 행·원래 집계를 남긴다.

## 1. 질문·입력·환경

분석이 사용한 제3자 입력 하나와 실제 보고한 필드 값 하나를 단위로, 발행판 존재(P), 소비자의 특정판 사용 선언(U), 특정 실행과 입력 객체의 연결(R), 해당 필드의 독립 발행자 값 대조(V)를 분리한다. 원문에 그 말이 있다는 것과 그 실행이 그 값을 읽었다는 것은 별도 주장이다.

계획 입력은 chore/workspace-foundation@1f722bfb7360ff9c8d221284d7b1b6484c6fa692, 실제 시작 통합 SHA는 manifest의 integration.commit이다. AF-RES-043@3e0b1433e95cf8fdd5a930db97afa3ae8e3ab1f3의 HANDOFF를 직접 읽었다. 그 자연4건의 실제 사용판 기준0과 추가 후보판 복원을 혼합하지 않는다. 039 네트워크 실험, 043 카드/DOI/UCLA 조사는 반복하지 않는다.

현재 제공된 클라우드 셸·GitHub 연결·웹 열람을 사용한다. 확인 가능한 모델 표시는 세션 지시의 GPT-6 Astra Pro이며 사용자 UI에서 web-pro 모델 선택을 직접 검증한 것은 아니다. 같은 모델 별도 문맥의 분담·정적 검토를 외부 독립 판독이나 독립 실험으로 부르지 않는다. 사용자 PC·유료 API·계정 변경·배포·PR·병합은 이 과제에 없다.

## 2. 소비자 우선 프레임: R Journal 30 + ESSD 30

시작 목차는 https://journal.r-project.org/ 및 https://essd.copernicus.org/articles/ 이다. R Journal 2022 첫 호, ESSD 2022 첫 달부터 시작해 발행일 오름차순, 같은 날은 문서 식별자(DOI suffix/기사 ID) 사전순으로 원문 연구/응용 글 첫30편을 노출 원장에 보존한다. 호/월이30편 미만이면 다음 호/월로 이어 간다. editorial, news, corrigendum 단독 문서는 프레임에서 제외하되 발견·제외 이력은 남긴다. 발행일이 일 단위로 없으면 공개된 호/월과 식별자 순서를 쓰고 날짜 불명확성을 표시한다. 검색 순위를 발행 순위로 대신하지 않는다.

각 층에서 제3자 공개 자료를 실제 입력으로 사용했고 표·그림·출력 예에 수치/분류가 있는 최초3편을 선정한다. 저자 자신의 자료 게시만은 적격이 아니다. 자체 생성 자료 분석에 제3자 입력을 실제 사용하는 경우에는 그 외부 입력만 적격 단위다. 판·해시·실행 기록의 존재 및 값 일치/정정 성과는 선정 조건이 아니다. 최초3편 뒤의 프레임은 노출만 보존하고 성과가 좋아 보인다는 이유로 교체하지 않는다. 앞선 후보의 본문 접근이 막히면 적격 미확인으로 남겨 엄격한 최초3 확정의 한계도 표시한다.

한 논문의 첫 적격 자료는 초록·배경·단순 참고문헌을 제외한 본문 읽기 순서에서 처음으로 실제 입력임을 밝힌 외부 자료다. 그 자료를 사용한 최초 표/그림/출력 예의 첫 명명 필드와 첫 비결측 수치/분류를 선택한다. 관련 수치가 표/그림보다 앞 본문에만 있을 때는 그 첫 명시 수치를 보조 필드로 기록하되 원규칙 표본과 분리한다. 표는 행 우선·열 우선 읽기(헤더 다음 첫 데이터행의 왼쪽 첫 해당 필드), 다중 패널은 (a)부터, 출력은 위에서 아래다. 행 수/표본 수 자체도 입력으로부터 보고한 필드이면 적격이지만 일반적인 데이터셋 소개의 개수만은 실제 분석 사용을 대신하지 않는다. 첫 필드를 발행자에게서 못 찾으면 다음 필드로 교체하지 않고 대안 필드로만 보존한다.

소비 목적, 대상 시점/기간, 행 키, 필드, 단위, 반올림·필터·결측 표기를 소비 본문에서 먼저 고정한다. 소비자 본문을 연 UTC와 발행자 판 자료를 처음 연 UTC를 별도로 기록한다. 본문 링크의 판/결말이 우연히 먼저 보이면 outcome_exposure에 기록하고 미노출이라고 주장하지 않는다.

## 3. 실행 보강 프레임: 최대30 노출 + 2슬롯

시작점은 공개 실행 산출물 목록 https://www.researchobject.org/workflow-run-crate/ 이며 그 examples/실행 사례 목록의 실제 링크만 따른다. 목록이 안내하는 WorkflowHub 또는 공개 RO-Crate 사례·보관소 레코드를 발행연도2021–2024, 발행일·공개 식별자 순으로 정렬한다. 목록을 확대할 때는 출발 문서의 링크 순서를 보존한다. 최초30 노출을 기록하되 실제 목록 소진/접근 실패를 만들어낸 노출로 채우지 않는다. 출발 목록·메타데이터 순서가 확보되지 않으면 표집 수용을 미충족으로 남긴다.

선정은 실행 ID와 입력 객체를 잇는 provenance가 있다는 정보까지만 사용한다. 서로 다른 공개 프로젝트의 최초2건을 택한다. 정의-only, toy/fixture, 실행 없는 예제, 자기 객체 게시만인 사례는 제외 이유를 남긴다. 실제 연구 분석과 도구 시연을 구별할 정보가 없으면 미확인이다. 생성자와 재사용자의 동일 여부, 당대 실행과 후대 재실행을 기록한다. 값·정정 성공을 보고 새 사례로 바꾸지 않는다. 두 슬롯은 자연6 분모에 넣지 않는다.

## 4. 근거 등급과 동일판

- P: 발행자가 구별하는 판 ID/날짜/파일 객체가 직접 확인됨. 개념 DOI는 판 DOI와 별개다. 같은 DOI의 in-place 변경 가능성은 제거하지 않는다.
- U: 분석 작성자의 원문/당대 부록이 해당 판·파일·checksum을 구체적으로 지목한다. 인용만, 동적 다운로드 코드만, 대략 연도만 있으면 엄격 U는 미확인이다.
- R: 실제 실행 ID에 입력 객체가 명시적으로 연결돼 있다. workflow 정의의 예상 입력, 설치/lock 파일, 해시만, 다른 실행의 로그, 후대 재현은 원래 R을 충족하지 않는다. 실행 선언을 읽은 것과 실행 진위를 별도로 검증한 것도 구분한다.
- V: 같은 행 키·필드·단위·대상시점·변환을 발행자 파일/값 또는 다른 계보의 실행 영수증과 대조했다. 숫자만 일치, 다른 행, 복사본 대조는 엄격 V가 아니다.
- 엄격 사용판+값 양성: 다른 계보의 발행자 객체/정정문과 당대 사용 기록이 만나고, 같은 객체 및 필드 투입이 확인돼야 한다. U만, R만, 값만의 조건부 성과를 합쳐 승격하지 않는다.

hash는 실제 내려받은 전체 바이트로 계산했을 때만 계산했다고 쓴다. 공개 메타데이터의 hash는 '발행자 기재'다. 해시 동일은 같은 바이트를 뜻하지만 실행 입력 여부를 뜻하지 않는다. URL 동일/다름만으로 동일판/다른판을 결정하지 않는다. 동일 저작의 판·파일·미러는 비교 증거를 추가하지만 고유 원문 최소수에는 추가하지 않는다.

## 5. A/B/C·재사용·감도

8슬롯 각각 A=원 소비 목적·인용·링크, B=A+발행자 판 목록·원문 위치, C=B+소비자의 당대 부록/실행 기록. 24행에서 실제 보이는 URL·값을 고정한다. C 미존재는 결측 슬롯이며 내용이 그대로 답이면 '기록 재독'이다. 동일 작성자의 누적 근거 감사이며, 무작위·맹검 성과 비교가 아니다. B의 특정판을 채점할 때 별도 작성자 기록, C 사용 선언에는 별도 발행자 파일/값 또는 별도 실행 영수증을 요구한다.

사용 후보판과 그 다음 발행판 한 쌍에서 같은 필드/행/기간을 비교한다. 최초판 재현 목적과 최신값 재사용 목적을 구분한다. 최신판 없거나 파일이 막히면 미확인, 값 불일치로 세지 않는다. 메타데이터만 변경, 값 같아 구별 불가, 같은 값·다른 행, 값 달라도 목적 유효의 반례를 적극 탐색한다. 공식 통계2·지구과학2 원문은 보조 ID로 별도 비교하고 핵심 빈 슬롯을 대체하지 않는다.

각 사례에서 시간 목적/자료 식별자/실제 사용 근거/당시 값/현재 정정의5항목을 하나씩 제거한40행을 만들고 유지/정정/보류와 허용 문장의 변화를 적는다. 원래 없는 항목의 제거는 새 정보 손실0이다. 실제 추천 채택/사용자 비용은 관측하지 않는다.

## 6. 수량·결측·원장·예상 반증

최소 고유 직접 원문24의 배당은 소비분석/원실행보고8, 발행판·파일·정정의 서로 다른 저작8, 작성자 당대 기록/실행 provenance 실제 사례4, 공식통계2+지구과학2다. 한 저작은 한 배당만 산입한다. 전문 실패·검색요약·미러·재방문·같은 저작 다른판은 0추가. 본문 의미 판독과 HTTP성공은 별도다. 웹 도구 반환의 해당 절을 읽은 것은 그 범위의 직접 열람이며 원파일 전체 바이트 검증은 아니다.

frame.csv의 사전90슬롯은 아직 관측0이며 실제 exposure 아니다. 후속 프레임에서 실제 노출과 결측을 채우고 최초 커밋을 원본으로 남긴다. sources.jsonl은 ID, work/edition, source/final URL, publisher/type, publication/update, opened UTC, exact locator, observation, limitation, Q/case, duplicate/count 필드를 가진다. 확인 불가는 '미확인: 사유; 첫 시도; 재개 첫 자료'로 적는다. 조건부 실제 분모0은 '해당 없음'이다. 독립 기준이 없는 표본도 분모/빈 슬롯에 남긴다.

사전 예상: 판목록 B는 발행판을 좁혀도 실제 투입을 증명하지 못할 수 있다. 반증은 공개 당대 사용 기록이 특정판과 필드를 연결하는 사례다. C는 답 재독만 늘릴 수 있다. 반증은 별도 발행자 파일과 정확한 행·값의 일치다. 같은 값은 여러 판에서 반복될 수 있다. 반증은 해당 객체만의 checksum 및 실행 입력 연결이다. 정정판은 옛 재현에는 부적합하면서 최신 판단에는 적합할 수 있다.

묶음별 즉시 커밋·원격 확인, 마지막 RESULT/수용 파일 고정 SHA 재독, session check --fetch 후 HANDOFF만 마지막 단독 커밋. 수정은 owned_path 안에서만 한다. 중간 SHA는 evidence/commits.jsonl에 다음 묶음에서 기록한다.
