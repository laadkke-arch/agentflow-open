## 중요한 미확인과 다음 첫 행동

- 최초 철회 경고 전파 UTC와 당시 사용자 로그의 cache 해시·pip 판은 미확인이다. 2024년 3월 9일 공개 로그는 캐시된 wheel 설치의 근거다. 이번 실행은 Linux/CPython 3.12.14/pip 24.0 및 HTML 후보 세 개의 dry-run이다. 실제 pytest 설치·실행, 다른 클라이언트 및 전체 공개 인덱스는 범위 밖이다. Crossmark 화면 및 PubMed 표시 일부는 열람 실패했고, 출판의 원문·공고·공식 배포 색인 행은 읽었다. [고정 역사 근거](https://github.com/pytest-dev/pytest/issues/12069#issuecomment-1986989847) · [판정을 뒤집는 세 관측](RESULT.md)
- 다음 첫 행동은 원격 작업 브랜치 head가 이 인계이며 부모가 위 고정 결과 SHA인지 확인하고, 결과판의 첫 두 표와 SELF_CHECK를 검토하는 것이다. 다중 인덱스로 확장할 때에는 같은 세 파일과 원 I02 포인터로 Simple JSON 응답 및 metadata sidecar 조건을 고정해 비교한다.
- 색인 반영 제안은 **AF-RES-229 / 정확 핀과 범위에서 pip 24.0이 철회된 pytest wheel을 선택하고 경고하는 조건 / DONE / RESULT.md / 선행 AF-RES-216 `9a306b74…`**다. 통합 담당은 위 결과 SHA와 이 인계 커밋을 연결할 수 있다.

## 고정 입력 재생

CPython 3.12.14의 Codex Cloud에서 GitHub 저장소 체크아웃 루트를 사용한다. 첫 명령으로 결과 커밋을 받는다. 네 wheel의 공개 HTTPS 입수와 SHA 검증 뒤 로컬 server와 깨끗한 venv에서 18회 실행한다. 재생용 입력·출력은 새 임시 경로에 둔다.

```sh
git fetch --no-tags origin refs/heads/work/research-af-res-229 refs/heads/work/research-af-res-216
AF229_DIR=docs/workstreams/research/AF-RES-229
AF229_SHA=a10e044150195e0c3d7219c5314b54d35dee6f66
AF229_TMP="$(mktemp -d /tmp/af-res-229-replay.XXXXXX)"
git archive "$AF229_SHA" -- "$AF229_DIR" | tar -x -C "$AF229_TMP"
AF229_PIN="$AF229_TMP/$AF229_DIR"
python -B "$AF229_PIN/run.py" fetch --wheelhouse "$AF229_TMP/wheels" --receipt "$AF229_TMP/fetch.json"
python -B "$AF229_PIN/run.py" run --wheelhouse "$AF229_TMP/wheels" --group all --out "$AF229_TMP/replay"
python -B "$AF229_PIN/verify.py" --suite "$AF229_PIN/receipts/main" --suite "$AF229_PIN/receipts/controls" \
  --replay "$AF229_TMP/replay" --main-csv "$AF229_TMP/matrix.csv" \
  --controls-csv "$AF229_TMP/matrix-controls.csv" --summary "$AF229_TMP/audit.json"
cmp "$AF229_PIN/matrix.csv" "$AF229_TMP/matrix.csv"
cmp "$AF229_PIN/matrix-controls.csv" "$AF229_TMP/matrix-controls.csv"
```

Wheel을 다시 입수할 수 없는 경우에는 고정 원로그를 펼쳐 같은 분석을 할 수 있다. 이 경우 위 `fetch`·`run` 대신 아래 명령을 사용한 뒤 위 `verify.py` 및 `cmp`를 실행한다.

```sh
tar -xzf "$AF229_PIN/receipts/replay-raw.tar.gz" -C "$AF229_TMP"
```
