PDF 내 score ID·면으로 구분한 경우에만 8 이상; 별개 원파일 요건이라면 1 부족. 그림을 직접 열지 않은 검색 요약은 산입 안 함. 4+4 형식 조건 중 제작/사양은 4, 타 분야는 10 원자료이되 독립적인 동일 AV 원본·접근본 직접 쌍 0. 타 분야 실제 읽은 산출물은 Cinderella 원면/전사, Trek image/OCR 비교 화면의 3 distinct artifacts (Cinderella main은 전사 재표시로 중복 제외); 실제 산출물만 4개 기준이면 부족. 사례 수: 음악 시험 6, 판독 자리 12, 타 분야 사건/사례 4(전자책 1, 신문 1, 영상 정책/인수 2); 독립 관측 = 시각 판독 12자리(한 publisher/구현, 독립 검토 0), 타분야 실제 paired 사례 2(하나는 기관 제공 비교 화면). 자료 수와 독립성 혼동 금지.

## Q1 동일 시험·입력인가?

[C1](https://lilypond.org/doc/v2.24/input/regression/musicxml/collated-files.html) 및 [C2](https://lilypond.org/doc/v2.26/input/regression/musicxml/collated-files.html)에서 ID/filename 6개가 유지됐다. ID 이동 없음. 소수점판은 footer, MusicXML 버전은 XML 선언/DTD로 별도 기록. X11–X26 tag 원문+blob+part/measure/voice locator, 비교는 comparisons.md. 02a duration 256/64→2048/512(quarter unit 4)는 같지만 time 4/4 common→2/2 numeric이 다르고, 11a m7 print new-system 추가, 33c m3 추가, 41i 표시 문자열 변경. 같은 ID나 같은 이미지로 동일 입력 추론 금지. 정확 build option/배포 XML 원바이트는 보류.

## Q2 XML 원값·기호·기능 분리

C5 rest는 complete-measure 속성; C6 multi-rest 숫자와 use-symbols; C7 time의 beats/beat-type·표기; C8 tie 소리와 C9 tied 인쇄; C10 slur의 type/number/연결 위치, C11 part-name-display의 표시 덮어쓰기를 각각 분리했다. 33b에서 X14/X24에 tie와 tied가 각각 존재하고 O14/O24에는 곡선만 있다. 음향 보존 결론은 원문 규칙에 반한다. 이 사양은 MusicXML 4.0 CG Report이며 구판의 DTD와 무조건 같은 규칙이라 간주하지 않음.

## Q3 경로와 증거 층

[C3](https://lilypond.org/doc/v2.26/Documentation/contributor/musicxml-tests)와 C1/C2는 input/regression/musicxml, musicxml2ly, LilyPond 문서 생성/출판 사례를 연결한다. 이 출판은 규범적 기준 이미지가 아니라 해당 변환 결과. caption=기대/테스트 의도, tag XML=입력 후보, 실제 PNG/PDF=직접 관측. 신판 동일 stem PNG/SVG 후보를 열지 못해 PDF 물리7,9,26,36/37쪽을 선택했다. 이는 임의 렌더가 아닌 공식 collated-files.pdf. 원래 개별 그림 URL은 미확인, PDF 위치가 실제 링크. .ly 중간물, build invocation, input byte hash 결합 미확인. 소스 원장 F/G/H/R 실패 기록.

## Q4 양판 속성

표1 참조. 02c 구판 숫자 16, 신판 15 및 독립 쉼표; m1 3은 동일 count지만 glyph가 다르다. 11a 2/2 cut C와 m3 숫자 2/2, 33b F4 연결, 41i P1/P2 문자열을 직접 읽었다. 33c는 구판 겹친 curve에서 endpoint를 유일하게 지정하지 못했다. 신판 m2 n1→n4, n2→n3를 구별하나 m3는 화면에서 교차 성부 curve 확인 못 함. 그림 선명도와 무관한 audio/edit 추정 금지.

## Q5 경쟁 설명·반례

comparisons.md에 전체 본문 비교와 반례. 02c 구판 caption 3,15,1,12와 실측 3,16,12가 어긋남(C1 L93 / O12); 합이 같아도 분리 표지는 다르다. 02a 구판 caption 2+별도 whole과 실측 첫 3도 유사. 신판 02c 입력은 뒤 3구간 추가, 02a meter 변경이 있어 개선 인과를 단일 버전 차이로 귀속하지 않는다. 11a m7 줄바꿈 지시가 새로 생겨도 양판 판면에서 자연/강제 줄바꿈이 비슷할 수 있다. 33b 사양상 tied-only와 tie+tied는 동일 그림 가능(미렌더 가설); 41i 같은 원래 part-name이 서로 다른 표시를 갖는 직접 사례. 33c 새 bar와 판면/곡선 배치, 엔진 옵션, 실제 변환 누락은 아직 경쟁. 동일 bytes 입력×양판 옵션 고정 재렌더 및 중간물 비교가 판별에 필요.

## Q6 타 분야

T8 원면(1865 Cinderella, printed 5)에는 반복 제목과 행말 god-/mother, 쪽수 5가 있고, T9 전사는 godmother 연결 및 별도 header/footer. ## Q7 조합 조건과 비용

- 인쇄 독자: C5–C11 규칙 + O 실제 결과 링크 + edition/measure/voice locator. 인쇄 표기 판독 가능할 때만 직접 관측이라고 말한다.
- 작곡자/편집자: 같은 링크는 위험 신호로만 사용; 목표 editable measure/slur/name object의 실제 import/edit/export 확인 추가.
- 자동 연주 작성자: tie/tied를 분리해 note pitch, duration, voice, MIDI onset/offset과 실제 재발음을 검증. 출력 곡선으로 재생 추천 금지.
- 설계 후보 A(링크+정확판+객체 키) / B(A+실제 결과 위치+판독 가능 속성·미확인) / C(B+입력 hash·중간물·실행 증거). A는 가볍지만 성공 보증 없음; B는 실제 사용자 결과 일부를 설명하나 판독·링크 관리 필요; C는 비용 높으나 편집/재생 질문에 필요. 비용 수치 미측정. 제품 DB·수집기·검색 형식은 확정하지 않음. 173 strict 0/4,175 0/8과 대조하면 출판 자료의 작은 파일은 접근 가능성을 높였지만 엄격 동일성 문제는 남음.
