## 최종 검사와 수용의 분리

`validate_artifacts.py`는 실제로 원장의 분모를 다시 세고, 모든 조건의 정오층·두 표의 행 ID·52개 원개수 차이·출처 연결·최종 약점 표 정확히3행을 확인한다. 결과는 `evidence/artifact-validation.json`에 기록한다. 이 검사는 통계적 식별이나 새 인간 검증을 대신하지 않는다.

고정 결과 SHA의 RESULT와 acceptance-evidence를 GitHub에서 다시 열어 해시를 대조하고, 요청된 `python -B -m workbench.session check docs/workstreams/research/AF-RES-058/manifest.json --fetch`를 실행한 뒤에만 HANDOFF를 작성한다. 실행 주체·명령·실제 SHA·stdout/stderr/exit code는 후속 `evidence/final-verification.json`에 남긴다. 검사 이전 이 파일에서 성공을 선점하지 않는다. 연구의 전체 수용은 저장·계약 검사 결과와 무관하게 현재 PARTIAL이다.
