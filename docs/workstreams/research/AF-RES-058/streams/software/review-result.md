# RESULT 초안 A층 감사

## 판정과 실제 검토 범위

**검토한 A층 수치와 분모에는 정정이 필요한 산술 오류를 발견하지 못했다.** A01/A02의 수락 분자·분모는 모두 미확인으로 남으며 A03/A04는 연구 미충원이다. 파일이 일관된다는 감사 결과는 연구 수용 PASS가 아니다. A층 최초 네 연구, 원행별 같은 후보, 정오별 수락 효과는 여전히 복원 미완료다.

- 실제 검토자: `/root/software_ir`, A층 원장·집계의 최초 작성자인 AI 보조 조사자. A층 자체 검토이며 외부 사람·독립 코호트·맹검 검증이 아니다.
- 1차 입력 고정: `2026-11-23T04:13:21.974146+00:00`. 아래 SHA-256의 로컬 초안과 원장을 읽었다. 부모가 동시에 B층·진단층 수정 중이므로 이 해시는 원격 결과 커밋을 뜻하지 않는다.
- 직접 대조한 RESULT 범위: 표1의 A01–A04 네 행, 표2의 A01–A04 전체49행, 모집·방법 미확인 문단, Q1–Q4의 A층 주장과 제공/열람 구분, Q6 첫 소절의 A01, Q7 제품 이전 조건·네 관점의 두 대안, 세 선택지 추가 분석, 마지막 약점 세 행.
- 생성기 `build_tables.py` 전체를 읽었고, 마지막 `path.write_text` 이전 AST만 읽기 전용으로 실행해 A층53행을 메모리에서 렌더링했다. 원래 RESULT 및 root 파일은 수정하지 않았다. 전체 B층·진단층의 효과 수치나 출처 전편은 이번 감사에서 새로 검증하지 않았다.
- 공개 패키지의15개 JSON Lines 파일을 다시 읽어 합계/고유 ID/동일 batch 연결을 집계했다. 개인 응답·ID를 출력하거나 새로 게시하지 않았다.15개 입력 SHA는 `package-audit.json`의 스키마 명세와 모두 같았다.
- A02 포스터의 캐시 PDF 추출문과 실제 렌더 이미지를 다시 읽었다. Brown 보고서 캐시의 §4–6 관련 문장과 기존 원개수 원장을 다시 대조했다. 이 감사에서 새 외부 원문을 취득한 것은 아니다.

## 세 선택지 논리 반례 검산

이는 **자가 생성 진단**이다. 실제 관측·독립 외부 저작·054 재계산이 아니다. 정답A, 오답B/C이고 AI 정권고는A, 오권고는B로 고정했다. 모든 셀은0이상의 정수이며 정오층마다50기회다.

| 표 | 정권고에서 최종A/B/C | 오권고에서 최종A/B/C | 총수락 | 최종정답 | 오권고 거절 뒤 제3오답 |
|---|---|---|---:|---:|---:|
| 대조 |40/10/0|20/20/10|40+20=60|40+20=60|10|
| 가능세계I 개입 |45/5/0|15/15/20|45+15=60|45+15=60|20|
| 가능세계II 개입 |35/15/0|25/25/0|35+25=60|35+25=60|0|

각 표 N100, 전체 거절40, 최종오답40이다. 오권고 수락 차이는 세계I `(15−20)/50=−0.10`, 세계II `(25−20)/50=+0.10`; 정권고 수락 차이는 각각+0.10/−0.10이다. RESULT의 축약표는 정권고 거절의 B/C 구분을 합쳤지만 JSON의6셀 표와 모순되지 않는다. 오답 선택지별 개별 분포를 고정했다고 주장하지 않은 점도 맞다.

단일 정답의 완전한 이지선다에서는 `T=x+y`, `C=x+(Dwrong−y)`이므로 오수락 `y=(T+Dwrong−C)/2`가 된다. RESULT가 이 경우까지 비식별이라고 주장하지 않는 제한은 맞다. 새 실제 효과·신뢰구간을 이 논리표로 추정하지 않았다. Python `Fraction`으로 ±1/10을 대조하고 행합·총합을 별도로 확인했다.

## 수행 기록과 남은 검사

이 감사에서 실행한 검사는 로컬 `python -`의 읽기 전용 집계/assertion이며 모두 종료코드0이었다. 검사 대상은 고정 캐시15파일·두 JSON 원장·root 통합 원장·RESULT·생성기의 쓰기 이전 AST·toy JSON이다. 기존 두 재현 스크립트의 결과를 덮어쓰지 않았으며 원문 앱/서버 또는 외부 API를 실행하지 않았다.
