# 진단층 D01–D05 및 D07: 독립 반증과 공개 원행 검산

이 파일은 주 모집 A/B의 여덟 자리를 채우지 않는다. 고정된 주 검색에서 누락된 사전지식 후보 다섯 논문을 별도 진단층으로 열었다. 결과 방향을 이미 암시하는 제목·초록과 연구에 대한 사전지식에 노출되었다. 진단층은 효과의 빈도나 대표성을 추정하는 표본이 아니다. 조사·계산 주체는 `/root/diagnostics` assistant이며 새로운 사람 실험을 실시하지 않았다.

후속으로 root가 읽은 D06 Vasconcelos2023의 경계조건을 확인하기 위해 D07 de Jong2025를 추가했다. D07의 두 과제·원 자극·모형 결과·자료 탐색은 `dejong-findings.md`에 별도 기록했다. D06은 root stream에만 세며 여기서 중복 합산하지 않는다.

## 직접 답할 수 있는 결과

**설명 제공 후 전체 정확도가 올라가면서 틀린 권고 수락도 늘어난 실제 공개 사례가 있다.** Lai와 Tan의 호텔 후기 판별에서는 plain prediction 대비 prediction+heatmap의 전체 최종 정답이 990/1600에서 1160/1600으로 늘었다. 그러나 틀린 권고 수락은 123/205에서 152/205로 늘었다. 두 조건 모두 권고 정답 1395건, 오답 205건이다. 따라서 이 차이는 조건별 정답 비중 차이가 만든 현상은 아니다. 실제로 설명을 읽었는지, 원래 같은 답을 가지고 있었는지는 기록되지 않았다. 이 결과는 외부 진단 사례이지 개발 부품 선택의 효과 추정치가 아니다. [DI-LAI-P §3–4, Fig3–4; DI-LAI-DATA]

**반대 방향도 같은 정의로 관측된다.** Bansal 등의 Amazon 책 후기에서는 Conf.+Single의 틀린 권고 수락이 220/728, Conf.는 256/736으로 −4.563%p였다. LSAT에서는 같은 명칭 대비가 358/707 대 331/714, +4.278%p였다. 단일 논문의 서로 다른 과제를 독립 연구로 세지 않으며 이들을 합산하지 않는다. 이 파일의 집계는 공개 필터 후 응답 기록의 기술량이다. 사람 단위 무작위 배정의 표준오차나 새로운 유의성 검정을 만들지 않았다. [DI-BAN-P §4–5; DI-BAN-DATA]

### 실제로 본 화면의 범위

- **D03 Fig1, PDF p6**: 같은 침실2·욕실2·면적1140·예측$160만인 clear2와 blackbox2를 한 그림에서 직접 대조했다. clear에는 계수와 덧셈 구조, blackbox에는 숨겨진 모델 상자만 있다. 완전한 같은 후보 설명 조작의 **원 예시 한 쌍**이지만, 이 연구의 종점은 이산 수락이 아니므로 Q5를 대신 충족시키지는 않는다.
- **D01 Fig2–3, PDF p6**: 책 후기의 잘못된 positive 권고와62.7% 신뢰도, positive span과 negative counterargument를 직접 보았다. LSAT는 같은 화면에 D/B 두 선택지의68.5%/31.5%와 두 이유문장을 제시한다. 원 JSON의120개 자극에 후보·정답·예측 필드를 확인했다. 화면 캡처를 모든 조건의 완전 자극 배정표로 간주하지 않는다.
- **D04 Fig2c, PDF p4와 Fig18b, p16**: prediction+heatmap과 plain prediction 모두 수치 정확도 없이 권고를 보여 준다. 출판된 화면 예시의 후기는 서로 다르다. 같은 후기의 모든 조건 렌더링을 확보했다고 주장하지 않는다. 동일 내용·예측은 공개 원행에서 별도로 감사했다. Fig2b의87% 정확도 문구는 다른 조건이다.
- **D02 Fig1, p6**: 설명 차트의 네 대체재와 두 값, 추가 confidence prompt·클릭 버튼·30초 대기 변형을 직접 확인했다. 이 버튼은 외부 문헌 원문 링크가 아니라 AI 제안과 설명을 여는 버튼이다.
- **D05 Fig7, p7**: 소득분류 Shapley 기여 막대와 base chance를 직접 보았다. 원 문서·검증 출처로 이동하는 링크 실험은 아니다.

이 다섯 연구에서 외부 문서 링크를 실제로 열어 읽도록 무작위 배정한 처치는 확인되지 않았다. D02의 on-demand만 클릭 선택을 포함하지만 설명을 열기로 한 사람의 실제 열람 효과를 설명 제공 배정 효과로 치환할 수 없다.

LSAT Fig3의 신뢰도는 top2가 합100%가 되도록 재척도했다고 caption이 명시한다. raw conf/conf2의 조건 간 동일성은 확인했지만 모든 조건에서 실제 화면의 정규화·표현까지 동일했는지는 조건별 전체 렌더링 부재로 미확인이다.

### D04 손검산: 그림의 반올림 비율에서 정수를 역산하지 않았다

1. 공개 파일에서 각각80개 person key와20개 원행:80×20=1600. `experiment, anonymized_worker_id, review_num` 키 중복0. 각 person key는 한 조건에만 있다.
2. 조건별1395건 권고정답+205건 권고오답=1600. 관련5조건에서 같은 후기 내용마다 truth/pred 일치, exact text318개×5회+1개×10회=1600. 논문의320 test IDs와319exact texts 차이는 내용 중복 원인을 확인할 별도 ID가 없다는 한계다.
3. plain prediction의 최종 정답=908+(205−123)=990;990/1600=61.875%, Fig3의61.9%와 반올림 일치.
4. heatmap의 최종 정답=1107+(205−152)=1160;1160/1600=72.5%, Fig3와 일치.
5. 틀린 권고 수락:123/205=60.0%,152/205=74.146…%, Fig4의60.0/74.1과 일치. 차이29/205=+14.146%p.
6. 전체 정답 차이(1160−990)/1600=+10.625%p. 이것이 오류 선별 개선을 뜻하지 않음은 동일 원행에서 직접 확인된다.

평균의 분해식은 `전체정답 = π×정권고수락 + (1−π)×(1−오권고수락)`이다(이진 강제 선택만). 여기서는 π=1395/1600=0.871875다. 두 수락률이 거의 같은 폭으로 상승해도 많은 정권고 시행의 정답 이득이 소수 오권고 시행의 정답 손실보다 크므로 전체 평균이 상승한다. 이는 계산상의 설명이며 다른 연구에 π를 이식하지 않는다.

## Bansal 공개 파일의 중복과 분석 단위

`decision-result-filter.csv`66040행과 prefilter68810행을 읽었다. `(task,condition,assignmentId,questionId)`200키가 각각 두 행이어서400행의 키가 모호하다. 익명 person key4개, Beer의 Human/Conf./Conf.+Double/Conf.+Adaptive(Expert) 각각50키다.200키 모두 time이 다르고57키는 choice도 다르다. 이는 완전히 같은 행의 기계적 복사로 판정할 수 없다. 같은 사람이 재수행했는지 익명 ID가 충돌했는지는 미확인이다.

주 파일은 저자가 배포한 필터 후 **기록**을 그대로 집계하고, 감도 파일은 모호한400행을 모두 제외한65640행을 별도 집계한다. 첫 행 또는 마지막 행만 임의 채택하지 않는다. Amazon/LSAT 위 대비는 해당 중복의 영향을 받지 않는다. Beer raw person key92개인 Conf.에4650행(93×50)이 있어 person key수×50과 일치하지 않는다. 논문의 조건별N 문장과 파일의 일부N 차이도 공개 모집·제외표로만 해결할 수 있다. 결과가 연구의 원래 배정 전체를 복원했다는 주장을 보류한다. 구체적 조건별 pre/filter 수와 제외 행 수는 `bansal-audit.json`에 있다.

## 수치가 있어도 원개수로 바꿀 수 없는 경우

**D02**의 Table2는 SXAI/CFF에서 틀린 AI의 전체 선택 overreliance0.30/0.26, carb-source overreliance0.64/0.48를 제시한다. 이것은 단순 원비율이 아니라 사람 랜덤효과를 보정한 marginal means다. 본문의χ²검정N663을 두 조건에 임의 분배하거나 이 평균에 곱해 정수 수락 건수를 만들지 않았다. 최종 correct, AI-following, other-human-error를 나눈 설계는 유용하지만 조건별 분자·분모는 미확인이다. 모집260, 분석199, 개인별 두 블록이라는 사실만으로 여섯 주조건의 실제 분석 분모를 알 수 없다(탐색조건 블록이 섞임).

**D03**은 공개 원행이 풍부해도 원 목표의 이산 종점이 없다. exp1의1250×12, exp3의999×12를 검산했고 원행의`q_id=11` 모두 actual_price=−1이다. R코드는 이 값을 그림에서NA로 치환한다. 가상의12번 아파트에 객관적 거래가격이 있는 것처럼 해석하거나 모델과 가격이 정확히 같으면 수락, 임의 범위 이내면 정답이라고 새 기준을 붙이지 않았다. 일반10문항에는 실제 거래가격이 있지만 원래 continuous loss를 binary correctness로 바꾸면 사전 규칙을 위반한다.

**D05**는 사전 답과 사후 답을 구분하는 방법상의 직접 반례다. 원래 자기 답=AI답이면 final agreement가 자동으로 기록되므로 agreement 자체는 권고를 보고 마음을 바꿨다는 뜻이 아니다. 저자는 initial disagreement에서의 switch를 별도 측정한다. 그러나 공개 그림은 confidence bin별 switch와 평균 정확도여서 정오별 A/D를 복원할 수 없다. 새 설명9인과 기존 대조집단 비교, 사람별confidence층화 표집이 추가 한계다.

## 반례·정오표·대안에서 얻는 제품 문장

### 바로 쓸 수 있는 문장

“설명 제공은 맞는 권고와 틀린 권고를 모두 더 많이 따르게 할 수 있다. 전체 완료·정확도와 오류 선별을 따로 측정해야 한다.” D04의 원행이 이 문장을 뒷받침한다. “오권고 거절 후에도 다른 오답을 선택할 수 있으므로 거절과 최종 성공을 분리한다.” D01 LSAT와 D02의 outcome 정의가 이 문장을 뒷받침한다. 둘 다 소프트웨어 효과 크기 예측이 아닌 측정 설계의 근거다.

### 두 대안과 네 관점

1. **설명을 항상 같이 제공하는 화면**: 추천받는 사람에게 입력 근거와 반대 근거를 즉시 대조할 기회를 준다. 근거 작성자는 그럴듯한 잘못된 이유도 만들 수 있으므로 추천의 참·거짓과 이유의 참·거짓을 별도 채점해야 한다. 채점자는 버전·요구조건·단일/복수 허용 후보를 먼저 고정해야 한다. 화면 설계자는 클릭 수나 평균 만족도를 오류 선별의 대체지표로 삼지 않는다. D04 random heatmap의 수락 증가와 D01 잘못된 LSAT 선택지에 붙인 expert reason이 중단 조건을 제공한다.
2. **먼저 자기 판단 또는 별도 검증을 요구하는 화면**: D02 Update/OnDemand/Wait는 사고 유도를 통해 오권고 상황 성과를 개선하는 대안을 제시하지만 클릭·시간·자기응답을 함께 바꾸므로 “설명만의 효과”로 부를 수 없다. 추천받는 사람의 추가 작업, 작성자의 검증 가능한 원문 근거, 채점자의 사전 정답, 설계자의 타이밍을 별도 기록해야 한다. 단순히 강제30초 대기를 제품에 옮기는 것은 아직 보류한다. 실제 원문 링크 클릭 배정과 동등한 증거도 아니다.

“설명은 패키지 선택에서 오류를 줄인다”와 효과 크기 이동은 보류한다. 이를 바꾸려면 같은 candidate/version/rank/recommendation을 고정한 배정, 설치·보안·라이선스·기능 요구의 검증 가능한 정답, 사람×항목×조건×기간×사전/최종 응답의 공유키가 필요하다. 결과가 좋아 보이는 문서 분류의 원시 정확도를 패키지 선택에 합산하지 않는다.

### 자기 결론을 뒤집는 자료

- 보편적 “설명은 오권고를 더 따르게 한다”는 주장은 D01 Amazon Single에서 반박된다. 반대로 보편적 “설명은 오류를 걸러낸다”는 주장은 D04 heatmap과 D01 LSAT Single에서 반박된다.
- D04 저자 정정 공지는 코드 오류 후 영향 실험을 다시 했다고 명시한다. 현재v4와 fixed repo를 읽었지만 어느 원행이 어떤 재실시 코호트인지 연결표가 없다. 정정 전 숫자를 현재 분석과 섞지 않았다. 별도 demo는 계속 수정되므로 원 실험 자극의 고정판으로 쓰지 않는다.
- D02는 오류 선별 개선의 가능한 설계 대안이나 explanation-only 질문을 직접 답하지 않는다. D03는 같은 예측/다른 설명 예시가 명확하지만 성공·수락의 이산 기준이 없다. 이 둘을 “데이터가 없어서 효과 없음”으로 바꾸지 않는다.

## 재현·확인 범위

`reproduce_diagnostics.py --download`는3개 고정판 공개 입력만 읽어SHA256을 확인하고78개 outcome·52개 contrast 기록, 두 audit, 실행 receipt를 만든다. author 실험 앱을 실행하거나 새 참가자를 모집하지 않는다. 실제 로컬 실행은 `execution.json`에 저장됐으며 exit0이었다. R 분석·혼합효과 모델 재실행은 미실시이고 본문의 저자 추론을 새로 검증했다고 주장하지 않는다. 재현 명령·입력·산식·불가능한 칸은 `reproduce.md`에 별도로 정리한다.

이 stream에서 직접 읽은 외부 고유 저작은 **10**: 독립 사람 연구6(D01–D05, D07), 별도 author data/analysis package3, 별도 preregistration1이다. 논문부록·저자 미러·정정 공지·한 패키지의 CSV/R/README를 별도 저작으로 더하지 않는다. 원래 목표군 중 독립 반대/다른 분야 연구4개 이상은 충족하지만 이 stream만으로 전체20·8자리·패키지4를 충족했다고 하지 않는다. 원본 파일과 개인 행은 ignored `_cache`에만 있으며 커밋 대상에는 링크·스키마·합계·재현 코드만 둔다.
