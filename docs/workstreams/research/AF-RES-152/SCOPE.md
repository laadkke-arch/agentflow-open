## 모집과 시간

- 연속 창은 `[2025-06-01, 2026-04-01)` UTC다. 학습은 `[2025-06-01, 2025-10-01)`, 유보는 `[2025-10-01, 2026-04-01)`다. 시간 간격은 1시간이다. 원전의 날짜만 알려진 정규 발행은 하루 구간과 그 끝을 남긴다. 구간 끝의 재생 지연을 분리하고 최초 웹 가용 시간은 미확인으로 남긴다. 처음 관측 가능 시각은 채널마다 별도다.
- 모집 단위는 curl 전체 공식 정식판, Mozilla Firefox 데스크톱 Release 채널의 각 `.0` 정식판, Cloudflare Workers 제품 변경 기록의 각 달 첫 항목이다. 같은 날짜에 복수 항목이면 원문 주소를 오름차순으로 택한다. Firefox와 Cloudflare의 발행·문서는 Git 코드 저장소 바깥 공개 기록도 직접 읽는다. 배포 문서·원문의 독립성을 원장에 둔다. 빠르게 반복되는 Cloudflare의 월별 한 건은 층을 고정한 표본이다.
- 안정 대조는 시작 직전 curl 정식판 4개와 Firefox `.0` 4개의 이미 출시된 고정판이다. 이유는 그 고정판의 발행 기록을 가리킨다는 제한된 명제다. 시작 전 판 기록과 종료 이후 공식 보존본을 각각 본다. 중간 무장애 연속 측정과 모든 본문 표현의 불변은 미확인이다.
- 기존 자료의 운영 상태는 Pocket 저장과 내보내기, Firefox 115 ESR의 OS 지원, Cloudflare 프록시와 1.1.1.1 DNS를 시작 시점의 지정 후보로 삼는다. 위 대상의 공식 기록에서 종료·연장·가용성 손실·회복의 구간을 판독한다. 특정 범위의 관측에만 상태를 붙인다. 이와 별개로 연합 목록의 뒤늦은 편입과 목록 비노출/원문 보존 사례를 직접 연다. 학술 출판과 다른 분야의 시각 있는 정정 각각 2건 이상을 문맥 대조에 둔다.
- 사건 단위는 발행 하나 또는 기존 근거를 바꾸는 전이 하나다. 같은 사건을 설명하는 정정문·상태 업데이트·복제 원문을 사건 수에 더하지 않는다. 장애 시작·회복은 같은 장애군의 서로 다른 전이로도 기록하되, 발행만으로 자연 사건 하한을 넘겼는지 별도로 검사한다.
