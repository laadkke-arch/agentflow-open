## 판정 범위

**PARTIAL — 구조/공급 경계 비교 완료, 정확 대상 저널의 실제 수정 제보·승인 및 실행 검증 미확인.** 모집 주표본 4 styles×3목적=12/12, 두 소비자 하위 판정 24/24. 부모는 실제 href가 동일하므로 1개만 산입. 제품 링크 최소 조합은 사용 목적, 정확 소비자/판, 현재 설치 여부, 저널 label 보존 여부, language 요구를 먼저 구분한다. '어느 CSL 파일을 고치나'에는 body 원문과 고칠 구간, '저널 목록에 넣기'에는 alias/installation link, '오프라인'에는 local resolution chain과 필요한 실제 참조 파일·locale 공급 조건, '약어/항목 오류'에는 해당 item/option 안내가 먼저다. 사용자가 보유 여부를 제시하지 않으면 필요조건과 이미 내장되었을 때 0 추가 자산을 함께 보여준다. 
- **A. alias+parent 분리 링크.** 정확 저널 목록과 shared update를 보존; Zotero bundle 이미 있으면 alias만(또는 이미 설치 0), Pandoc offline은 alias+local parent 최대 2 style files. 비용: parent resolution, cache/version, sibling 영향 확인. 반증: current R02가 기대 parent와 다름 또는 같은 basename 다른 parent, 없으면 정확 parent 다시 탐색.
- **B. 독립 copy 링크.** 목적이 저널별 포맷 수정 또는 locale/local offline portability이고 label/공유 update가 필요 없으면 A03/A04 full copy 1 style file(참조/engine 별도). 새 ID/title/self 및 검증, 유지보수 필요; upstream 변경 누락 가능. D04와 같은 모든 sibling의 공동 오류를 실제로 고치는 목적이라면 공유 PR/업데이트 경로가 더 적절할 수 있다. 
- **C. 내장 locale 우선, 필요한 override만.** stock Zotero source bundle 및 비교 citeproc embedded locales인 경우 일반 영어/불어로 추가 locale 파일 다운로드 0(조건부, installed 확인 필요). Zotero fixed default locale와 Pandoc explicit lang의 차이; fr APA plural override가 locale file 링크만으로 해결되지 않는 반례. 정확 locale bytes 보장이 목적이면 build lineage 또는 style-local override 확인이 추가 비용. 
- **D. data-first 분기.** R04, R06처럼 item type, DOI/URL, volume/page, abbreviation field/option이 결손인 경우 style edit보다 원래 데이터 수정 경로를 반환. 약어 동일 문자열은 identity 아님(X18); 데이터 충분한데 공식 스타일 규칙과 다르면 parent macro/정확 source로 전환.
- **E. WordPress식 child override**는 실제 child body가 허용되는 다른 시스템에서만 추천. CSL 별칭의 child body override 제안은 스키마상 거부한다.

최소 기록 제안(제품 설계 확정 아님): asset_role={listing-alias,independent-body,locale,reference-data,consumer-rule}; id/href + exact source/version/blob; edge={independent-parent,template-nonruntime,locale-supply,override,consumer-resolution}; purpose, requested locale, source provenance vs installed observation, present/missing/unknown, required/conditional/not-needed, sibling scope, failure counterexample, evidence section. 선택 순서는 role→purpose→resolve→current inventory→minimal links→uncertainty. 저널 편집자는 승인/공유 영향, 스타일 저자는 editable body/unique id, 런타임 배포자는 installed sources and versions, 오프라인 저자는 local files+refs+no fetch, 테마 저자는 child override/specificity가 중요하다. 비용은 파일 개수/유지 책임/추가 확인 단계로만 비교했으며 시간·바이트·성능을 실측하지 않았다. 202에서 확인한 파일 존재와 load 구분을 text XML domain에서도 유지했다.

### 추가 분석 — 검증을 바꿀 조건

24 판정의 기대값은 문서/고정 코드/정적 XML로 설명했으며 렌더러 실행 금지 조건을 지켰다. Codex는 별도 권한으로 exact sources/installed package hash, fresh offline profile 및 판 고정 engine, fixed test CSL JSON과 명시 lang을 비교할 수 있다. 성공 조건은 출력 문자열뿐 아니라 실제 선택한 파일/locale provenance 및 remote request 0이다. 상세 입력·절차는 마지막 HANDOFF. 정적 증거와 실제 실행을 분리하지 않은 평가를 거부한다.
