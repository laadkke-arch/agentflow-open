## 신호

| 안 | 이전 공개판 → 현재 공개판에서 쓸 신호 |
| --- | --- |
| A | 모든 공개 안정판. 첫 판은 초기 검증이다. |
| B | 추천 논리 경로 또는 지정 제목·앵커의 정적 해소 상태 변화. 판·커밋만 다른 permalink는 경로 변경에서 제외한다. |
| C | 고정한 기능 절의 정규화 SHA-256 변화. 두 판의 원문 파일과 추출 절 각각의 원바이트 SHA-256도 보존한다. |
| D | C 또는 공개 등록·연산 구현·직접 위임의 원바이트 구성 지문 변화. 직접 위임 패키지의 당시에 선택 가능한 판의 관련 출처를 포함한다. 전이 위임 전체와 실행값은 경보에 넣지 않는다. |

B–D에서 추천 경로 이동이나 절 누락·정적 링크 미해소·필요 파일 누락은 `forced`다. 가능한 대체 경로는 차이를 함께 남긴다. 정적 해소가 가능한 고정판을 주 분석으로 쓰고, 현재 제품 웹 응답은 별도 비교한다. 역사 서버 응답의 증거가 없으면 현재 HTTP 상태와 당시 고정 파일을 구별한다. `openlayers`의 주 절은 `src/ol/interaction/Translate.js`의 `Options` JSDoc typedef다. README와 예제 HTML은 별도 취득·대조다. D는 배포 Translate 모듈의 구현 부분과 등록 export, 해당 모듈의 직접 호출을 공급하는 로컬 모듈을 사용한다. OpenLayers 소스 계약의 단위는 두 가드와 hit 경로다. 지도 화면 전체·렌더러 경로는 확대 해석하지 않는다.

d3-scale의 주 절은 `README.md`에서 `scaleLinear`, linear 호출·clamp·invert와 연속 축척으로 위임한 unknown 설명에 대응하는 절이다. 같은 순서로 정의가 이동하면 텍스트를 다시 판독하고 논리 경로 이동은 별도 비용을 붙인다. D는 배포판의 공개 진입점, linear 등록·구현과 직접 위임 모듈에서 시작하며, 초기 배포처럼 별도 내부 파일이 없으면 실제 제공하는 번들을 해시한다. 직접 호출을 공급하는 외부 패키지의 관련 모듈을 포함하며, 없는 직접 위임은 근거와 구별한다. 공통 코드·형식 변경까지 섞이는 보수적 파일 단위 대리 지표이므로 수치 동작 이외 변경으로 경보가 날 수 있다. 추출 규칙과 패키지별 경로를 실행 전 신호 커밋에 보존한다.

정규화는 UTF-8, CRLF·CR을 LF로, 설명선의 JSDoc 장식과 행 앞뒤의 공백을 제거, 빈 행을 제거, 수평 공백 연속을 한 칸으로 합친다. 독립 버전 배너 줄만 고정 표식으로 바꾼다. 예제·동작 설명에 들어간 버전 번호와 URL은 보존한다. B의 정적 대상 범위는 고정 파일에서 외부 요청 없이 판독할 수 있는 제목/앵커와 명시적 내부 단락이다.

## 입력, 비교 단위와 의존

`replay/inputs.json`의 같은 Node 런타임, 수식과 벡터를 사용한다. 공개 패키지 진입의 UMD/CommonJS는 require, ESM은 공개 import 경로를 사용한다. 로드 결과의 값 종류와 수치가 정확히 같아야 동일하다. 숫자 0, −0, NaN, 양·음의 무한대, null, undefined, 반환 문자열, 예외 종류, 메서드 부재, 로드·설치 실패는 각각 별도 코드다. 예외는 이름과 가능하면 코드로 비교하고 경로가 섞일 수 있는 메시지는 원 로그에 따로 남긴다. 성공적으로 로드한 판에서 메서드가 없는 것은 비교 가능한 출력 상태다. 로드·설치 실패만 비교 미확인이다. 비교는 입력별 및 ‘하나라도 바뀐 인접 공개쌍’으로 하며 판 하나의 입력 여러 개를 독립 공개로 세지 않는다.

기본 실행의 잠금은 판 발행 UTC까지 공개된 안정 의존 중 범위 내 가장 높은 semver를 택하는 결정적 근사다. 현재 packument에는 당시 dist-tag나 철회 상태의 완전한 이력이 없으며 원 사용자의 lockfile은 미확인이다. 공유 직접 의존 범위가 중첩되는 인접쌍의 대조는 늦은 쪽 발행 UTC에서 양쪽 범위에 맞는 가장 높은 동일 버전을 택한다. 공유 의존 하나라도 맞지 않으면 완전 대조는 미확인이다. 직접 집합에 한쪽에만 있는 패키지는 별도 해결하며 작은 하위 그래프 차이도 기록한다. 두 독립 임시 경로에서 같은 lock·무결성으로 설치물을 만들고 동일 답을 재생한다.

## 비용

질의 순서를 사전 고정한다. 구판 고정은 전체 공개 이력 뒤 첫 판 질의 한 번, 최신형은 공개마다 당시 최고 semver판 질의, 두 지원판은 전체 공개 이력 뒤 첫 판과 마지막 판을 번갈아 각각 세 번 질의한다. 지도는 마지막 판이 10.11.0, 축척은 4.0.2다. 마지막 실측판 필드에는 근거가 있을 때만 값을 넣는다. 일괄과 요청 시 재확인의 공개 경보 입력은 같은 저장 순서와 같은 판별 신호를 사용한다. 요청 시에는 최근 확인부터 목표까지의 경보를 확인하고 목표판만 검증하며 미실행 사이판과 그 출력은 별도로 표시한다. 동일 판의 캐시 적중과 새 판에 이전 답을 이어 쓰는 경우는 각각 센다.

원문 취득 바이트는 자료의 취득한 바이트, 해시 비용은 비교 규칙이 읽은 파일·바이트, 검증 비용은 입력 묶음 실행 또는 지도 소스 근거 재판독과 읽어야 할 기능 절이다. 한 판에서 절 한 묶음을 읽고 사용한다. 취득 시도, 성공, 초도 비용과 재사용을 남긴다. 인프라 비용·사용자의 시간은 실측이 있을 때 별도로 적는다.
