## 적용 대안/철회 및 원자료 분모
- 원 파일 링크+복사 가능한 SVG/원문 위치(디자이너): 수정 가능한 형상 우선. 활성 defs, 외부 CSS/폰트 또는 raster 등이 발견되면 standalone 최소성 철회.
- host + 동일 출처 sprite + ID(개발자): 반복 슬롯/테마 가능. missing ID, base/permission 변경, 별도 stylesheet 등 있으면 보완. 사용량·전송 최적화 위해 subset sprite를 만들 수 있으나 공식 자산과 구분해 manifest, hash, ID mapping 제공; 실제 성능은 시험 필요.
- host + individual img: 문맥 색 상속이 불필요할 때. host color 기반 동적 theming이 요구되면 A/B 또는 별도 변형을 제안, 동일 출력이라고 부르지 않음.
발행자(생성 규칙/고정 배포), 페이지 작성자(base·ID·색), 디자인 시스템 관리자(버전/집합·subset), 편집/오프라인 소비자(원문과 재현 폐쇄) 요구를 별도 판단. 원장 55행, 산입 33 고유 work_id: 발행 12≥6, 규격 5≥5, 시험 9≥6, 결함·사례 5≥3, Geo 2≥2. 비산입 22(접근 실패 3, 보조/중복/불충분 19); spec 여러 anchor는 같은 work. 시험 ref는 입력의 보조. 조회 전체 tool 호출 횟수와 원자료 수를 동일시하지 않음(원장 접근 행 55, 그룹/재조회 호출 별도 정확 총수 미확인). 모든 관측은 소스 관측이며 제품 실행 0. 자체 상태 PARTIAL: 공식 OGC 예제 바이너리/ZIP·npm 실물 대응 및 지정 여섯 슬롯 표시·요청 영수증 미확인. 본문 정적 결과·분모 유지.
