# 기억 검색 확장 후보

2026-11-15에 https://github.com/basicmachines-co/basic-memory 의 README를 확인했다. 당시 파일 blob SHA는 e4966701aa7aeac2e79d12d54e8b2870cb678f0e이다.

Basic Memory는 Markdown 양방향 동기화, 관찰·wikilink 관계, 의미 검색과 MCP를 제공한다고 설명한다. 이 기능은 원문의 '기록이 쌓이면 다음 프로젝트에서 활용'이라는 목적과 관련 있다. 현재 SpaceDock recall과 workbench의 문자열 검색을 더 큰 자료 집합으로 확장할 때 비교할 후보다.

이번에는 설치하지 않았다. README는 Python 3.12 이상과 0.23 계열의 FastMCP 사전 릴리스 의존성을 안내하고, 라이선스는 AGPL v3로 표시한다. 별도 의미 검색 설정·모델·자료 인덱스를 검증하지 않은 상태에서 기존 기억을 자동 이관하지 않는다. 클라우드 유료 상품도 등록하지 않았다.

자료 규모가 늘어 검색 실패 사례가 생기면 동일한 질문·같은 기록으로 기본 recall과 비교한다. README의 'never forgets' 표현을 검증된 보장으로 사용하지 않는다.
