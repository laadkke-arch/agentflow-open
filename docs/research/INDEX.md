## 앞으로 연구 묶음을 추가할 때

담당자의 허용 작업 경로 안에 본문과 필요한 증거를 저장하고, 이 색인의 변경 제안을 인계한다. 편집 담당 한 명이 현재 색인을 갱신한다. 원본을 색인에 복제하지 않는다. 기록할 항목은 **고유 ID / 답하는 질문 / 현재 상태 / 파일 / 핵심 의존·충돌**이다.

새 제품 연구 묶음: **아직 없음**. 만들어지기 전 예시 파일이나 빈 결과를 완료 자료로 등록하지 않는다.
