## 진행·완료 판정
- 상태 표는 GitHub 변경에 자동 동기화되지 않는다. 최신 판단은 실제 이슈·브랜치·PR을 다시 조회한다.
- 완료는 채팅의 텍스트 보고가 아니라 작업 파일+커밋+근거+검증 결과+다음 HANDOFF로 판단한다.
- A의 후보 종류가 B 스키마에서 표현되는지, C의 비교 UX가 B 근거 필드와 충돌하지 않는지 통합 시 검토한다.
- 서로 다른 대화가 동일 파일을 건드리면 병합 충돌이 나므로 자기 작업 폴더만 편집한다.
- 운영 DB/배포/기존 Studio/`main`은 아직 병렬 작업 범위 밖이다.
